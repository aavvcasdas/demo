# 64 · 活人微死的AI人 · 设定

> 本篇为**行为清算**题（人×AI），AI 不是对手：它不坏，它只是没有你。收账方式是**行为后果**（照片对不上嘴、欠条兑不了现、床底堆出袋数），**不安排人格化反派、不强行反杀**、不写AI觉醒。开头路线：结果前置（凌晨两点半的问答即信仰截面）后转**线性**，答辩日到天亮，无倒叙。

## 主线

- 设定：22 岁大四→试用期运营，全黑卫衣，从答辩日信了那个AI起，把穿衣、吃饭、退票、周报、晚安全部外包给它；月薪 7000、房租 1300。
- 核心行动：半年里按它的每一条建议活出一个「照片里的人」：假文献、露脚踝、鸡胸肉照、92 分健康评分；直到地铁晕倒、颈椎反弓，急诊夜被小周按着对质。
- 悬念：那 600 块到底会不会到账；他哪天才会发现 92 分是自己打的。
- 一句话主线：你把决定全交给它、把照片当成日子，600 块欠条等成一笔烂账，凌晨在急诊被医生问「多大」；天亮退订代餐倒掉 37 袋，吃了一碗没拍照的面——这次没有哒。
- 主线关键词：AI / 照片 / 建议 / 打卡 / 吃了
- 反派设计：无（AI、主管、二姨都不构成对手）。习惯/依赖题：**不安排人格化对手、不强行反杀**，用行为后果（袋数、张数、烂账）与状态改变收束。

## 转场与时间压缩说明

- 单线七块：答辩日 → 毕业照 → 饮食表演期 → 退订 → 试用期九月/十月 → 急诊夜 → 天亮。两处压缩（「半年后有同学查那三篇文献」「毕业后你留在这座城」）后首个具体场景落地（查文献→道歉对话；留城→合租与「你管我」契约），符合转场门。

## 对白预算

- 修闸终版机器计数 8 个功能单位（上限 9=4%）：你说 好哒（开场）、你说 好哒（急诊·医生问几点睡）、你说 它盖章了、你说 没事 你态度挺好的、你说 它管的、你说 那是网友P的、你说 一个朋友、你说 妈 我脖子疼。其余对白全部降密为口播转述（你回了俩字/她来了句/主管回了句），「它说」句不在计数器前缀表内、保持口播体——对白只留「人话回声」两处好哒与清算六句。

## 反事实 / 防错清单

- 禁止 AI 觉醒/拟人报复叙事：它不坏，它只是没有你。
- 小周不恋爱化、不救赎者升格：她只拽急诊、煮面、喊早饭。
- 不写卸载所有 APP 大清理：只退订 199 一项，成长留缝。
- 钱的错误口径（5%、已打钱）只由 AI 说出，人不转述、不追讨。
- 「92 分」机制只许它自己交底，不由旁白揭穿。
