# 设定：干什么都反骨的嘉豪

## 基本信息
- 题材方向：人生副本实录 · 清算志（讨嫌人设的社死 · 喜剧向）
- 对标拆文：`拆文库/30_喜欢小众的小众哥`（稳态曲线 / 双账本「其实」开关 / 半秒自觉收束）+ `13 死装姐`（案例陈列 + 单点击穿）+ `29 愤怒的普通人`（自产自销的战争 / 无加害者）
- 目标情绪：笑（案例连击）→ 击穿（认知反转：他不是自由的，他是被遥控的）→ 半秒自觉的自嘲
- 正文字数目标：2200–2600 字
- 视角：第二人称「你」= 嘉豪（讨嫌/可爱兼具的清算对象）
- 反骨素材来源：网络「反骨时刻」合集（明知有雨绝不带伞 / 面对「请勿」内心 os「哦？」/ 妈说做淑女「谁爱做谁做」/ 老师劝文科偏读理科）+ 2026 热梗（我要验牌 / 你已急哭 / 丝瓜汤文学 / 允许一切发生 / 人生是旷野不是轨道 / 我去不早说）

## 故事核（一句话）
> 一个从秋裤开始就「你越让我我越不」的男生嘉豪，把反骨当成自由的证明；直到大学室友把「反着说」用成了遥控器，一年里让他心甘情愿地打扫了 217 次卫生——当他在群聊里看到《嘉豪遥控器使用手册》，才发现一身反骨的人是全世界最听话的人，只要你把话反着说。

## 志与曲线
- 志：清算志（你以为的你 vs 别人眼中的你）
- 曲线：装逼稳态（+2 平台连击）→ 82% 单次陷落 -4（手册揭晓）→ 半秒自觉回到 -1/0（他想「顺一次」来反这个反，然后卡住）
- 收束：灰带笑，无教训

## 六段与占比
1. 开题 + 基线（10%）：三岁秋裤事件——反骨的第一次成功，定价
2. 编年案例陈列（30%）：小学「请勿踩踏草坪」/ 初中「别走神」/ 高中分科所有人劝文他偏理（数理化 38 分）/ 明知下雨绝不带伞（与天气对赌）/ 妈的丝瓜汤 vs 他的冰美式 / 「人生是旷野不是轨道」贴床头
3. 大学升级（18%）：辅导员「别翘课」→ 翘；室友「你肯定考不上驾照」→ 一次过；室友「你别去表白」→ 去了被拒；他把每次「反」都记成战绩
4. 遥控期（15%）：室友学会了；「嘉豪你千万别扫地」「你可别把外卖垃圾带下去」「这道题你肯定不会给我讲」——你一年没输过一次
5. 揭晓（15%）：室友手机忘锁屏，群名「404 遥控中心」，置顶文件《嘉豪遥控器使用手册 v3》：正话反说 / 反话正说 / 双重否定慎用 / 成功 217 次 / 失败 0 次 / 备注：夸他会失效
6. 半秒自觉与收束（12%）：你想反击——顺一次；室友说「那你随便」你卡住；你去阳台抽了半根烟，回来把地扫了；判词

## 数字判词链
三岁 -5℃ 穿短裤 → 数理化 38 分 → 被雨淋 41 次 → 表白被拒 1 次（被「反」出去的）→ 遥控成功 217 次 / 失败 0 次 → 最后一次扫地：第 218 次

## 器物判词
秋裤（第一件被反的东西）→ 扫帚（被遥控的证物）→ 《使用手册 v3》（冷揭晓方）

## 热梗（各一次）
哦？（面对一切「请勿」）/ 丝瓜汤文学 / 人生是旷野不是轨道 / 我要验牌 / 你已急哭 / 允许一切发生 / 我去不早说

## Phase 2 设计校验
- 题材参考：`references/genre-styles/人生副本实录.md`
- 核心招式：清算志 × 稳态陷落曲线；案例陈列 + 单点击穿（对标 30/13）；数字判词链由「使用手册」冷揭晓；半秒自觉两拍收束
- 反派设计：不适用（室友是「顺手利用规律」的普通人，无恶意；张力来自主角人设的自我拆穿）
- 反转类型：认知反转（自由 → 被遥控）
- 反转位置：第 5 段 / ~82%
- 目标平台：抖音口播（第二人称 · ASR 语感 · 2200–2600 字）
- 审核：无教唆、无群体抹黑、结局承担后果、不写鸡汤总结
