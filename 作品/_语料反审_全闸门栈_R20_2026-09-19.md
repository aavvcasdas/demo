## 2. 修了什么（7 处，全按 0.6 入册三字段 + 一进一出）

1. `fuben_loop.py` 首屏闸 → **报告制**（WARN），词表顺手扩容（上午/下午/岁/x:xx/学生/店/摊/站…）；首屏质量归 fuben-review「首屏显微镜」人审行（v10.5 已有位）。
2. 判决闸 → **拆两半**：硬闸只拦宣判词（报应/活该/罪有应得/你堕落了/这就是命/天道好轮回）；围观/疏远词降报告制交人审。
3. 品牌闸 → **报告制**（R13b 同判补全孤儿），红线由人审裁决（64 豆包该删 / 15 iPhone 删了就死）。
4. 内心闸 → 「你以为」移出计数（错位引入钩是语料常式）；「你觉得/你感到」惰性直报照拦。
5. 时戳闸 → 整行计数降报告制；**保留硬闸三件**：前5行独立钟面≤1、第6–16行禁时戳分段、时戳开头行占比≤3.5%（75 病灶 6.6% 仍拦得住，11 先例放行）。
6. lint 环境/身体 → 报告制（对齐 R17b，修孤儿）。
7. lint 术语 → 拆两半：行业词（KPI/绩点/综测/学分…）报告制；运营黑话（赋能/抓手/闭环/复盘/OA）保留硬闸 ≤1。

**一进一出账**：本轮 0 新增禁令、0 删除条款——5 道闸从「误杀大师」修成「测得准」，1 处 lint/draft 降级不同步补全。**A 类保命层（事实锁/玩法唯一/年表禁令/收束落点/指代/时戳占比线）一条未动。**

**修后复判**：44/44 篇原文过正文层全部硬闸（仅 37 模板句 2 连发与 29 预告尾两处真违例，均在教义容忍带、判得对）。回归：`test_gates` **T1–T6 全绿**（新增 T6 语料红绿样：大师写法放行=True，报应/黑话仍拦=True）；T3 全库七闸回归 10/10；78/76/75 复跑七闸全 PASS 不变绿为红。**改闸零破坏。**

## 3. 直出对照实验（裁决用户假设）

同题「把每笔消费的票据都留下来的人」（习惯/代价题，无正主撞题：查 01/06/28 借机制不借事实），三臂同模型：

- **A 臂·裸直出**（一句主题进 prompt）：`作品/_语料反审_R20_直出对照/A_直出版_正文.md`（472 字）
- **B 臂·全流程**（精读Gate→事实锁→爽点表→场面表→成稿→fuben_run 七闸→回填）：`作品/_语料反审_R20_直出对照/B_全流程_正文.md` + `_设定.md`（829 字，设定卡全套）
- C 臂（GPT6 提示词单页直出）= 仓库已存在的中间臂：它把 B 的**交付契约**（事实锁/爽点表/快推位置表/习惯漂移）压进一页 prompt——本实验直接验证「契约在不在正文留下痕迹」的差异，见下。

| 判据（预注册） | A 直出 | B 全流程 | 读数 |
|---|---|---|---|
| 正文层硬闸违例（旧闸/新闸） | 2 项（单行过长 7 处、lint 指代 4 处） | 0 项 | 新闸下差距没变大——**闸拦的不是水平差** |
| 密度带（fuben_density 对账口径） | 12.5/千字 ✓ | 22.9/千字 ✓ | 都在带内，打平 |
| 数字守恒 | **崩**：42,173 张票＝10 年 11.6 张/天（含睡眠），无账可核 | 87/2101/350=100+250 三处咬合，账算得平 | **A 的爽是假账**——正文层闸抓不到（无设定可对），hype/设定层合同抓到 |
| 放大事件 ≥10% 逐拍（3.7） | 倒票段 ~4% | 踩箱重排段 14 行 ≈12%（在场者+时间膨胀「坐到嗓子发干」） | B 胜 |
| 爽点曲线 | 无表；首正向事件在 30%+，峰值缺位，谷底被一句顿悟替代 | 首爽 19%、双 +6 峰 @41–51%、谷底 -7 @83%，锚点全部机核命中 | B 胜——**且第一版 B 的位置声明也被闸打了**（「声明73% 实际63%」），回填后才绿：闸抓的正是我自己的虚报 |
| 一遍听懂三问 | ①无回听点（段落体不硌耳）②「钱花出去不算数→票据进盒才算数」因果靠旁白补 ③「盒子装不下所有的暖」不像人话像签名档 | ①「先写再进盒」一处轻微 ②触发齐 ③「记到明面上」1 | A 1 处宣判句踩 3.5（结尾作者宣判 = Phase4 人审行 FAIL）；B 收在器物+数字 |
| 字数（成片 3 分钟带） | 472 字＝1:14，**装不下十五年** | 829 字＝2:10 ✓ | A 短是因为直出没有「跨度写法」装备 |

**裁决**：
1. **用户假设的前半句成立**：规则确实压制过水平——5 道闸把 66%–23% 的课文判死，模型被训得绕开课文的写法（围观句、品牌主体、一日编年）；这轮已修。
2. **后半句不成立**：直出不如全流程，但原因**不是「词表规则多」，是「交付契约在」**——A 臂死在没有事实锁（42173 假账）、没有爽点回填（位置全靠感觉）、没有放大事件装备（跨度写不出来就抒情）；这三样都不是「规则」，是**账**。B 臂的价值由闸**抓出我自己的位置虚报**反证：闸不美化，只对账。
3. **正确的人机分工**（R20 定版）：机械闸只留可判定真假处（守恒/位置/年表/时戳占比/指代——本轮验证 8 道语料零违例）；**文风一律走「课文精读 + 人审清单」**；直出的对法不是拆契约，是把契约压进一页 prompt（GPT6 文件）+ 正文层用本轮修好的轻闸。
