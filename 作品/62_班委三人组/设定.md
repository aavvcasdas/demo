# 设定：你们班有一个官威很大的班委三人组（搞笑版 v3）

- 题材方向：人生副本实录 · 迷因荒诞志 · **搞笑风节奏板（14.4）**
- 对标拆文：`32 水牛室友`（无辜自证 / 第三方误会 / 递归正义）、`39 蛀虫`（制度空白套娃）、`29 愤怒的普通人`（叙述者零评价让逻辑自爆）
- 节奏：每 40–60 字一个包袱；三连升级；反转即制度反锁三人组；≤3 行收尾；1,800–2,400 字
- 搜索素材：班干部动机=综测+3 / 学生会点名耍官威上热搜 / 小组作业社会惰化：划水、不当组长却指挥组长、组长背锅
- 梗（叙述者用，各一次）：小小年纪一身班味 / 已读乱回 / 活人微死 / 预制请假 / 那咋了 / 偷感很重 / 我要验牌
- 故事核：三个为综测 3 分上台的人把 47 人的班管成一个部委（15 秒签到、三级审批、41 条条例、早八齐喊「收到」被保安当传销），随机数把三人分进同一小组，三人互相考勤互相驳回，作业 0 分，按自己的条例自扣综测，第 41 条「最终解释权归班委会」——他们决定本次不解释；改选全票连任，因为弃权计旷课。
- 收束：你回了「收到」。
