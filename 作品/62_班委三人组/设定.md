# 设定：你们班有一个官威很大的班委三人组

## 基本信息
- 题材方向：人生副本实录 · 迷因荒诞志（喜剧支线，走 14.3 门槛）
- 对标拆文：`32 水牛室友`（受害者观察席「你」/ 加害者无辜自证 / 第三方误会「阳台养牛」/ 解决方案更荒诞 / 递归正义收束）、`39 蛀虫`（制度空白→自洽荒诞→套娃升级）、`29 愤怒的普通人`（叙述者零评价，让逻辑自洽运行到自爆）
- 搜索素材：班干部真实动机是综测加分（+3）/ 学生会点名爆粗口耍官威上热搜 / 班干叫集合没人来 / 小组作业「社会惰化」：划水者、不当组长却指挥组长、组长背老师全部怒火
- 笑点纪律：0 热梗；台词只许「无辜自证」或「制度原话」；三人组理直气壮到结尾；审判交给结构

## 故事核
> 你们班 47 个人，被班长、考勤副班长、纪律委员三个人管出了一个部委的气势：15 秒签到码、请假三级审批、「收到」计入综测、班群置顶《班级管理条例（试行）》共 41 条。直到大三小组作业，老师用随机数分组，把三个人分进了同一组——三个人在自己的组里互相考勤、互相审批、互相记旷课，一份作业没交，全组三个人的综测被自己的条例扣光；而条例第 41 条写着「本条例最终解释权归班委会」——班委会就是他们仨。

## 曲线（荒诞脉冲）

3. 外部误会（18%）：每天早上 8 点全班在教室齐声喊「收到」（条例第 12 条：签到需口头确认）/ 保安大爷举报三楼有传销 / 保卫处来人 / 班长掏出条例 / 保卫处走了留下一句「以后喊小点声」
4. 小组作业（18%）：老师随机数分组 / 第 9 组：班长 副班长 纪律委员 三个人 / 第一天三个人各建了一个群 / 每个群都要求另外两个人「收到请回复」
