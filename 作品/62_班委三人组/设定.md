# 设定：你们班的班委三人组（搞笑版 v4 · 真实梗库版）

- 题材：人生副本实录 · 迷因荒诞志 · 搞笑节奏板（14.4）；「你」= 受害者观察席（对标 32 水牛室友 / 29 愤怒的普通人：叙述者零评价，让三人组的逻辑自洽运行到自爆）
- 合理性原则（v3 被否的教训）：不编 41 条条例、不靠随机数巧合。所有事件必须是**每个大学生都经历过**的班委行为；反转用最常见的机制——老师汇报时随机抽人讲

## 大学班委梗库（搜索 + 常识，全篇按出场顺序用）
竞选：「为同学服务」/ 综测加 3 分 / 竞选稿打印装订
通知：收到请回复 / @全体成员 / 【重要】【紧急】🔴 / 请知悉 请周知 特此通知 / 务必 严禁 不接受任何理由 / 通知在群里自己看 vs 群 999+ / 私聊催「看到回一下」/ 凌晨 1 点发表格今晚 12 点前交
考勤：学习通 15 秒 / 位置签到 / 拍照留痕（拍到正脸）/ 后排记名 / 私发辅导员
讲座：「自愿报名 每班至少 20 人」/ 凑人数 / 拍照走人 / 志愿时长 / 转发朋友圈截图
班长官腔：「同学们」「我们班」/ 说话跟辅导员一个调 / 中秋不发月饼不是好班长 / 全班等你一个人（他自己迟到）
副班长：点名居多 / Excel 标黄标红 / 「待处理」相册
纪律委员：后排拍照 / 上课看手机记名 / 小蜜蜂
小组作业：班长自动当组长 / 「我来统筹」/ 分工表全是别人 / 「我负责查资料」/ 「PPT 我不太会做」/ 「大家进度怎么样」已读不回 / 提建议活儿就是你的 / 最后一夜赶工 / 汇报他讲 封面他第一 / 分数一样
小群：全班群 47 人 vs 没有班委的小群 44 人
## 故事核
大一：三人组用通知、签到、讲座凑人数把班管成部门；大二小组作业你被分到三人组那一组（班长当组长，副班长管考勤，纪律委员管监督，活只有你和另一个女生干）；汇报那天老师说「随机抽一个人讲」，抽到班长，他讲了封面和目录，老师又抽，抽到副班长，他说「我负责考勤」——老师给了组内分开打分：你 92，他们仨 61；期末三人连任，因为没人上台；你在小群里看见 44 个人的笑，回全班群一个「收到」。
