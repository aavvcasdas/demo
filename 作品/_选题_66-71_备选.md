# 66–71 选题备选（2026-09-14 · 依新入库拆书 + 人生副本实录 §四/§15）

## 新入库 9 篇的可迁移点（它们本身不是人生副本体，只取机制）

| 入库篇 | 体裁 | 可迁移到人生副本的机制 |
|---|---|---|
| 隐娘 | 盐选死人文学 | **「最爱」与「最认不出来」是同一个人**——深情是真的、给错人也是真的 → 第二人称「你」是那个给错的人 |
| 乱葬岗里的姑娘 | 盐选民俗报应 | **「配不上」这三个字压死人之后，账以什么形式还**；讨回名分不靠说话，靠仪式（把棺材抬进祖坟） |
| 掌控 | 盐选反拐悬疑 | **人被拆成零件**（心脏/眼角膜/替代品）；亲情被拆成「利用」和「替代」 |
| 泠泠千古调 | 盐选宫斗 | **花十年扮演一个身份**，只为一次清算；表演即武器 |
| 偏偏喜欢你 | 盐选甜宠 | 三次不信对方，因为**从没把自己放在「值得被偏爱」的位置** |
| 洗白后她们黑化 / 朕要杀疯了 | 番茄长篇 | 「必死 flag 清单」量化；**反派话术失效本身就是爽点**（不靠更强，靠不吃这套） |

人生副本的壳不变（第二人称 / 编年 / 器物判词 / 六段），下面每个选题都指定：模板篇（拆文库旧号）+ 迁移机制（新入库）+ 搜索原型方向。

## 66 · 寝室里那个「什么都不争」的女生
- **主题**：看起来最没存在感、从不参与任何争执的舍友，四年后是唯一拿到保研/好 offer 的人；「你」是那个一直替她出头、以为她需要保护的人
- **志/曲线**：清算志（受害者以为自己是保护者）· 平台+断崖（37 型）
- **模板**：37 骨架 + **隐娘**机制（你对她最好，也是最认不出她的人）
- **双坐标**：她每次「算了 我不要」都发生在你在场时；她的推让替她省下了所有站队成本
- **戳穿机关**：保研名单公示，导师推荐信落款日期是大二——她「什么都不争」的那两年一直在争唯一重要的那件事
- **收束**：毕业聚餐她第一次主动敬酒，敬的是你；你到现在也没想明白那杯酒是谢还是别的
- **搜索**：知乎「宿舍里最不起眼的人最后混得最好」「闷声保研」

## 67 · 把「配不上」说出口的那个人
- **主题**：大学恋爱，「你」家境好一点，分手时说了一句「我们不合适」，实际意思是配不上；六年后同学会
- **志/曲线**：代价志 · 编年缓降 → 一次对账（28b 型）
- **模板**：28b（一秒钟的判词）+ **乱葬岗**机制（「配不上」压死人之后账怎么还——这里不是鬼，是她把你那句话原样活成了简历）
- **放大事件**：分手那天你说的三句话，逐字写；后面每一段编年都有一句被她兑现
- **戳穿机关**：同学会上她的工牌 / 她给服务员的小费 / 她没认出你
- **收束**：她加你微信备注是你的全名，你的备注还是六年前那个
- **搜索**：「前任分手时说的话后来全应验了」「门当户对 大学恋爱」

## 68 · 被家里当成「零件」养大的女儿
- **主题**：县城二胎家庭，「你」是姐姐，从小的功能是「给弟弟挣学费的那一个」；大学四年兼职、汇款、被要求毕业回家
- **志/曲线**：实录志 + 代价志 · 剪刀差（01 型：奖赏递减×代价递增）
- **模板**：08/11 的账本双轨（汇款数 × 弟弟的花销数）+ **掌控**机制（人被拆成零件：你在家里的名字是「你姐会给」）
- **数字判词**：四年汇款 63,400 / 弟弟一部手机 6,999 / 你的一双鞋 89
- **戳穿机关**：你妈手机里家庭群的名字是「一家三口」
- **收束**：你把汇款备注从「生活费」改成「借」，转账成功，没有人问
- **搜索**：「扶弟魔」「重男轻女 大学 兼职 汇款」知乎高赞真实经历

## 69 · 花四年扮演「有趣的人」的男生
- **主题**：大学里那个永远在活跃气氛、段子不断、酒桌上第一个站起来的男生，「你」；毕业时没有一个人给你发私信
- **志/曲线**：清算志（表演型人格）· 高开缓降
- **模板**：13（表演选址学：每个段子都有名义功能和实际舞台）+ 30 小众哥（防御的理论化）+ **泠泠**机制（十年扮演一个身份）
- **双坐标**：每个笑话都是给刚进门的人讲的；安静时你会看手机假装有消息
- **戳穿机关**：毕业晚会点名让你上台「说两句」，你说了三个段子，台下笑；下台后没人跟你碰杯
- **收束**：毕业照你在最中间，做鬼脸；洗出来只有你一个人在笑
- **搜索**：「班里的开心果毕业后」「讨好型人格 搞笑担当 孤独」

## 70 · 从来不觉得自己值得被喜欢的女生
- **主题**：有人追「你」，追了一年，你三次把他推开，理由每次都不同，真实理由只有一个
- **志/曲线**：温情志带苦底 · 救赎打折（28b 型：反转有效但情绪清账）
- **模板**：28（长得不好看但很爱你的女朋友，反写为你是被爱的一方）+ **偏偏喜欢你**机制（三次不信，因为从没把自己放在值得的位置）
- **三次推开**：他记得你不吃香菜（你说巧合）/ 他等你到宿舍关门（你说他顺路）/ 他把你的名字写进毕业论文致谢（你说客套）
- **收束**：三年后你在他婚礼上，新娘不吃香菜；你终于承认那三次都不是巧合，但已经不需要承认了
- **搜索**：「配得感」「低自尊 谈恋爱 推开」

## 71 · 对所有话术都不吃这套的普通人
- **主题**：「你」大学毕业进公司，所有 PUA 话术（自己人 / 看表现 / 年轻人别计较 / 你要感恩）对你全部失效——不是你强，是你听不懂潜台词，只会按字面执行
- **志/曲线**：迷因志 · 迷因脉冲（29 型）
- **模板**：29 愤怒的普通人 + 39 蛀虫（制度空白→递归正义）+ **朕要杀疯了**机制（反派话术失效本身就是爽点）
- **爽点三连**：「都是自己人」→ 你问那合同第八条为什么写乙方 /「看表现」→ 你把打卡记录导出来问看哪一项 /「年轻人要感恩」→ 你回复谢谢并抄送 HR
- **收束**：老板最后一句话是「你这人怎么听不懂话」，你说听懂了，然后按字面执行了离职流程
- **搜索**：「职场 PUA 话术 字面理解 反杀」「听不懂潜台词的人」
