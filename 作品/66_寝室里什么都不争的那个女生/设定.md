# 66 · 寝室里什么都不争的那个女生 · 设定 v1

## 志 / 曲线
清算志（「你」= 自以为是保护者的那个人，加害者视角的变体：你的保护是她的掩体）· 平台+断崖（37 型）· 模板 = 拆文库/37 骨架 × 新入库《隐娘》机制（你对她最好、也是最认不出她的人：深情是真的，看错人也是真的）

## 六段（37 型）
| 段 | 占比 | 内容 |
|---|---|---|
| 开篇放大事件 | 12% | 大一空调费吵架 她说「算了 我不用」 你替她拍桌 她在你身后拉了一下你衣角 |
| 「你比她们懂」三连 | 20% | 你替她争选课 / 替她挡学姐推销 / 替她跟辅导员说她家里困难 她每次都在你旁边 不说话 |
| 编年 | 26% | 大一她让出评优 大二她让出班委 大三她让出竞赛队名额给你 你觉得她需要你 |
| 戳穿 | 16% | 保研公示：她第一名 推荐信落款日期是大二三月 导师是你大二嫌课难退掉的那门课的老师 |
| 放逐 | 16% | 寝室没人提这事 / 她照常给你带饭 / 你帮她拎行李她说不用 / 群里她给你的消息回复只剩「好哒」 |
| 认领 | 10% | 毕业聚餐她第一次主动敬酒 敬的是你 你到现在没想明白那杯酒是谢还是别的 |

## 戳穿机关
保研公示名单 + 推荐信落款日期（大二三月）+ 导师姓名 = 三年来所有「算了我不要」都发生在同一个方向之外；你替她争的没有一样是她要的。

## 原型（逐条落地）
1. 「保研结果出来之前，你什么时候听说过她要保研？」一向不引人注意的隔壁寝黑马唐芸，大一就联系学长选高分老师的课（澎湃 6457345）→ 戳穿
2. 室友放烟雾弹「我先过考试明年再考研」，实际一直在准备，还从你这学会了怎么联系导师（同上）→ 编年大二
3. 谁高调宣布要保研谁被整个寝室盯着 熬夜刷书互相监视（同上）→ 你高调，她安静
4. 弱 committee 学院导师权力大，越早联系越早定名额，五一以后好导师没名额（知乎 684674809）→ 落款日期大二三月
5. 「大一就对培养方案了如指掌，提醒同学哪几门课绩点高」（知乎 489805137）→ 她帮你选课，你选了轻松的
6. 室友 B 表面对导师 C 方向不感兴趣，9 月瞒着室友 A 去找 C（知乎 558566779）→ 你以为她对那门课不感兴趣
7. 讨好型「不懂拒绝 主动道歉」的外壳被当成软弱（知乎 20710222）→ 你的误读来源
8. 出结果当天被踢出实验室群「只是择优」（558566779）→ 放逐段的「不用」

## 侧面四通道
- 旁观者身体：她拉衣角 / 按肩 / 站在导师身后半步 / 其他两个舍友对视一眼
- 旁观者的话：隔壁寝「你们寝那个不说话的 我大二就见她去老师办公室」；舍友「你不知道？」
- 环境规格：公示栏第一行 / 落款日期 / 群消息只剩两个字
- 权力者不作为：辅导员看到你在公示栏前 点了点头 没停
主角误读：「你觉得她需要你」「你把她的沉默归给害羞」。内心 ≤6。

## 收束
器物/动作：那杯酒。她敬完坐下 你举着杯 到现在没想明白那杯酒是谢还是别的；末句：你替她把杯子收了。

## 同题检查
拆文库 37 是越界者视角、13 是装努力；本篇换视角：「你」不是恶人，是把保护当成优越的人，被清算的是你的自我认知，不是恶行。
