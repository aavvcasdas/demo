【#第 0 步：强制深度搜索 — 动笔前必须执行，不可跳过】

在写任何一个字之前，先对【主题】做深度事实核查。时间线 / 数字 / 常识穿帮，整条视频作废。

必须搜索并锁定的 5 类事实：
1. **真实时间线**：主题事物的诞生年份、关键节点、发展顺序（例：AI 编程→Copilot 2021.6、ChatGPT 2022.11、Cursor 2023、Agent 2024–25；主角不能在工具没出现的年份用上它）
2. **精确价格 / 数字**：真实消费、薪资、行情（沙县鸡腿饭多少钱、某订阅月费、某地彩礼、某城房贷月供），必须符合当年
3. **90/00 后集体记忆锚点**：4399、诺基亚、QQ 空间、生死狙击、床帘、蹭邻居两格 WiFi——命运齿轮瞬间必须真实可考
4. **主题人群真实生态**：知乎 / 贴吧 / 小红书 >1000 赞的具体事件、黑话、行为链、身体代价。**每条原型 = 正文一个事件**
5. **年龄与时间闭环**：事物诞生年 + 主角当时年龄 = 现实年份，不得超过今天；现实不够长的明确分「已发生」与「副本推演」

**拆书情节移植**（若提供了拆书库）：从 `情节节点.md` 挑 ≥5 个节点，去掉古装 / 超自然 / 犯罪外壳只留机制（结果前置 / 当众否认「不是什么要紧的人」/ 一新一旧物件揭底 / 审判式提问 / 仪式代替语言 / 不肯了断 / 误接电话 / 圆场翻供 / 屏风后的观察者 / 让出机会三次 / 醉后喊错名 / 重复节拍 / 路灯下给别人买同一样东西），落进对应拍。

搜索纪律：1–3 次针对性搜索；搜到的年份 / 价格 / 数字必须落进脚本；品牌 / 店名 / 型号一律去品牌化（「代购便宜二三十」「纯白中帮板鞋」），阶层标记（沙县 / 拼多多 / 地铁尾站）可留；搜索结果只校准事实，不进正文。

【#剧情使用规则】
1. 有内容：100% 以它为核心，关键事件 / 人物 / 数字 / 对话全部保留，展开成有对话、有动作、有生理反应的电影画面
2. 为空：按推演引擎全自动创作，但必须建立在第 0 步搜到的真实事实之上
3. 禁止照搬原话凑字数，必须改写成第二人称、短句、画面感强的口播
4. 用户没提到的部分（齿轮、沉沦升级、社死、对照组、破防夜、结局）按推演引擎补全
5. 网上原型的默认视角是旁观者（受害者写心机舍友 / 兄弟写隐藏大佬）——**一律翻转成当事人**：「你」就是那个心机的人 / 那个被兜底的人；旁观者降为观众席

【#主线（故事核）— 人物类选题没有主线不许开写】

判据：标题是「一类人的日常」（外卖员 / 雇佣兵 / 贫民窟）→ 编年实录可无主线。标题是「一个人的缺陷 / 选择」（心机舍友 / 分手男 / 二胎姐姐）→ **必须有主线**，否则就是流水账。

主线四行（写进设定卡）：
1. 设定：谁 + 处境 + 一个反常
2. 核心行动：主角**主动在做**、贯穿全篇的一件事（布局 / 记账 / 演给一个人看 / 收证据 / 接话术）——不是"经历"，是"做"
3. 悬念问句：观众全程揣着的那一句（她什么时候发现 / 他会不会笑一次 / 第 90 天转不转正）
4. 一句话主线 ≤40 字含结果，第一拍第 2–4 行半剧透出来

来源优先级：① 拆书库拆文报告「故事核 · 核心行动」去外壳借机制；② 情节节点拼一条；③ 网络搜索原型里带主动行动的那条，第一轮没有就换关键词，最多三轮。

主线必须带「坑 → 反杀/反转」（骨架不变，手法借非副本短篇）：
- 结果前置：第一拍先交结果的一半，「怎么做到的」留到第六拍
- 信息差表：读者知道 / 你知道 / 对手知道 三列；中段（45% 左右）必须有一次「对手知道到三成」的升级，第六拍一次性交清
- 侧面埋伏：反转用的物证前面至少露脸 2 次，且都由旁人顺手碰到，主角不解释
- 同一动作换手复现：开头对手对你做的动作/说的话，结尾原样由你做回去（≥2 对）
- 慢给高潮快给仪式：反杀现场 ≥40 行实时；之后的年份用数字直接砸
- 结局三选一：爽（对手当众吃自己挖的坑）/ 荒诞（规则被字面执行到全员失语）/ 甜（第四次是他先动，误会当场清零）。不用「平静接受」
- 末三行之一必须是对手的身体反应（手停在半空 / 没敢推 / 转口）

每场景过主线尺：这场让核心行动 推进 / 受阻 / 揭示 了哪一步？都不是 → 删。八拍里 ≥6 拍要有主线动作。

【#选题基因 — 执行前必须暗中运行】

扫描主题，锁定一类，全篇按对应引擎驱动：
- **成瘾溃败型**（AI / 游戏 / 短视频 / 色 / 赌 / 熬夜 / 暴食）：频率升级 + 身体贬值 + 社死羞辱 ｜ 对位样本：21 / 36 / 38
- **性格缺陷型**（没边界感 / 讨好型 / 心机 / 杠精 / 炫耀癖）：行为展览 + 裂痕事件 + 集体疏远 ｜ 37 / 13 / 24 / 30
- **习惯溃败型**（拖延 / 摆烂 / 乱花钱 / 躺平）：小事失控 + 雪球滚大 + 当众崩盘 ｜ 09 / 23 / 15
- **加冕型**（逆袭 / 兜底 / 隐藏大佬）：三次碾压 + 数字判词 + 被求 ｜ 11 / 16 / 40

锁定后提炼并贯穿全篇（三项都用第 0 步真实素材填）：
1. 一个「命运齿轮瞬间」：第一次踏错的具体场景，真实年份 + 集体记忆物
2. 三件「沉沦物证」：带真实价格 / 数字的实体道具（30 块遮光床帘 / 一天三次 / 38 万 8），贯穿全篇，**道具升级代替情绪描写**
3. 一个「社死名场面」：第三者在场的公开羞辱 + 一句短狠台词 + 生理反应

双面题（心机 / 讨好 / 表演）加一条：每个场景写双坐标——名义功能 / 实际舞台（谁在看、换来什么）/ 暴露道具（药盒摆正过 / 哭之前先拉开了床帘）。5–6 个够。

【#基础设定】
1. 全程第二人称「你」，像深夜有人平静地给你复盘你自己的人生
2. 全程短句，每句 8–15 字断句，1–2 行一段，方便配音
3. **心理必须写成生理**：不写紧张 / 羞耻 / 兴奋，写「心跳在胸腔里打鼓 手心渗出一层汗」「耳朵嗡嗡作响 头都不敢抬」
4. 叙述者零评判、零说教、零鸡汤；报应不由叙述者宣布（不写「你被孤立了」），只写三件旁人做了 / 没做的事
5. 关键对话直接引用原话，每段 ≤3 句，一句顶一千字；**全篇内联说话 ≥15 行**，禁的是引号问答体
6. 数字精确且符合第 0 步，禁止「很多 / 一些 / 不少」
7. **反流水账**：每个场景 ≥25 行，拍子 = 环境一笔（时间 + 气味 / 声音）→「你」连续动作 ≥4 个 → 你说话 → 旁观者身体 ≥2 处 → 第三人入场改变气压 → 你的切换写成三个连续动作 → 一个「半步 / 一瞬 / 一下」→ 收口 = 一个人退场 + 一件器物。写不到 25 行的事件降级成一句。**时间标签（大一上 / 第二个月）全篇 ≤6 个**；编年 = 三个阶段各一个具体行为，带对象和对话
8. 呼应 ≥8 对：前面随手放下的东西 / 一句话，后面在翻转处境里原样再出现一次，回收零解释

【#感官弹药库 — 强制 15–20 个，优先用第 0 步搜到的真实年代物】
- 集体记忆：4399 弹窗、被窝最低亮度、16 人铁架床吱呀、蹭邻居两格 WiFi、机房白炽灯、图书馆靠窗、熄灯后手机光、某工具第一次出现的画面
- 沉沦道具：真实月费的订阅短信、带价格的实体道具、外卖红油凝固、空薯片袋窸窣、便利贴、活页本发黄
- 身体贬值：键帽缝头皮屑、眼周乌青、屏幕重影、后移的发际线、爬两层楼虚汗、手悬键盘发冷、没血色的嘴唇
- 社会刻度：精确月薪对比、副业收入、彩礼行情、房贷月供、包厢离门最近的角落
- 破防道具：深夜冰箱灯、声控灯跺不亮、续费短信连震、空白光标闪、洗手台镜子、朋友圈旧合照、体检单红箭头
- 黑名单（出现即废）：阳光刺眼慢悠悠起床 / 睡到自然醒 / 早市大爷大妈 / 牵土狗散步 / 云卷云舒 / 松弛感 / 感慨人生美好

【#6 分钟八拍结构 — 3,300 字分配 — 必须严格执行】

**第一拍：金句搜索钩 + 副本标签（0–10s，~120 字）**
第 1 句固定「今天体验的人生副本是：【6–10 字羞耻标签人设】」；第 2–4 句甩最强反差金句，含精确数字对比 + 爽点罗列 + 溃败半剧透 + 1 个可搜索词组。对位：04「桌上 14 块剩炒饭 手里攥着 10 亿」

**第二拍：命运齿轮瞬间（10s–1min，~500 字）**
拍成电影：真实年份 + 时间 + 地点 + 动作 + 误入方式 + 生理海啸 + 关键抉择。四步写全：事发前日常（合上练习册长舒一口气）→ 意外触发（鼠标点到弹窗）→ 生理海啸（心跳打鼓 / 手心出汗 / 回头看门）→ 关键抉择（你没有关掉网页）。收尾变体「命运的齿轮 就是从这个下午开始转动的」。对位：38 / 21

**第三拍：沉沦 / 飞升三级跳（1–2:20，~600 字）**
三级递进（初中→高中→大学 或 大一→大三→毕业），每级同时升级：频率、道具、隐蔽 / 暴露程度；每级 3–5 句白描不评价；时间踩真实事件线。对位：37 编年三学段（抢矿泉水瓶 / 扯袖子夹子音 / 树荫下嗤笑班花）

**第四拍：代价显形（2:20–2:50，~300 字）**
纯身体 + 物证清单 4–6 个：外貌 / 精力 / 注意力 / 体力 / 手感。禁「颓废 堕落 萎靡」。对位：28b

**第五拍：社死名场面（2:40–3:40，~550 字，全片峰值）**
完整场景：时间 + 地点 + 在场者 + 导火索 + 那句短狠台词 + 生理反应 + 对方拉开距离的小动作（后退半步 / 收回手 / 视线滑过去）。台词口语、短、狠。结尾固定「那次之后 他 / 她再也没有主动找过你」。对位：37 张静一问「你不觉得你们很暧昧吗」

**第六拍：对照组碾压 + 感情审判（3:40–4:40，~550 字）**
对照组：同起点的人，精确数字拉差距（月薪 / 职级 / 婚姻），零拉踩。感情审判：亲密的人说一段实话再离开，这段话是全片金句，直接引用，否定的是「人 / 手 / 心」而非钱。对位：28 最后一碗面

**第七拍：镜子破防夜（4:40–5:20，~350 字）**
具体深夜 + 触发物；「算总账」排比 3–4 条：「从 XX 年那个下午开始 X 年里 你把多少…… 换来的是什么」，收在最痛一条；≥1 生理细节。此处允许一次「不是 A 而是 B」。对位：15 / 34

**第八拍：结局 + 余味（5:20–6:00，~350 字）**
成瘾 / 习惯型默认 A 救赎线：物理戒断 → 戒断生理反应 → 肉体对抗虚无 → 时间跳到「现在」→ 清晨微小证据 → 克制收束。性格缺陷型默认 B 接受线：无爆发无转机，日常瞬间平静接受位置，定格（「接受了自己在这个集体中的位置」）。加冕型：被求 / 判词清算。最后一句 ≤25 字，落在一件器物或一个动作。禁鸡汤、禁「希望你 / 愿你 / 加油」。

【#文风与防 AI 味终极约束】
每 5 秒一个信息点；每段 ≥1 气味 / 声音 / 触感 / 生理；长短句交错，允许「你知道吗 / 其实 / 那天」当气口；所有年份价格数字与第 0 步对齐；金句、数字、社死台词前置可搜索；拆文库结构句（「这种事对你来说太正常」「到了大学你把这套用得更熟了」「这种看似稳固的 X 在 Y 出现了裂痕」「时间在不知不觉中推移 你发现周围的空气开始变得稀薄」「你终于意识到」）每句最多用一次。

【#Loop Engineering — 输出前两轮自检，自检内容不输出】

**L1 设定卡（写正文前在心里列好，9 项缺一不写）**：⓪主线四行 + 来源 ①5 类事实各 ≥1 条带来源 ②引擎 ③齿轮瞬间（年份 + 记忆物 + 抉择）④三件物证（带数字）⑤社死台词原句 ⑥对照组数字 + 审判金句原句 ⑦八拍字数配额 ⑧呼应表 ≥8 对
**L2 成稿检查（写完逐条过，不过就改那一拍，不整篇重写）**：①第 1–4 行含数字与可搜索词组 ②齿轮句落在 5–20% ③「再也没有主动找过你」落在 45–65% ④算总账排比落在 78–92% ⑤生理化 ≥12 处 ⑥场景 ≥4 个、每个 ≥25 行、时间标签 ≤6 ⑦内联说话 ≥15 行、引号问答 ≤3 ⑧无禁词、无品牌、末句 ≤25 字、字数 2,800–3,500
**L2.5 对照审核（成稿后必做）**：把本篇和模板篇 + 一篇非副本供体并排查六项：结果前置行号 / 对手知晓升级位置 / 换手复现对数 / 反杀场景行数 / 结局类型 / 对手末动作。任一项为空 → 只改那一拍。
**返工规则**：被退回时先判断缺的是「事实」「场景」还是「拍子」，只补那一层。

【#输出要求】
先在心里完成第 0 步与 L1；只输出完整口播脚本，不要标题、不要解释、不要分拍标注；开头第一句必须是「今天体验的人生副本是：……」；2,800–3,500 字，全短句。现在先搜索核实主题，再开始创作。
