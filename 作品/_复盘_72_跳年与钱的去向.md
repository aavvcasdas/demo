# 复盘：72 为什么「跳年生硬 / 中奖前没生活 / 钱被骗光 / 号码没换」

> 用户四条意见：「第 1 年到第 7 年跳转太生硬，长时间跨度要么一笔带过」「中奖前的描述呢」「中奖后钱是被骗光的，需要爽，要花光的爽」「买彩票是一天一天的习惯，天天买，只是不买之前的号码了，认为中了不会中了」。
> 结论：**四条里三条半是 skill 的问题，一条半是 72 设定自己写错**。skill 已升 v6，机械闸加了三条，72 正文与设定重写为 v6。

## 一、逐条定位

| 用户意见 | 责任方 | 具体病灶 | 证据 |
|---|---|---|---|
| ① 跳年生硬 | **skill**（主） | v5 §2.6 只写了「压缩铺垫：3–5 个短蒙太奇，每个 ≤8 行」，示范句是「一年里你做了三件事：A／B／C」——等于教作者按年列条目；全篇没有任何「跨度怎么写」的规则 | v5 正文 §2：`第一年一次没中 / 第二年换工作 / 第三年搬家 / 第四年母亲住院 / 第五年食堂 / 第六年母亲的药`，六行编号 |
| ② 中奖前没描述 | **skill** | 位置表把 12–24% 划成「压缩」，却没给**生活占比下限**，也没要求「把习惯写成可复现的一天」；作者把「压缩」理解成「删生活、留事件清单」 | v5 正文里七年只有 40 行，其中没有一次完整的「一天」；钩子到兑奖之间只有事故清单 |
| ③ 钱被骗光 | **skill + 设定** | skill 的爽点池里能抄的是「跪—给—晒—删」「余额跳水」「爆通讯录」，04 供体的后半是围猎与囚禁——**被骗被当成默认的坠落方式**；拆文库真正的花销机制（04 全款 8,600 万买房 +7、05 消费三件套 +4/+7/+6）反而没人抄。设定照抄成「借出 112 万 + 工程 70 万 + 理财入股 90 万」 | v5 设定数字链：4,183,200 − 车 − 房 − … − 借出 1,120,000 − 表哥工程 700,000 − 理财与入股 900,000 = −897,800；正文 §6 有空办公室、派出所台阶、「我不知道往哪边转」 |
| ④ 号码没换 | **设定** | v5 事实锁的「禁止越界」写死`不写复式、胆拖、多注、追加、倍投、换号、机选替换`——把「中奖前守号」这条事实错写成「永远不换号」，读者要的习惯漂移被判成违禁 | v5 设定 `反事实防错清单`：`不是每天 10 元、五注、倍投、重仓` + `不写…换号`；正文结尾 `你说 还是那七个号` |

### 为什么 skill 这一层要负主责

`scripts/fuben_hype.py` 在 v5 只卡位置与密度（爆点 ≤32%、爆点后 ≥4 节点），**跨年写法、钱的去向、习惯结尾都不在闸门里**——所以 v5 的 72 是「机械闸全绿、观众四条不满意」。这跟前两轮（v4 零爽点、v5 慢热）是同一个模式：**观众看得见的毛病，只要没变成闸门，就会一直复现**。

## 三、改了什么

### skill（`人生副本实录.md` v5 → v6）

1. **§2.6 跨度写法（新增）**：禁止「第N年…」年表罗列；同一动作重复 + 细节漂移；一个从头到尾不变的参照物；兑现/转折前的生活占比 ≥10% 且 ≥2 处身体/环境；真要跳年只写「时间 + 一个物件降级」一行。
2. **§2.7 钱的去向（新增硬门，兑现/暴富题）**：花 ≥50%、花+给 ≥60%、亏 ≤20% 且必须自己拍板、**被骗 ≤1 处且不得是归零主因**；每笔花销配他人身体反应做刻度；`## 钱的去向表` 账要平；收束判断句是「你花的每一笔你都记得，只有总数你不记得」；禁写集资跑路 / 空办公室 / 报案要不回来。
3. **§2.8 习惯题结尾（新增硬门）**：动作原样运行、内容换掉、信条由角色说出来；`## 习惯漂移` ≥2 行；不许写「他戒了」，也不许原样重复「一切照旧」。
4. §2.2 位置表加三行（跨度 / 钱的去向 / 习惯漂移）；§4 验收清单与 `fuben_run` 说明同步；§4.2 人工三问；§5 变更记录记 v6。
5. `人生副本_通用骨架.md` v4 → v5：三张图变五张图（新增跨度图、钱的去向图），位置表 12–24% 那一格改写。
6. 提示词同步：`GPT6_人生副本剧本生成提示词.md` 第 1 步加三条硬要求；`作品/_提示词_人生副本_v2.md` 加 v6 增补段。
