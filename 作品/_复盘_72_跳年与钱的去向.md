# 复盘：72 为什么「跳年生硬 / 中奖前没生活 / 钱被骗光 / 号码没换」（含第二轮：过渡、借钱、旅游、加量）

> 用户四条意见：「第 1 年到第 7 年跳转太生硬，长时间跨度要么一笔带过」「中奖前的描述呢」「中奖后钱是被骗光的，需要爽，要花光的爽」「买彩票是一天一天的习惯，天天买，只是不买之前的号码了，认为中了不会中了」。
> 结论：**四条里三条半是 skill 的问题，一条半是 72 设定自己写错**。skill 已升 v6，机械闸加了三条，72 正文与设定重写为 v6。

### 为什么 skill 这一层要负主责

`scripts/fuben_hype.py` 在 v5 只卡位置与密度（爆点 ≤32%、爆点后 ≥4 节点），**跨年写法、钱的去向、习惯结尾都不在闸门里**——所以 v5 的 72 是「机械闸全绿、观众四条不满意」。这跟前两轮（v4 零爽点、v5 慢热）是同一个模式：**观众看得见的毛病，只要没变成闸门，就会一直复现**。

## 三、改了什么

### skill（`人生副本实录.md` v5 → v6）

1. **§2.6 跨度写法（新增）**：禁止「第N年…」年表罗列；同一动作重复 + 细节漂移；一个从头到尾不变的参照物；兑现/转折前的生活占比 ≥10% 且 ≥2 处身体/环境；真要跳年只写「时间 + 一个物件降级」一行。
2. **§2.7 钱的去向（新增硬门，兑现/暴富题）**：花 ≥50%、花+给 ≥60%、亏 ≤20% 且必须自己拍板、**被骗 ≤1 处且不得是归零主因**；每笔花销配他人身体反应做刻度；`## 钱的去向表` 账要平；收束判断句是「你花的每一笔你都记得，只有总数你不记得」；禁写集资跑路 / 空办公室 / 报案要不回来。
3. **§2.8 习惯题结尾（新增硬门）**：动作原样运行、内容换掉、信条由角色说出来；`## 习惯漂移` ≥2 行；不许写「他戒了」，也不许原样重复「一切照旧」。
4. §2.2 位置表加三行（跨度 / 钱的去向 / 习惯漂移）；§4 验收清单与 `fuben_run` 说明同步；§4.2 人工三问；§5 变更记录记 v6。
5. `人生副本_通用骨架.md` v4 → v5：三张图变五张图（新增跨度图、钱的去向图），位置表 12–24% 那一格改写。
6. 提示词同步：`GPT6_人生副本剧本生成提示词.md` 第 1 步加三条硬要求；`作品/_提示词_人生副本_v2.md` 加 v6 增补段。

# 第三轮反馈（v8 → v9）：他凭什么敢花

> 用户：「中奖之后需要保持买彩票的习惯，只是没有再中过，一直花的原因是认为还能再中啊！」

## 一、定位（还是 skill 的洞）

| 问题 | skill 缺什么 | 修法 |
|---|---|---|
| 花光的**动机**没写 | v8 把「补欠花 + 场面花」写足了，但没有一条要求解释「他凭什么敢花」——观众只看到钱在流走，看不到他心里的账 | §2.7.2 新增「花光的底气」：底气 = **还会再中**，一句话、带数字、正文 ≥2 处、结尾不破 |
| 习惯与花销**没咬合** | v8 把「换号 + 加量」放在结尾 95% 当彩蛋，于是「一直在花」和「还在买」是两条线 | 换号 + 加量提前到**中奖第二天**（32%），写成同一段因果：换号 → 买得更多 → 觉得还会中 → 花钱不看余额 |
| 「没中过」没说 | 只在结尾说「中过奖的只有一张」，中间没有「一次没中过」 | 明写「换了号以后你一次都没中过，五块的都没中过」，与「还信下一期」同时出现 |

机制依据：彩票/赌博成瘾的核心是「下一把就能回本」的信念，而大奖本身是最大的强化物（`拆文库/21` 的首胜诱饵 → 余额跳水即是这套结构）。

## 第五轮（v9 → v10）：底气为什么没兑现成「机制」，以及票钱怎么涨上去

### 一、用户的第六次反馈（原话要点）

「中奖之后需要保持买彩票的习惯，只是没有再中过；一直花的原因是认为还能再中啊」——并且追问：**为什么这个设定没有实现**？彩票在后续「也不知不觉花了很多钱」。

### 二、根因：不是写手没写，是 skill 没要求（skill 问题）

| 环节 | v9 的 skill 写了什么 | 结果 |
|---|---|---|
| 底气 | 「正文出现 ≥2 次（一次花钱中段、一次结尾习惯段）」 | 只够写成 **3 句口号**（36% / 59% / 98%），中间的车、房、席面、旅行、请客各段没有它的位置 |
| 票钱 | skill 只锁「中奖后一天五注、一天 10 元」 | 花费全是**外部消费**，彩票本身十年一个价；观众读不出「后来不知不觉花了很多钱」 |
| 没中过 | skill 要求「一次都没中过」必须明写 | 写成了极端句，反而与「注数越买越多」冲突：买得越多越必然中小奖 |

**一句话**：v9 把「还会中」当成了**结论**（写在开头与结尾各一次就够），没有当成**引擎**（每一段花钱都要它点火），也没有把「花光的钱」与「继续买彩票的钱」接上。

### 三、v10 的四处修改

1. **底气变成引擎**：`## 花光的底气` 5 行（车房 / 席面 / 请客 / 日常 / 结尾各一处），正文信念句 **6 处**——3%（钩子）· 35%（买车前）· 52%（席面上说出口）· 59%（请客时）· 61%（「花掉的是一期」）· 98%（结尾）。
2. **新增 `## 加注阶梯`**（skill 新门）：5 注 / 10 元 → 15 注 / 30 元 → 50 注 / 100 元，日期区间 105 天 / 365 天 / 261 天；中奖后票钱 **38,100**，七年一共才 **5116**——结尾判词改成「中奖前七年 5116 块 / 中奖以后 三万八千一」，从此「一共花掉多少」是**彩票自己涨上去的**。
3. **小奖是燃料**：正文两次写「五块的 十块的 你中过不少 / 最多一次两百 / 大的没有」「每中一个五块 / 你都觉得下一张更近」；删掉 v9 的「一次都没中过、五块的都没中过」——注数涨到 15–50 注，小奖必然出现，它才是继续买的 Reinforcement。
4. **账重算**：去向表新增 1 笔「花」= 38,100（票钱），场面日常由 900,000 调为 861,900；到账 4,000,000 + 变卖 400,000 − 4,385,200 = **余额 36,200（误差 0）**；彩票总支出 12,426 → **43,216**。
