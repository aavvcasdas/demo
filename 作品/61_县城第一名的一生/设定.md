# 设定：县城第一名的一生（主题：你从什么时候开始发现自己不是这个世界的主角）

## 基本信息
- 主题（用户给定，非题目）：你从什么时候开始才发现自己不是这个世界的主角
- 题目：县城第一名的一生
- 题材方向：人生副本实录 · 实录志 + 清算志（主角感的分期折旧）· 灰收束
- 对标拆文：`06 职高生毕业后的残酷现实`（题眼原句「你从来都不是这个世界的主角」的出处；三段跳跃 + 每段一个财务尾数 + 星巴克跨阶层镜像）、`13 高中死装努力姐`（校园编年 + 榜单器物）、`30 小众哥`（「其实」双账本）
- 搜索素材（知乎「什么时候意识到自己不是主角」）：高中新年晚会一个人坐角落 什么都不会 / 数学 49 历史 99 / 大三清醒意识到保研与我无关 / 「如果我是主角 这本书销量该有多惨」/ 「别人都是 NPC」的中二期
- 本篇按 skill 第十四节新门槛写：≥2800 字 / 感官 ≥6‰ / 价格 ≥12 / 品牌 ≥4 / 对话 ≤3% / 热梗 0 / 开篇 3 行落到皮肤

## 故事核
> 你是县城高中 11 年来第一个全县第一，校门口挂过 18 米的红横幅；你带着你爸的蓝白编织袋去省会读 211，从英语分级 C 班、迎新晚会的角落、高数 49 分、保研名单第 19 名、137 份简历、月薪 6500 减房租 2300，一层一层交出主角感；28 岁回县城，校门口又挂了一条一模一样的横幅，上面是别人的名字，你妈说那孩子跟你当年一模一样。

## 志与曲线
- 志：实录志 × 清算志
- 曲线：+6（横幅）→ 编年缓降（每段 -1）→ -5（保研 19 名 / 秋招 137 份）→ 82% 横幅回环击点 -6 → 灰收（你给那孩子的横幅拍了张照 发给了你妈）
- 主角感折旧刻度：全县第 1 → 全省 4127 → C 班 → 角落 → 49 分 → 第 19 名 → 137 份 → 6500-2300 → 一个新名字

## 六段占比（11/20/25/15/17/12）
1. 开题 + 横幅（11%）：8 月的县城 / 红横幅 18 米 / 鞭炮 / 你爸的编织袋 / 全县第一 全省 4127
2. 报到 + 第一学期（20%）：绿皮 K 字头 / 宿舍 / 室友 MacBook vs 你的 2999 联想 / 英语分级 C 班 / 迎新晚会角落 / 军训后你在校园卡里存了 800
3. 大二到大三编年（25%）：高数 49 / 第一次挂科 / 你妈问你还是不是第一 / 保研名单 12 个名额你第 19 / 竞赛 / 同学的父亲是谁 / 寒假回县城 老师让你给学弟学妹讲经验 你讲了 45 分钟
4. 秋招（15%）：137 份简历 / 宣讲会 / 6500 / 房租 2300 / 余额 1,846.30 / 你的工位编号
5. 28 岁回县城（17%）：校门口新横幅 / 一模一样 / 你妈的话 / 那个孩子
6. 收束（12%）：你拍照发给你妈 / 判词

## 器物判词
红横幅（18 米 / 你的名字 → 别人的名字）/ 蓝白编织袋（你爸 → 你自己拎去北京）/ 高三作文被印成全校范文 → 需求文档没人打开 / 校园卡余额 → 支付宝余额

## Phase 2 设计校验
- 题材参考：`人生副本实录.md`（含第十四节新增质地门槛）
- 核心招式：编年折旧刻度 + 每段一层感官 + 器物回环（横幅）+ 冷揭晓（你妈的一句话）+ 灰收束
- 反派：无；加害者为「排名系统」本身（分级考试 / 保研名单 / 简历筛选 / 房租）
- 反转位置：82%
- 对话：全篇 ≤3 行，唯一一场正面台词给你妈
