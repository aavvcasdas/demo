## Phase 3 Findings
- S1 / 事实 / L58–66, L206–210, L262–266, L452–470 / 「朋友圈 访客」「访客功能关了」/ 微信没有访客记录，整条主线（她看见你每晚来）站在一个不存在的功能上；抖音评论区第一条一定是「朋友圈哪来的访客」/ fix：主线物证必须是真实存在的东西（共同好友截图 / 点赞手滑 / 她发的「仅他可见」）——需重搜。
- S1 / 主线 / 全篇 / 「你」的核心行动 = 每晚偷看她朋友圈记「对」/ 这不是观众自己干过、能代入的事；三年每晚一次并记备忘录是变态行为不是共鸣行为。「感同身受」的版本应是观众都经历过的：被一句「不合适」甩掉后暗自较劲、想证明自己、想让对方后悔；或者反过来——甩人时觉得自己在给对方好处，多年后被对方一句话点醒。本篇两边都没站 / fix：重选核心行动，先搜真实帖子「分手时对方说不合适 后来」，从评论区最高赞找共鸣句。
- S1 / §12 谁先出手 / L15–24 / 「你」甩她只用四十秒、劝她「别太拼」/ 「你」是施害者，她是受害者，但全篇 POV 是「你」，观众既不能爽（她的反杀太轻）也不能代入（谁愿意当那个混蛋）。§12 尺 1 不过。
- S2 / 代价 / L318–321 / 「公司黄了 车卖了 投了七十四份」三行 / 「你」的坠落没有一次具体的疼；她的成长「两万八 带团队」也只有数字。§12 尺 2 不过。
- S2 / 机制过载 / 备忘录「对」+ 相册「他」+ 访客 + 奶茶 + 腊肠 + 项链 + 打印纸「很好」+ 硬座车票 / 8 件，回收 3 件。§12 尺 4 不过。
- S3 / 常识 / L344 / 「最后一轮面试官是她」而她是「同事本来面你 她要来」/ 现实里利益相关方应回避，评论区会挑；原帖是 HR 面且当事人自嘲，本篇写成正式终面。
