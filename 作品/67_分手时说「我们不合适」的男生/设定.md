# 67 · 分手时说「我们不合适」的男生 · 设定 v1

## 志 / 曲线
代价志（单点决策的毁灭：三句话）· 编年缓降 → 一次对账（28 辜负志型：清算不由被辜负者执行，由世界执行）· 模板 = 拆文库/28 骨架（藏她/瞒她/一句话否认/最后一碗面）× 拆文库/28b 数字判词 × 新入库《乱葬岗里的姑娘》机制（「配不上」这三个字压死人之后，账以什么形式还——这里没有鬼，她把你那句话原样活成了简历）

## 六段（28 型）
| 段 | 占比 | 内容 |
|---|---|---|
| 开篇放大事件 | 13% | 大三分手 学校后门奶茶店 你说了三句话 逐字写；她没哭 把吸管插回去 |
| 基线 | 12% | 大一认识 她是助学金名单第一个 你是家里给了车的那个 你觉得你没在意 |
| 编年（她兑现你的三句话） | 28% | 每一段一句被兑现：「你以后会明白」→ 她明白得比你快 /「不是一个世界」→ 她换了世界 /「你别太拼」→ 她拼了 |
| 谷底 | 15% | 你毕业家里安排的公司黄了 你去投简历 面你的人是她的同事 |
| 对账 | 22% | 六年后同学会 她的工牌 她给服务员的小费 她没认出你 |
| 认领 | 10% | 她加你微信 备注是你的全名；你的备注还是六年前那个 |

## 三句话（开篇逐字，之后逐句兑现）
1. 「我们不合适 你以后会明白的」
2. 「我们不是一个世界的人 这不怪你」
3. 「你也别太拼了 女孩子 差不多就行」

## 戳穿机关
同学会签到表：她的单位一栏是你去年投过简历被刷的那家；她给服务员的小费是两张二十，你当年请她喝的奶茶是十二块，你付的。

## 原型（逐条落地）
1. 「对方觉得自己永远想不明白你要什么，每一次委曲求全的道歉累积成怨气，直到觉得没什么好说的」（知乎 26601522，1008 答）→ 分手前她的三次沉默
2. 分手后固有印象成型「护城河固若金汤」，靠道歉/送礼/偶遇不可能（知乎 629196482）→ 同学会你的所有动作无效
3. 「新鲜感缺失 = 你的价值在对方眼里降低了」（知乎 374784986）→ 反写：六年后是你的价值在她眼里为零
4. 「安全感不足主动退出」→ 反写：她不是没安全感，她是听懂了
5. 乱葬岗：讨回名分不靠说话靠仪式 → 她的仪式是「备注全名」
6. 28：用「没有」两个字否认她 → 你当年在同学面前说「没在一起 就是玩玩」
7. 28：最后一碗面 → 同学会她给你倒了一杯茶 倒到七分
8. 大学恋爱门当户对话题：家境好的一方分手常用「不合适」代替「配不上」→ 主题句一次

## 侧面四通道
- 旁观者身体：她的视线从你脸上滑过去没停 / 同学替你介绍时她伸手的高度 / 服务员先给她添茶
- 旁观者的话：「她现在可厉害了」「你俩当年不是——」「哦 是吗」
- 环境规格：签到表 / 座位 她主桌你末桌 / 微信备注
- 权力者不作为：她全程没提当年一个字
主角误读：「你觉得她是装的」「你把她的礼貌归给没认出来」。内心 ≤6。

## 收束
器物/动作：微信备注页面 她给你的备注是三个字全名 你给她的还是六年前那两个字；末句：你没改。

## 同题检查
拆文库 28 是穷男孩辜负丑女孩（20 年）；本篇换轴：时间压缩到 6 年，辜负的工具是语言（三句话），清算的工具也是语言（备注）。
