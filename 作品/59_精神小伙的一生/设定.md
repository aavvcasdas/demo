# 设定：精神小伙的一生

## 基本信息
- 题材方向：人生副本实录 · 实录志 × 温情志（苦底带暖）· 微喜剧
- 对标拆文：`05 县城精神小伙的沉沦之路`（同题，但 05 走沉沦/绞肉机，本篇刻意避开：不走灰产、不走网贷，走「一生编年 + 代际回环」）、`02 外卖员的一生`（一生编年腔）、`26 邻家姐姐`（苦底带暖收束）
- 差异化：05 是「系统吃人」，本篇是「一种审美的一生」——精神小伙这个身份从 14 岁穿上到 38 岁传给儿子，中间真正剩下的是「能吃苦、讲义气、一个月寄回 5500」
- 目标情绪：笑（语录/花手/豆豆鞋）→ 酸（19 岁结婚、工地、寄钱）→ 灰暖（儿子锡纸烫，你没骂，你教他花手）
- 正文字数目标：2200–2600 字
- 素材：精神小伙标配（锅盖头 / 豆豆鞋 / 紧身裤 / 电动车 / 兜里不超过 50 个窝窝头的钱）、社会摇 / 花手、寒王语录（跟着寒王混三天饿九顿 / 先擦鼻涕后提裤 / 天冷脾气燥）、「初中没上完的精神小伙现在怎么样了」纪实（早婚早育、挣六千寄五千五、孩子留给爷爷奶奶）

## 故事核
> 14 岁的你花 15 块剪了锅盖头、39 块买了豆豆鞋，在县城广场用一套花手完成成人礼；38 岁那年你在工地日结 280、月寄 5500 回家，回家发现 13 岁的儿子顶着锡纸烫在客厅跳新的社会摇——你想骂，看见电视柜上自己 14 岁的照片，最后你把儿子拉到院子里，教他一套完整的花手。精神小伙的一生，没有发财，没有翻盘，只有一双 39 块的豆豆鞋走完了一代人。

## 志与曲线
- 志：实录志（亚文化的白描）+ 温情志（苦底带暖）
- 曲线：编年缓降 +4（14 岁广场之王）→ +1 → -3（19 岁结婚 / 22 岁孩子留家）→ -5（35 岁工地 / 视频里儿子不认识你）→ 82% 回环击点（儿子锡纸烫）→ 收 -1/0 暖灰

## 六段与占比
1. 开题 + 14 岁购置（12%）：15 元锅盖头 / 39 元豆豆鞋 / 29 元紧身裤 / 家里的电动车；广场花手，你是这条街的排面
2. 15–17 岁全盛（22%）：寒王语录当人生哲学 / 兄弟 7 个人 5 辆电动车 / 快手 3 万粉 / 「跟着寒王混三天饿九顿」你真饿了 / 退学 / 台球厅 / 第一次打架 输了 但豆豆鞋没脏
3. 19–22 岁落地（20%）：19 岁结婚 彩礼 8 万 8 是你爸借的 / 婚礼上你跳了花手 / 20 岁当爹 / 22 岁跟表哥出去打工 / 儿子留给爷爷奶奶
4. 23–35 岁编年（18%）：工地日结 280 / 每月 6000 寄 5500 / 锅盖头剃成板寸 / 豆豆鞋换成劳保鞋 / 视频里儿子叫你叔叔 / 兄弟群 7 人剩 3 人在线
5. 38 岁回家（16%）：推门儿子锡纸烫 + 新社会摇 / 你火了 / 儿子一句「你懂什么」/ 电视柜上你 14 岁的照片 / 你妈说 一模一样
6. 收束（12%）：院子里教花手 8 个动作 / 儿子学得比你快 / 你说了一句你 14 岁听过的话 / 判词

## 数字判词链
15 元锅盖头 → 39 元豆豆鞋 → 快手 3 万粉 → 彩礼 8 万 8 → 日结 280 → 6000 寄 5500 → 儿子锡纸烫 128 元 → 花手 8 个动作

## 器物判词
豆豆鞋（39 元 → 劳保鞋 → 儿子脚上 399 的老爹鞋）/ 电动车（你爸的 → 你的 → 儿子的）/ 电视柜上 14 岁的照片

## 审核自查
无教唆退学（后果写实）、无群体嘲讽（笑点全在主角自身）、无暴力细节、无鸡汤总结

## Phase 2 设计校验
- 题材参考：`references/genre-styles/人生副本实录.md`
- 核心招式：一生编年 + 器物判词链（豆豆鞋三代）+ 代际回环（避开 05 的陌生新人回环，改为亲子回环）+ 语录反讽（寒王语录逐条兑现）
- 反派：无（实录志）
- 反转：认知/情感反写——预期「骂」，实际「教」；位置 82%
- 目标平台：抖音口播
