# 短篇核心框架

**基本信息**
- 题材方向：人生副本系列 / 现实主义爽文 / 清醒克制
- 目标情绪：沉浸感、冷眼旁观现实、用结构性权力完成抽离的真实爽感。
- 视角：第二人称（你），带有“人生副本”系列特有的纪录片式旁白感。

**故事核**
- 起因：底层社畜中奖千万级（税后一千万），但没有立刻声张。
- 核心冲突：原生态家庭的道德绑架（女友的扶弟魔原生家庭）vs 男主建立的新生活壁垒。
- 人设底色：
  - 你：清醒克制的成年男性。中大奖后，第一反应不是狂喜，而是审视周围的风险。钱是生存的底牌，做事不动声色，不刻意炫耀，也不把“自私”或“理智”挂在嘴边，而是通过行动（默默买房买车、清偿债务）来掌控人生。
  - 女友（夏夏）：被原生家庭道德绑架的疲惫女孩，但在关键时刻，拥有挣脱泥沼、维护两人感情的勇气。
- 情绪反转（爽点）：抛弃刻意说教和刻意装逼。面对女友弟弟上门逼迫，男主不炫富、不争吵，直接带着女友“降维抽离”——把你渴望的破出租屋留给你，我带她去我的新世界。

**对标《拆文库》技法**
- **微观动作与账单细节**：用精确的数字（63,412.5元的网贷、450万的江景房）锚定真实感。
- **沉默的爽感（信息差压制）**：对方在用“穷”来攻击男主时，男主内心毫无波澜。
- **不着痕迹的资产处理**：买房签字等行为写得自然流畅，去除了“刻意拒绝加名”这种生硬的桥段；向女友坦白时，去除了“钱都是我的”这种生硬台词，改为“不开口是为了防止把你拖回泥沼”的成年人智慧。
