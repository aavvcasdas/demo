# 短篇核心框架

**基本信息**
- 题材方向：人生副本系列 / 理智暴富 / 现实主义爽文
- 目标情绪：剥离刻意装逼，体验极度理智、冷眼旁观现实、用绝对的结构性权力完成降维打击的真实爽感。
- 视角：第二人称（你），带有“人生副本”系列特有的沉浸式、纪录片式旁白感。

**故事核**
- 起因：底层社畜中奖500万（税后400万），但没有立刻摊牌。
- 核心冲突：原生态家庭的吸血（女友的扶弟魔原生家庭）vs 男主建立的资产防火墙。
- 人设底色：
  - 你：极度理智的成年男性。中大奖后，第一反应不是狂喜，而是审视周围的风险。钱是生存的底牌，绝不会因为一时的感动而全盘托出，更不会去填女方原生家庭的无底洞。
  - 女友（夏夏）：被原生家庭道德绑架的疲惫女孩，但在关键时刻，拥有挣脱泥沼、维护男主底线的勇气。
- 情绪反转（爽点）：抛弃“买豪车泼水打脸”这种刻意凑字数的三流网文套路。爽点来自于男主“置身事外”的冷静观察，以及最后在弟弟上门逼迫时，男主不炫富、不争吵，直接带着女友“降维抽离”——把你渴望的破出租屋留给你，我带她去我的新世界。这种“不在一个维度上的无视”，才是真正的降维打击。

**对标《拆文库》技法**
- **微观动作与账单细节**：不写“我很激动”，写“把彩票套进密封袋塞进冬装羽绒服内衬”。用精确的数字（63,412.5元的网贷、220万的全款房）锚定真实感。
- **沉默的爽感（信息差压制）**：对方在用“穷”来攻击男主时，男主内心毫无波澜，因为存款余额构成了绝对的心理防御机制。看对方跳脚就像看猴戏。
- **大男主的情感逻辑**：我的钱永远是我的（切断女方家属吸血的可能），但我的屋檐可以为你遮避一生的风雨（极致的护妻与救赎）。
