# 短篇核心框架

**基本信息**
- 题材方向：人生副本系列 / 现实世情打脸
- 目标情绪：从极度压抑到沉稳抽离，最后实现结构性降维打击的真实爽感。
- 视角：第一人称（我）——严格遵循短篇视频口播与网文代入感要求，去除旁白说教，全靠动作和细节推动。

**故事核**
- 起因：底层社畜在习惯性替关系户背锅受辱的瞬间，查出自己中了千万大奖。
- 核心冲突：原生态家庭的道德绑架（女友的扶弟魔原生家庭）vs 男主建立的新生活壁垒。
- 逻辑补全与反套路设计：
  - 【钩子精简】：黄金简介极大缩短，三句话交代冲突与爽点承诺，极具短视频冲击力。
  - 【高能开局】：强调职场背锅属性。错不是主角的，而是主管的关系户犯错让主角背锅。增加主角长期的“憋屈感”，让千万底牌的降临更具反差爽感。
  - 【离职掩护】：离职后向女友谎称“接了远程外包”，完美掩盖不上班的Bug。
  - 【抽离式反杀】：不跟吸血鬼争吵出租屋的归属，直接降维嘲讽，带人走向新世界。

**去AI味与口播优化**
- 禁用元叙事与说教，如“在短视频里”、“三流爽文”。
- 微观细节当刀：5000块背锅罚单、冲锋衣口袋里的汗水、63412.5元的借呗账单。
