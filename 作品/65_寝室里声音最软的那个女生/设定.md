# 65 · 寝室里声音最软的那个女生（主题：看着人畜无害实际心机很重的舍友）· 设定 v2

## 原型（知乎 6663 赞回答 + 换宿舍帖 + 六人寝五个群帖，逐条落地）
1. 口红：舍友代购买了两支贵口红 → 你酸「有钱人」→「代购假货多」→ 你自己去旗舰店买同款、拿礼盒炫耀 → 撺掇家境差的舍友也买「不就一百七 省省就出来了」
2. 板鞋：听见舍友闺蜜要送她一双纯白中帮板鞋 → 你「我看上好几个月了 你别买了」→ 让她换个色 → 她不换 → **你坐床上哭 舍友围上来** → 擦泪「那我现在买 你别跟我同一天穿」
3. 踹门：舍友发烧躺着 别人都小声 你踹门进（平时有人推门 没人踹门）→ 被提醒回一个「哦」→ 继续大声
4. 鞋盒：把自己鞋盒往对床桌底硬塞 把她东西全挤掉 → 「我鞋这么贵 潮了怎么办」→ 她光脚下床给你腾地方 你理都不理；你多占一个柜子
5. 助学金四年 + 演唱会 / AA 拖三天「又不是不给你」/ 小组作业「我不会呀」换最轻
6. 班长拉票：群里让大家公平投票，你只把不可能赢的和你喜欢的提议报上去；私信全班拉票；带头孤立、阴阳
7. 六人寝五个群，你在一个
