# 设定：大学里官威最大的考勤副班长

## 基本信息
- 题材方向：人生副本实录 · 清算志（加害者视角的社死复盘，对标 37 边界感女生 / 13 死装姐）· 冷幽默
- 对标拆文：`37 班级里那个没有边界感的女生`（加害者代入位 / 零外部审判 / 社死由细节自动完成 / 放逐清单）、`13 高中死装努力姐`（榜单器物 + 单点击穿）、`39 班里的蛀虫上大学了`（制度空白 + 校园编年冷幽默）、`32 水牛室友`（Excel 制度判词）
- 搜索素材：大学班干部靠「综测加分 / 保研优先提名」驱动而非服务（学生会官威热搜）；点名叫集合没人来只能一个个求（班干吃力不讨好）；小组作业「社会惰化」：划水者、不当组长却指挥组长的人、组长承担老师全部怒火、「提了建议活儿就是你的」
- 第十四节质地门槛：≥2800 / 感官 ≥6‰ / 价格 ≥12 / 品牌 ≥4 / 对话 ≤3% / 热梗 0 / 开篇 3 行落皮肤

## 故事核
> 大一竞选时你说「为同学服务」，实际盯着的是综测 3 分的班干部加分。你和班长、纪律委员组成「班委三人组」，用学习通签到截图、「收到请回复」、旷课记录表管了全班 46 个人两年；到大三小组作业，老师随机分组把你分给了你记过 11 次旷课的四个人，他们一句话不说把活干完，组内互评给了你全组最低；学期末综测公示：你的 3 分班干部加分在，民主测评 30% 你全班第 46。你拿着 Excel 去找辅导员，辅导员只说「那是同学打的」。

## 志与曲线
- 志：清算志（你以为的你 = 管理者；别人眼中的你 = 系统的一个提示音）
- 曲线：+3（竞选 / 权力上手）→ +2 平台（管理日常，读者已在下方）→ 小组作业 -2 → -4（互评）→ 82% 综测公示 -6（冷揭晓：Excel 第 46/46）→ 灰收（改选没人提名你，你在群里发了最后一条「收到请回复」，已读 45，回复 0）

## 六段（11/20/25/15/17/12）
1. 竞选（11%）：9 月教室 / 你手心的汗 / PPT 3 页 / 「为同学服务」/ 综测细则第 4 条 班干部 +3 / 当选 副班长（考勤）
2. 权力日常（20%）：学习通签到二维码 / 15 秒 / 截图 / 每天早上 7:50 的群公告「收到请回复」/ 旷课记录表.xlsx / 纪律委员的 39 块扩音喇叭 / 班长跟辅导员汇报的语气 / 你们仨在食堂三楼固定的位置 / 全班群 47 人 班委群 4 人
3. 编年升级（25%）：大二 你把旷课表按人头排序 / 一个女生请假去看病 你要病历照片 / 一个男生奶奶去世 你要求补假条 / 期末 5 个人因为你的表被取消评优 / 你的综测 全班第 3 / 老师说你「认真负责」/ 全班没人加你微信好友 你以为是他们怕你
4. 小组作业（15%）：大三 随机分组 / 你和 4 个被你记过的人一组 / 你在群里发分工表 / 没人回 / 他们私下建了群 把作业做完了 / 汇报那天 PPT 上有你的名字 第五个 / 组内互评
5. 综测公示（17%）：Excel 贴在公示栏 / 班干部加分 3 / 民主测评 30% / 你 第 46 / 班长 第 8 纪律委员 第 12 / 辅导员一句「那是同学打的」
6. 收束（12%）：改选 / 没人提名 / 新副班长第一天在群里发签到码 全班 15 秒内签完 / 你最后一条群公告 已读 45 回复 0 / 判词

## 数字判词链
综测 +3 → 15 秒 → 47 人 / 4 人 → 11 次 → 5 个人取消评优 → 全班第 3 → 第五个名字 → 第 46/46 → 已读 45 回复 0

## 器物判词
学习通二维码 / 旷课记录表.xlsx / 39 块的小蜜蜂扩音器 / 综测公示 Excel（A4 打印 4 颗图钉）/ 群公告「收到请回复」

## Phase 2 设计校验
- 题材参考：`人生副本实录.md`（含第十四节）
- 核心招式：加害者视角 + 制度器物（学习通/Excel/综测细则）承担全部冲突，人只是执行端 / 冷揭晓（打印的 Excel + 辅导员一句）/ 无救赎收束
- 反派：无；系统 = 综测加分制 + 民主测评
- 反转位置：82%
- 唯一正面台词：辅导员「那是同学打的」
