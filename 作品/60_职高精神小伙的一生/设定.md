# 设定：职高精神小伙的一生（加冕弧）

## 基本信息
- 题材方向：人生副本实录 · **逆袭加冕弧**（实录志升格）· 带笑
- 对标拆文：`05 县城精神小伙的沉沦之路`（同人群 / 反向：他沉沦我加冕）、`06 职高生毕业后的残酷现实`（同场景：汽修学徒洗轮胎 / 找不存在的扳手 / 师傅护城河——本篇把 06 的第二重幻灭改写为「熬过去的那百分之十几」）、`16 县城刀枪炮的父亲`（加冕型收束参考）
- 与 59 的差异：59 走温情灰（花手传代），60 走扬式收束（手艺加冕），不重复「儿子回环」
- 目标情绪：笑（精神小伙 × 汽修专业的错位）→ 憋屈（学徒期）→ 三次碾压（30% / 55% / 85%）→ 扬收
- 正文字数目标：2200–2500 字
- 搜索素材（真实社会逻辑）：汽修行业三道坎「3 个月学徒 / 三四年中工 / 5 年师傅」；班里三四十人最后留在行业的只有几个；改行的一毕业三四千、7 年后还是三四千；学徒月薪 200 还要给师傅买早餐 / 洗车 / 换机油换到崩溃 / 师傅核心拆装不教；坚持下来的要么开店要么当主管

## 故事核
> 15 岁中考 213 分的锅盖头精神小伙进了县职高汽修班，全班 41 个人，班主任第一天就说「你们这批能有 3 个干这行就不错了」。你是被点名「最不像那 3 个」的人。学徒期你洗了 1400 辆车、给师傅买了 90 天早餐、找了无数把不存在的扳手，但你有一样别人没有的：跳社会摇练出来的手稳和耳朵好，听发动机声就能判故障。7 年后你开了店，当年那个师傅的儿子来你店里应聘学徒；当年的班主任把车开进你店里，说「你是那 3 个里的」。你把工牌翻过来给他看：编号 41。

## 志与曲线
- 志：实录志（职高 / 汽修行业白描）升格加冕弧
- 曲线：+3（锅盖头入学的自我感觉良好）→ -2（定义句）→ -5（学徒地狱）→ 30% 露一手 +3 → 55% 中工被求 +4 → 85% 被求加冕 +6 → 扬收（不喊口号，判词落在工牌编号 41）

## 六段与占比
1. 开题 + 入学（11%）：中考 213 分 / 锅盖头豆豆鞋走进职高 / 汽修班 41 人 / 班主任定义句「能有 3 个干这行就不错了，尤其是你」
2. 职高三年 + 硬通货埋设（20%）：实训课花手改成拧螺丝手稳 / 你能听出摩托车哪里响（从改鬼火练的）/ 同学 41 人 → 毕业时 28 个去了电子厂 / 你去了县城最破的汽修铺
3. 学徒地狱（20%）：月薪 800 / 每天给师傅买 6 块钱早餐 / 洗车 1400 辆 / 找「17 号扳手」找了三个月才知道没有 17 号 / 师傅核心拆装从不让看 / 你偷偷录声音 / 30% 碾压①：一辆五菱宏光异响，师傅拆了两天，你趴着听了 40 秒说「右前轮轴承」——对了，师傅没说话，第二天早餐让你别买了
4. 中工三年（17%）：月薪 3500 → 6000 / 师傅开始让你上手 / 电子厂同学群工资还是 3800 / 55% 碾压②：4S 店挖你，师傅第一次求你留下，涨到 8000，你留了；手上有了 43 道疤
5. 开店与被求（20%）：第 7 年你盘下店 / 第一个月 11 单 / 靠听音诊断口碑 / 85% 碾压③：师傅儿子来应聘学徒，你让他先洗车，早餐你请；班主任的车异响进店，你听了 30 秒 / 他认出你 / 「你是那 3 个里的」
6. 收束（12%）：你把工牌翻给他看 编号 41 / 你给他免了工时费 / 41 人群里的消息 / 判词

## 数字判词链
213 分 → 41 人 / 3 个 → 月薪 800 / 早餐 6 块 → 1400 辆车 → 40 秒 → 3500 → 8000 → 43 道疤 → 第一个月 11 单 → 编号 41

## 器物判词
豆豆鞋（入学 → 实训被机油泡烂 → 换劳保鞋）/ 17 号扳手（不存在的扳手 = 学徒羞辱 → 你店里真挂了一把写着 17 号的扳手）/ 工牌编号 41

## 审核自查
无教唆、无对职高群体贬损（笑点在主角）、爽点全部贴地（手艺 / 熬）、不喊口号

## Phase 2 设计校验
- 题材参考：`references/genre-styles/人生副本实录.md` 第六节加冕弧
- 核心招式：定义句伏笔（班主任 3 个 / 尤其是你）→ 硬通货（耳朵 + 手稳，来自社会摇 / 改鬼火，编年里验证 3 次）→ 三碾压 30/55/85 各配实物判词（早餐停买 / 8000 / 工牌 41）→ 扬收 + 题眼追认
- 反派：无实体恶人；师傅是护城河型普通人，最后被求时不羞辱他，用「早餐我请」轻轻放下
- 反转位置：85%
- 目标平台：抖音口播
