## 基本信息
- 标题：每天买一张彩票的人
- 平台：抖音人生副本旁白
- POV：第二人称「你」
- 叙事路线：线性；2019年9月17日第一张新票 → 2026年9月16日第2557张 → 2026年9月17日停止
- 目标字数：2,400–3,500 字；短行是配音节奏，不为凑行数扩写
- 情绪目标：先让普通观众看懂「一张、两元、同一组417」，再让中奖成为官方结果核对，不把彩票写成神谕
- 结局：中奖1040元后把钱用于母亲的药，第二天停止购买

## 主线
- 主线类型：规则/习惯的低剂量沉沦分支；没有会说话的反派，不强行写反杀。
- 反派设计：不适用；冲突来自随机规则、时间和习惯，用官方核对与状态改变收束。
- 设定：你把母亲的生日417写进第一张福彩3D单式票，七年里每天只买一张2元新票。
- 核心行动：买一张 → 放进铁盒 → 依据官方结果核对 → 在失业、搬家、母亲用药等变化中仍不加倍、不换号 → 第2557张客观中奖 → 用1040元买药 → 停止。
- 悬念问句：你守住的到底是417，还是每天还能做同一件小事的自己？
- 一句话主线：你用七年守住一张2元新票，最后等来的不是号码有灵，而是一次可核对的中奖和一次停止。
- 主线关键词：417 / 2元 / 一张 / 铁盒 / 核对 / 药单
