# 短篇核心框架

**基本信息**
- 题材方向：复仇打脸 / 世情打脸 / 彩票爽文
- 目标情绪：憋屈累积、终极反转、降维打击、断舍离的爽感
- 字数预估：3000字左右
- 视角：第二人称（你）

**故事核**
- 起因：普通社畜中奖600万（税后480万），直觉决定**向相恋三年的女友和势利眼准岳母绝对隐瞒**。
- 核心冲突：你装穷试探，女友和准岳母以为你一辈子是个穷光蛋，在订婚前夕疯狂吸血甚至背刺（女友出轨有钱主管，准岳母索要天价彩礼）。
- 人设底色：极度清醒，中奖后拥有了上帝视角，像看猴戏一样看着周围人的丑态。
- 情绪反转（爽点）：在她们以为拿捏了你、当众撕破脸侮辱你的时候，你不再隐忍。直接退掉她们看中的房子，甩出证据反杀渣女，拿着几百万开始独美的“退休生活”。

**对标与借鉴技法**
- 借鉴技法（基于 `genre-styles/复仇打脸.md` 与 `世情打脸.md`）：
  1. **日常之恶清单化**：准岳母不仅要彩礼，还要你的父母卖掉老家房子给她儿子凑首付。
  2. **录音/监控先手**：发现出轨不吵不闹，冷眼收集证据。
  3. **信息差的降维打击**：她们以为你连两百块都要凑满减，实际上你每天在“秘密基地”规划几百万的理财。
  4. **打脸金句（冷账句）**：当面撕破脸时不骂街，用钱和证据砸人。
