## v5 规则（已写进 skill）

`skills/story-short-write/references/genre-styles/人生副本实录.md` 新增 **§2.6 快推结构**：

| 位置 | 必须完成 |
|---|---|
| 0–5% | 结果前置钩子（最狠的结果 / 数字并置） |
| 5–12% | 主线启动（核心动作、规则、赌注） |
| 12–24% | **压缩铺垫**：习惯与前史压成 3–5 个带数字的短场景，每个 ≤8 行 |
| 24–32% | **第一次大事件**（兑现 / 对质 / 承认 / 翻车 / 社死） |
| 32–50% | 峰值区（+6 以上） |
| 50–85% | **「之后」**：后果、二次交锋、代价、关系新常态（≥40% 篇幅） |
| 85–100% | 判词与收束 |

「之后能写什么」也写进了 skill：对手的二次交锋、周围人的重新定价、代价账单、主角旧习惯复发、换手复现、新常态 + 判词。

机械闸也换了尺子（`scripts/fuben_hype.py`）：
- 新增 `首个大事件≤32%`、`爆点之后≥4节点`、`后半(>50%)≥3节点`；
- 情绪死区从 ≤30% 收紧到 **≤22%**；
- 钩子行（结果前置）不再算作「大事件」，否则会假装已经启动剧情。
