# 人生副本口播 · 轻量创作 profile v13

适用：人生副本、剧本人生、第二人称人生体验口播。本文件替代 v12 与更早的累加规则，不叠加旧骨架和普通网文契约。**少配额不等于少戏：本账号默认要抓人的开头、可感知的爽感、牵引下文的伏笔钩子和有作用的侧面描写。不能把“自然、无错、过机检”当成写好了。** 用户明确指定其他目标时，以本次要求为准。

## 执行入口：借鉴的 Agent 方法

新稿、创作审核与改稿按 [人生副本 Agent 方法](人生副本_Agent方法.md) 执行对应阶段：主控比较可兑现的切口 → 主笔写连续关键戏 → 审读定位追看断点 → 按结构/场面/表达分层返工。调用方只给子 Agent 本轮所需片段，不让每个角色重读全部规则。研究或借鉴 Agent 的任务只交来源、采纳方法及接入改动，不擅自转成样稿。

## 先找到观众要追的那件事

读本题相近的真实原文，不只看拆解摘要。重点看：它让人等什么、怎样吊住期待、爽在哪里落地、别人或环境的变化怎样替主角说话。借处理方式，不搬人物经历与原句；不把转写错误当事实。材料够用就写，不要求先填设定卡和情绪表。

默认第二人称「你」、口语、具体。先抓住本题最有张力的处境和欲望：人物想得到什么，什么在挡他，观众想看到谁翻盘、谁露馅、什么被揭开。切口太平，就换入场位置或重构事件，不靠添一句“你绝对想不到”续命。

## 把追看和兑现写进正文

- **开头先发生事。** 尽早给一个反常结果、正在发生的冲突、身份错位或未完成的动作，让观众生出具体疑问。不要先讲完整背景，也不要拿题目复述充当钩子。签名式开场可以保留，后面要立刻进入本题的戏。
- **钩子带动下一步，不是一直欠账。** 解开一层，同时让行动带出新的阻力、选择或信息差；必要背景在观众想知道时补。开头许下的核心期待要在本篇得到实质回应，不把一串日常轶事接在刺激开头后面。
- **伏笔当下有用，后来变义。** 一次不合常理的阻拦、一个被藏起的物件、一句多余的解释，都可以埋线索。后面的揭示须由前面的东西长出来，不临时塞证据、贵人或新身份；呼应不是把同一个词再说一次。
- **侧面描写承担戏。** 让对手改口、旁人收起原本要说的话、一个人把刚递出的东西拿回去、环境留下不同痕迹，使观众自己看出能力、处境或话语权变化。动作要有动机并影响后续，不是轮流“震惊、僵住、脸白”，也不强迫每场都加围观者。
- **爽点要演到兑现。** 前面蓄起的憋屈、好奇、期待，需要一个看得见的变化：能力压住质疑、话被原样顶回去、伪装露馅、包袱揭开、代价反过来落下。把关键交锋、揭示和反应写到场，别用“大家都服了”“你很厉害”跳过最好看的部分。爽感不只等于反杀，但不能拿“不必反杀”替没有情绪力度开脱。

每段至少在当前故事里有去处：推进处境、改变理解、蓄积期待或兑现情绪。不按句子计数；必要的缓冲、心理与旁白可以留。删的是断掉主线的重复和闲笔，不是所有慢句。结尾可以安静，但不能用安静替代前面欠下的兑现。

## 审稿先看为什么有人愿意听

完整读当前正文，直接指出：哪句抓住了什么期待，哪段让这个期待断掉，最好的一刻是否真正展开，伏笔揭示是否成立，侧面反应是否让局面变化。**用户说“不好看”，优先改开头、主线、蓄势与兑现，不自行转去修工具、数词、建测试包。**

问题要指到原句和影响，然后拿改写回答。主线散了就重构，不只润色；不要用“我有意这么写”替代效果。不给自己凑高分，不把几个审查角度冒充独立评审。机械通过但抓不住人、爽点落空的稿，仍应转 `fuben-review` 判创作 `FIX`。

## 事实是底线，工具在后台

保留用户给定事实和剧情，分清虚构、角色误信与现实信息；必要时核查来源、数量、日期及账号约定，不伪造授权与数据。字数估时不等于配音实测。文学效果不靠八拍、峰值百分比、感官词频、对白数量或数字预算证明。

需要机械检查时用 `python3 scripts/fuben_run.py 路径 --profile full`；短版检查自己的正文并用 `--profile short`。BLOCK 修明确错误，REVIEW 结合语境判断，ERROR 不算通过。**不以机检结果替代创作审核，不以回归报告替代用户要的好稿。** 只有用户要求制作或发布时，才进入媒体及发布证据阶段。
