# 题材风格包：人生副本实录（第二人称 · 口播沉沦 / 清算志）

> 抖音「人生副本 / 剧本人生 / 体验 100 种人生」赛道专用包。来源：`拆文库/_系列总拆书.md` 对抖音爆款《剧本人生》39 篇的系统深拆（十大志 / 曲线类型学 / 家族 / 数字判词学 / 语库指纹 / 结构公式），以及本赛道 2026 实热数据的反差验证。
> 一句话定位：**把一种抽象的人生焦虑翻译成身体、器物与数字；把人生的下坠铺成编年与清单；把清算留给一个最小的单位（一碗面 / 半步 / 一秒 / 68 块 5）。第二人称「你」是代入接口——故事是别人的，痛是自己的。**
> 阅读顺序：先读 `short-craft.md` 通用底座，再读本包覆盖该文体的全部专属调性；写作时「口播气口 / 第二人称 / 记录腔」三项以本包为准，与本包冲突的网文通用默认一律让位。

## 一、这是哪个包——与 skill 既有十包的硬分工

| 对照包 | 它们的做法 | 本包为什么不同 |
|---|---|---|
| 世情打脸 / 复仇打脸 | 第一人称「我」，恶人作恶→当众打脸→报应，反派实体化 | **本包第二人称「你」，未必有恶人**——爽点在「清算自己的丑角身份 / 直面结构性死路 / 数字与器物判词」，不是打脸某个亲戚 |
| 沙雕脑洞 / 系统 | 脑洞设定、搞笑反转 | 本包是**贴着真实下沉语感的实录与沉沦**，不卖无厘头 |
| 甜宠 / 糖水 | 无冲突纯甜 | **本包禁止纯糖**——糖水志是文体税 16 分重灾区 |
| 追妻火葬场等 | 8000–20000 字网文、付费点 | 本包是**抖音口播短片：ASR 语感、~3000 字 / 3 分钟内、行=气口**，无付费点 |

**识别器（满足任一即切本包，覆盖「世情→世情打脸」的默认路由）**：
- 对标拆文 `_meta.json.genre_secondary` 含「第二人称口播 / 沉沦 / 实录 / 清算 / 编年」；
- 稿件以「今天体验的人生副本是……」「今天要体验的人生副本是——」开场；
- 项目用途是发抖音口播人生副本号，而非知乎盐选 / 小程序付费短篇。

## 二、叙述腔调（三句成篇）

1. **第二人称「你」全程在场**。允许 28b / 39 之类在结尾或某节点短暂滑向「我 / 你们」，但主体锁定「你」。它 = 代入接口，读者租一段人生，别写成旁观第三人称或教训口吻。
2. **记录腔 / 编年腔**：时间轴按「人生切片」推进（小学→中学→大学→职场 / 第 1 集→第 8 集），句子短、行=气口、可无标点分行（成文补标点但保留短句与换行节奏），像一个人在逐段念给你听，**不是章回体小说的"叙述"**。
3. **冷揭晓 > 大呼小叫**：主反转和判词用平静、甚至冷漠的口吻吐出，情绪让读者自己起。参考「做不了就提出来 / 别翻了以后也别翻了」——失望比愤怒更终审。

## 三、开篇范式（3 句定生死）

固定开场模板（不可省，是本赛道的识别点）：
```
今天体验的人生副本是
{副本题（一句话人生）}
```
- 第 2 拍立刻进入**具象化气味/器物/数字**（参考 16：皮革、冷气、古巴雪茄、路虎后排 / 13：下水道酸臭、发白起球的校服）。
- 黄金结构：**最高屈辱 / 最大底牌在同一场景引爆**（参考 04：「桌上是 14 块钱的剩炒饭，手里攥着 10 亿——你没有欢呼，只有彻骨的恐惧」）。
- 副题 = 选题钩子本身，必须**自带张力或反常**（"县城刀枪炮的父亲 / 卖肾买 iPhone4 / 世界上只剩你一个人 / 极度性压抑的男大学生"）。忌抽象题（"躺平治愈的一生"、纯粹正向题）——正面题天然低热。

## 四、选志与选曲线（先定天花板）

**写作前先在 设定.md 记下志与曲线**。志决定天花板——先天缺对抗的文体技术再好也压在 16–17：

- 高分志（优先选）：**实录志 / 沉沦志 / 清算志 / 代价志 / 加害者视角**——都带强对抗，能戳共鸣、不靠虚构惨博眼球。
- 中分志：寓言志、孤独志、身体志、温情志（**必须带苦底**才能上 21–23，纯暖必塌）。
- 低分志（避坑 / 须补张力）：糖水志、无坠落爽文志、纯警世志、软文志、暴富反写若写成"躺平满足"也归此类。

| 志 | 一句话 | 参考爆款拆篇 |
|---|---|---|
| 沉沦志 | 坠落曲线的编年（首胜免费的毒饵） | 09/21/23 |
| 清算志 | 讨嫌人设的社死（你以为的你 vs 别人眼中的你） | 13/24/30/31/37 |
| 实录志 | 行业 / 地域的白描（气候的阶级税） | 05–08/11 |
| 代价志 | 单点决策的毁灭（147 万 / 68 块 5） | 15/28b/31 |
| 身体志 | 身体即命运，每项参数都有市场价 | 19/20/25/28b |
| 温情志 | 苦底带暖（距离进度条） | 22/26/33 |

曲线参考（`_系列总拆书` 第四节）：堕落曲线 / 编年缓降 / 剪刀差 / 深谷三连 / U 型救赎 / 救赎打折 / 平台+断崖——先选曲线再排节点。**别默认写"平台糖水 + 暖流爬坡"的躺平曲线。**

## 五、六段结构公式（合集最大公约数）

1. 人生副本开题（第二人称口播签名）
2. 基线铺设（正常 / 甜 / 无敌的起点——给下坠定价）
3. 触发事件（免责设计：误点 / 被推荐 / 时代浪潮）
4. 编年下行（**清单化证据**：身体账单 / 社交账单 / 数字账单）
5. 谷底（结构性死路 + 情感性死刑的双谷为佳）
6. 反转或清算（数字判词 / 器物判词 / 钝刀判词三选一）
7. 收束二选一：灰（接受 / 少年留在过去）或暖（题眼追认 / 器物回暖）

**占比模板：11 / 20 / 25 / 15 / 17 / 12；反转置 80–85%，尾部留给余波。** 别把反转放太早，也别拖过 90%。

## 六、颗粒度纪律（本包最高优先级，最常被 AI 违背）

**每句一问："这个画面是只有这一个人、这一刻才有的吗？"——不是就删。**

- 用**专属身体细节 / 器物 / 数字**承担情绪：杀猪屠户"横肉抽搐、夹烟的手发抖"；百达翡丽"没 logo 却值一套房"；"水龙头永远修不好、滴答作响"。可被任何 AI 账号复用的句子 = 无效画面。

**库存空镜头黑名单（一旦出现即判 AI 味 / 无代入）**：
- "阳光刺眼才慢悠悠起床""睡到自然醒""早市大爷大妈讨价还价""牵着土狗散步""看云卷云舒""呼吸都顺畅了""无比踏实/松弛感""感慨人生美好"
这些是全网躺平号共用库存。出现就替换成**专属记忆**（某一单具体外卖、某条具体负债尾数、某个身体症状的第一天、某件被踩脏的鞋）。

## 七、数字判词学（反转引擎，3 条纪律）

**数字的刺痛与位数成反比**：147 万 → 48,452.31 → 15 块 8 毛 6 → 4,576 → 68 块 5。
1. 判词前必铺**数字链**（估价 / 分辨率 / 总筹码），不能裸掉一个大数。
2. **小数字承担大清算**时落差最大（68 块 5 = 解药的真实价格）。
3. 数字出现配一个**冷漠的揭晓方**（收费员 / 短信 / 账单 / 系统），不配情感旁白。

## 八、语库指纹（复用作者语感，选 3–5 个植入）

平淡重判句（失望比愤怒更终审）/ 拒绝的微缩计量（半步 / 一秒）/ 正常世界的嗅觉标记（干净的人用气味出场）/ 器物判词（面碗 / 红烧肉 / 保温桶 / 破旧风箱）/ 编年三段升级（初中→高中→大学约束递减=剂量递增）/ 无狂喜反高潮（修好了但回不去）。**写"这像谁写的"的细节，才像这个作者。**

## 九、收束（别写大团圆）

- **灰收束**：接受、少年留在过去、回归日常的钝痛。结尾留余韵 / 一个带走的判词金句，让它可传播可评论。
- **暖收束**：题眼追认 / 器物回暖，仍不搞"从此幸福快乐"。
- **禁止**：励志鸡汤总结、上价值喊口号（"这就叫通关了""你就已经赢了"类直给），除非是刻意的软文/题眼追认且符合灰·暖收束。

## 十、避坑清单（本赛道实测数据 + 本项目文体税双验证）

1. **别写"躺平 / 存钱治愈 / 彩票暴富满足"型**——本赛道此类单条实测仅约 2k 赞，且彩票题材你的账号已连发多期造成同质稀释。
2. **彩票 / 暴富若写，写成 04 式反写**（暴富=恐惧 / 围猎 / 孤独 / 身份死亡 / 锁链），不是 50 式躺平——参考 04 的"14 块炒饭 vs 10 亿 + 防弹主卧 + 疗养院镇静剂"。
3. **一篇一选题，别自我克隆**：同一骨架（打工人→中奖→瞒→躺平）连写 4 篇 = 系统判低质批量号。
4. **对仗/排比/ABAB 节奏**是网文腔，会露馅；用记录腔的短句与跳切。
5. 极端编造苦难（"惨到离谱博眼球"）有平台整治风险——用**真实颗粒 + 共鸣清算**取胜，不靠虚构惨。
6. **口播时长远低于网文字数惯性**：成稿目标 ~3000 字 / 3 分钟内；中段冗余优先砍。

## 十一、Phase 2 题材字段写法（机器验收合规）

在 `设定.md`「Phase 2 设计校验」区写：

```markdown
- 题材参考：`references/genre-styles/人生副本实录.md`
- 核心招式：{志+曲线定位}；{一个数字判词链/器物判词方案}；{开篇倒叙引爆 or 编年清单写法}[可三选二]
- 反派设计：不适用（{人生副本实录以结构/自身清算为张力，无实体恶人——除非该志需具象加害者}）
- 反转类型：{数字判词 / 器物判词 / 认知反转 / 报应兑现}
- 反转位置：第 {X} 段 ÷ 全篇（置 80–85%）
- 目标平台：抖音口播（第二人称 · ASR 语感 · ~3000 字 · 无付费点）
```

> 若对标 `_meta.json.genre_detected` = 「世情」且 `genre_secondary` 含「第二人称口播 / 实录 / 沉沦 / 清算」，**直接加载本包，不加载 `世情打脸.md`**（本包识别器优先）。
