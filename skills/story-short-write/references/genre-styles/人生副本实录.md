# 人生副本实录 · v2（2026-09-15 重排）

> v1 是 17 节、40 条门槛、16 处补丁叠出来的，每条都是「被退回后加的」，执行者平均用力，写出来是流水账。用户拿一份 3,000 字的提示词直出，效果反而更好。差别不在规则多少，在**提示词是按「拍」组织的，v1 是按「禁令」组织的**。
> v2 只做一件事：把用户提示词的八拍当骨架，把 v1 里被验证有用的东西（拆文库对位、呼应/侧面、双坐标、拆书移植、loop）折进每一拍，其余全部归档到 `人生副本实录_v1_归档.md`。**本文 ≤ 200 行，超过就是又在叠补丁。**

## 0. Loop Engineering（怎么用、怎么改本包）

**三层，顺序不可换：**

| 层 | 时机 | 命令 | 管什么 |
|---|---|---|---|
| L0 事实门禁 | 动笔前 | 人工：`设定.md` 第一节「事实核查表」 | 时间线 / 价格 / 集体记忆 / 人群生态 / 年龄闭环，每类 ≥1 条带来源 |
| L1 设计门禁 | 写正文前 | `python3 scripts/fuben_loop.py design 设定.md` | 引擎、齿轮瞬间、三件物证、社死台词、对照组数字、审判金句、八拍字数、呼应表、移植节点 |
| L2 成稿门禁 | 写完 | `python3 scripts/fuben_loop.py draft 目录/` | 八拍位置、场景拍子、生理化、时间标签、内联说话、禁词、金句可搜索 |
| L3 数据回流 | 发布 72h | `record NN 点赞 播放 备注` → `report` | 特征 × 点赞 归因 |

**改本包的唯一方式：**
- 新规则 → 只能先进 §9「advisory 池」，写明篇号 + 返工原话。
- advisory → 正文条款：`report` 里该特征在高低赞组同向 **且连续 3 篇**；或用户明确说「这条以后都这样」。
- 本包正文条款不得因单次返工重写；返工只改「拍」的示例，不改结构。
- **每次返工必须先问：这一拍缺的是「事实」「场景」还是「拍子」？** 66–71 三版返工的答案依次是：没搜事实（v1）、没用拆书情节（v2）、没有场景拍子（v3）。三样都缺，规则再多也没用。

## 1. 第 0 步：事实核查（L0，不可跳过）

写任何一个字之前，对主题做 1–3 次针对性搜索，锁定 **5 类事实**，落进 `设定.md` 第一节表格（类别 / 事实 / 来源 / 落在第几拍）：

1. **真实时间线**：主题事物的诞生年份、关键节点（例：Copilot 2021.6 / ChatGPT 2022.11 / Cursor 2023）。主角不能在工具没出现的年份用上它。
2. **精确价格 / 数字**：当年真实消费、薪资、行情（沙县鸡腿饭 / 订阅月费 / 彩礼 / 房贷月供）。数字必须符合当年，禁止「很多 / 一些 / 不少」。
3. **90/00 后集体记忆锚点**：4399、诺基亚、QQ 空间、生死狙击、床帘、蹭邻居两格 WiFi——齿轮瞬间必须是真实可考的。
4. **人群真实生态**：知乎 / 贴吧 / 小红书 >1000 赞的具体事件、黑话、行为链、身体代价。**每条原型 = 正文一个事件**，写明落在哪一拍。
5. **年龄与时间闭环**：事物诞生年 + 主角当时年龄 = 现实年份 ≤ 今天。现实不够长的（AI 才 4 年）明确分「已发生」与「副本推演」。

**拆书情节移植（并入本步）**：从 `拆文库/*/情节节点.md` 挑 ≥5 个 N#，剥壳保机制，落进对应拍；表格列「源篇 N# / 原文摘句 / 机制 / 落点」。机制清单见归档 §十六（结果前置 / 当众否认 / 物件揭底一旧一新 / 审判式提问 / 仪式代替语言 / 不肯了断 / 误接电话 / 圆场翻供 / 屏风后的观察者 / 让出机会三次 / 醉后喊错名 / 重复节拍 / 路灯下买同一样东西）。
去品牌：原型里的品牌 / 店名 / 型号一律换成「代购便宜二三十」「纯白中帮板鞋」；**阶层标记**（沙县 / 拼多多 / 地铁尾站）可以留。

搜索结果只用于校准，不进正文，不念来源。

## 2. 选题基因（写前暗中运行，写进 设定.md 第二节）

扫描主题，锁一个引擎，全篇按它驱动：

| 引擎 | 适用 | 驱动 | 拆文库模板 |
|---|---|---|---|
| **成瘾溃败型** | AI / 游戏 / 短视频 / 色 / 赌 / 熬夜 / 暴食 | 频率升级 + 身体贬值 + 社死羞辱 | 21 / 36 / 38 |
| **性格缺陷型** | 没边界感 / 讨好型 / 心机 / 杠精 / 炫耀癖 | 行为展览 + 裂痕事件 + 集体疏远 | 37 / 13 / 24 / 30 |
| **习惯溃败型** | 拖延 / 摆烂 / 乱花钱 / 躺平 | 小事失控 + 雪球滚大 + 当众崩盘 | 09 / 23 / 15 |
| **加冕型**（可选） | 逆袭 / 兜底 / 隐藏大佬 | 三次碾压 + 数字判词 + 被求 | 11 / 16 / 40 |

锁定后提炼三样，全部用第 0 步搜到的真实素材填：
1. **一个「命运齿轮瞬间」**：第一次踏错的具体场景（真实年份 + 集体记忆物）
2. **三件「沉沦物证」**：带真实价格 / 数字的实体道具（30 块遮光床帘 / 一天三次 / 38 万 8），贯穿全篇，**道具升级代替情绪描写**
3. **一个「社死名场面」**：第三者在场的公开羞辱 + 一句短狠台词 + 生理反应

**双面题（心机 / 讨好 / 表演）加一条**：每个场景写双坐标——名义功能（说出来的理由）/ 实际舞台（谁在看、换来什么）/ 暴露道具（药盒摆正过 / 哭之前拉开了床帘）。5–6 个够，不做善举清单。

## 3. 基础设定（全篇不变）

1. 全程第二人称「你」，像深夜有人平静地给你复盘你自己的人生。旁观者原型（心机舍友 / 隐藏大佬）**一律翻成当事人**：「你」就是那个心机的人 / 那个被兜底的人。
2. 全程短句，每句 8–15 字断句，1–2 行一段，方便配音。**行 = 气口**，成文可不带标点。
3. **心理写成生理**：不写紧张 / 羞耻 / 兴奋。写「心跳在胸腔里打鼓 手心渗出一层汗」「耳朵嗡嗡作响 头都不敢抬」。
4. 叙述者零评判、零说教、零鸡汤。不骂主角，不喊口号，审判权交给观众——**报应不许由叙述者宣布**（不写「你被孤立了」），只写三件旁人做了 / 没做的事。
5. 关键对话直接引用原话，内联不加引号，每段对话 ≤3 句，一句顶一千字。**内联说话 ≥15 行**（37 原文 30+）；禁的是引号问答体（≤3 行）。
6. 数字精确且与第 0 步对齐。
7. **每个场景 ≥25 行**，拍子照 37 原文开头：环境一笔（时间 + 气味 / 声音）→ 「你」连续动作 ≥4 个 → 你说话 → 旁观者身体 ≥2 处 → 第三人入场改变气压 → 你的切换写成三个连续动作 → 一个「半步 / 一瞬 / 一下」 → 收口 = 一个人退场 + 一件器物。写不到 25 行的事件不配做场景，降级成编年一句。
8. **时间标签 ≤6 个**（大一上 / 第二个月…）。编年不是年表，是三个阶段各一个具体行为（37：抢矿泉水瓶仰头倒 / 扯袖子夹子音 / 树荫下嗤笑班花），每个 4–8 行带对象和对话。
9. 呼应 ≥8 对（前置随手、回收零解释）；侧面四通道（旁观者身体 / 旁观者的话 / 环境规格 / 权力者不作为）每篇都用。主角内心句 ≤6，只许「编年自辩」和「你终于意识到」两种。

## 5. 八拍结构（2,800–3,500 字，L2 按位置检查）

| 拍 | 时间 | 字数 | 必须写全 | 拆文库对位 |
|---|---|---|---|---|
| **一 · 金句钩** | 0–10s | ~120 | 第 1 句固定「今天体验的人生副本是 {6–10 字羞耻标签}」；第 2–4 句最强反差金句：**精确数字对比 + 爽点罗列 + 溃败半剧透**，含 1 个可搜索词组（例「月入 24 万靠 AI 30 岁连 for 循环都写不出」） | 04「桌上 14 块剩炒饭 手里 10 亿」 |
| **二 · 命运齿轮瞬间** | 10s–1min | ~500 | 拍成电影：真实年份 + 时间 + 地点 + 动作 + 误入方式 + 生理海啸 + 关键抉择。四步：事发前日常 → 意外触发 → 生理海啸（心跳打鼓 / 手心出汗 / 回头看门）→ 关键抉择（你没有关掉网页）。收尾变体「命运的齿轮 就是从这个下午开始转动的」 | 38 浏览器 / 21 PG 电子 |
| **三 · 沉沦 / 飞升三级跳** | 1–2:20 | ~600 | 三级递进（初中 → 高中 → 大学 / 大一 → 大三 → 毕业），**每级同时升级：频率、道具、隐蔽或暴露程度**；每级 3–5 句白描不评价；时间踩真实事件线 | 37 编年三学段 / 25 六级升格 |
| **四 · 代价显形** | 2:20–2:50 | ~300 | 纯身体 + 物证清单 4–6 个：外貌 / 精力 / 注意力 / 体力 / 手感。禁「颓废 堕落 萎靡」 | 28b 痘疤 / 19 身高 |
| **五 · 社死名场面** | 2:40–3:40 | ~550 · 峰值 | 完整场景：时间 + 地点 + 在场者 + 导火索 + **那句短狠台词** + 生理反应 + 对方拉开距离的小动作（后退半步 / 收回手 / 视线滑过去）。结尾固定「那次之后 他再也没有主动找过你」 | 37 张静一问 / 28b 一秒钟退缩 |
| **六 · 对照组 + 感情审判** | 3:40–4:40 | ~550 | 对照组：同起点的人，精确数字拉差距（月薪 / 职级 / 婚姻），零拉踩。感情审判：亲密的人说一段实话再离开，**全片金句，直接引用，否定的是「人 / 手 / 心」不是钱** | 28 最后一碗面 / 33 |
| **七 · 镜子破防夜** | 4:40–5:20 | ~350 | 具体深夜 + 触发物；「算总账」排比 3–4 条：「从 XX 年那个下午开始 X 年里 你把多少…… 换来的是什么」，收在最痛一条；≥1 生理细节 | 15 / 34 数字判词 |
| **八 · 结局 + 余味** | 5:20–6:00 | ~350 | A 救赎线：物理戒断 → 戒断生理 → 肉体对抗虚无 → 跳到「现在」→ 清晨微小证据 → 克制收束。B 接受线：无爆发无转机，日常瞬间平静接受位置，定格。禁鸡汤 / 希望你 / 愿你 / 加油 | 37「接受了自己在这个集体中的位置」/ 36 删除文件夹 |

**峰值位置**：社死 45–60%，审判 70–78%，破防 80–88%。反转别早于 60%，别晚于 90%。
**双面题**：第五拍社死 = 外圈第一次看见舞台坐标（辅导员看到药盒照片和踹门是同一天）。

## 6. 结局二选一的判据

- 主题是成瘾 / 习惯 → 默认 **A 救赎线**（有具体戒断动作 + 现在时证据），否则观众没出口。
- 主题是性格缺陷 / 加害者视角 → 默认 **B 接受线**（37 型），醒悟反而假。
- 加冕型 → **扬收束**：被求 / 判词清算 / 题眼追认。
- 最后一句 ≤25 字，落在一件器物或一个动作。是否加开放式提问：性格型不加，成瘾型可加一句回扣齿轮瞬间。

## 7. 文风与防 AI 味

- 每 5 秒一个信息点；每段 ≥1 气味 / 声音 / 触感 / 生理。
- 长短句交错，允许「你知道吗 / 其实 / 那天」当气口。
- 禁：首先其次最后 / 综上所述 / 让我们一起 / 希望你 / 愿你 / 加油 / 任何总结陈词 / 「不是…而是」（**第七拍清算句允许一次**）。
- 金句、数字、社死台词前置，可被搜索。
- 拆文库结构句位可复用：「这种事对你来说太正常」「到了大学 你把这套用得更熟了」「这种看似稳固的 X 在 Y 出现了裂痕」「时间在不知不觉中推移 你发现周围的空气开始变得稀薄」「你终于意识到」。**每句最多出现一次。**
