**铁律 A：先改包，再出稿。** 用户任何一次返工意见到达时，第一步不是改正文，是：①把意见翻译成一条规则写进本包（§10 advisory 池或对应节）→ ②给 `fuben_loop.py` 加对应机械检查 → ③在本节「变更记录」记一行 → ④才允许动 设定.md / 正文。顺序颠倒 = 返工无效，下次同样的问题还会出现。

**铁律 B：出完必问、问完必审。** 每篇成稿过完 L2/L2.5 后，**先停下来向用户提问**（ask_user）：「正文已出，是否现在调用 `fuben-review` 三方审核？」选项：现在审 / 我先看稿再说。用户选「现在审」才跑 `/fuben-review 作品/NN_xxx/`；选「先看稿」则本轮到此为止，不得自行开审也不得继续改稿。审核报告里 VERDICT 非 PASS 的，修完再问一次。

## 1. 第 0 步：事实核查（L0，不可跳过）

写任何一个字之前，对主题做 1–3 次针对性搜索，锁定 **5 类事实**，落进 `设定.md` 第一节表格（类别 / 事实 / 来源 / 落在第几拍）：

1. **真实时间线**：主题事物的诞生年份、关键节点（例：Copilot 2021.6 / ChatGPT 2022.11 / Cursor 2023）。主角不能在工具没出现的年份用上它。
2. **精确价格 / 数字**：当年真实消费、薪资、行情（沙县鸡腿饭 / 订阅月费 / 彩礼 / 房贷月供）。数字必须符合当年，禁止「很多 / 一些 / 不少」。
3. **90/00 后集体记忆锚点**：4399、诺基亚、QQ 空间、生死狙击、床帘、蹭邻居两格 WiFi——齿轮瞬间必须是真实可考的。
4. **人群真实生态**：知乎 / 贴吧 / 小红书 >1000 赞的具体事件、黑话、行为链、身体代价。**每条原型 = 正文一个事件**，写明落在哪一拍。
5. **年龄与时间闭环**：事物诞生年 + 主角当时年龄 = 现实年份 ≤ 今天。现实不够长的（AI 才 4 年）明确分「已发生」与「副本推演」。

**拆书情节移植（并入本步）**：从 `拆文库/*/情节节点.md` 挑 ≥5 个 N#，剥壳保机制，落进对应拍；表格列「源篇 N# / 原文摘句 / 机制 / 落点」。机制清单见归档 §十六（结果前置 / 当众否认 / 物件揭底一旧一新 / 审判式提问 / 仪式代替语言 / 不肯了断 / 误接电话 / 圆场翻供 / 屏风后的观察者 / 让出机会三次 / 醉后喊错名 / 重复节拍 / 路灯下买同一样东西）。
去品牌：原型里的品牌 / 店名 / 型号一律换成「代购便宜二三十」「纯白中帮板鞋」；**阶层标记**（沙县 / 拼多多 / 地铁尾站）可以留。

搜索结果只用于校准，不进正文，不念来源。

## 2. 主线（故事核）——先于引擎，没有主线不许开写

**判据**：标题是「一类人的日常」（外卖员 / 雇佣兵 / 印度贫民窟）→ 编年实录可无主线。标题是「一个人的缺陷 / 选择」（心机舍友 / 分手男 / 二胎姐姐）→ **必须有主线**，否则观众不知道在等什么，就是流水账。

主线 = 拆文库拆文报告里的「故事核」四行，原样搬进 设定.md 第二节：
1. **设定**（一句）：谁 + 处境 + 一个反常（「她什么都不争，但她是寝室唯一在布局的人」）
2. **核心行动**（一句）：主角**主动在做**的一件贯穿全篇的事（不是"经历"，是"做"）：布局 / 记账 / 演给一个人看 / 数次数 / 接住话术
3. **悬念问句**（一句，观众全程揣着的）：她们什么时候发现 / 她会不会放你过 / 你什么时候停 / 他会不会笑一次 / 第四次是谁先动 / 第 90 天转不转正
4. **一句话主线**（≤40 字，含结果）：一拍第 2–4 行就把它半剧透出来

**来源优先级**：① 拆文库 `*/拆文报告.md ### 故事核` 的「核心行动」——去外壳留机制直接借（隐娘=用物证逼他自己认出来；掌控=不跑、留下记账、最后炸掉；泠泠=花四年演给一个人看；偏偏=一张单子把人推回去；乱葬岗=一句话压死人后账怎么还；朕=不吃这套）；② 拆文库 `情节节点.md` 拼一条；③ 网络搜索原型里带「主动行动」的那条，**第一轮没有就换关键词再搜，最多三轮**。

**主线必须带「坑 → 反杀 / 反转」**（借拆文库非副本篇的手法，骨架仍是八拍）：
| 手法 | 借自 | 落法 |
|---|---|---|
| 结果前置 + 悬念 | 隐娘 引子 | 一拍先交结果的一半（「她举报了你 结果举报信成了你的证据」），把「怎么做到的」留到六拍 |
| 信息差表 | 隐娘 §4 / 乱葬岗 §4 / 偏偏 §4 | 设定.md 写三列：读者知道 / 「你」知道 / 对手知道。中段必须有一次「对手知道到三成」的升级，六拍一次性交清 |
| 侧面埋伏 | 隐娘 物件四件套 | 反转用的物证前面至少露脸 2 次，且都由**旁人**顺手碰到（室友借电脑 / 门卫问名字），主角不解释 |
| 同一动作换手复现 | 隐娘 §7 / 偏偏 §7 | 开头对手对你做的动作 / 说的话，结尾原样由你做回去（「你人真好」「别废话 坐吧」） |
| 慢给高潮 快给仪式 | 乱葬岗 §3 | 反杀现场 ≥40 行实时；之后的年份用数字直接砸（「两年」「八年」） |
| 结局三选一 | 朕 / 偏偏 / 乱葬岗 | **爽**（对手当众吃自己挖的坑，你一句话收尾）/ **荒诞**（规则被字面执行到全员失语）/ **甜**（偏偏式：第四次是他先动，误会当场清零）。默认不用「平静接受」——只有性格缺陷型没有对手时才允许 |
| 对手最后一个动作 | 乱葬岗 结尾 | 末三行之一必须是对手的身体反应（手停在半空 / 转口赶人 / 没敢抬头） |

**清单式反杀（「举报六条 / 三条罪状 / 五个括号」这类逐条翻盘）的硬规则**——66 v6 的六条被用户打回「看不懂、和主题不符」，原因是每条都是作者自己发明的抽象罪名（「私自参加评优以外的项目」「拿了导师名单」），观众没有现成认知，翻盘物证又是另一个抽象物（「座位记录」「申报表编号」），一条要脑补两次：
0. **直白测试（先于一切）**：每条罪名 = 举报人**当面跟老师告状会说的那句话**，口语、不带任何学校术语，初中生能懂；写完把专有名词（评优 / 综测 / 推免 / 经手人）全删，还能懂才算过。物证那一行同样：不写「经手人那一栏」，写「让人签字的地方 写的是她自己的名字」。感同身受来自**观众也经历过的寝室场景**（装睡偷偷学 / 说不保研骗我们 / 分享资料结果她考第二 / 拉开帘子问是不是偷着学），搜到什么用什么，先搜后写。
1. **罪名必须来自搜索到的真实举报清单**，用观众一眼认识的词：保研题 = 志愿时长刷的 / 综测证书假的 / 论文挂名 / 考试给人抄 / 夜不归宿 / 骗助学金；职场题 = 迟到 / 报销 / 泄密 / 越级；不许自造。搜索结果里没有的罪名不许写。
2. **罪名与物证必须是同一个东西的正反面**：举报「志愿时长是刷的」→ 物证就是那本时长簿和签字的人；举报「评优放弃说明成绩有问题」→ 物证就是那张评优表，上面有举报人自己的签名。不许「夜不归宿 → 座位记录」这种要跳一步的。
3. **每条 ≤6 行**：罪名一行（用举报人的原话）→ 物证一行（一个实物 + 一个签字的人）→ 旁人一个身体动作。六条总长 ≤40 行，剩下的行数留给对手的身体。
4. **顺序 = 前文埋伏顺序**：第 N 条对应「课件 第 N 张」，前文每张出现时必须写出那张纸上具体是什么（不是「第三张」三个字），读者在反杀现场是**认出来**，不是被告知。
5. **至少两条要反咬到举报人自己身上**（她的签名 / 她发的消息 / 她拍的截图），否则只是自证清白，不是反杀。
6. 清单读完，收一句旁人的话，≤12 字，用举报人自己的词（「你举报的六条 都是她的加分材料」）。

**沉沦型分支（对手 = 系统，不是人；设定.md 写 `主线类型: 沉沦`）**：彩票 / 网赌 / 分期 / 卖号找回这类题，「坑」是主角自己挖、「反杀」由系统完成。八拍不变，上表五项按下面换算，loop review 读到 `主线类型: 沉沦` 自动切换正则：
| 手法 | 沉沦型落法 | 借自 |
|---|---|---|
| 结果前置 | 一拍先交「你回到了同一张塑料凳上」这一半，把「中间那一千万怎么没的」留住 | 04 反写开局「你没有欢呼」 |
| 信息差表 | 读者知道 = 概率 / 系统规则；你知道 = 「规律」「守号」「天选」；对手（系统）知道 = 你是数据点。中段升级 = **旁人第一次看出你上瘾**（老板娘「今天打了多少了」/ 你妈翻到票根） | 21 猎手叙事「完美的新增数据点」 |
| 侧面埋伏 | 物证 = 首张票 / 走势图 / 站里的凳子，由旁人碰到 ≥2 次 | 04 单物件双义（14 块炒饭） |
| 换手复现 | 开头系统/旁人对你说的话（「明天再来」「守着 会中的」），结尾由你对下一个新人说 | 02/03 回环结尾；04 待补强项「疗养院外一个刚买彩票的人」 |
| 数字反向 | 每拍一组：账户 ↓ 与单注 ↑（2 元 → 2 万 → 4 万 → 8 万）同屏 | 04 数字反向 / 21 数字坠落线 |
| 回本三部曲 | 「条件 + 路径 + 退出承诺」自我谈判句，三拍到七拍各念一次，措辞一次比一次短 | 21 |
| 系统末动作 | 末三行之一是**系统的动作**：机器吐票 / 老板娘递票 / 屏幕跳号，替代「对手身体反应」 | 04 「门在你身后关上」 |
| 结局 | 默认 B 接受 + 回环（成瘾题按 §7 可给 A，但 04/21 数据支持 B 更硬）；末句落在票或凳子 | 04 / 21 |

**每场景必须过主线尺**：写完一场问一句「这场让核心行动 推进 / 受阻 / 被揭示 了哪一步？」三者都不是 → 删，不管写得多好。设定.md 八拍表加一列「主线动作」，八拍里 ≥6 拍要有。

## 3. 选题基因（写前暗中运行，写进 设定.md 第三节）

扫描主题，锁一个引擎，全篇按它驱动：

| 引擎 | 适用 | 驱动 | 拆文库模板 |
|---|---|---|---|
| **成瘾溃败型** | AI / 游戏 / 短视频 / 色 / 赌 / 熬夜 / 暴食 | 频率升级 + 身体贬值 + 社死羞辱 | 21 / 36 / 38 |
| **性格缺陷型** | 没边界感 / 讨好型 / 心机 / 杠精 / 炫耀癖 | 行为展览 + 裂痕事件 + 集体疏远 | 37 / 13 / 24 / 30 |
| **习惯溃败型** | 拖延 / 摆烂 / 乱花钱 / 躺平 | 小事失控 + 雪球滚大 + 当众崩盘 | 09 / 23 / 15 |

锁定后提炼三样，全部用第 0 步搜到的真实素材填：
1. **一个「命运齿轮瞬间」**：第一次踏错的具体场景（真实年份 + 集体记忆物）
2. **三件「沉沦物证」**：带真实价格 / 数字的实体道具（30 块遮光床帘 / 一天三次 / 38 万 8），贯穿全篇，**道具升级代替情绪描写**
3. **一个「社死名场面」**：第三者在场的公开羞辱 + 一句短狠台词 + 生理反应

**双面题（心机 / 讨好 / 表演）加一条**：每个场景写双坐标——名义功能（说出来的理由）/ 实际舞台（谁在看、换来什么）/ 暴露道具（药盒摆正过 / 哭之前拉开了床帘）。5–6 个够，不做善举清单。

## 4. 基础设定（全篇不变）

1. 全程第二人称「你」，像深夜有人平静地给你复盘你自己的人生。旁观者原型（心机舍友 / 隐藏大佬）**一律翻成当事人**：「你」就是那个心机的人 / 那个被兜底的人。
2. **短行体**（实测原文：均 9–10 字/行、>18 字的行 = 0、≥300 行）：一行只装一个动作或一个感官，>18 字必拆，拆在动词后。行的七种构造、八拍实测位置、11 步场景拍子见同目录 `人生副本_通用骨架.md`（L2 已按 ≥280 行 / 无长行 检查）。
3. **心理写成生理**：不写紧张 / 羞耻 / 兴奋。写「心跳在胸腔里打鼓 手心渗出一层汗」「耳朵嗡嗡作响 头都不敢抬」。
4. 叙述者零评判、零说教、零鸡汤。不骂主角，不喊口号，审判权交给观众——**报应不许由叙述者宣布**（不写「你被孤立了」），只写三件旁人做了 / 没做的事。
5. **对白是稀缺品，不是节拍。** 拆文库实测：04 彩票 0 行对白、39 蛀虫 1 行、28 4 行、37 5 行（之前写的「37 原文 30+」数的是含「说」字的行，其中「没有说话 / 一边说一边站起身 / 与其说是打」都不是对白——这条错门槛让 66–72 的对白行冲到 17–30%）。规则改为：**全篇直接引语 ≤12 行、≤ 总行数 3%**；一场戏最多一来一回（2 行），第三句必须换成动作或旁人身体。对白只留三种：① 社死那句短狠台词；② 换手复现要原样念回去的那句；③ 旁人一句实话（审判）。其余信息一律走**转述**（「她问你数学是不是最高 你说是蒙的」→ 「她问你数学 你说蒙的」再压成「她问数学 你没接」）或走动作（「你说 好」→ 「你点头」/ 直接删）。「你说 好」「他说 行」「她说 嗯」这类应答行**零容忍**，一律删。
5b. **「她 / 他」是读者最容易迷路的地方。** 出场人物 ≥2 时，每个新段落、每次换人说话、每个动作句的主语**第一次出现必须用名字或身份**（林悦 / 周雨 / 系办老师 / 老板娘），之后同一段落内才可用她。连续两行主语不同的人，两行都写名字。旁人一律给身份词，不给「一个女生」「有人」。lint 会数：前 6 行里出现 ≥2 个人名却写「她」= 模糊。
5c. **初中生测试**：全篇不许出现学校 / 公司黑话（评优 综测 推免 经手人 申报 编号 绩点 OA KPI 复盘 对齐 赋能），换成观众口语（评优 → 让名额 / 奖学金；经手人 → 让人签字的地方）。
6. 数字精确且与第 0 步对齐。
7. **每个场景 ≥25 行**，拍子照 37 原文开头：环境一笔（时间 + 气味 / 声音）→ 「你」连续动作 ≥4 个 → （至多一句话，或不说）→ 旁观者身体 ≥2 处 → 第三人入场改变气压 → 你的切换写成三个连续动作 → 一个「半步 / 一瞬 / 一下」 → 收口 = 一个人退场 + 一件器物。写不到 25 行的事件不配做场景，降级成编年一句。
8. **时间标签 ≤6 个**（大一上 / 第二个月…）。编年不是年表，是三个阶段各一个具体行为（37：抢矿泉水瓶仰头倒 / 扯袖子夹子音 / 树荫下嗤笑班花），每个 4–8 行带对象和动作，对话走转述。
9. 呼应 ≥8 对（前置随手、回收零解释）；侧面四通道（旁观者身体 / 旁观者的话 / 环境规格 / 权力者不作为）每篇都用。主角内心句 ≤6，只许「编年自辩」和「你终于意识到」两种。

## 7. 结局二选一的判据

- 主题是成瘾 / 习惯 → 默认 **A 救赎线**（有具体戒断动作 + 现在时证据），否则观众没出口。
- 主题是性格缺陷 / 加害者视角 → 默认 **B 接受线**（37 型），醒悟反而假。
- 加冕型 → **扬收束**：被求 / 判词清算 / 题眼追认。
- 最后一句 ≤25 字，落在一件器物或一个动作。是否加开放式提问：性格型不加，成瘾型可加一句回扣齿轮瞬间。

## 8. 文风与防 AI 味

- 每 5 秒一个信息点；每段 ≥1 气味 / 声音 / 触感 / 生理。
- 长短句交错，允许「你知道吗 / 其实 / 那天」当气口。
- 禁：首先其次最后 / 综上所述 / 让我们一起 / 希望你 / 愿你 / 加油 / 任何总结陈词 / 「不是…而是」（**第七拍清算句允许一次**）。
- 金句、数字、社死台词前置，可被搜索。
- 拆文库结构句位可复用：「这种事对你来说太正常」「到了大学 你把这套用得更熟了」「这种看似稳固的 X 在 Y 出现了裂痕」「时间在不知不觉中推移 你发现周围的空气开始变得稀薄」「你终于意识到」。**每句最多出现一次。**

## 12. 66 发布复盘（抖音数据差 · 评论「乱七八糟」）——通篇深读后的诊断，新篇开写前必须过的 6 把尺

**先说结论**：66 前十版改的全是表面（对话比例 / 指代 / 术语 / 清单行数），没有一版碰到真正的病。通篇读下来，观众看不懂不是因为句子，是因为**立场、常识、机制**三样全乱。

### 12.1 诊断（按严重程度）

| # | 病 | 66 里的证据 | 观众感受 |
|---|---|---|---|
| 1 | **主角站在反派的位置上** | 林悦全篇做的事：让床、让奖学金请火锅、发导师名单「你要用就用」、拍肩膀。她唯一的「恶」是最后那次告状——而那次告状是「你」故意把文件夹放桌面钓出来的。「你」从军训第一晚就开始给室友记账 | 「这女的才是心机」「室友对她这么好」——观众替对手抱不平，爽点全部反向 |
| 2 | **让出去的东西没有代价** | 每一次让都是「让 0.5 换 2」，让的当场就赚了。三年没有一次真疼 | 没有压抑就没有释放；「不争」变成了「算计」 |
| 3 | **制度常识全是错的** | 奖学金靠签一张表就能让给别人 / 图书馆闭馆盖章盖在借书卡上 / 搬作业算志愿时长 / 没选课去办公室问一次题就进项目 / 辅导员把举报信当加分材料 / 导师的「抄送人」 | 大学生观众一条条挑刺，评论区变成找茬现场 |
| 4 | **机制过载** | 课件文件夹 + 旧课件 + 借书卡 + 时长簿 + 演算纸 + 名单 + 白药盒褪黑素 + 毛肚 + 推表换手 + 「你人真好」换手 + 「账」 | 十一个道具，只有 3 个真回收；药盒、褪黑素、旧课件是死线 |
| 5 | **动机只有两行** | 「你从小就知道 什么都不要的人 别人才放心」 | 没有伤口，观众不知道她为什么要这样活；只剩「她就是这种人」 |
| 6 | **一拍没交代谁坏** | 一拍只说「室友告了你 六件事全给你加分」——观众 3 秒内不知道该站谁 | 抖音 3 秒不知立场直接划走 |

### 12.2 六把尺（写进 设定.md「## 观众立场」节，L1 机械检查存在性；已发布篇标 `状态: 已发布冻结` 免检）

1. **谁先出手尺**：对手必须在 20% 之前做一件**观众公认的恶事**（抢、骗、当众羞辱、拿走属于你的），并且是对手主动，不是「你」钓出来的。「你」全篇只准**反击**，不准**设局害善人**。设定.md 写一行 `对手首恶: 第 N 行 / 做了什么 / 你失去了什么`。
2. **代价尺**：「你」每次让 / 忍 / 退，必须写出**当下真实的损失**（钱、机会、脸面、身体），当场不许回本；回本只能在反杀现场一次性兑现。设定.md 写「代价表」：让什么 / 当时疼在哪 / 什么时候才拿回来。三行以上。
3. **常识尺**：每一个制度性事件（评奖、保研、举报、处分、盖章、报销、合同）写进 设定.md「常识核查表」：事件 / 现实里怎么办的 / 来源链接。**搜不到就不许用**。66 的六条里有四条搜不到现实依据。
4. **机制上限尺**：全篇道具 / 机制 ≤ 3 件，每件必须出现 ≥2 次并在末段回收；写完用 grep 数一遍，多出来的删。
5. **伤口尺**：动机段 ≥ 12 行，要有一个**具体事件**（几岁、在哪、谁、说了什么），不是「你从小就知道」这种总结句。
6. **3 秒立场尺**：一拍前 5 行必须让观众知道①谁欺负谁 ②「你」失去了什么 ③结局你赢了。缺一条重写一拍。

### 12.3 对旧规则的修正
- §2 清单式反杀第 5 条「至少两条反咬到举报人」——保留，但前提是尺 1：反咬的必须是**她先做过的恶**，不是她的好意（66 里「你要用就用」这句好话被拿来反咬，观众反感）。
- §2 「侧面埋伏由旁人碰到 3 次」——降为 2 次，且不许用「故意把文件夹放桌面」这类主角钓鱼动作充当埋伏。
- §8 结构句「这种事对你来说太正常」「时间在不知不觉中推移 空气稀薄」在 66 里都是硬贴，位置没有对应事件 → 改为：**结构句只能跟在一个具体事件后面**，前一行必须是动作或物件。
- L2.6 的对话 / 指代 / 术语 lint 保留，但**它们是最后一道，不是第一道**。66 的教训：前十版全在过最后一道，第一道（立场）从来没检查过。顺序改为：立场尺 → 常识尺 → 主线 → 八拍 → 文字 lint。
