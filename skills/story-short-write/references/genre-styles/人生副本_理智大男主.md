# 题材风格包：人生副本 / 男频理智大男主

> **一句话定位**：拒绝恋爱脑、拒绝舔狗、拒绝刻意装逼。核心卖点是主角在获得巨大财富/底牌后，展现出的**“极度情绪稳定”与“成年人的绝对理智”**。不与小丑对骂，通过【信息差】和【核心资产证明】进行阶级维度的降维打击。

---

## 1. 叙述腔调与口播网感
- **第一人称沉浸式**：自带短视频“纪录片旁白”感。语言极简、冷酷、直接。
- **Show, Don't Tell（去说教化）**：严禁出现“我没有像三流爽文那样大喊大叫”、“我是一个极度理智的人”这种自我标榜的废话。理智必须通过**“查出巨款后面不改色”、“遇到挑衅平静无视”**等具体动作展现。
- **微观细节当刀**：用极其精确的数字和物件锚定真实感（如：63,412.5元的网贷、5000块的背锅罚单、带着泥水的假潮牌鞋）。

## 2. 核心爽点机制：降维打击
- **信息差爽感**：反派（职场恶霸、吸血亲戚）以为主角是底层耗材，疯狂跳脸输出；主角手里捏着千万底牌，像看猴戏一样看着对方表演。
- **打脸不靠争吵，靠资产与抽离**：反派叫嚣时，主角对白极少。最终绝杀是**甩出核心资产铁证（如全款房产证）**，然后直接抛弃旧生活（“破出租屋留给你”），完成物理和阶级上的双重抽离。
- **警惕“暴发户式炫富”**：不要写“给豪车猛按喇叭”、“用钱砸人”。豪车（如小米SU7）的作用是为了给伴侣圆梦或代步，核心的阶级碾压永远来自于“不动产”和“从容的心态”。

## 3. 感情线逻辑（清醒护妻）
- **绝不倒贴与防范吸血**：面对有原生家庭泥沼（如扶弟魔）的女主，男主绝不盲目给钱填无底洞。**钱永远是男主的**。
- **大男主的顶级浪漫**：男主的爱体现在“护城河”。不给你钱，是为了不让你被家人吸血；但我为你买下安保极严的大平层，为你兜底人生，只要你不背叛，我就是你一辈子的底气。

## 4. 黄金开局与逻辑闭环
- **开局黄金 3 秒**：直接使用“150字倒叙钩子”交代最激烈的冲突、最反常的逻辑和最终的绝杀画面。
- **痛点与底牌的瞬间碰撞**：正文开局必须将“主角受到的最大屈辱（如替人背锅）”和“底牌揭晓（查出千万大奖）”放在同一时间、同一场景。
- **严密的现实逻辑（Bug清零）**：
  - 暴富后不上班，必须对身边人有合理的掩护（如谎称接了远程外包）。
  - 大额消费（买房买车）必须有情感或现实动机（如撞破女主被原生家庭吸血，需要建立物理壁垒）。
  - 牵涉租房、辞职等社会规则时，必须符合现实（租房只能送出剩余租期，不能送押金；辞职要走OA系统等）。
