# 人生副本 · 通用骨架（拆文实测 · v7，2026-09-18）

> 这份文件回答一个问题：**同一套事实，怎么排才好看。**
> 它是从 `拆文库/01 / 04 / 13 / 15 / 21` 等篇的情绪曲线与节点位置里量出来的观察区间，不是写作配额；节数不固定，**没有「必须八拍」这回事**。
> 配套机制与爽点池见 `人生副本实录.md` v9；
> 机械闸 `scripts/fuben_hype.py`、`scripts/fuben_loop.py`。

## 一、先画三张图，再写正文

### 1. 事实/对象图

```text
对象名称/身份 | 首次出现时间地点 | 数量/金额/规则 | 谁能看见 | 后段如何回收
```

示例：`一张新的2元双色球单式票 | 2019-09-17彩票站 | 每天只一张、固定03 07 12 19 24 31+09 | 你/母亲/老板娘/陈哲 | 官方结果核对后放回铁盒`

### 1.5 跨度图（v5 新增：长期题必填）

```text
不变的参照（从头到尾不变的那件东西） | 同一动作（重复出现的那个动作） | 第1次细节 | 第2次细节漂移 | 第3次细节漂移
```

示例：`彩票站第三张塑料凳 | 每天一张2元、折三折、进铁盒 | 铁盒里1张 | 甩进第365张、盖子开始紧 | 第2558张、盖子合不上`

- 不许写「第一年…第二年…」的年表；跳年只允许「时间 + 一个物件降级」的单行。
- 兑现/转折之前的内容占比 ≥10%，且至少有两次同形不同细节的一天。
- **压缩段必须落地**：前史段结束时用一句把镜头拉回当下（现在几号、你在哪、手里拿着什么），不许从七年前直接切进下一场；跨度题写 `## 转场表`（压缩段 → 回位句 → 正文锚点 ≥2 行）。

### 1.6 钱的去向图（v5 新增：兑现/暴富题必填）

```text
笔数 | 金额 | 类别（补欠/场面/给自己人/借出/亏/被骗） | 他人反应 | 正文锚点
```

- **补欠**（没钱时想买没买的、旅游、把当年请不起的客请够）+ **场面**（车房席面）≥ **70%**，**补欠 ≥4 笔**；**借出 = 0 笔**（钱不能是借完的）；被骗 ≤1 笔且不得是归零主因；亏 ≤15% 且必须自己拍板。
- **花光的底气**（必填）：他为什么敢花——一句话、带数字（「一注五百万，再中一次就都回来了」「你花掉的是一期，不是那四百万」）；正文出现 ≥2 次，一次在花钱中段、一次在结尾习惯段；「换了号以后一次都没中过」必须明写，底气结尾不破。
- 忘本写成筛爽的：**来借钱的不借，来吃饭的都请**——穷时别人决定他坐哪桌，现在他决定谁上桌。
- 结尾余额 = 到账 + 变卖 + 收回 − 各笔，误差 0。

### 2. 爽点/情绪图（v3 新增，缺这张图不许开写）

```text
位置% | 情绪值 | 事件 | 判定类型 | 正文锚点
```

- 第一格必须是钩子（≤22%），中间必须有一个 ≥+5 的峰值（25%–48%），后段必须有一个 ≤−6 的谷底，结尾必须落在数字或器物上。
- 相邻两格之间不得超过全文 30%：超过就是「年表区」，观众会划走。

### 3. 因果/状态图

```text
上一状态 → 触发（为什么现在） → 主角动作 → 客观结果 → 下一状态
```

没有箭头就不是剧情，只是年份和漂亮句子的并排。

## 二、情绪值口径（沿用拆文库五维标记）

| 值 | 含义 | 用法 |
|---|---|---|
| +5…+8 | 大爽点：兑现、被围观、打脸、称呼翻转、数字砸脸 | 每篇 2–4 个，峰值一个 |
| +1…+4 | 小爽点 / 暖点：被看见、物件找回、姿态爽点 | 每隔 150–250 字补一个 |
| 0 | 状态点：习惯形成、关系定型 | 只用来换气 |
| −1…−5 | 代价：羞辱、借钱、被骗、身体账单 | 必须能说出是谁做了什么 |
| −6…−9 | 谷底与判词：余额见底、关系清零、判决数字 | 放在 70%–90%，不要提前用光 |

## 三、常用节拍（按位置排，不按拍数排）

| 位置 | 功能 | 拆文库对位 |
|---|---|---|
| 0–5% | 结果前置钩子：数字并置、最痛判词、或直接甩出最狠的结果 | 04 N1、67 原稿 |
| 5–12% | 主线启动：核心动作 / 规则 / 赌注说清楚 | 01 N1–N3、21 N2 |
| 12–24% | 压缩铺垫：习惯与关系用 3–5 个短蒙太奇带数字推过去；长期题用「同一动作重复 + 细节漂移」，**不许年表罗列** | 13 N4–N9（但只留最狠的几段）、01 时间操控 |
| 24–32% | **第一次大事件**：兑现 / 对质 / 承认 / 翻车 / 社死 | 04 N5、16 N5 |
| 32–50% | **峰值区**：最高的那一次兑现或交锋 | 04 N6、15 N13 |
| 50–70% | 之后·对抗：欠债的人、笑过你的人、想复制你的人一一结账 | 04 N7、21 N11–N13 |
| 70–85% | 之后·代价：余额、药单、位置、关系出账 | 15 N18–N19、21 N18 |
| 85–100% | 判词与收束：数字 / 器物 / 一句换手 | 01 N22、04 N16 |

**v4 的核心变化**：爆点从「留到 75% 揭晓」改成「30% 之前就发生」，后面 70% 全部写「之后」。铺垫不是删掉，是压成蒙太奇。

**v5 的核心变化**：压时间不等于删生活——跨年段落要写成「同一天反复出现、每次只换一个细节」，兑现前的生活占比 ≥10%；兑现后的钱必须**主动花掉/给掉**（花+给 ≥60%，被骗 ≤1 处）；结尾的习惯原样运行、内容漂移（旧做法 → 新做法 → 他自己的说法；**对象 + 规模两维一起变，买得更多**）。三张图变五张图。

规则题、习惯题也走同一张表：**兑现可以小（一次中奖、一次被叫哥），但不能没有**。

## 四、单场景最小拍子

```text
场景可辨（谁、在哪、手里拿着什么；**时间仅当它本身是信息时嵌句尾出现**，不做分段器）→ 触发动作 → 主角连续动作 → 物件/规则留下证据 → 旁人或环境产生反应 → 状态改变 → 下一步有理由
```

只有真正改变风险、资源、信息、关系或决定的事件才扩成场景。对白一场一问一答以内；转述能过就转述，但打脸台词要直引。人物超过一个时，新主语先用身份/名字。

## 五、写作 Loop

```text
读取同型拆文（只记机制与位置）
→ 事实锁
→ 爽点表（位置/情绪值/锚点）
→ 情绪节拍表（6–10 节）
→ 对象台账 + 因果/状态台账 + 跨度图 + 钱的去向图
→ 正文
→ fuben_run.py（事实 + 爽点 + 成稿）
→ fuben_hype.py 复核 → fuben-review 人工一遍读懂
```

门禁失败时：缺爽点改位置与事件，缺事实改锁与数字；**不许用「润色得更文学」掩盖没有爽点，也不许用「事实更严谨」掩盖剧情不动。**
