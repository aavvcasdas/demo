### 0.5 对标样本的性质（2026-09-13 用户澄清）

### 0.4 本包的结构性问题（report 之外的人工审查）
0. **最根本的**：本包建立至今 **0 篇过百赞**。对照样本是 10w+ 的 39 篇，差三个数量级——这不是「哪条规则没做到」的问题，是**做到了所有规则也没用**。在拿到第一篇正样本之前，本包所有 BLOCK 都应视为假设。
1. **节序混乱**：十四、十五排在十二、十三前面，6.6 排在 6.5 前面，15.10 排在 15.9 前面——是补丁叠加的痕迹。执行者读到 §十四的「品牌≥4」和 §15.1 的「去品牌化」会同时遵守，65 v1 就是这样出的品牌。
2. **同一件事三处规定且互相冲突**：对话上限在 §6.6 / §14 / §15.7 各写一次；细节在 §七 / §7.1–7.5 / §14.1 / §14.2 各写一套（§14.2 还在要求「每 300 字一个品牌/型号/价格」）。
3. **没有任何一条是「可以不做」的**：全部是门槛，没有优先级。执行者在 40 条 BLOCK 下会平均用力，结果是每条都做到 60 分——61 就是这样：质地满分、剧本零分。
4. **缺失的层**：没有「选题层」规则。57/62 成功的共同点（加害者以为自己是受害者 / 没有坏人只有制度）和 58–61 失败的共同点（撞正主、无代价、自怜视角）都是选题层的事，而本包 90% 篇幅在写成稿层。

## 二、叙述腔调（三句成篇）

1. **第二人称「你」全程在场**。允许 28b / 39 之类在结尾或某节点短暂滑向「我 / 你们」，但主体锁定「你」。它 = 代入接口，读者租一段人生，别写成旁观第三人称或教训口吻。
2. **记录腔 / 编年腔**：时间轴按「人生切片」推进（小学→中学→大学→职场 / 第 1 集→第 8 集），句子短、行=气口、可无标点分行（成文补标点但保留短句与换行节奏），像一个人在逐段念给你听，**不是章回体小说的"叙述"**。
3. **冷揭晓 > 大呼小叫**：主反转和判词用平静、甚至冷漠的口吻吐出，情绪让读者自己起。参考「做不了就提出来 / 别翻了以后也别翻了」——失望比愤怒更终审。

## 三、开篇范式（3 句定生死）

固定开场模板（不可省，是本赛道的识别点）：
```
今天体验的人生副本是
{副本题（一句话人生）}
```
- 第 2 拍立刻进入**具象化气味/器物/数字**（参考 16：皮革、冷气、古巴雪茄、路虎后排 / 13：下水道酸臭、发白起球的校服）。
- 黄金结构：**最高屈辱 / 最大底牌在同一场景引爆**（参考 04：「桌上是 14 块钱的剩炒饭，手里攥着 10 亿——你没有欢呼，只有彻骨的恐惧」）。
- 副题 = 选题钩子本身，必须**自带张力或反差**：清算弧取"反常/刺痛"（"县城刀枪炮的父亲 / 卖肾买 iPhone4 / 极度性压抑的男大学生"），爽弧取"下行标签 vs 反杀"（"被全村看扁的机修工 / 从流水线爬到…"）。真正低热的是**无冲突**题（"躺平治愈的一生"这种既不痛也不爽的），不是正向不行。

## 六、逆袭加冕弧（爽点叠加模块：人生副本骨架 × 爽文爽点）

> 目标读者看腻了纯躺平、也看腻了悬空爽文——他们要的是「今天体验的人生副本是 X 的一生」这个编年容器里，你**靠真实的本事 / 洞察 / 机会，在人生的几道关卡上一次比一次碾压那些看扁你的人**。参考源爆款：11（种姓低贱者借机能上位）/ 16（县城强权继承的加冕）。爽来自「被定义没出息的人，一步步把定义他的人踩在脚下」。

### 6.1 骨架仍是人生副本（不许丢的壳）
- 第二人称「你」+「今天体验的人生副本是……才…的一生」开题 + 编年切片（18岁→25→30…或第一集→第N集）+ 短句口播 + 器物/数字/身体细节判词。**绝不能让位成第一人称网文，也不能砍成单一冲突场景（那是 51 的毛病）。**

### 6.2 爽点三件套（要在编年上铺出至少 3 个碾压点，别只有一次爆发）
| 爽点型 | 机制 | 源文/做法参考 |
|---|---|---|
| 轻视→失手 | 前期所有人判你死（老师/亲戚/主管下定义），你记一笔 | 编年开头铺 1–2 个「定义句」，它们是后面被清算的伏笔 |
| 露一手（手艺/洞察碾压） | 一个关键场景当众证明价值，让定义你的人哑口 | 第 2–3 段给 1 个「会一样别人不会的」硬通货 |
| 位置倒转（被求/被打脸） | 当年踩你的人，如今低头来求你；用数字/器物判词清算 | 结尾反转置 80–85%，配冷漠揭晓方 |

**爽点间隔纪律**：别挤在一段，按六段公式把碾压点均匀放在 ~30% / ~55% / ~85%；每次碾压给一个能记住的「实物判词」（一份合同 / 一张转账 / 一个头衔 / 一台机器），别只靠情绪。

### 6.3 爽要爽得「贴地」（下沉翻盘专用）
- 爽点必须**建立在真实社会逻辑上**：靠一门手艺、一个证书、一笔攒下的本金、一次不被忽悠的清醒，或一个冷门机会——不是天降金手指，不是「我是隐藏大佬」。读者越信，越爽；越悬浮，越出戏。
- 下沉打工人翻盘最吃香的三类硬通货：**技术过硬**（修机器 / 会看图 / 手艺）、**眼光清醒**（看懂行情 / 不被画饼 PUA）、**攒得住**（现金流本钱）。至少给主角一样，且让它在编年里被反复验证。
- 每次碾压带**具体损失落在施害者身上**（失业 / 丢单 / 下不来台），读者才解气。

### 6.4 数字判词在爽弧里怎么用
爽弧仍用第八节数字判词：铺数字链（学徒工资 1800 → 接单 200 → 第一桶金 8 万 → 被求时报价翻了 40 倍），结尾用一个小数字/大数字反差做判词。**小数字涨成大数字的过程本身就是爽。**

### 6.6 爽弧的对话纪律（2026-09-13 新增，65 号返工教训）
爽文≠对峙戏。65 v2 把三个碾压点全写成「你说 / 老板说 / 律师说」的短剧对白，对话行占比 38%，被退回。**逆袭加冕弧一样受第十四节 ≤3% 对话门槛约束**——14.3 的「对话不限比例」只对迷因志/荒诞志开放，爽弧不享受。
- 碾压不用嘴：用**文件、数字、器物**兑现（一份裁决书的三行金额 / 一个文件夹的厚度 / 88 张钟的照片 / 打卡机导出的 66 次 9 点半前）。对方的失手写成**身体与器物**（律师翻文件的手停在第三页 / 老板的保温杯没再拧开）。
- 全篇至多 **1 场正面台词**，放在位置倒转点（~85%），且只给对手一句、你不接。你的「回击」永远是动作：把文件夹推过去、把合同翻到第三条、把钟的照片按日期排开。
- 前期「定义句」（「你们00后」「都是自己人」「看表现」）允许以**转述**出现（老板说的是自己人，签合同这三个字他没提），不写成问答。
- 数字链与感官仍按 §十四：≥12 个带单位价格 / 感官词 ≥6‰ / 品牌 ≥4 / 第二拍落到皮肤。写完跑 `check_fuben_texture.py`（默认模式，**不要**用 `--mode comedy`）。

### 6.5 收束：爽弧用「扬」不用「灰」
逆袭篇走**题眼追认 / 器物回暖 / 被求加冕**的扬式收束（当年那位来求你，你把当年的定义句原样还回去，或把它轻轻放下）——这才是加冕弧的高点，别强行灰。但仍**禁止**直给喊口号式鸡汤（"你就赢了"）。结尾留一个带走的判词金句。

## 七、颗粒度纪律（本包最高优先级，最常被 AI 违背）

**每句一问："这个画面是只有这一个人、这一刻才有的吗？"——不是就删。**

- 用**专属身体细节 / 器物 / 数字**承担情绪：杀猪屠户"横肉抽搐、夹烟的手发抖"；百达翡丽"没 logo 却值一套房"；"水龙头永远修不好、滴答作响"。可被任何 AI 账号复用的句子 = 无效画面。

**库存空镜头黑名单（一旦出现即判 AI 味 / 无代入）**：
- "阳光刺眼才慢悠悠起床""睡到自然醒""早市大爷大妈讨价还价""牵着土狗散步""看云卷云舒""呼吸都顺畅了""无比踏实/松弛感""感慨人生美好"
这些是全网躺平号共用库存。出现就替换成**专属记忆**（某一单具体外卖、某条具体负债尾数、某个身体症状的第一天、某件被踩脏的鞋）。

### 7.1 细节的定义（2026-09-13 第三次重写 · 65 三次返工：先堆感官、再堆器物，都不对）

**本包说的「细节」= 让读者自己拼出结论的材料**。刘熙载《艺概》：「正面不写写反面，本面不写写对面、旁面，须知睹影知竿乃妙。」读者看见影子、自己推出竿——**推出来的那一下就是爽**。作者替读者说破（「她终于被孤立了」「没人再心疼你」），爽感当场归零。

细节只有两种合法用途，其余都是布景：

| 类型 | 机制 | 读者的爽从哪来 |
|------|------|----------------|
| **A · 呼应细节**（和下文） | 前面随手放下一个东西/动作/一句话，后面在翻转的处境里再出现一次 | 读者**认出来**了——「这是开头那个纸团/那句话」——认出的瞬间自己完成判决 |
| **B · 侧面细节**（不写他写旁边） | 主角的处境、下场、别人对他的看法，全部由旁观者的反应、环境的规格、器物的状态折射 | 读者比主角**多知道一层**——主角还在误读，读者已经看见——这层信息差就是暗爽 |

判据：一处描写删掉后，读者是否**少推出一个结论**？不会 → 是布景 → 删。

### 7.2 A · 呼应细节（setup→payoff）

**数据**：拆文库每篇 `_meta.json` 的 `setup_payoff` 字段——37 十对、28b 十对、33 十对、38 十对。**合集均值 8–10 对 / 3000 字**。这是硬指标：每篇 ≥8 对，写进设定.md 呼应表（前置位置/前置写法/回收位置/回收写法）。

**四种回收**（37 的十对里全部类型）：
1. **原样复现、处境翻转**：她翻他抽屉「看儿子孝敬」→ 他挡抽屉「别翻了」；她树荫下嘲班花 → 别人树荫下嘲她「原样奉还」。
2. **同一器物换属性**：00 搪瓷缸颜色由浅到深；28 同一碗面 38%↔86% 配方不变、坐的人变了。
3. **同一动作换主体**：「半步后退」（一个女友躲她）→「密不透风的墙」（所有女生躲她）——个体动作扩散成群体。
4. **一句话的兑现**：「我也看不上他」→ 他真的不再看她；38「随时可以叫停」→「无法重来」。**台词只允许为了将来被兑现而存在。**

**前置三纪律**：
- 前置**随手**：藏在一个正在进行的动作里，不停下来强调。「你把纸团扔向垃圾桶 没扔进 林悦弯腰捡起来」——就这样过去，不许加「你没注意到」。
- 前置与回收距离 **≥全篇 30%**；至少 3 对跨开篇与收束。
- **回收零解释**。「这一次 没有人围过来」可以；「你终于明白没人再心疼你了」不可以。

### 7.3 B · 侧面细节（合集第二人称的结构性要求）

「你」是加害者/沉沦者，**他看不见自己**，所以一切判断只能从侧面折射进来；作者若替他看见，视角就穿帮了。经典范式：不写海伦美，写看台上的老将领叹「为她打一仗值得」；不写全班紧张，写老师一转身「读书声一下子洪亮起来」。网文打脸的同一原理：**高潮必须有人围观、有人品头论足**，主角自己不评价。

**四个通道**（每篇四个都要用，每个通道 ≥3 次且幅度递增）：

| 通道 | 写什么 | 拆文库出处 | 65 的用法 |
|------|--------|-----------|-----------|
| **旁观者的身体** | 别人的手/脚/背/视线/音量的微变，替主角的地位打分 | 04 端咖啡手发抖；37 手指停顿/半步后退；19 视线坠落 | 别人开门放慢、鞋跟不落地（反衬你踹门）→ 四个手机同震四人同笑头不抬 → 搬家三趟经过你床边脚步不停 |
| **旁观者的话（不对你说）** | 别人之间的对话、别人对第三者的评价，让主角听见/看见 | 百度百科「配角聚在一起谈论主角」；37 树荫窃语 | 你听见隔壁寝说「她们寝那个软的」；辅导员对周晓说「你先出去」而对你说「坐」 |
| **环境的规格** | 设施/规则/空间的尺寸替「被排斥」说话，不写人的恶意 | 19 镜子高度；20 课桌尺寸；24 行李箱 | 你的椅子是办公室唯一一张塑料矮凳；合照里一个人的宽度；群里三条消息两条是你的 |
| **权力者的不作为** | 上位者只出席不表态，判决由「没做什么」完成 | 16 父亲「含笑看着」；36 经理拍肩 | 辅导员这次没拍肩膀，只把纸翻过去 |

**侧面三纪律**：
- **主角必须误读**（「你把那个空归给摄影师」「你觉得她们不礼貌」）。读者看见、主角没看见——批判由读者完成，不由叙述者宣布。
- **主角的内心句按 37 原文校准：≤6 处**（37 实测：太正常/比那些女生聪明/胜利者姿态/窘迫+防御/以为贬低能证明清白/终于意识到），且只许两种：编年段的自辩（「你觉得你比她们聪明」）和清算段的一次「你终于意识到」。**清算句允许「不是 A 而是 B」**——那是 37 的原句式，去味脚本对此报 blocking 时忽略。
- **报应不许由叙述者宣布**：不写「你被孤立了」「她们都疏远了你」。只写三件旁人做了/没做的事，让读者自己合上账本。

### 7.4 暗爽的节奏（网文铺垫法用在批判文上）

网文的打脸靠「三层递进 AB 面」：前置铺垫（A 面）逐项对应后文引爆（B 面），一项对一项，读者在引爆时逐条对账。人生副本把「打脸」换成「清算」，原理不变：
- **前 60% 每个恶行都配一个随手前置**（纸团/白点/一句话/抠掉漆），不解释。
- **戳穿段用 3–5 个原样复现一口气回收**（没人围过来/塑料凳没漆可抠/五十六条只换称呼/没拍肩膀），中间不插叙述者评论。
- **放逐段只写旁观者的动作**，四连递增（群里两个字 → 手停半空 → 脚步不停 → 一个人的宽度），每件单独看都可解释为偶然。
- **收束**：一件器物状态（你的鞋在盒里 / 一个赞）+ 主角最后一次误读 + 至多一句判词。

### 7.5 布景配额

气味/光线/时间/水杯倒了/书页折角——每场景 ≤1 笔，且只在它能被回收时保留（开篇的橘子皮结尾不再出现就删）。**写作顺序：先列呼应表（A）→ 再给每事件配侧面通道（B）→ 最后看哪里缺一笔布景。** 先铺布景再找呼应就是 65 v3。

## 八、数字判词学（反转引擎，3 条纪律）

**数字的刺痛与位数成反比**：147 万 → 48,452.31 → 15 块 8 毛 6 → 4,576 → 68 块 5。
1. 判词前必铺**数字链**（估价 / 分辨率 / 总筹码），不能裸掉一个大数。
2. **小数字承担大清算**时落差最大（68 块 5 = 解药的真实价格）。
3. 数字出现配一个**冷漠的揭晓方**（收费员 / 短信 / 账单 / 系统），不配情感旁白。

## 九、语库指纹（复用作者语感，选 3–5 个植入）

平淡重判句（失望比愤怒更终审）/ 拒绝的微缩计量（半步 / 一秒）/ 正常世界的嗅觉标记（干净的人用气味出场）/ 器物判词（面碗 / 红烧肉 / 保温桶 / 破旧风箱）/ 编年三段升级（初中→高中→大学约束递减=剂量递增）/ 无狂喜反高潮（修好了但回不去）。**写"这像谁写的"的细节，才像这个作者。**

### 14.1 三条根因（比表格更重要）
1. **段子体 vs 纪录片体**。失败稿把每个节点写成「情境 + 对白 + 包袱」的短剧小品；爆款把每个节点写成**一个可拍的长镜头**：气味（馊味防静电服 / 地沟油味 / 化油器清洗剂）→ 材质（起球 T 恤 / 掉金粉的证书 / 生锈铁架床）→ 价格（49 块帆布包 / 112 元绿皮 / 8 块套餐）→ 身体（肩胛骨针扎 / 食指血口 / 生理性泪水）→ 数字判词（第一天净赚 112 元）。**一个节点至少 4 层里占 3 层，否则不算写完。**
2. **痛要是结构的，不是人际的**。爆款的加害者永远是「系统」：厂规 / 算法 / 罚款价目表 / 合同第 8 页；失败稿的冲突全是室友、班主任、师傅这种「人」——人际矛盾观众看完只觉得「这是你们宿舍的事」，结构性的痛观众才会「这是我」。写人时把人写成系统的执行端（线长 = 履带的嗓子）。
3. **第二拍就要落到皮肤上**。爆款开题后 20 字内必有气味/温度/器物（「7 月下午 2 点的空气粘稠得像一锅熬糊的粥」/「县城空气里终日悬浮着修车铺的机油味」）；失败稿第二拍在交代人物关系。**开篇 3 行不出现一个可闻可摸的东西，重写。**

### 14.2 写法上的直接改动
- 每个编年节点先写「账单」再写「事件」：这个月赚了多少 / 花了多少 / 身体坏了哪 / 余额尾数几毛几。余额要有小数（412.50 / 842.50 / 124.50）。
- 台词一律改「转述 + 判词」：不写「兄弟 你昨晚笑出猪叫了」，写「三个舍友顶着一模一样的黑眼圈 没有一个人跟你说话」。
- 每 300 字至少一个「只有这个人这一刻才有」的实物（参考第七节颗粒度纪律），品牌/型号/价格三选二。
- 「你」的心理只用两种句：「你以为……」（幻觉）和「你终于明白……」（清算）；中间一律用身体和器物代替。
- 搞笑需求：只允许「冷幽默」——荒诞来自制度与价格（Excel 表叫「夜间光污染户」/ 学徒找 17 号扳手），禁止角色互抛梗。

| 荒诞来源 | 制度空白 / 误会升级 / 第三方震撼 / 递归正义 | 每篇至少 3 种：①一个荒诞但自洽的制度（时间差睡眠方案 / 养猪不违规）②一次外部误会（阳台养牛 / 宿舍养鹅）③一次「加害者被同款加害」的递归（404 夜猫寝）④一个「解决方案比问题更荒诞」的推进 |
| 加害者 | 全程不自知、不被审判 | 「你」或核心人物必须**理直气壮**到结尾；审判交给结构，不交给旁白 |
| 收束 | 反爽平静 / 循环归位 | 不能让讨嫌人设「醒悟」；给他一个更大的同类 或 让制度反锁他自己 |

### 14.4 「搞笑风」节奏板（用户点名要搞笑时用，优先级高于 14.3 的 0 梗）
搞笑短视频的节奏规律（2026 实测通用）：**0–3 秒一句话交代关系 / 3–8 秒先给一笔笑点定金 / 之后每 5 秒一个兴趣点、矛盾每层比上层更荒谬 / 反转落地后立刻结束，不补解释不喊口号**。落到口播稿上：
- **每 40–60 字必须落一个包袱**（口播 5–7 字/秒 ≈ 每 8 秒一笑）；连续 3 行没有笑点就删。
- 开题后第 2 拍就是第一个包袱，不许先铺人物背景。
- 升级用「三连」：同一制度连出三个越来越离谱的条款 / 三个人各来一下；第三下必须是最荒谬的。
- 反转 = 制度反锁制定者（递归正义），落地后 ≤3 行收尾。
- **梗的用法**：允许 4–6 个当下热梗，但只许**叙述者**用作判词或标签（「小小年纪一身班味」「已读乱回」），不许角色互抛；每个梗只用一次；梗必须贴人物（考勤=班味 / 请假流程=预制 / 三人组=活人微死）。
- 字数 1,800–2,400（搞笑口播超过 2,500 完播必崩）。写完人工数包袱：≥ 35 个。

## 十五、从主题到成稿的流水线（2026-09-13 新增 · 63/64/65 三篇共 15 次返工的教训，写前必读）

> 用户给的永远是**主题**（「心机舍友」「整顿职场的00后」「AI 精神股东×活人微死」），不是标题、不是设定、不是剧情。以下每一步都对应一次真实返工。

### 15.1 先搜再写，搜到的原型必须逐条落进正文（返工 4 次）
- 搜三类：①知乎/贴吧/小红书**高赞回答**（>1000 赞）里的具体事件 ②抖音/微博**热搜事件**（真实人名事件改成无名） ③年轻人当前的自嘲语汇（只给叙述者用作判词）。
- **设定.md 第一节必须是「原型清单」**：一条原型 = 一条正文事件，写明落在哪一段。不允许"参考了氛围"——用户的原话是「为什么就不能参照搜出来的东西结合了写」。
- 原型里的品牌/店名/型号一律**去品牌化**：口红不写牌子写「代购便宜二三十」，鞋写「纯白中帮板鞋」，AI 助手如果剧情就是围绕它的公开翻车事件（豆包幻觉/赔付承诺书）才可以保留名字，否则匿名。第十四节的「品牌 ≥4」指**沙县/拼多多/地铁 2 号线**这类阶层标记，不是让主角穿戴品牌。

### 15.2 标题 ≠ 主题（返工 1 次）
- 副本题要是**一个人 / 一个器物 / 一个动作**，不是形容词堆砌：「看着人畜无害实际心机很重的舍友」→「寝室里声音最软的那个女生」；「把身体交给 AI 托管的 22 岁」→「把命交给豆包的嘉豪」。
- 检验：标题里的那个词，正文第 3 行以内要兑现（声音软 → 第 3 行「眼泪掉在牛仔裤上」/ 第 10 行「尾音往上翘」）。

### 15.3 先选骨架再写（返工 3 次：「没有小说的要素」「剧情太烂」「太平淡」）
- 读 `拆文库/_系列总拆书.md` §二选志、§四选曲线，再抄 1 篇同型的 `拆文报告.md` Stage 2 段界表当大纲——占比、爆点位置照抄。**在设定.md 里写出「模板 = 拆文库/NN」并列一张六段占比表。**
- 常用对位：加害者视角清算 → 37（零外部判决、自辩即签字、放逐四连）；身体/托管升格 → 25（六级升格链、双谷、和解铺满 30%）；荒诞喜剧 → 32/39（制度空白→递归正义）；四幕情景连播 → 17。
- 「没有小说要素」的具体症状：只有段子没有**有名人物关系**（至少 2–3 个功能位角色）、没有**固定场景**（寝室/工位/急诊）、没有**升格**（同一件事一次比一次严重）、没有**谷底**、没有**停战/位置认领**。缺一即返工。

### 15.4 「有突出的点」= 单一事件放大，不是编年流水（返工 2 次）
- 一篇只能有**一个被放大的事件**（板鞋事件占开篇 11%，逐拍写：眼泪→围上来→擦泪→「别同一天穿」），其余事件是它的注脚。
- 编年（第一月/第二月…）只能做**节拍器**，每个月一句账单 + 一个器物，不许每个月都写成一场戏。三个月三场戏 = 平淡。

### 15.5 视角与人称（返工 2 次）
- 一律「你」。第三人称一出现就退回（65 v5 改成「嘉豪」被退回）。可用真人梗名做标签（「班里人叫你嘉豪」），叙述仍是「你」。
- 网上小作文的默认视角是旁观者（90 后写 00 后 / 受害者写心机舍友）——**本包一律翻转成当事人**：「你」就是那个 00 后 / 那个心机的人。旁观者降为观众席，他们的反应（模仿失败/沉默/把你的话原样还回）是笑点与判决的来源。

### 15.6 AI / 系统角色不许有心理活动（返工 1 次）
- 写 AI、平台、制度这类角色，只许用它**公开可查的原话与行为**（「哈哈抱歉抱歉」「已记录您今日情绪为稳定」「承诺人：豆包」）。**阴阳怪气的效果全部来自「你」的解读**（「你觉得它认错态度比你爸好」），不许让 AI 说损人的俏皮话——那是编剧在说话，用户一眼看穿。

### 15.7 对话（返工 2 次，见 §6.6 / §14）
- 沉沦/清算/爽弧一律 ≤3%；喜剧支线才放开。**写完必须跑 `check_fuben_texture.py` 看对话行%**，超了就把「你说/她说」改成转述+器物（「你回的永远是那八个字」/「她光着脚下床腾地方」）。

### 15.8 数字与生活逻辑审核（返工 3 次）
- 写前查一次**当年数据**：房租/起薪/通勤要与城市量级匹配（月薪 7000 不能一个人租 2600 次卧；二线合租单间 1000–1500）。**不写具体城市名和地铁线号**，写「二线」「地铁尾站」。
- 人物关系必须给出**相识路径**（舍友=同班同学同公司；不能凭空冒出一个「护士室友」）。
- 时间线自洽：前面说「四个月」后面不能出现「一年」；数量对账（每月 15 袋×3 月 − 拆过几袋 = 床底 37 袋）；证据链来源要在前文种下（截图是谁截的、文档是哪里来的）。
- 交稿前跑一遍：`grep -nE "不是.*而是|不仅|某种意义|与其说"` 清 AI 腔；再人工过一遍「这个数字/这个人/这个东西前面出现过吗」。

### 15.10 双面人设的写法（2026-09-13 第二次修订 · 模板 = 拆文库/13 表演选址学 × 37 清算骨架）

**错误示范（65 v6/v7）**：把「人前」写成一串善举清单（送水/带奶茶/请火锅）——那是好人，不是心机。心机不是「对外好」，是**每一个动作都同时有两个坐标**（13 手法 2）：
- **名义功能**（说出来的理由：帮你拿快递 / 替你拿药 / 帮大家投票）
- **实际舞台**（谁在看、这一步给她换来什么：辅导员的一句「细心」/ 全班的一个印象 / 舍友的一个人情债）

**写法 = 13 的表演选址学移植到寝室**：
1. **每个场景写双坐标，并用一个道具暴露舞台坐标**。13 是「风口在巡视必经之路」；寝室版：拿药的照片是拍给辅导员的（药盒摆正过）/ 哭的时候面朝门口（有人会进来）/ 在班群而不是寝室群里说「帮林悦拿快递啦」。
2. **观众进场时机**（13：吼声是给刚进门的人听的）：她的每次「软」都发生在第三人推门的瞬间——脏话说到一半门开了，尾音立刻翘上去。写 2–3 次这个切换，读者就懂了。
3. **人前的具体手法要从搜索原型里取**（知乎 318185842 / 262006327 / 326543545），不是泛泛的「热情」：
   - **撺掇**：自己买了就撺掇条件差的一起买「不就一百七」——名义是分享，实际是把别人的钱变成自己的排面
   - **装可怜先手**：想要别人的东西就先哭，让围观者去劝对方——名义是委屈，实际是借群体压人
   - **争助学金互揭**：寝室里谁用了个面膜就说「你有钱」——名义是公平，实际是清场
   - **抢先定义关系**：当着新朋友的面搂住你「我们最好了」——名义是亲密，实际是占位
   - **唯独对朋友不好**：对所有人都好，只对身为她朋友的你不好——因为只有你会威胁她
   - **告状的姿势**：去辅导员那把自己描述成弱势方，最好带一个见证人
4. **私底下**不是「变坏」，是**卸妆**：声音变粗、门用脚踹、别人的东西直接用、AA 拖着——**成本转嫁到只有 5 个人看得见的地方**。人前每一分钟的软，都要在人后有一笔账被别人付。
5. **旁观者两层**：外圈只见名义坐标，内圈两个坐标都见。中段写一次外圈对内圈说「你们寝那个女生人真好」，内圈不接话。
6. **戳穿 = 外圈第一次看见舞台坐标**（辅导员看到药盒照片和踹门是同一天）。
7. **配比**：双坐标场景 5–6 个足够，每个信息只落一次（§0.5）；不做善举清单。

**标题**：副本题写「表演」本身，不写「好人」：「寝室里永远第一个哭的女生」「对所有人都好唯独对室友不好的女生」——标题里要有那个双坐标的裂缝。

## 十六、拆书情节移植（2026-09-14 新增 · 66–71 返工教训：只借「机制」不借「情节」= 没用上拆书）

> 用户的原话：「在原本的基础上仿写，加入我上传的拆书的情节，情节得参考拆书的原文」。拆文库里非副本体的短篇（盐选古言 / 悬疑 / 甜宠 / 民俗）同样是**情节供体**，不是只供「主题句」。

### 16.1 供体单位 = 情节节点，不是主题
- 读供体篇的 `情节节点.md`（N1…N54，每条带原文引用），**不读拆文报告的主题句**。主题句只能借一句当判词；节点才能变成场景。
- 每篇副本 **≥5 个移植节点**，来自 ≥1 个供体；设定.md 必须有「移植节点表」：`源篇 N# | 原文摘句（≤30 字）| 节点机制 | 副本中的落点（第几段 / 哪一行）`。loop `design` 检查此表。

### 16.2 移植 = 换壳保机制（三步）
1. **剥壳**：去掉古装 / 超自然 / 犯罪 / 医院等供体外壳，只留机制。可移植的机制清单（供体实测）：
   - 结果前置（隐娘 N1「我死在他回京那日」）→ 副本开篇用「你是最后一个知道的」
   - 日期错位 / 平行剪辑（隐娘 N8「十月十八他救公主 / 我生产」）→ 同一天你在台上 / 她在办公室
   - 「不是什么要紧的人」的当众否认（隐娘 N3 / 乱葬岗 N17「连手都没牵过」/ 28「没有」）→ 你对第三人的一句话，日后被原样兑现
   - 物件揭底（乱葬岗 N6 相机里的乱葬岗 / 隐娘 N37 榻下鞋箱一旧一新）→ 抽屉 / 纸箱 / 相册里的两件东西
   - 审判式提问（乱葬岗 N15「谈过几个女朋友」）→ 饭桌上第三人随口一问，当事人在场
   - 「配不上」的原话（乱葬岗 N21「初中毕业配不上大学生」）→ 只许出现一次，且由「你」说
   - 仪式代替语言（乱葬岗 N35–36 抬棺入祖坟 / 隐娘 N50 一只绣鞋）→ 备注全名 / 一个字的转账备注 / 一张请柬
   - 「不肯杀他 只能继续活着」（乱葬岗 N50）→ 她不删你不拉黑你，让你一直看得见
   - 误接电话听到「催货」（掌控 N4）→ 误接家里电话听到「你姐那边搞定了没」
   - 玩笑圆场 + 当面翻供（掌控 N13）→「开玩笑的 别放心上」
   - 雇来的演员（掌控 N19）→ 饭桌上夸你的亲戚是提前打过招呼的
   - 公开场合设套 → 顺从即反击（泠泠 N8–N9）/ 屏风后的观察者（泠泠 N10）→ 联谊起哄 / 后门站着辅导员
   - 让出机会三次（泠泠 N25/N29）→ 「让他讲 他讲得好」
   - 醉后喊出别人的名字（泠泠 N30）
   - 报不准日期（偏偏 N3）→ 你报不准他等过你几次
   - 重复节拍（偏偏 N1/N9 听诊器掉两次）→ 同一个动作两次，第二次观众变了
   - 权威误判（偏偏 N8 护士「肯定怀孕」）→ 舍友「他对谁都这样」
   - 路灯下给别人买同一样东西（偏偏 N37 烤红薯）→ 给新娘挑香菜
   - 生存日记 / 必死清单（洗白 黄金三章）→ 原话本
2. **落点**：每个移植节点落在六段中的固定位置——结果前置只能在开篇；物件揭底只能在戳穿段；仪式只能在收束段。
3. **原文对照**：移植后的那一行，要能在设定.md 表里指回原文摘句。写不出对照 = 没移植，是自己编的。

### 16.3 纪律
- 一篇不超过 8 个移植节点，多了就是拼贴；每个节点只用一次。
- 移植节点必须仍满足 §7 呼应 / 侧面纪律：供体里的直白台词（「你只需要一个工具」）到副本里要降成器物或旁观者动作。
- 供体的人名、朝代、职业、地名一律不带。

## 十七、反流水账：场景化纪律（2026-09-15 新增 · 66–71 第二版被退「怎么都这么像流水账」）

**病灶**：把编年写成「大一上 你打回家 800 / 大一下 1,500 / 大二上 3,000」——一行一事、事事等重、没有人在场、没有人动。这是**账本**，不是副本。37 原文 2,999 字只写了 **4 个场景 + 1 段编年**，其余全是场景内部的拍子。

### 17.1 一个场景的最小拍子（照 37 开篇 60 行抄）
| 拍 | 37 原文 | 要求 |
|---|---|---|
| 环境一笔 | 早晨 6 点半 教室里充满了没吃完的包子气味 | 时间 + 一个气味/声音/温度，≤2 行 |
| 「你」的连续动作 ≥4 个 | 书包一扔 → 径直走向 → 熟练拉开椅子 → 一屁股坐下 → 双手伸进抽屉翻 → 书本哗啦 → 几支笔滚落 | 动词连着写，每个动作一行，中间不许插评论 |
| 你说话（内联 不加引号） | 看看儿子有没有拿好东西孝敬你 | 说的话是「行为」，和动作同权；对话不是禁区，**禁的是问答式来回** |
| 旁观者的身体 | 几个男生抬起头看了你一眼 / 林宇无奈地笑了笑 走过来站在你旁边 并没有赶你走的意思 | 每个场景 ≥2 个旁观者反应 |
| 第三人入场改变气压 | 后门走进来一个女生 脸色瞬间沉了下来 脚步停在原地 | 场景必须有一次「气压变化」 |
| 你的切换（表情/声音/动作） | 咽下薯片 拍了拍手上的碎屑 换上关切的表情 声音也柔和了几个度 | 切换要写成三个连续动作 |
| 微缩计量 | 往后退半步 / 笑容僵了一瞬 / 手指停顿了一下 | 每场景 ≥1 个半步/一瞬/一下 |
| 场景收口 = 一个人的退场 + 一件器物 | 林宇把话咽了回去 默默回到座位 开始整理被你翻乱的书桌 | 不许用叙述总结收口 |

**一个场景 ≥25 行**（37 开篇 90 行）。写不到 25 行的事件不配做场景，降级进编年一句。

### 17.2 全篇配额（37 实测）
- **场景 4 个**：开篇越界现场（30%）/ 裂痕（张静一问，15%）/ 放逐一（挡抽屉，10%）/ 放逐二三（球、墙，10%）
- **编年 1 段**（25%）：但 37 的编年不是年表，是**三个学段各一个具体行为**（抢矿泉水瓶仰头倒 / 扯袖子夹子音带带我 / 树荫下嗤笑班花拧不开瓶盖），每个行为 4–8 行，带对象和对话
- **清算 + 收束**（10%）
- 数字只在编年里出现，且每个数字带一个动作（「你把八百打回去 备注生活费 然后把手机屏朝下扣在桌上」），**禁止两列数字对照表进正文**（对照表放设定.md）

### 17.3 自检
- 数「大一 / 大二 / 第一周 / 第二个月」这类时间标签：**>6 个 = 流水账**。
- 数连续 3 行都是「你 + 动词」的段落：**<4 处 = 没有场景**。
- 数内联说话行：**<15 行 = 太干**（37 有 30+ 行）。§14 的「对话 ≤3%」指的是**引号问答体**，不是内联说话；loop 的「正面台词≤3行」统计口径同此。
- 喜剧支线（迷因志）的时间标签放宽到 ≤12（39 原文按周推进），误读项跳过。
- 任一事件写成「时间 + 数字 + 一句话」且相邻三个都是这个格式 → 合并成一个场景或删掉。

## 十二、因果逻辑与内容审核（防逻辑漏洞 + 过审）模块

> 用户核心痛点：AI 生成的剧本常「逻辑不通 / 动机空 / 审核不过」。**写任何清算弧 / 社死 / 犯罪向 / 骗局向之前，先跑本模块**，把剧情拧成一根能自洽的因果链，并主动规避 2026 短剧审核红线。

### 12.1 因果链自洽检查表（防"动机空"）
成稿前逐条回答，答不出即逻辑漏洞，须补戏或改设定：

| 必答问题 | 要求 |
|---|---|
| 关键事件（聚会/设局/名场面）的**真实目的**是什么？ | 必须有一个具体利害（圈钱/止损/夺产/翻案），不是"图风光/看不惯"这种空动机 |
| 清算者 / 对手**为何非现在出手不可**？ | 从"小怨"升级到"重大利害"（再不拦，老实人会受害 / 主角会进去 / 事件不可逆）——给出升级的那一根导火索 |
| 他的**证据为何齐全**？ | 给他合理立场（受害者本人 / 相关职业从业者 / 一直暗中观察的第三方），让取证有来路，别凭空变出证据 |
| 他**为何不更早行动**？ | 给机会（私下劝过 / 给过台阶），直到踩到红线才出手，人设才立得住（不是急于落井下石） |
| 被骗/受害一方**安全吗**？ | 关键动作要拦在"造成不可逆损失"之前（转账前拦下），无人真实受害 |
| 主角**结局有没有法律/现实后果**？ | 骗局/违法必须落空 + 警方/法律介入，不能"全身而退"美化犯罪 |

### 12.2 反派/清算者画像（别写成泄私愤小人）
- 清算动机 = **止损 + 救人 + 主持公道**，不是"报复羞辱"。这样清算才狠又不招黑，且结尾能留温度。
- 可安排清算者"私下劝过主角、给过机会"的戏，让主角恩将仇报 → 观众怒气值更高，清算更解气。

### 12.3 内容审核红线（2026 微短剧合规，主动规避）
写涉及犯罪 / 骗局 / 灰产 / 虚荣 / 复仇 / 网络暴力的题材，按下表自查并规避：

| 红线 | 规避写法（照做即安全） |
|---|---|
| **不教唆犯罪 / 传技** | 只写"现象与后果"，不写设局 / 手法 / 操作步骤；骗局一律以"被识破 + 无人得逞"收场 |
| **不美化犯罪 / 骗局 / 虚荣** | 主角若是作恶/虚荣方 = 负面被清算对象，结局承担后果，绝不"卷款全身而退" |
| **不渲染色情 / 赌博 / 血腥** | 性、赌、暴力只点到为止 / 作批判对象，不展示细节 |
| **不抹黑职业 / 群体 / 引战** | 别让整个行业 / 地域 / 群体背锅，把恶归到"个别人 + 系统性漏洞" |
| **不传播焦虑诈骗教义** | 高息集资 / 传销 / 刷单等 = 明示是骗局并加警示，做反诈教育而非引流教程 |
| **未成年人保护** | 校园 / 青春题材涉未成年人不涉早恋性话题、不渲染 |
| **导向正面** | 善恶有报，作恶有代价；需加虚构声明"本故事纯属虚构" + 必要时科普类提示 |
| **情绪安全** | 反派 / 苦难点到为止，重点给"解气 + 后怕 + 警示"，不卖惨博同情 |

### 12.4 一篇稿的自查闭环（写完跑一遍）
1. 因果链逐问 → 全通？2. 红线表逐行 → 无触雷？3. 加虚构声明 / 警示句？4. 通读无教唆感、无"爽完无代价"感？——任一不过，回头改设定/大纲，别硬补正文。

## 十三、Phase 2 题材字段写法（机器验收合规）

在 `设定.md`「Phase 2 设计校验」区写：

```markdown
- 题材参考：`references/genre-styles/人生副本实录.md`
- 核心招式：{志+曲线定位}；{一个数字判词链/器物判词方案}；{开篇倒叙引爆 or 编年清单写法}[可三选二]
- 反派设计：不适用（{人生副本实录以结构/自身清算为张力，无实体恶人——除非该志需具象加害者}）
- 反转类型：{数字判词 / 器物判词 / 认知反转 / 报应兑现}
- 反转位置：第 {X} 段 ÷ 全篇（置 80–85%）
- 目标平台：抖音口播（第二人称 · ASR 语感 · ~3000 字 · 无付费点）
```

> 若对标 `_meta.json.genre_detected` = 「世情」且 `genre_secondary` 含「第二人称口播 / 实录 / 沉沦 / 清算」，**直接加载本包，不加载 `世情打脸.md`**（本包识别器优先）。
