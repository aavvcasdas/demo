# 成片逐镜人审清单（TTS/剪辑后、发布前）

> 出处：R17 偷师 chaosinu7-svg/life-sim-video-pipeline 的铁律——「渲染成功、脚本零报错、自动质检全绿，但成片是坏的」。
> 其 2026-08-10 EP01 实例：自动质检（黑帧/静音/响度/分辨率）全绿，成片里同时存在 7 个内容错误。
> 用法：每条成片发布前逐镜过一遍，任何一条不过 = 不发。本清单是人工项，无机械闸（chaosinu7 同款结论：逐镜看是唯一兜底）。

## 数字对账
- [ ] 画面里出现的每个数字 vs 旁白说的同一笔账（其实证：屏幕画 95/90/85，旁白说 40%/30%；计算器 987.50，旁白说四千五）
- [ ] 字幕与口播逐字一致（TTS 加字/吞字/断句错位）
- [ ] 标题卡、封面上的数字与正文判词一致

## 存在性对账
- [ ] 画面/字幕里的人名、地名、机构名在设定.md 与事实锁里存在（其实证：底稿特写出现剧本里根本不存在的「作者：林砚」）
- [ ] 道具连续性：同一物件前后镜头是同一件（其实证：结尾记账本换成另一本，封面还多了个 logo）

## 时间与逻辑
- [ ] 日期先后一致（其实证：合同「先公示、两天后才签署」）
- [ ] 人物状态与情节一致（其实证：该失眠的人在笑）

## 画面物理
- [ ] 人物看手机的镜头一律拍背面/过肩，屏幕不出现内容（其实证：屏幕朝镜头+视线朝手机 = 看的是背面）
- [ ] 画面内文字一律不可读（失焦/虚化/极浅景深）；汉字不生成；主体是数字的镜头单独放开阿拉伯数字并在提示词写死数值
- [ ] 开头模板/标题卡完整（其实证：流复制拼接丢帧，标题卡整段消失而容器时长正常）

## 本管线加项
- [ ] 成片实长 vs 估时（6.4 字/秒实测）：差 >10% 先查 TTS 语速再查漏段
- [ ] 去品牌红线在成片层复扫：画面 graffiti、道具 logo、字幕里的平台名
- [ ] 发布包三件套（标题/封面字/钩评）与成片口径一致
