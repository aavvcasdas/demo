## 前三篇到底哪里跑偏了

- **维修员稿**：抽屉的小笑点结束后，立刻散成冰箱、猫照片、饭桌等经历。家长会出场太晚，前面没有一个必须追到那里的问题。不是少几个感官词，而是没有贯穿期待。
- **字幕员稿**：反复检查虽然有行为细节，几轮却没有明显改变局面。重复本身不能自动变成紧张；迟到与关屏的释放也偏弱。
- **教父亲地图稿**：学习—练习—独自买菜都顺理成章，但题材里的温情没有变成足够具体的悬念和情绪兑现。不能因为通顺、善意，就称它完成了本账号的创作目标。

## 这次维修员稿改的不是一句标题

旧稿是“修抽屉趣事→职业经历清单→家长会”。新稿围绕**当众指责收费→为什么不敢放完整录像→当时究竟怎么修→别人如何重新看你**展开。

开头先把人放进冲突；按住进度条既是当下动作，也是后面的线索。卷尺不是单独的小笑话，而会揭穿片段里被省略的过程。侧面不用“众人震惊”，用收回镜头、擦破纸巾、改口、递来另一扇柜门的照片表现局面变化。结尾再次接单时，对方先接受报价，不再开摄像头，回应开头的轻视。

这些是改写意图，是否真正有劲要看正文，不用自评分或机检结果替代判断。
