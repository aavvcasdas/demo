## 这次比较的范围

三道未在本轮写出示范稿的新题，每题三种输入：

| 条件 | 实际输入 |
|---|---|
| A | 相同题面、事实与原文材料直出，不加载专项规则 |
| B | 相同材料＋Git `c064a61` 的旧主profile和旧骨架全文 |
| C | 相同材料＋本次轻量主profile全文；不预加载可选骨架 |

**这是单次“提示文本包”的小试，不是完整Skill／Agent／工具循环的效果评测。** B和C的其他引用、脚本、检索与多轮流程都不执行。旧组没有偷偷截短；若上下文装不下，记录失败或不可比，不换成摘要。

输入的内容、结构和长度同时发生变化，不能只归因于“规则数量”。这三个题也偏向本轮要恢复的多样写法，不能据此声称全部题材都获益。没有真实制度题、媒体或平台终点。

本轮已经展示的 `S01–S03` 单会话试写不进入本包。不能把看过的轻量稿冒充匿名C组，也不能让我在已知三组规则的当前会话里故意写一份差的旧组作陪衬。

## 1. 生成：每题每组一个全新会话，共9个

在你选择的同一模型、同一版本/选项与可控参数下进行。**不要在自动加载本仓AGENTS／Skill的会话中做A组**；最好九份都在干净新会话里完成，不携带这次修复讨论、其他组稿件、示范稿或评审说明。

分别完整复制 `生成输入/` 下的九份文件。模型只看到该次输入的正文，不要同时上传整个对照包。

- H01：婚礼签到的表弟，轻喜剧。
- H02：代看洗衣代收店的一周，职业日常。
- H03：妈妈独自去现场听歌，短版与主体性。

每份只取第一次完整回应，不挑最好的一次，不单独帮某组润色。不完整、拒答、截断或错误也保留原响应及状态。不得只比较成功的一部分而隐去其他失败。

同题三组的事实和参考原文完全相同。A不是“什么都不给”，而是“同资料、无额外Skill文本”。输入字符数包含公共原文：A约4.2–4.8千字符，B约3.1–3.2万字符，C约5.8–6.5千字符。**不是token数**；具体值与哈希在 `清单.json`。

## 2. 回填：原样保存，不编造运行数据

把九份回应分别存为：

```text
回填/H01_A.md  回填/H01_B.md  回填/H01_C.md
回填/H02_A.md  回填/H02_B.md  回填/H02_C.md
回填/H03_A.md  回填/H03_B.md  回填/H03_C.md
```

填写 `回填/运行登记.json`。空白起始版本另存为 `运行登记.template.json`；可以复制到新的回填目录，使用 `--responses 新目录`，不要改冻结模板。

登记内容：

- 模型选项名称、实际能设置的参数；不知道的参数保留null。界面选项相同不等于服务端版本已被认证。
- 每份使用不同的自拟会话代号，例如 `session-01`，不需要放私人会话链接或任何密钥。
- `stop_reason` 如实填写：`COMPLETE`、`TRUNCATED`、`REFUSED`、`ERROR`、`UNKNOWN`；未做保留`NOT_RUN`。
- 输入/输出token只填实际可取得的统计；未知为null，不用字数推算后冒充实际token。
- 三个声明只在真的做到时改为true。工具不能认证这些声明。

如果聊天界面不能设置或记录预算、自动进行了上下文压缩，就记录限制，不能称严格的“同预算同上下文窗口”实验。

在仓库根运行：

```bash
python3 scripts/fuben_trial_blind.py check
```

当前应返回 **INCOMPLETE，退出3**，而不是通过。输入被改、登记格式错误等返回ERROR、退出2。

## 3. 匿名导出：先收齐，再评

九份原始回应及登记齐全后：

```bash
python3 scripts/fuben_trial_blind.py export --out evaluations/匿名评审_第1次
```

输出目录必须是新目录，不覆盖既有文件。工具只核对文件、绑定与声明，不改写稿件，不执行模型，不评分。

输出分为：

- `给评审/`：同题公共材料、打乱顺序的三稿与空白评审记录。
- `主持人勿外发/映射.json`：来源映射、原稿哈希、运行登记与输入清单绑定。

**只把“给评审”目录交给没有参与生成、也没看过映射的评审。** 不要把整个父目录上传。工具会提示明显的组别/规则版本泄漏，不自动删除正文来伪造匿名；发现泄漏就保留并报告，不能悄悄换成更漂亮的回应。

这只是遮蔽标签，不保证读者无法从篇幅或文风猜出来源，也不能认证评审身份。三个“审查角度”不等于三个独立人或Agent。

## 4. 先保存原始评审，再揭盲

先做每题偏好排序，可并列，也可无法判断。理由需引用真实原句和具体影响，不按固定情绪点数、句式命中率、机检PASS或字数给质量分。空模板不算平局或通过。

收齐并保存评审记录后，再看映射。不在看到来源后修改排序；失败稿、平局、分歧、未评项与成本缺失一起报告。

9份稿只足够发现问题，不足以宣称显著领先、恢复原作水平或平台必爆。真实声音、媒体一致性、发布授权和抖音表现必须另测。

## 文件与冻结边界

`清单.json`记录**准备时**的状态；后续真实运行以回填登记和导出包为准。`冻结规则/`保留指定文本，`公共资料/`保留各题共同输入。原库和现有作品没有被编辑。

`fuben_trial_blind.py`及其测试是实验辅助工具，不进入轻量创作profile，不作为写新稿的前置，也不加入默认生产部署包。
