# 人生副本实录 · v10（2026-09-18）

> 这份包服务抖音「今天体验的人生副本是……」的第二人称旁白稿。
>
> **v3 的教训**：为了修 67–72 的事实错误，v3 把「对手、社死、反杀、结果前置」当成错误一起删掉，改成「事实锁 + 线性 + 无对手 + 低对白 + 八拍路线图」。结果是当年 72 的「重生成基线」事实全绿：2510 字、334 行、3 句对白、零个爽点，唯一正向事件是 90% 处的 1040 元，峰值没有、对抗没有、兑现没有。**事实对了，剧死了。**
>
> **v4 的立场**：事实锁管「不能写错」，爽点锁管「不能难看」。两把锁都要，缺一个都不算过稿。
>
> **v5 的教训**：v4 只锁了爽点的「数量」，没锁「位置」。66/67/70/71 四个稿子于是长成同一个样子——开头前置一句结果，然后把对质、面试、认账这些真正的高潮留到 **70%–85%**，前面 60% 全是慢慢铺。观众的原话是「过了 1 半才开始」。
>
> **v5 的立场**：**前半加速，后半展开。** 主线大事件（第一次兑现 / 对质 / 承认 / 爆点）必须在 **30% 之前**发生；从 30% 到 100% 这 70% 全是「之后」——后果、二次交锋、代价、新常态。铺垫不许过夜。
>
> 一句话：**爽点必须来自拆文库的机制，事实必须来自事实锁；借爽点不是抄事实。**

## 0. 执行顺序与冲突优先级

### 0.1 顺序（缺一步不许开写正文）

```text
账号主出题确认环（R18b 硬流程）：出题后先联网搜主题相关真梗（社区梗/真事段子/行话，见 3.5.1）→ 交一页「剧情大纲 + 设定要点 + 梗素材清单（每个梗注明出处与拟落点）」→ **账号主明确批准后才动笔**；未批准不进下面的流程
→ 精读 Gate：拆文库同型 2–3 篇**原文全文**进上下文（`拆文库/NN_*/原文/原文.txt`；不是拆文报告、不是 meta、不是节点表），写前交 5 行「场面写法」复述——原文怎么膨胀一个瞬间（见 0.4）
→ 事实锁 L0
→ 爽点表 L1（位置 / 情绪值 / 事件 / 类型 / 正文锚点；新稿另附「位置%→第几秒」换算，见 2.9）
→ 情绪节拍表 L1（6–10 节，节数不固定）
→ 场面表 L1（五要素；新稿必备，见 2.9）
→ 正文
→ fuben_run.py（design → facts → hype → draft → review → lint → AI patterns）
→ python3 scripts/fuben_density.py 作品/NN_xxx/正文.md（对账口径报数，禁手搓正则自报）
→ fuben-review 人工三方审核（含并排读自批判，见 4.2⑨）
```

### 0.2 冲突优先级

`用户明确硬事实 > 事实锁与官方规则 > 爽点预算与节奏 > 线性因果与可读性 > 对白/行数/短行等形式`

形式永远排在最后。**「事实正确」不构成过稿理由；「这一题没有爽点」不是风格，是没写完。**

### 0.4 精读 Gate（v10.2 最高优先，零成本）

- 写正文之前，同型原文**全文**必须逐字进生成上下文，并在设定.md 追加一行：`精读：拆文库/NN、NN；场面写法复述——<5 行>`。复述只回答一个问题：**它怎么把一个瞬间写大到能住进去**（感官落在哪、动作链怎么走、时间在哪膨胀）。
- 违规定义：没有精读行或复述写成机制提纲（「它有爽点、在 20%」）= 视同没走流程。考点提纲不能生产质地；**课文才能**。
- 依据（R9 会审实证，R13b 修正基数）：原文感官/千字全库带 0.0–15.0（中位 3.8）——旧表述「原文带 7.7–15」是上四分位带，被误当义务下限。精读的目标不是把计数拉过某个线，而是学 06 怎么把一个瞬间写大到能住进去；计数只做带位参照。39 篇 10w+ 原文从未被读过全文，这一条不变。
- **R13b 规则体检（2026-09-19，账号主令「约束太多，全面排查」）**：45 篇原文被自家 texture 判 46/47 至少一项 BAD——开篇落皮肤 39 死、品牌 38 死、价格 36 死、感官 34 死。定性：这不是「规则太多」的总量问题，是 B 类伪语料阈值（把 06 一篇当 45 篇义务）+ advisory 被评审话术升格为软闸（「低于 3 直接 S1」）两个病灶。处置：texture 改带位报告制、品牌行删除（与 R2 红线互斥）、0.6 日落条款立制、fuben-review 皮肤密度行降为人审一问、提示词 L58 数字砸脸咒语改回原文开场拍。A 类保命层（事实锁/时戳禁令/三问/反抽）154 条全保留——它们背后是用户明令与真实事故。
- **texture 计数器的边界（2026-09-19 实测）**：给 `check_fuben_texture.py` 补动作流计数后，75=12.9、73=14.4、66=12.4 全绿——但稿子仍是流水账。动词密度高而场面仍是台脚步：**动作流计数不辨别时间膨胀，感官计数才有区分度（原文带 7.7–15.0 vs 本库 0.0–3.2）**。所以 texture 永远只作 advisory，质地修复靠精读（0.4）与场面表（2.9），不靠把计数做成闸。

## 1. L0 事实锁：写任何正文之前完成

### 1.1 固定字段

`设定.md` 必须有 `## 事实锁`，每项都要能逐条对账：

| 字段 | 必须回答的问题 |
|---|---|
| 规则/玩法 | 这是什么制度、游戏或现实活动？一次如何判定？写清**玩法名称**，不许混称 |
| 频率/次数 | 每天、每周还是一次性？「每天一张」是每天一张**新票**还是重复使用？ |
| 单价/金额 | 一次多少钱？金额是否允许变化？奖金/工资/欠款分别是多少？ |
| 对象/号码 | 人、物、地点、号码的明确称呼；固定还是会变化 |
| 结果/判定 | 谁在什么时候用什么证据确认结果（官方公告、单据、当事人动作） |
| 日期/计数 | 起点、终点、天数、张数、余额如何对账，写出算式 |
| 禁止越界 | 不得补写哪些预感、加倍、换号、身份、功能或制度 |

每个数字要有「单位 + 对象 + 时间」：`每张双色球单式票 / 2元 / 每天一张`，不能只写「2」「七年」「中奖」。

### 1.2 彩票题的专用硬账

- 先锁**玩法名称**再写正文。双色球＝6 红 + 1 蓝、每周二四日开奖；福彩 3D＝三位数、每天开奖。两者不能混用，也不能互相改名。
- 「每天一张」写成每天一张**新出的单式票**；旧票只作收集，不重复使用。
- 人物不越界：想写倍投/复式/重仓，必须在事实锁里**从第一行就锁成那个人物规则**，不能中奖之后临时升级。
- 金额账分开列：购票成本 / 奖金 / 税 / 医药 / 借款 / 被骗，各占一行，且合计要能算出结尾余额。
- 日期要对：`(中奖日 − 起始日) + 1 = 张数`。七年＝含两个闰日的 2558 天，不是 2555。
- 禁止玄学因果：「有感觉」「预感」「快了」「会中的」「它认出了你」「三等奖是信号」一律 BLOCK；中奖只能由官方结果与票面核对确认。

### 1.3 事实来源

规则、价格、税率、平台功能、制度动作要来源（≥2 条链接写进 `## L0 事实核查`）；浮动奖金可以锁成剧情设定值，但要标明「剧情设定，不冒充真实期号」。

### 1.4 反事实清单（不能勾完就不写正文）

```text
[ ] 玩法/制度只有一个名称，未混用相邻规则
[ ] 频率、单价、数量、金额全程不漂移（含设定卡自己）
[ ] 起点、终点、天数/张数/余额能算出来
[ ] 关键对象首次出现有身份、名称、单位
[ ] 结果由现实证据确认，不由预感确认
[ ] 供体拆文的金额、年份、玩法、结局没有越权进入正文
```

## 2. L1 爽点锁：v4 的核心（硬门）

> 拆文库的证据：39 篇里 23–24 分区全部具备**强对抗结构**（11 阶级对照 / 13 表演与拆穿 / 15 身体期货 / 25 反弹复利 / 28 辜负审判）。**对抗密度决定上限**，情绪节点密度决定完播。

### 2.1 爽点表格式（`设定.md` 必须有 `## 爽点表`）

```text
| 序 | 位置 | 情绪值 | 爽点/情绪事件 | 类型 | 正文锚点 |
```

- 情绪值用拆文库口径：`+1…+8` 是爽点，`0` 是状态点，`-1…-8` 是代价与谷底；**一行一件事，锚点必须是正文里独一无二的一句**。
- 机器会核对锚点真实位置；声明位置与实际相差超过 8% 判 BAD（不许纸面爽点）。

### 2.2 位置与密度（拆文库 01/04/13/15/21 实测区间）

| 指标 | 硬要求 | 拆文库实测 |
|---|---|---|
| 情绪节点密度 | **≥ 4.0 个/千字** | 39 篇样本 5.1–16.7（01=6.9，04=12.4，13=6.3，15=5.1，21=7.5） |
| 正向爽点（≥+3） | **≥ 2 个（绝对数）** | 01=6，04=2，13=5，15=3，21=2；沉沦/代价题天然少，但也不许为 0 |
| 第一个爽点 | **≤ 22%** | 01 在 6%，04 在 13% 已给数字钩，15 在 44% 才出现第一个兑现（下限样本） |
| 峰值 | 爽/加冕题 **≥+5 且落 25%–48%**；沉沦/代价题可 ≥+3、落 15%–55% | 04 峰值 +7 @ 34–40%，01 +7 @ 21%，15 +6 @ 51% |
| 大爽点（≥+5） | **≥ 2 个**（沉沦/代价题 ≥1 个） | 01 有 +7/+5/+5，04 有 +6/+7，15 只有 +6 一个（下限样本） |
| 谷底（≤−6） | **≥ 1 个** | 21 在 78%（−8），15 在 76%（−9） |
| 相邻爽点间距 | **≤ 全文 30%** | 39 篇没有「只读年表」的连续段落 |
| 结尾 | 锚点落在 ≥85%，最后 12 行内要有数字或器物判词 | 01「微辣」/ 28 面碗 / 38 水池 |
| **爆点位置（v5）** | **第一个 ≈+5 事件 ≤32%**；≤12% 完成主线启动 | 01=18%，04=29%，16=27% |
| **之后长度（v5）** | 爆点之后 ≥4 个情绪节点；>50% 处已有 ≥3 个节点 | 04 峰值在 35%，其后仍有 8 个节点 |
| **跨度写法（v6）** | **禁止「第 N 年…」年表罗列**（以「第N年」开头的行 ≤2 且不连续）；长期跨度用「同一动作重复 + 细节漂移」；兑现前必须有可复现的一天，占比 ≥10% | 01「还是小火 / 还是两个钟头」；05「时间碾过 7 年」+ 降级清单 |
| **钱的去向（v8）** | 兑现/暴富题必须写 `## 钱的去向表` ≥8 笔：**补欠花（想买没买的、旅游、请朋友）≥4 笔且与场面合计 ≥70%**，**借出 0 笔**，被骗 ≤1 处且不得是归零主因 | 04 全款 8,600 万买房（+7）、05 消费三件套（+4 / +7 / +6） |
| **习惯漂移（v7）** | 习惯/成瘾题必须写 `## 习惯漂移`：习惯原样运行、**对象 + 规模一起换**（还每天买，但不买中过的那组号，而且买得更多） | 05 结尾「接单成功 / 请前往取餐」＝动作不变、身份已换 |
| **转场回位（v7）** | 压缩/前史段结束必须有回位句把镜头拉回当下；跨度题必须写 `## 转场表` | 01 每次跨年前都先落回一个具体场景 |
| **爽的忘本（v8）** | 兑现/暴富题必须写 `## 忘本（拒绝与筛选）` ≥3 行；拒绝有理由 + 有动作 + 有对照 + 母亲那句用事实回击 | 大衣哥式被索取、富豪堂姐拒借被叫好 |

### 2.4 情绪节拍表（6–10 节，节数不固定）

```text
| 节 | 位置 | 情绪值 | 事件 | 状态前 → 后 |
```

- 节数由剧情决定，**不是固定八拍**。两节之间没有可见状态变化（钱、身体、关系、信息、决定）就合并。
- 每一节都要回答：谁做了什么、因此状态从什么变成什么。
- 允许结果前置（开奖夜、社死现场），但必须在前 4 行给时间路标并说明回到哪一天；不许倒叙完再倒叙。

### 2.5 对手与见证人

- 人物题：必须有对手（谁做了什么、何时升级、在哪结算），并写 `## 反转表（报应对应表）`，≥3 行。
- 规则/习惯/制度题：不要求反派，但必须写清**谁有反应**——见证人、对照者、亲戚、旧同事，至少两次「他人反应」的场面，否则全篇就是年表。
- 报应不由叙述者宣布：只写没接的电话、空号、删掉的好友、「别翻了」这类动作和话。

### 2.6 快推结构：前半加速，后半展开（v5 硬门）

抖音口播没有「起承转合」的余裕。拆文库实测：第一个大事件（≥+5）的位置是 **01=18%、04=29%、16=27%**；慢热的 13（49%）、15（53%）靠的是每一段都有小兑现，不是靠把高潮留到最后。

**位置表（硬门）**

| 位置 | 必须完成 | 不许出现 |
|---|---|---|
| 0–5% | 结果前置钩子：最狠的结果、最痛的数字、或最爽的一句判词 | 环境、天气、人物履历 |
| 5–12% | 主线启动：核心动作 / 规则 / 赌注说清楚，观众知道自己在等什么 | 还在铺背景 |
| 12–24% | 压缩铺垫：把「习惯 / 关系 / 前史」压成 3–5 个带数字的小场景（蒙太奇），每个场景 ≤8 行 | 一个场景写 20 行以上 |
| 24–32% | **第一次大事件（爆点）**：第一次兑现、对质、承认、翻车、社死、面试 | 爆点留到 50% 之后 |
| 32–50% | 峰值区（+6 以上）：第二次兑现或双人交锋的最高点 | 峰值之后还在补前情 |
| 50–85% | **「之后」**：后果、二次交锋、代价、关系新常态（≥40% 篇幅、≥4 个情绪节点） | 用倒叙回填前情 |
| 85–100% | 判词与收束：数字 / 器物 / 一句换手 | 抒情总结 |

**三条判据**

1. **爆点位置**：第一个大事件（情绪值 ≥+5，或类型为对质/兑现/翻车）必须 ≤ **32%**。
2. **之后要够长**：爆点之后还要有 **≥4 个情绪节点**，且 **>50% 的部分必须已有 ≥3 个节点**。爆点之后如果直接收尾，说明你写的是短梗，不是副本。
3. **不许有空窗**：相邻两个情绪节点的间距 ≤ 全文 **22%**；任意 10% 区间内至少能指认一个情绪节点。

**「之后」能写什么**（写不出来就是选题太薄，换题而不是拖长铺垫）

- 对手的反应与二次交锋（他不服、他找人来、他改口、他学你）
- 周围人的重新定价（谁开始躲你、谁开始借你、谁改口叫你哥）
- 代价的具体账单（钱、身体、关系、信息、位置）
- 主角自己的习惯复发（旧反应在新处境里再出现一次，但结果不同）
- 换手复现：开头他对你做的动作，结尾你做回去
- 新常态 + 一个可见判词（数字 / 器物 / 一句话）

**压缩铺垫的写法**：不要写「那天之后又过了一年」，写「一年里你做了三件事：A（数字）／B（数字）／C（数字）」，每件 3–6 行，用物件和数字推进，不用对话推进。

**跨度写法（v6 新增：治「第 1 年到第 7 年跳转生硬」）**

拆文库的时间操控实测（`01/写作手法.md` 第 3 节、`05/写作手法.md` 第 3 节）：

| 手法 | 拆文库原样 | 用在哪 |
|---|---|---|
| 恒定的物 vs 飞掉的时间 | 母亲「还是小火 / 还是两个钟头」；主角的胃从 10 分钟涨到半小时 | 长期习惯题、长期照顾题 |
| 时间刻度按危险定价 | 平静期按月过、收网前按周过、灾难当天按小时过、灾后按年跳 | 漫长等待段 |
| 一句话跳年 + 降级清单 | 「时间悄无声息地碾过了 7 年你 24 岁」+ 平头 / 外卖服 / 月供 2,850 / 房租 350 | 灾难或兑现之后 |

**硬要求**（四条，缺一条就是「年表稿」）

1. **禁止年表**：不许「第一年… 第二年… 第三年…」按年编号列事。时间靠**同一动作的重复 + 细节漂移**走：同一句话、同一个位置、同一件物件，第二次出现时只换掉一个数字（药从一种变三种、面从两块五变三块五、铁盒从一张到三百张）。机械闸：以「第N年/第N个年头」开头的行 ≤2 且不得连续（`fuben_loop.py draft`）。
2. **一个不动的参照**：至少给一件从头到尾不变的东西（母亲的火候、彩票站第三张塑料凳、铁盒的缺口），主角的日子在它旁边变；跨度越大，这件东西越要反复出现。
3. **兑现/转折前必须有生活**：核心习惯要写成**可复现的一天**（六点半起床 → 上班 → 买票 → 晚上对号 → 进盒），至少出现 2 次，第二次带一个可见的变化。压缩不等于清单：兑现点之前的内容占比 **≥10%**，且 ≥2 处身体/环境。
4. **真要跳年，只跳一行**：「时间 + 一个物件降级」的单行（「那年冬天 你妈的药加了一种」），跳完立刻回到眼前的场景，不解释、不总结。
5. **时戳不作分段器（v6.1 反流水账）**：不许「X点+你做什么」一行一拍地推日子。时间只能嵌在动作句里、且仅当时间本身是信息（约定时刻、掐表成绩、发病/建档/删除的钟点）才保留；前16行时间开头 ≤1、全篇整行时戳 ≤1 处且不得在开头、时戳开头行 ≤3.5%。机械闸：`fuben_loop.py draft` 的「开头不堆时戳」。起因：75 开头「凌晨三点十一」独立成行 + 全篇 22 处时戳分段，读感＝钟面台账——根因是旧提示词把「时间」写进环境一笔与回位句、L2 首屏闸强制前 12 行含时间词，三层合力所致（2026-09-19 三处已改）。

5. **压缩段必须落地（回位句）**：前史/蒙太奇段结束时，用一句把镜头拉回当下——你在哪、手里拿着什么（「那天早上你坐第一班车 / 票用塑料袋包着 / 揣在贴身的兜里」；**不报「现在几号」**，时间只在它是信息时嵌句尾）。**不许从七年前直接切进兑奖窗口**（观众反馈「过度的太突然了」就是这个毛病）。机械闸：跨度题必须有 `## 转场表`（压缩段 → 回位句 → 正文锚点），锚点必须命中正文。

**为什么**：观众说的「跳转生硬」不是嫌快，是嫌**中间没有生活**——只有编号和事件，没有可复现的一天。压时间不是删生活，是把生活的重复压成同形不同细节。

### 2.7 钱的去向：先补欠、再给朋友，最后才是亲戚（v7 硬门，兑现/暴富题）

抖音口播的爽不是「他有钱」，是**他花出去的那一下**——而且他花的地方，得是观众自己也想花的地方。拆文库实证：`04` 全款 8,600 万买顶层复式，写的是售楼小姐端咖啡的手在抖（+7）；`05` 88 元染头 + 65 元紧身短袖 + 120 元烧烤，写的是兄弟齐声喊哥（+4/+7/+6）。

**v6 写错了什么**（观众反馈「不要是借钱借完的」）：把「给」全写成亲戚借钱 → 钱是**借完的**，不是花光的；借出去的钱只有关系里的憋屈，没有爽。v7 把去向按「观众自己想不想花」重排：

| 优先级 | 类别 | 占比 | 怎么写 |
|---|---|---|---|
| 1 | **补欠花**：没钱时想买没买的、想去没去的 | ≥ 25% | 替当年站在橱窗外的那个人买单：一直想要的那件东西、带家人第一次坐飞机看海、把当年请不起的客一次请够。心理学口径：**补偿性消费**（匮乏→有能力后报复性补偿，本质是「自我养育」）+ **心理账户**（彩票钱落在「天上掉下来的」账户，最不经用） |
| 2 | **场面花**：车 / 房 / 席面 / 修路 | ≥ 25% | 每笔都配「他人身体反应做刻度」（手抖、不敢坐、跟着车跑） |
| 3 | **给自己人**：穷时陪过你的朋友、工友、家人 | 15–30% | 请客、给母亲最好的病房与护工、把当年请不起的那顿补上；**不是借给亲戚** |
| 4 | 借出与送出 | **0 笔（v8 硬门）** | 亲戚借钱只写「拒绝现场」；一分钱不出门，钱不能是借完的 |
| 5 | 亏：自己拍板的生意 | ≤ 15% | 可写可不写；写了必须是他自己签的字 |
| — | 被骗 | **0–1 处，绝不能是归零主因** | 被骗是憋屈不是爽 |

- **忘本要写成爽的忘本**（v7 新增，v8 加严）：发达后他把旧关系筛了一遍——「**来借钱的不借，来吃饭的都请**」。穷的时候是别人决定他坐哪一桌，现在是他决定谁能上桌。爽点落在**筛选权**和「谁能坐上桌」上，不落在骂人、也不落在道德忏悔上（拆文库口径：嘲讽先记账，后面才结账；读者要的是公正世界，不是你反思）。

### 2.7.1 爽的忘本：四个必写镜头（v8 硬门）

社会情绪对位（写进设定留档，正文不解释）：「嫌你穷，恨你富」的亲戚索取是当下最强的共鸣点——大衣哥借出去的钱没人还、富豪堂姐拒绝救济穷亲戚被网友叫好、「先守好自己的家，再谈对外的情」被反复引用。**读者要看的不是主角大方，是他终于会拒绝。**

| # | 镜头 | 写法 | 检验 |
|---|---|---|---|
| 1 | **拒绝要有理由（当场，短）** | 不哭穷、不绕弯：一句事实顶回去。「你上次借的三千 还没还」「他母亲住哪家医院 先说这个」 | 有具体数字或事实，不是「不借」两个字 |
| 2 | **拒绝要有动作** | 关门、倒一杯水不提钱、把点心收下钱不给、删好友、退出家族群 | 有一个可见动作落在正文 |
| 3 | **对照：他后来怎样** | 半个月后晒新车 / 借条写不写 / 群里开始说你忘本 | 拒绝被证明是对的（观众解气） |
| 4 | **母亲说你变了 → 用事实回击** | 「谁在我吃三块五挂面的时候 请过我」——把当年那顿饭、那件小事说出来 | 主角不辩解道德，只报事实 |

- 设定必须写 `## 忘本（拒绝与筛选）`：`谁来 → 怎么开口 → 你怎么拒 → 他后来 → 正文锚点`，≥3 行。
- **借出必须为 0**：亲戚借钱一律写成「拒绝现场」，一分钱不出门。钱的归宿只能是三件事——**旅游、买自己以前舍不得买的东西、请自己的朋友**（第 2.7 表第 1、3 类）。
- 被拒绝的亲戚不许写成主角的亏欠：拒绝之后不给任何「其实我心里也不好受」的补偿句；镜头立刻切到他请朋友的那张桌。
- **钱必须是他在场、点头的时候出去的**：归零的理由只能是花法与请客的规模失控（一天一顿变一天三顿、一次三百变一次三千）。**禁写**集资跑路、空了办公室、报案要不回钱、假合同——这些是憋屈结算。
- `## 钱的去向表` **≥8 笔**；账要平：`到账 + 变卖 + 收回 = 各笔去向 + 余额`，误差 0；每笔都要有能命中正文的锚点。
- 收束判断句仍然是「你花的每一笔你都记得，只有总数你不记得」。

### 2.7.2 花光的底气：他为什么敢花（v9 硬门）

观众会问一个最朴素的问题：**四百万怎么会十八个月花光？** 如果答案是「被骗」「不懂理财」「失控」，那就是把主角写成傻子，观众替他憋屈。拆文库的答案是**他相信钱还会来**——`04` 的挥霍建立在「12 亿财产还在涨」的错觉上，`21` 的加注建立在「下一把就回本」上。

兑现/暴富题的底气只有一种写法：**他还在买、他信还会中**。

| 要求 | 写法 |
|---|---|
| 底气必须是一句话，且带数字 | 「一注就是五百万 / 再中一次就都回来了」「一期五百万 / 花掉的是一期，不是四百万」 |
| 底气是**每一段花钱的引擎** | 正文出现 **≥3 次**，并且**每个花钱阶段（车房 / 席面 / 旅行 / 请客）至少落一次**；不能只在开头结尾各放一句 |
| 花销与习惯必须咬合 | 换号、**加注阶梯**、算账写在同一个因果里：**换号 → 注数越买越多 → 觉得下一期就中 → 花钱不看余额** |
| **加注阶梯（必填）** | 兑现之后每天买多少必须**逐级涨**，并写进 `## 加注阶梯`：`阶段 / 日期区间 / 注数 / 每天花多少 / 正文锚点` ≥3 行（例：五注 10 元 → 十五注 30 元 → 五十注 100 元）。涨了多少钱观众要能算出来 |
| 小奖是信念的燃料 | 注数涨上去必然中小奖（蓝球中一注 5 元）：写「五块的 十块的 中过不少 / 最多一次两百 / 大的没有 / 每中一个五块 你就觉得下一张更近」。**不许写「一次都没中过」**——那违反常识，也丢掉了最强的强化物 |
| 「大钱没有」必须说出来 | 观众要同时看见「小奖不断」「大奖没有」「他还信」 |
| 底气不许破 | 结尾不写醒悟、不写「你终于明白不会中了」；只让数字轻轻提醒（「中过奖的只有一张」） |

- 设定必须写 `## 花光的底气`：`他的底气（一句话）| 依据 | 正文锚点`，≥3 行；正文里的信念句 ≥3 处（机械闸按 `还会中 / 还能中 / 再中 / 下一期` 计数），且要能看出它落在不同阶段。
- 设定必须写 `## 加注阶梯`：`阶段 | 日期区间 | 注数 | 每天花多少 | 正文锚点`，≥3 行且金额递增（机械闸核对比值）；结尾判词要给「兑现前 vs 兑现后」的彩票总花费对比。
- 归零的理由公式：**花法（规模失控）× 底气（还会中）= 花光**。缺了底气，观众只会问「他凭什么」。

### 2.8 习惯题结尾：习惯不变，内容漂移（v6 硬门）

成瘾 / 习惯 / 上瘾型题目（彩票、游戏、减肥、吃药、刷手机）的结尾**不许写成「他戒了」**，也不许原样重复「一切照旧」——观众要看见习惯**活着、但换了内容**：

| 维度 | 必须 | 例 |
|---|---|---|
| 动作 | 依旧每天一次，地点时间都不变 | 还去彩票站、还是每天买 |
| **对象** | 换掉那个旧元素 | **不再买中过的那七个号**（「中过的号 不会再中」） |
| **规模（必变）** | 买得更多或更少，直接给数字 | 从一张一注 2 元 → 一次五注 10 元 |
| 信条 | 给新做法一个他自己的解释，直接写出来 | 中过的号不会再中 |
| 判词 | 结尾仍落在器物/数字上，且能算出「换了多久、多了多少」 | 铁盒里的张数照旧在涨、总成本能算出来 |

- 设定必须写 `## 习惯漂移`：`旧做法 → 新做法 → 他的说法 → 正文锚点`，≥2 行。
- **漂移至少两维，其中规模必须有变化**：只换号码不算漂移（观众会觉得「还是那个他」）；号码换了 + 买得多了，才是习惯活着、内容换了。机械闸会核对「新做法的数字大于旧做法」。
- 漂移不能是「他变好了」：习惯的力量在于它自己会找新的理由继续，观众认的是这个。
- **兑现后的习惯动力（v9）**：中奖/成功之后继续买，动力是**「还会再中」**，不是「上瘾」这种抽象说法；正文要写清「一次都没中过」＋「还信下一期」两件事同时成立（见 §2.7.2）。
- 事实锁要分时段写：**兑现前**锁死玩法（一注 2 元、不倍投），**兑现后**允许号码与规模一起变（多注不是倍投），闸门按「中奖后」段落放行；只有「号码有灵 / 预感 / 天选」永久禁止。

- 原子单位从「节点」换成「场面/镜头」：`设定.md` 在 `## 情绪节拍表` 旁**必须**并列 `## 场面表`，每个场面一行，五要素齐：**在场者（≥1 个有身份的活人）/ 地点 / 进行时动作链（动词连着动词，不是状态形容词）/ 一句转述引语 / 一件可拍器物**。
- **关键场面 ≥12 行逐拍写**（v1 §15.4 板鞋事件条款的机械表达）。3.7 的 10% 是及格线不是目标：原文 32 一个呼噜写 20+ 行才叫场面。
- 秒级节奏图：爽点表位置% 逐行换算「第几秒」（口播按 4.8 字/秒估，D0 有真实时长后换实测倍率）。0–3s 必须是「具体的人在做具体的事」，不许放抽象钩；15s 第一个可看见的场面；30/60/90s 各一个场面爆点；末 20s 判词+器物。

## 3. L2 正文规则

### 3.1 第二人称与称呼

全篇「你」。每个人物首现带身份或名字：`母亲`、`同事陈哲`、`彩票站老板娘`；两个同性别在场时，换主语就重报身份，不让观众猜「他/她」。

### 3.2 对白是爽点武器，不是节拍填充

- 保留能改变行动、关系或规则的台词：一句边界（母亲）、一句嘲讽（先记账）、一句借钱（结账）、一句打脸、一句姿态。全篇 6–10 个功能单位为宜。
- 删掉的：空回应（「说 好 / 嗯 / 行」）、轮流问答、为换行而写的问答。
- 转述代替对白没问题，但**不要把最狠的打脸台词转述掉**。

### 3.3 短行与段落

- 一行一气口，8–12 字是常见节奏；**行数不是指标**，不为凑行数重复年份、动作、环境。
- 每 45 行至少一次身体/环境；身体反应服务状态变化，不按配额硬塞。
- **v10.2 改带**：一篇 2,800–3,600 字（拆文库原文实测 3,043–3,849；v1 归档「≥2800、<2600 按段子体退回」的依据回收）。现行 draft 闸硬下限 2200 暂不动——终值等 D 批次真实时长数据校准后一次改闸（R9-A2：3 分钟假设从未被验证过）。

### 3.4 每一节的最小闭环

```text
明确时间/地点 → 触发 → 主角连续动作 → 物件/旁人反应 → 状态改变 → 下一步有理由
```

### 3.5 去模板与去 AI 味

「命运的齿轮」「空气开始变得稀薄」每篇最多一次；黑名单意象（阳光刺眼慢悠悠起床 / 早市大爷大妈 / 云卷云舒 / 松弛感 / 感慨人生美好）出现即改。旁白不宣判「你堕落了」「这就是报应」。

### 3.5.1 梗预算：素材现场搜索制（R18 立制；R18b 按账号主令重构）

- 账号主令 R18「加入些搞笑的梗，少量合理的加入」；R18b 补令：「不是写死在 skill——是每次出题后搜主题相关的真梗，大纲给账号主确认后再动笔」。
- **素材必须现场搜**：每篇创作前按主题联网搜索当下真实流行的梗（社区梗 / 真事段子 / 行话），每个梗在设定.md 记**出处 + 拟落点**，与事实锁同纪律。**禁止**从本包词表或模型记忆搬梗——过期梗＝假梗，自编段子不是梗（观众认不出的不是梗）。
- texture 脚本的 MEME 词表**仅是检测器**（数热词用），不是素材库；已知梗词随批次增补。
- **预算 ≤3**：梗要服务刻画或判词、落物证/引语形态；判词式幽默优先。梗清单随大纲一并交账号主（0.1 确认环）。
- 入册三字段——出处证据：账号主明令 R18 + R18b；冲突自检：与 0.1 顺序兼容（清单并入确认环一页）、与事实锁互补（梗也交出处）、与 3.5 去模板互补（真梗≠模板句式）；日落条件：账号主撤销确认环流程，或连续两批 D 数据显示带梗稿表现更差。

### 3.6 数字预算（advisory，二轮会审定，不设硬闸）

- **非钱题**：全篇数字密度 **10–20 个/千字** 为语料带（死装 10.0 / 无辣 13.0 / 17.4 / 18.1）。低于 10 会失去账感，高于 20 先自查；**超过 25，爽点表每个数字回答「这个数字在指控谁」**，答不出的删。75 初版 46.6（≈每 2 秒口播一个数字）就是反面教材——数字和数字互踩，听众一个都记不住。
- **钱题**：≤30/千字（04 语料 28.2 ↔ 72 成稿 28.4 带内对），因为钱题的每个数字本来就是账。
- **删装饰数字的四把尺**：重复出现的总额（同一数报两遍留一遍）；精确到无指控对象的秒数/分钟数（念稿超时留「超出去一截」，删「三十七秒」）；日程表的裸钟点（有背叛/等待功能的留，纯报时的删）；算式校注（「误差二十块以内」这类给机器看的话不进正文）。
- **不许硬凑下限**：为把密度提进 10 塞装饰数字 = 反向违规。数字只跟指控、账本、判词走。
- **数字三处原则（R9-B5，3.6 的深化——给替换方向而不只是上限）**：数字只许出现在三处——**钩子对比**（4,320 万 vs 8,712）、**账本合上**（47 划 29 剩 18）、**判词**（二百一十七个字）。三处之外的数字一律**翻译成动作或场面**：不写「4,320 万播放」的第三次，写「他把你的独白垫在电影后面，评论区在问这是什么电影」。判据从「≤25/千字」升级为「超出三处之外的每个数字，要么有指控，要么成场面」。
- **汇报口径纪律**：任何向评审席/发布单报密度，必须现场运行 `scripts/fuben_density.py` 并附输出行；手搓正则自报 = 还款态度记账（R9 起因：同一稿出现 21.7 与 38.4 两个自报数，差的正是这把尺）。

### 3.7 单一放大事件（v1 教义回写，advisory）

- 除压缩铺垫的 3–5 个 ≤8 行小场景外，**必须有一件主线大事件按拍逐写 ≥10% 篇幅**（连续场景，一拍一段，动作—物件—身体反应轮着来）。v1 §15.4 的原义：压缩是手段，放大是本篇的正面强攻；只有压缩没有放大，通篇就是行程表。
- 反例账：75 白嫖段初版 5.5%（17 行）一天 40 件事流水过去、最狠的冲突一掠而过；扩到 33 行 10.2% 后，全篇才有一场「正面打完」的戏。73 走廊夜 8.6% 同案。
- 放大事件内**不加新装饰数字、不加对白配额外的对白**——靠拍子长，不靠数据撑。

### 4.2 人工（fuben-review）

额外检查：拆文机制是否真正落地（不是只写了「参考 04」）、爽点是否落在声明位置、外部事实是否适用、每节是否有状态变化、普通观众能否一遍听懂。

v6/v7/v8 追加六问：**① 跨年段落读起来像生活还是像年表？② 前史段有没有回位句、会不会直接切场？③ 钱是花出去的，还是借完/被骗走的？花的地方观众自己想去吗？④ 有没有「旅游、买自己以前舍不得买的、请自己的朋友」这三件，且每件都有数字和场景？⑤ 忘本写成了「筛选权 + 拒绝现场」还是写成了骂人/亏欠？⑥ 结尾的习惯还在吗——号码换了没有、买得更多了没有？**

二轮会审追加两问（advisory，进评分表不进机械闸）：**⑦ 数字密度在非钱题是否 ≤25/千字、每个数字答得出「在指控谁」？⑧ 是否存在一件 ≥10% 篇幅的放大事件按拍逐写，还是全篇只有压缩？**

R9 会审追加两问：**⑨ 并排读自批判（学 OnlyShot 阶段 5）：与同型原文并排读 300 字，列出「原文有而本稿没有」的刻画元素清单（温度/气味/动作链/在场者反应/时间膨胀点），逐条给改法或删除理由；⑩ 听感 QA：发布前 TTS 通读一遍，数字念着硌耳朵的当场删——密度上限的最终裁判是耳朵，不是脚本。**

同一问题在两篇以上复现 → 先改本包与脚本，再改正文。


### 3.9 状态三问：成因、时间形状、物证（R16 立制，advisory）

人物带一个**核心状态**进稿（不想听歌 / 三年不写自己 / 再没回过老家 / 戒了酒），当场过三问，答不上的状态不许写进正文：

1. **何时种下**——状态是哪件事、哪一年种下的？成因可以延迟揭示（先物证后揭晓，语料常式），但不许没有。
2. **一直还是变了**——时间形状要可指认：一直如此（重复行为、「还是」句式）还是何时拐的（拐点前后要有行为对照）；结尾若有变化，变化必须有机制——今晚与三年前那晚做了不同的事，观众要能指出差在哪一拍。
3. **观众从哪拼出来**——成因、形状、变化，至少两样走物证 / 第三方转述 / 重复行为；叙述者和任何人物之口都不许替观众总结状态。

**两条红线（v1 §7.1/内心≤3 血统恢复并加严）**：

- **题眼句禁入人物之口**——妈、围观、反派，谁把主题说出来谁死。长辈的理解只许走「菜都切好了」式：问一句明知答案的话，做一件早就开始做的事。
- **叙述者禁直报情绪**（孤独 / 难过 / 说不上来 / 替谁疼了）——情绪一律翻译成动作、时长、器物：扣过去又拿起来、数了两遍她的字、键还弹得起来。

**判例（拆文库，全是默认操作）**：01 无辣不欢＝「从那以后泼辣油」（何时种下）→「还是小火 还是两个钟头」（一直）→「整锅汤喝完 一口辣椒油都没再加」（变了），全篇无一句「和解」「想家」；食堂白水面条＝「他为了给你买下午茶 在食堂吃了一个月白水面条」（动机经第三方转述、延迟揭晓）；课堂绰号＝「眼睛盯着书页上的一个字 看了整整10分钟也没看进」（行为暴露状态）；01＝「备注还是那句话 外加双倍辣」（习惯的时间形状藏在订单里）。

**反例账（75 v2，未发布稿内部判例，R16 已修，修复 diff 即教材）**：妈把题眼说出口（「你这一年 过的都是别人的日子」）；三年不写自己无成因无拐点；Delete 键磨没立了物证没兑现收据；叙述者直报×3（说不上来哪种心情 / 疼了三秒钟 / 这四个字你不熟）。

**入册三字段**——出处证据：账号主明令（R16「为什么不想听歌 / 一直还是变了 / 句句不提但观众就懂了」）+ 75 v2 全稿违例；冲突自检：与 3.6 数字预算无冲突（三问物证里的数字按「三处原则」执行）、与 3.5 旁白不宣判互为加强、与 2.6 快推结构无冲突（成因锚允许落后段，延迟揭示是语料常式）；日落条件：连续两批 D 数据若显示带三问脊柱的稿完播不升反降，三问删、保留 v1 §7.1 原理层（睹影知竿）。

# 人生副本 · 通用骨架（拆文实测 · v7，2026-09-18）

> 这份文件回答一个问题：**同一套事实，怎么排才好看。**
> 它是从 `拆文库/01 / 04 / 13 / 15 / 21` 等篇的情绪曲线与节点位置里量出来的观察区间，不是写作配额；节数不固定，**没有「必须八拍」这回事**。
> 配套机制与爽点池见 `人生副本实录.md` v9；
> 机械闸 `scripts/fuben_hype.py`、`scripts/fuben_loop.py`。

## 一、先画三张图，再写正文

### 1. 事实/对象图

```text
对象名称/身份 | 首次出现时间地点 | 数量/金额/规则 | 谁能看见 | 后段如何回收
```

示例：`一张新的2元双色球单式票 | 2019-09-17彩票站 | 每天只一张、固定03 07 12 19 24 31+09 | 你/母亲/老板娘/陈哲 | 官方结果核对后放回铁盒`

### 1.5 跨度图（v5 新增：长期题必填）

```text
不变的参照（从头到尾不变的那件东西） | 同一动作（重复出现的那个动作） | 第1次细节 | 第2次细节漂移 | 第3次细节漂移
```

示例：`彩票站第三张塑料凳 | 每天一张2元、折三折、进铁盒 | 铁盒里1张 | 甩进第365张、盖子开始紧 | 第2558张、盖子合不上`

- 不许写「第一年…第二年…」的年表；跳年只允许「时间 + 一个物件降级」的单行。
- 兑现/转折之前的内容占比 ≥10%，且至少有两次同形不同细节的一天。
- **压缩段必须落地**：前史段结束时用一句把镜头拉回当下（现在几号、你在哪、手里拿着什么），不许从七年前直接切进下一场；跨度题写 `## 转场表`（压缩段 → 回位句 → 正文锚点 ≥2 行）。

### 1.6 钱的去向图（v5 新增：兑现/暴富题必填）

```text
笔数 | 金额 | 类别（补欠/场面/给自己人/借出/亏/被骗） | 他人反应 | 正文锚点
```

- **补欠**（没钱时想买没买的、旅游、把当年请不起的客请够）+ **场面**（车房席面）≥ **70%**，**补欠 ≥4 笔**；**借出 = 0 笔**（钱不能是借完的）；被骗 ≤1 笔且不得是归零主因；亏 ≤15% 且必须自己拍板。
- **花光的底气**（必填）：他为什么敢花——一句话、带数字（「一注五百万，再中一次就都回来了」「你花掉的是一期，不是那四百万」）；正文出现 ≥2 次，一次在花钱中段、一次在结尾习惯段；「换了号以后一次都没中过」必须明写，底气结尾不破。
- 忘本写成筛爽的：**来借钱的不借，来吃饭的都请**——穷时别人决定他坐哪桌，现在他决定谁上桌。
- 结尾余额 = 到账 + 变卖 + 收回 − 各笔，误差 0。

### 2. 爽点/情绪图（v3 新增，缺这张图不许开写）

```text
位置% | 情绪值 | 事件 | 判定类型 | 正文锚点
```

- 第一格必须是钩子（≤22%），中间必须有一个 ≥+5 的峰值（25%–48%），后段必须有一个 ≤−6 的谷底，结尾必须落在数字或器物上。
- 相邻两格之间不得超过全文 30%：超过就是「年表区」，观众会划走。

### 3. 因果/状态图

```text
上一状态 → 触发（为什么现在） → 主角动作 → 客观结果 → 下一状态
```

没有箭头就不是剧情，只是年份和漂亮句子的并排。

## 二、情绪值口径（沿用拆文库五维标记）

| 值 | 含义 | 用法 |
|---|---|---|
| +5…+8 | 大爽点：兑现、被围观、打脸、称呼翻转、数字砸脸 | 每篇 2–4 个，峰值一个 |
| +1…+4 | 小爽点 / 暖点：被看见、物件找回、姿态爽点 | 每隔 150–250 字补一个 |
| 0 | 状态点：习惯形成、关系定型 | 只用来换气 |
| −1…−5 | 代价：羞辱、借钱、被骗、身体账单 | 必须能说出是谁做了什么 |
| −6…−9 | 谷底与判词：余额见底、关系清零、判决数字 | 放在 70%–90%，不要提前用光 |

## 三、常用节拍（按位置排，不按拍数排）

| 位置 | 功能 | 拆文库对位 |
|---|---|---|
| 0–5% | 结果前置钩子：数字并置、最痛判词、或直接甩出最狠的结果 | 04 N1、67 原稿 |
| 5–12% | 主线启动：核心动作 / 规则 / 赌注说清楚 | 01 N1–N3、21 N2 |
| 12–24% | 压缩铺垫：习惯与关系用 3–5 个短蒙太奇带数字推过去；长期题用「同一动作重复 + 细节漂移」，**不许年表罗列** | 13 N4–N9（但只留最狠的几段）、01 时间操控 |
| 24–32% | **第一次大事件**：兑现 / 对质 / 承认 / 翻车 / 社死 | 04 N5、16 N5 |
| 32–50% | **峰值区**：最高的那一次兑现或交锋 | 04 N6、15 N13 |
| 50–70% | 之后·对抗：欠债的人、笑过你的人、想复制你的人一一结账 | 04 N7、21 N11–N13 |
| 70–85% | 之后·代价：余额、药单、位置、关系出账 | 15 N18–N19、21 N18 |
| 85–100% | 判词与收束：数字 / 器物 / 一句换手 | 01 N22、04 N16 |

**v4 的核心变化**：爆点从「留到 75% 揭晓」改成「30% 之前就发生」，后面 70% 全部写「之后」。铺垫不是删掉，是压成蒙太奇。

**v5 的核心变化**：压时间不等于删生活——跨年段落要写成「同一天反复出现、每次只换一个细节」，兑现前的生活占比 ≥10%；兑现后的钱必须**主动花掉/给掉**（花+给 ≥60%，被骗 ≤1 处）；结尾的习惯原样运行、内容漂移（旧做法 → 新做法 → 他自己的说法；**对象 + 规模两维一起变，买得更多**）。三张图变五张图。

规则题、习惯题也走同一张表：**兑现可以小（一次中奖、一次被叫哥），但不能没有**。

## 四、单场景最小拍子

```text
场景可辨（谁、在哪、手里拿着什么；**时间仅当它本身是信息时嵌句尾出现**，不做分段器）→ 触发动作 → 主角连续动作 → 物件/规则留下证据 → 旁人或环境产生反应 → 状态改变 → 下一步有理由
```

只有真正改变风险、资源、信息、关系或决定的事件才扩成场景。对白一场一问一答以内；转述能过就转述，但打脸台词要直引。人物超过一个时，新主语先用身份/名字。

## 五、写作 Loop

```text
读取同型拆文（只记机制与位置）
→ 事实锁
→ 爽点表（位置/情绪值/锚点）
→ 情绪节拍表（6–10 节）
→ 对象台账 + 因果/状态台账 + 跨度图 + 钱的去向图
→ 正文
→ fuben_run.py（事实 + 爽点 + 成稿）
→ fuben_hype.py 复核 → fuben-review 人工一遍读懂
```

门禁失败时：缺爽点改位置与事件，缺事实改锁与数字；**不许用「润色得更文学」掩盖没有爽点，也不许用「事实更严谨」掩盖剧情不动。**
