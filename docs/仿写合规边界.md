# 仿写/同题重写的合规边界（2026-09-19 立）

> 拆文侧已有护身声明（`story-short-analyze` 拆解边界：只读的转化性文学批评），仿写侧一直没有等价文档。本文件补上。它只约束**本仓库的仿写产物**（`作品/` 40 号以后的同题平行重写系列），不是法律意见。

## 1. 拆解与仿写的性质分界

| | 拆文（`拆文库/`） | 仿写（`作品/` 同题/同型重写） |
|---|---|---|
| 性质 | 只读分析：结构提取、机制命名、评论教学 | 衍生创作：新文本 |
| 合法支点 | 转化性使用（criticism/review），不复制不传播 | **可复用思想 vs 表达**的风险区分 |
| 允许复制 | 最小必要引文（带行号点评用） | **见第 2 条红线** |

## 2. 仿写红线（本仓库自定，严于平台默认）

1. **骨架可借，表达必换。** 借的是结构机制（情绪曲线位置、反转工程、节奏税），不是表达。同一篇的句子级重合必须为零（含 ASR 化改写）。
2. **「同骨架换血」存量件（作品 43/44 等）是历史实验，自本文件起冻结，不再新增同题平行重写任务**；新实验一律走 71 式「事实锁自造＋机制借拆文库」路线（即：事实是自创的，借的只是结构）。
3. 仿写稿的角色名、单位时间、金额数字、关键道具**不得与原稿同一组合**（数字链是「换血」最容易偷懒的层，见 43 号教训）。
4. 系列原名（剧本人生/人生副本）、原合集名、原作者名**不出现在仿写成品正文或标题**；发布渠道不得带「官方/授权/续作」暗示。
5. 上传原稿（`uploads/`、`分篇/`）是 ASR 语料资产，仅供内部分析训练，**不二次分发、不做语料打包外传**；若仓库转公开许可证，原稿目录须先剥离。
6. 出现真人真实事件（恒大、印度高温等公共事件层）评论时保持虚构叙事立场，不指导现实行为、不构成侵权指控。

## 3. 抖音平台层红线（发布侧，与 skill 合规红线同一套）

- 违禁词双检（正文 0/引文 0）是发布前置；蹭热梗=0 是政策闸（见 `FUBEN_wordlists.json` CHANGELOG，29 号原稿经验：热梗有效但写完即过期，且易触审核）。
- 涉及彩票/中奖题：只写制度事实（玩法、公益金、周期），不写「包中」「内部渠道」；未成年人题材不出现消费引导。
- 社会议题（房产/债务/职场）不点名真实企业与可识别个人。

## 4. 违反处理

任何仿写稿被复核命中第 2 条：稿档回炉或删除，问题机制回写本文件与 `人生副本实录.md`，不只删某一篇（与 fuben-review「规律性问题回写 skill」同规则）。
