## Stage 2 结构 + 情节节点

### 故事核

- **设定**：一座 3 万人的大学，一个 402 寝室的普通男生——五官端正、不出彩也不丑、白 T 恤新头发、递烟分零食，一切完美符合「正常大一新生」的运转轨迹。他花 120 块买了一瓶大牌平替香水喷在衣领上，以为爱情的门票已经握在手里；他不知道门后是一座「壁垒森严的冰冷金字塔」。
- **主题**：魅力的幻觉与市场的真相——他以为情场的货币是才华与思想（3,000 字剧本大纲），实际流通的是社交直觉与情绪价值（一杯记得你胃不好的三分糖乌龙茶）；他以为压抑可以通过算法代偿（擦边流 / 交友软件），实际连「被明码标价的资格都没有」——他是庞大数据里的分母。全篇是一场缓慢的认知结算：从「门票在手」到「定死在原点」到「接受撕裂」，最终把虚无当成日复一日的口粮吞咽。
- **核心行动**：入学（正常轨迹 + 120 元门票）→ 日常（余光雷达 / 幻觉电影）→ 图书馆三秒钟（「没没没没人你你坐」+ 冷汗浸透 + 反刍一万遍）→ 背景板自白（微信列表只有妈妈室友群聊 / 问卷不敢回复）→ 床帘后（外骨骼卸下 / 四级资料文件夹 / 分身小号 / 私信「妈妈」/ 右滑分母）→ 咖啡馆（3,000 字大纲 + 36 元拿铁 vs 一句「记得你胃不好」→ 铅水无力 → 原点判词）→ 98 元 VIP（99+ 喜欢 = 僵尸号 → 无比疲倦 → 平静卸载）→ 3 天后复发重装 → 21 岁：吞咽虚无。
- **一句话**：一个 3 万人大校里的「背景板」男生，用 21 年时间确认了自己在一个「由外貌、社交直觉、情绪价值构成的立体坐标系」里的位置是原点——他的全部浪漫预算是 254 元（120 元香水 + 36 元拿铁 + 98 元 VIP），全部社交成就是六个字磕巴三次的三秒钟对话；白天他穿着「正常人的沉重外骨骼」当无害的壁纸，夜晚在 2 米 × 90 厘米的床帘后向算法乞讨 0.1 毫升多巴胺——他曾平静地卸载过一切，3 天后又重新下载；最终他接受了这种撕裂，在这台庞大冷漠运转良好的机器边缘，日复一日地吞咽属于他的那份隐秘而庞大的虚无。

### 故事梗概

9 月的燥热还未褪去，你提着 24 寸行李箱推开 402 寝室的门。白 T 恤、新剪的头发、递烟分零食——你完美符合一个正常大一新生的运转轨迹。班主任那句「考上大学你们就自由了」还在回荡，你对自由有着具象的渴望：操场并肩漫步、自习室相视一笑、周末两杯半价奶茶。你深信在 3 万人的大学里脱单只是按部就班的事，还花 120 块买了瓶大牌平替香水喷在衣领上——你以为门票已经握在手里。你只是没意识到，门后的社交法是一座壁垒森严的冰冷金字塔。

日子规律推进：早八、食堂、开黑。外人眼里你情绪稳定老实本分；只有你知道皮囊之下，五官感官已被「极度渴望又极度恐惧」的矛盾体彻底扭曲。余光像永不休眠的雷达：百褶裙让心脏漏跳一拍，前排女生的洗发水香味让你的呼吸小心翼翼。图书馆第三排，一个马尾女生的侧脸，你的大脑在零点几秒内完成了一部人生电影——她一定喜欢村上春树，一定温柔如水，你们毕业后在出租屋里做晚饭，灯光昏黄。然后她凑过来问：「同学，请问你旁边有人吗？」——这只是一个最基础的物理空间确认请求。你的警报系统全线崩溃：声带被浸水的棉花堵住，视线死死钉在她的帆布鞋尖上。「没没没没人 你你坐」——六个字，磕巴三次。她皱了下眉，说了声谢谢，再没看你一眼。你把这三秒钟反刍了一万遍，痛恨自己局促猥琐的模样。白天你是无害的背景板：微信列表里除了妈妈室友就是群聊，班级群里有女生发问卷链接，你总是第一个填完，却绝不敢回复一句「填好了」。

## Stage 4 反转 + 写作手法

### A. 反转分析

#### 前置反转检查

- 「你以为门票已经握在手里」（10%）——认知错误标注：爱情的门票制想象。
- 「但你并没有意识到 这扇门后的社交法则是一座壁垒森严的冰冷金字塔」（11%）——结构预告：全篇是这个几何命题的证明过程。
- 「你连被明码标价的资格都没有」（62%）——市场定位标注：代偿市场的底层身份预先亮明。

#### 主反转分析

- **类型**：认知反转（门票幻觉 → 原点认知 → 虚无接受：三拍揭示）
- **三拍**：第一拍 10–12%（「你以为门票已经握在手里 但你并没有意识到……冰冷金字塔」——叙述者预先盖章幻觉）；第二拍 82–84%（「在这个由外貌社交直觉情绪价值构成的立体坐标系里 你从一开始就被定死在了原点」——坐标系判词：幻觉的数学结算）；第三拍 95–99%（「你接受了这种撕裂……吞咽着属于你的那份隐秘而庞大的虚无」——接受即终章：认知反转的完成态，幻觉连残值都不再计提）。
- **铺垫线索**（4 条）：①「门票已经握在手里」（10%，门票制世界观——错误前提：把爱情理解为入场券问题）②「你明明想展现出从容和幽默 但身体却不受控制的执行了最拙劣的程序」（35%，知行分裂的机制预演）③「明知道对方可能是……引流机器人 但……依然分泌出多巴胺」（53%，明知故发——认知与行为的分裂已被平台利用过一次，98 元是第二次）④「你没有愤怒 因为你清醒的知道」（83%，清醒设防——愤怒的缺席预告了接受的必然）。
- **反转效果**：本篇的认知反转没有揭示瞬间的震惊（13 的数学 34 分、15 的化验单），它的揭示是弥散的——金字塔的判词在开头 12% 就已签发，正文只是漫长的执行公示。读者全程先知：看着他把 120 元喷在衣领上、把 3,000 字打印整齐，全部都是已知结局前的挣扎——与 15 的「剧透式悲剧」同构，但 15 的剧透指向事件（疤痕是假的），18 的剧透指向身份（你是原点）：命运悲剧（古希腊）与性格 / 结构悲剧的现代合流。

#### 副反转一：乌龙茶的错位（坐标系误读）

咖啡馆对撞的深层反转在他自己身上：他以为的情场货币（才华 / 深邃思想 / 3,000 字）在场外早已停止流通，实际流通的货币（记得你胃不好的体贴）他连见都没见过——「被拔了电源的复读机」输给的不是情敌而是整套汇率体系。副反转的本质：他连参赛项目都报错了。

#### 副反转二：付费的揭穿（98 元买真相）

99+ 喜欢 → 僵尸号：平台把「被喜欢」做成幻觉商品，98 元购得的是幻觉的验货报告。这一笔与 15 的空头支票构成镜像：15 的纸面 147 万赔偿无法兑现（制度承诺的落空），18 的 99+ 喜欢是付费后才见底的空数据（市场承诺的落空）——两个文本共用同一判词：**承诺的到账形态是假的**。

#### 副反转三：复发闭环（唯一的行动被作废）

卸载（91%）是全篇唯一一次主动的自我改造——三重删除（软件 / 分身 / 小号）接近一次自我清算；「3 天后某个深夜」用 26 个字把它作废。这一反转的狠度在于零渲染：没有心理描写、没有挣扎过程，只有一条进度条——戒断失败被拍成了纪录片而并非苦情戏。

#### 报应设计（缺席）

本篇无反派故无报应：夹克男生不是反派（他只是社交直觉的正常持有者）、平台不是反派（它只是精准）、算法不是反派（它只是捕获）——「庞大冷漠 运转良好的机器」没有恶意，只有运转。与 05–15 的加害者谱系对照，18 是系列「无加害者悲剧」的第二篇（第一篇 13 的机器是筛选制度，18 的机器是社交市场 + 算法）：批判对象从人彻底让渡给结构。

### B. 写作手法

详见 `写作手法.md`（11 项）。核心手法 Top3：①双重生活装置（外骨骼 / 床帘——白天与夜晚的空间语法）；②对位道具战（3,000 字大纲 vs 三分糖乌龙茶）；③复发闭环收束（3 天后重装 + 吞咽虚无的现在时）。

### 可复用结构

1. **双重生活装置**：白天的外骨骼 + 夜晚 0.9 米宽的领地 + 伪装文件夹——表面正常 / 内里深渊的人设三件套。— 适用场景：社恐 / 隐私 / 双面人生题材。
2. **对位道具战**：双方全部筹码物化为一件可同框道具（3,000 字大纲 vs 三分糖乌龙茶），道具的物理位置（压在水杯下）替作者宣判。— 适用场景：一切竞争 / 对比 / 败北场景。
3. **社死逐帧播放**：对话保留原声（含口吃）、失控写到器官、事后给物证、反刍用动词三连——社死的完整生命周期。— 适用场景：尴尬 / 紧张 / 崩溃场景的显微。
4. **复发闭环**：改变给足笔墨（三重删除），反弹极度吝啬（一条进度条）——戒断失败不写心理只写动作。— 适用场景：成瘾 / 恶习 / 循环题材的收束。
5. **钝感收束**：年龄盖章 +「依然」三连 + 摄入动词（吞咽）+ 永恒现在时——悲剧从经历改写为属性。— 适用场景：无事件 BE、慢性绝望的收尾。

### 同类型写作动作

1. 开写前列「浪漫预算表」：每笔支出标金额、日期与「重大投入」等级——账本即情节，最后一笔必须买到真相。
2. 给主角限定一套机器词汇的自我描述（运转 / 程序 / 电源 / 分拣），让机械化由他自己的嘴完成。
3. 社死场景先写「正常请求」的社会学定义（最基础的物理空间确认请求），再放生理灾难全谱——落差由定义先行垫高。
4. 对手写「无恶意胜者」：他的全部武器是一句体贴（记得你胃不好）——恶意的缺席让败北更无解。
5. 收束前安排一次「被作废的行动」（卸载 → 3 天后重装），用 26 个字完成——反弹的篇幅越短，绝望越长。
