# 势力：魔王教

- **名称**：魔王教（Demon Lord Cult）
- **性质**：潜伏于人类世界、信仰魔王（原作最终 BOSS）的隐秘教团，与魔族势力深度交织。在本作力量层级中，奈特梅尔称面对外神「魔王都只是路边一条」（第 284 章），暗示其位格低于外神三母，但仍是地表主要敌对势力。
- **核心成员**：
  - **魔王**：教团信仰对象，原作设定最终 BOSS，魔族共同信仰（第 13、284 章）。
  - **梅琳娜·贝拉多娜**：魔王私生女，**魔王教教主**，被下属尊称「神女殿下」（第 142 章）。原作一号位 / 本作关键女主，从第一幕起便活动于幕后（第 151 章）。试图借外神（堕落之母）之力污染原作女主（如西尔维娅），并借亡灵事件排除异己、谋得接近勇者维多利亚的新身份（第 142、151 章）。
  - **岩刺**：魔王教护法，梅琳娜心腹，已死（第 142 章兜帽男 / 黄泉提及）。
  - **黄泉**：魔王教干部，主持亡灵仪式，被格雷格暗影吞噬前遗言警告魔王「小心您的女儿（梅琳娜）」，暗示其不站梅琳娜一侧（第 151 章）。
  - **兜帽男（魔族护法）**：第 77 章被格雷格击杀的魔王教高层护法，梅琳娜心腹亲信之一，携带堕落之母石板执行任务（第 77 章）。
- **目标**：扩张魔王信仰与人类世界的隐秘影响；借外神力量畸变关键人物（使徒化）；为梅琳娜接近勇者并干预原作流程铺路。
- **与主角关系**：**宿敌 / 幕后黑手**。格雷格以 81 周目记忆识别魔王教成员身份与阴谋（第 77、142、151 章）。魔王教试图污染西尔维娅，直接威胁主角洗白求生路线；梅琳娜作为「真正的幕后黑手」（第 151 章标题）贯穿全书暗线。格雷格击杀其护法、吞噬外神石板进阶，并多次破坏其计划，双方处于持续对抗。

> 说明：梅琳娜「魔王私生女 + 教主 + 神女殿下」、岩刺 / 黄泉 / 兜帽男护法身份、借堕落之母污染、第 151 章「幕后黑手」均回原文核对；魔王教总坛、确切信徒规模原文未明确。
