# 西尔维娅·洛林

- 别名：西尔维娅、候补圣女、粉发少女、粉发学妹、二号位女主、女神容器、粉眸
- 重要性：核心配角（女主）
- 出场章节：第1-289章（共117章，依据 corpus）
- 身份背景：教会候补圣女，粉发粉眸少女，凭光属性魔法进入学院A班，被称「二号位女主/女神容器」。
- 核心经历：
  1. 第1章于地下城被暗河怪物拖拽濒死，为格雷格所救；第2章确认其勇者身份后同行。
  2. 第19章以光属性防御墙击败安吉拉，证实教会身份进A班。
  3. 第67-72章被奥德丽以麻醉气体制服掳走，格雷格破顶降临救下，西尔维娅解绳明白其心意。
  4. 第78章接住昏迷的格雷格并觉醒爱意；第216-218章夜访推倒格雷格、与维多利亚互生嫉妒陷入修罗场。
  5. 第263章与另一圣女维罗妮卡对手戏，互相识破对格雷格的在意。
- 性格特质：温柔崇拜中暗藏占有欲与危机感，对格雷格由朦胧好感渐生执念，易因被冷落而纠结。
- 能力特长：光属性魔法（光属性防御墙等），作为候补圣女具净化资质；后期以补魔与格雷格建立亲密接触。
- 人际关系：与维多利亚同为格雷格身边女主，既有闺蜜情亦生醋意竞争；视格雷格为拯救者与倾心对象。
- 成长轨迹：从被救的候补圣女，觉醒爱意并主动参与对格雷格的争夺，黑化伏线（眼中暗色）渐显；末章（第289章）耳语「下次我也要」，黑化倾向明确化。
