# 凯瑟琳·罗曼

- 别名：四号位女主、罗曼商会会长千金、罗曼商团千金、小姐/四号位、凯瑟琳学姐、凯瑟琳
- 重要性：核心配角（女主/商会千金）
- 出场章节：第37-215章（共29章，依据 corpus）
- 身份背景：罗曼商会会长千金（私生女），为生存布局的商界才女；原作四号位女主。
- 核心经历：
  1. 第37章私生女处境揭示，秘密研发广域驱散魔导器（尖啸项目），以虚构公司合约挑三名学生做地下城人体测试，三人失联冷静接受数据损失。
  2. 第57章推断有隐藏第三者并锁定格雷格，发布投资委托；第92-94章提前拦路登场、邀格雷格单独谈，却被薇薇安代拒。
  3. 第114-115章直球出价千枚金币+5%股份买断格雷格沉默被拒，终签保密并援助维多利亚的契约。
  4. 第133-145章以商界思维评估格雷格异常行为、借接触深挖其秘密，参与坟场战斗以风刃清场。
  5. 第153-158章金色坩埚「阳谋」得逞、桌下撞见西尔维娅秘戏冷静伪装、第一次修罗场冷静分析；第215章出征阵容中缺席说明。
- 性格特质：精于算计、冷静理性，好感阈值后有算计倾向；对格雷格由好奇到关注、世界观生裂缝。
- 能力特长：商业布局与魔导器研发（广域驱散），风刃魔法清场。
- 人际关系：罗曼商会千金，与格雷格有保密契约与微妙博弈，为维多利亚/西尔维娅组队伙伴。
- 成长轨迹：从冷漠布局的私生女，到对格雷格产生好奇、对「不计利益」行为世界观生疑。
