# 梅琳娜

- 别名：一号位女主、神女殿下、黑发室友、学妹、梅琳娜·贝拉多娜、殿下/公主殿下
- 重要性：核心配角（一号位女主/暗线反派向）
- 出场章节：第77-282章（共21章，依据 corpus）
- 身份背景：一号位女主角，神女殿下，关联「堕落之母/破碎之母」，以新生/转学身份接近目标。
- 核心经历：
  1. 第77-78章亲信（兜帽男/魔族）被格雷格击杀，揭晓其关联堕落之母；反噬致格雷格昏迷、西尔维娅觉醒爱意。
  2. 第142章墓穴现身，以旧情要挟黄泉保守秘密，布局「亡者归来」图谋以新身份接近勇者维多利亚；第149章制傀儡逼黄泉保密，第151章黄泉遗言指其为真凶。
  3. 第164章街头讨苹果、摊主事后记不清其貌，锁定格雷格为「意外变量」。
  4. 第213-230章格雷格疑其谋划定为头号警惕；以「天赋新生」转学捷径登场，被科尔温引荐、格雷格识破伪装，暗示只对格雷格本人好奇。
  5. 第239-282章双线碰壁（薇薇安心灵修复、帝都剑侠挫计划），「只属于我」占有宣言、抗命母神，92分追平维多利亚，末章试探格雷格被「男德」拒诱。
- 性格特质：神秘魅惑、占有欲强、工于心计，对格雷格格外关注，暗线反派向。
- 能力特长：神女身份与信仰加持，可制造「被遗忘」气场（摊主记不清其貌），擅长傀儡操控与布局。
- 人际关系：关联堕落之母/破碎之母，辖黄泉等下属，以维多利亚为接近目标，格雷格的头号警惕对象。
- 成长轨迹：从幕后布局的暗线反派，到正面登场、对格雷格生出特殊占有欲，黑化伏线延续。
