# 温蒂·冯·莱恩菲尔德

- 别名：第五皇女、大内总管、夜鸦、暗鸦、暗鸦大人、教团三把手、蜜发少女、温蒂
- 重要性：核心配角（皇女/教团高层）
- 出场章节：第79-284章（共27章，依据 corpus）
- 身份背景：王国第五皇女，暗夜教团「夜鸦/暗鸦」（三把手），潜伏于艾莉身边，后真实身份揭晓。
- 核心经历：
  1. 第79章于贫民窟向少女宣讲暗夜信仰、搬出艾莉震慑、献计清除灰鼠帮。
  2. 第156-161章借玛格丽特向贵族圈播暗夜信仰，以「主教刮目」诱艾莉探查格雷格团身份，并亮明夜鸦身份。
  3. 第207-213章格雷格委其带艾莉赴帝国、在帝都建据点，温蒂震撼主教知悉皇族内情。
  4. 第221-247章与艾莉清剿山贼、伪装入帝都，用毒素制敌；第247章第五皇女身份揭晓，芬恩下令抓捕。
  5. 第262-272章处刑通告发布、真实身份曝光，格雷格决意救人，温蒂牢中不屈、主动入局欲借处刑台揭皇兄。
- 性格特质：冷静务实、忠诚教团，心系百姓，对艾莉既利用又关心，潜伏时隐忍。
- 能力特长：毒术（以毒素令敌变白痴）、教团组织与情报斡旋，具皇女身份与号召力。
- 人际关系：暗夜教团三把手，受命/效忠格雷格（主教），与艾莉为搭档，真实身份为第五皇女。
- 成长轨迹：由潜伏的夜鸦，到第五皇女身份暴露、主动入局周旋皇位之争，成为帝国线关键变量。
