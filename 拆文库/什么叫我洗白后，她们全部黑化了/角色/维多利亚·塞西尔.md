# 维多利亚·塞西尔

- 别名：维多利亚、勇者、小灰毛、小灰毛·LV26、灰发少女、师妹、灰毛勇者
- 重要性：核心配角（女主/勇者）
- 出场章节：第1-289章（共120章，依据 corpus）
- 身份背景：勇者，灰发少女（小灰毛），格雷格的师妹；身负勇者加护与三大加护，童年惨剧奠定「绝不能输」的执念。
- 核心经历：
  1. 第1-2章于地下城与西尔维娅同行，被格雷格谎称河神救场后取信。
  2. 第17-21章与莉莉丝·卡恩约战，凭边境经验与勇者加护应战，终因格雷格预言反被炎爆术落败（第24章直面被碾压式落败）。
  3. 第124章连升2级至LV22，与格雷格、西尔维娅首入第二层创造历史；第129章控尸集齐眼眸碎片。
  4. 第132章参与讨伐缄默忏悔者；第254-255章复辩以「不确定性」立论获92分，与梅琳娜成并列劲敌。
  5. 第281章因格雷格失踪四天疑其内卷而焦虑，与莉莉丝因六分差距互呛险些动手。
- 性格特质：好胜要强、傲娇别扭，护短且不许他人骂格雷格；平民天才的自尊下藏着对师兄的在意。
- 能力特长：勇者加护与三大加护，水火土等多系魔法（水克火、土流壁），战斗经验丰富；等级曾达LV22（第124章），别名标注LV26。
- 人际关系：与格雷格为师兄妹兼互呛同盟，与西尔维娅亦友亦醋；与莉莉丝为宿敌。
- 成长轨迹：从被碾压落败的勇者，逐步在地下城讨伐与学院复辩中证明自己，对格雷格的依赖与占有欲同步增长。
