# 莉莉丝·卡恩

- 别名：第二公主、红发公主、莉莉·卡洛（伪装潜入）、三号位女主、妹妹殿下、姐姐大人（称薇薇安）、莉莉丝
- 重要性：核心配角（女主/第二公主）
- 出场章节：第8-289章（共62章，依据 corpus）
- 身份背景：王国第二公主，薇薇安之妹，伪装为「莉莉·卡洛」潜入地下城；原作三号位女主。
- 核心经历：
  1. 第8-11章伪装「莉莉·卡洛」潜入地下城被触手拖入暗河，被格雷格救起后隐瞒身份编名同餐；第12章回宫揭伪装。
  2. 第16-23章为破格雷格「预言」深夜加练，凭炎爆术击败维多利亚结为宿敌；第65章格雷格推理出莉莉·卡洛即莉莉丝·卡恩。
  3. 第109-112章被格雷格当众揭穿对姐姐的憧憬逼至社死（第125章裹被自我否认只称尊敬）；第136-138章潜入被擒破冰，得知薇薇安同样憧憬自己，姐妹双向憧憬坐实。
  4. 第198章察觉自身黑化转向；第204章邀下午茶被薇薇安三箭拒绝委屈跑离。
  5. 第261-289章傲娇夸赞格雷格、与维多利亚互呛，末章通道确认心意、黑化伏线延续。
- 性格特质：傲娇好胜、带吃货属性，对姐姐既憧憬又自卑，后逐渐卸下光环自在。
- 能力特长：火焰魔法（炎爆术、火焰锁链、火箭散华），红发公主天赋卓绝。
- 人际关系：薇薇安之妹（双向憧憬），维多利亚的宿敌，格雷格的「报复/调教」对象与暧昧线。
- 成长轨迹：从自卑憧憬姐姐的二公主，到卸下光环确认自我、对格雷格心意渐明并显黑化倾向。
