# 薇薇安·卡恩

- 别名：第一公主、学生会会长、蓝发冰美人、长公主、会长大人、姐姐大人（莉莉丝称）、薇薇安
- 重要性：核心配角（女主/第一公主）
- 出场章节：第12-289章（共75章，依据 corpus）
- 身份背景：王国第一公主，学院学生会会长，格雷格·萨斯的前婚约者；在原作设定中为必死反派。
- 核心经历：
  1. 幼时（八岁）与格雷格初遇递蛋糕破冰，后因格雷格家族改信魔王教致关系生变，十五岁解除婚约（第175章回忆）；原作临终独白「嫉妒纯粹」（第61章格雷格揭示其为同类必死反派）。
  2. 第60-61章以学生会会长身份亲临地下城调查八足夫人讨伐者，察觉格雷格异样未深究；第83章以剑叫醒格雷格亮明前婚约关系，第89章回溯退婚渊源。
  3. 第167-174章对格雷格生情感恐惧与纠结，办公室独处时格雷格俯身耳语「你渴望力量吗」，薇薇安沉默定格。
  4. 第175-193章随格雷格潜入地下城第二层并肩对抗「渴求之喉」，被格雷格舍身挡冰霜吐息所救后立誓「不再离开」，第二阶段救赎完成；冰魔法进阶、等级飙至LV38。
  5. 第241-289章多次吃醋误读、夕阳下约会撞破修罗场，终在通道内与格雷格确认心意、主动献吻轻吻其脸颊。
- 性格特质：外表冰山高傲、自律威严，内心傲娇寂寞、对格雷格矛盾纠结却逐渐坦诚。
- 能力特长：冰系魔法体系（冰晶突刺阵）优等生，高效控场，冰魔法克制血肉自愈放大伤害。
- 人际关系：与格雷格为前婚约者兼救赎同伴，与妹妹莉莉丝双向憧憬，与艾莉构成情敌修罗场。
- 成长轨迹：由冰封心绪的必死反派，被格雷格一路拯救、心灵修复，最终主动确认心意完成救赎。
