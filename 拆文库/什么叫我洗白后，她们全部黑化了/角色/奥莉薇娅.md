# 奥莉薇娅

- 别名：学院长、最后牛仔、死牛仔、学院长大人/残念美人、奥莉薇娅·莫尔
- 重要性：核心配角（学院长）
- 出场章节：第86-276章（共22章，依据 corpus）
- 身份背景：魔法学院学院长，被称「最后牛仔/死牛仔」，废柴酒鬼形象下是战力天花板。
- 核心经历：
  1. 第86-88章学院长办公室反差登场（废柴酒鬼+战力天花板），点破格雷格暗属性，令其代表学院出战五院大比并达成交易。
  2. 第169-171章提名百院交流会代表、追讨120金币委托金，第二次交易要求交流会期间须站格雷格这边；识破亡灵骑士非格雷格独立击杀。
  3. 第215章动员宣布出征启程；第222-227章与露娜·星逝两院长拔兵刃、争收格雷格为徒。
  4. 第235-237章为格雷格「英灵转世」谎言违心作证、立「最后牛仔」人设，圣女胸前沿礼祝福致双方脸红。
  5. 第256、276章于复辩与战斗相关章节被提及/参与。
- 性格特质：看似废柴贪酒实则精明强势，护短、爱炫权、戏谑。
- 能力特长：战力天花板（左轮魔导器），可识别暗属性魔法，具学院长权威与调度力。
- 人际关系：学院长，与格雷格有多笔交易与默契，与露娜·星逝等院长为同事/竞争。
- 成长轨迹：从借格雷格脱身的学院长，到明确站队、成为格雷格在学院与圣女面前的护持者。
