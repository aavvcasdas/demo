# 艾莉·希尔

- 别名：艾莉、专属女仆、副主教、战斗女仆、持剑女仆、暗影剑客、笨蛋女仆、暗金少女、艾莉大人
- 重要性：核心配角
- 出场章节：第6-280章（共54章，依据 corpus）
- 身份背景：格雷格的专属女仆，暗夜教团副主教，暗金发色的战斗女仆（暗影剑客），与格雷格有十余年感情线。
- 核心经历：
  1. 第156章被温蒂以「主教刮目」诱去探格雷格团身份，认出格雷格后神情转阴沉。
  2. 第211-212章格雷格追入巷确认剑气主为艾莉，溯源三年前退婚艾莉为他出头；澄清误会后艾莉带其至豪华庄园据点。
  3. 第247章魔王教再现，艾莉秒杀展LV70实力；第269章回顾幼年黑化逼格雷格收己为女仆并吻昏睡格雷格。
  4. 第270-272章格雷格昏迷被紫汤救醒，艾莉自责获安慰；第276章绕后拖敌、领域雏形斩杀，助格雷格升LV41。
  5. 第277章透露LV70突破时领悟领域雏形，奈特梅尔赞其「好女孩」。
- 性格特质：呆萌忠犬兼具武力，典型「笨蛋女仆」却对格雷格独占欲强；生气属「闷着等哄」型，吃醋直接拔剑。
- 能力特长：暗影剑客，剑气凌厉，LV70实力并领悟领域雏形；兼具女仆侍奉与副主教教务。
- 人际关系：与格雷格为主仆兼青梅竹马，十余年感情线，视薇薇安为情敌；温蒂为其教团同僚、具皇女身份。
- 成长轨迹：由幼年逼格雷格收为女仆的「笨蛋少爷」羁绊，成长为LV70、领悟领域雏形的核心战力与暗恋者。
