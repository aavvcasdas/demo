# 格雷格·萨斯

- 别名：格雷格、暗夜君王、主教/少爷、主教大人·教主大人、前公爵之子、吾之半身（奈特梅尔称）、临时风纪委员、代表
- 重要性：主角
- 出场章节：第1-289章（共271章，依据 corpus）
- 身份背景：落魄前公爵之子、穿越者，原身为必死反派；暗夜教团主教，获奈特梅尔授「暗夜君王」名号，实为共享神格半神。
- 核心经历：
  1. 开篇遭公爵家驱逐，确认地下城为规避死亡CG的唯一安全区，凭地下城天赋求生（第1章）。
  2. 跳河救下西尔维娅并击杀黑水章鱼升至LV16，以勇者身份与家族秘辛取信维多利亚（第2章）。
  3. 第13-15章遇黑猫自陈暗夜女神奈特梅尔，被宣判共享神格已是半神，获「暗夜君王」名号，得知五大地下城为封印外神的坟墓。
  4. 中期讨伐缄默忏悔者（第132章）并升至LV30（第129章）、LV36（第181章）；后期卷入温蒂皇女与艾莉重逢等修罗场，第276章升至LV41，末章与薇薇安确认心意。
- 性格特质：谨慎苟活、擅算计伪装，惯于让功隐入黑暗；表面别扭实则护短，以「绅士人设」周旋众女之间。
- 能力特长：暗属性魔法（暗蚀武装、虚化、暗波）配合触手缠绕、毒腺，辅以药剂炼金策应；掌握缄默圣约、碎影步伐。
- 人际关系：与奈特梅尔共享神格，被称「吾之半身」；与西尔维娅、维多利亚、艾莉、薇薇安纠缠出修罗场与暧昧线。
- 成长轨迹：由苟命求生的穿越者逐步膨胀为意图组建后宫、从被动洗白转为主动布局的暗夜君王。
