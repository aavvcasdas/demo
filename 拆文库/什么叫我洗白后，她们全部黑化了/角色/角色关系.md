## 关键关系演变轨迹

1. **格雷格 → 西尔维娅（救赎 → 依赖 → 黑化竞争）**
   - 第1-2章：地下城救起濒死西尔维娅、击杀黑水章鱼取信 → 状态：拯救者/被救者（正面）。
   - 第78章：接住昏迷格雷格觉醒爱意 → 触发事件：补魔与亲密接触，情感转依赖倾心。
   - 第216-218章：夜访推倒格雷格、与维多利亚互生嫉妒陷入修罗场 → 情感：由崇拜转为占有式竞争（复杂）。
   - 第289章：耳语「下次我也要」，眼中暗色明确化 → 黑化伏线坐实。

2. **格雷格 → 艾莉（主仆 → 忠犬 → 副主教）**
   - 幼年（回溯第269章）：艾莉黑化逼格雷格收己为女仆并吻昏睡的他 → 状态：主仆 + 青梅羁绊（正面）。
   - 第211-212章：格雷格追入巷确认剑气主为艾莉，溯源三年前退婚艾莉为他出头、澄清误会 → 信任回归。
   - 第247章：魔王教再现艾莉秒杀展LV70；第276-277章：助格雷格升LV41、领悟领域雏形，奈特梅尔赞「好女孩」 → 副主教核心战力定型。

3. **格雷格 → 薇薇安（前婚约 → 救赎同伴 → 确认心意）**
   - 幼时八岁递蛋糕破冰 → 十五岁退婚（第175章回忆），关系生变（负面/中性）。
   - 第83章：以剑叫醒格雷格亮明前婚约；第89章回溯退婚渊源 → 重新建立联系。
   - 第175-193章：并肩对抗「渴求之喉」，格雷格舍身挡冰霜吐息，薇薇安立誓「不再离开」 → 救赎完成（正面）。
   - 第241-289章：多次吃醋误读、夕阳约会撞破修罗场，通道内主动献吻确认心意。

4. **格雷格 → 莉莉丝（救助 → 识破 → 双向憧憬/暧昧）**
