# 奈特梅尔

- 别名：暗夜女神、哈基米、黑猫、古神、影中神明、吾/哈基米、暗夜女神（回溯提及）
- 重要性：核心配角
- 出场章节：第13-289章（共93章，依据 corpus）
- 身份背景：暗夜女神，以猫形（黑猫/哈基米）现身的古神，神力衰微无法化形；与格雷格共享神格、生命同契。
- 核心经历：
  1. 第13章黑猫开口自陈暗夜女神，格雷格以套路识破其身份，女神揭示共享神格、生命同契，宣判格雷格已是半神。
  2. 第14章报名并说明神力衰微无法化形，将名号「暗夜君王」授予格雷格。
  3. 第15章认定格雷格有攻略五大地下城潜能，揭露五大地下城实为封印外神的坟墓、苏醒即终焉。
  4. 第39章点破西尔维娅身上气味来自光明女神，爆料双女神姐妹渊源却不死不休；第206章宣告可赐加护并举行仪式，胸口咏唱赐护结尾落吻。
- 性格特质：毒舌戏谑、毫无羞耻心，常以生理梗调侃格雷格；对信仰增多、自身加护之力恢复感到满意。
- 能力特长：作为古神掌握神格与加护授予之力，能感知女神气息与暗属渊源，随信仰扩张逐步恢复神力。
- 人际关系：与格雷格为共享神格的「半身」，称其为吾之半身；与光明女神为不死不休的姐妹。
- 成长轨迹：由衰微不可化形的猫形古神，随格雷格洗白事业推进、信仰增多而逐步恢复加护之力；末章（第289章）仍以咒骂收尾，点题「她们全部黑化」的伏线。
