# 剧情/ 目录索引与用途说明

> 本目录为《什么叫我洗白后，她们全部黑化和》长篇拆解 **Stage 3 收口**的权威剧情产物。
> 由 4 段部分聚合（`_partial_A/B/C/D.md`）+ 结构化索引（`analysis_corpus.json`）合并而来。
> 所有事实均可溯源到所读四段与索引；不确定项标注「原文未明确」。

## 一、文件清单与用途

| 文件 | 性质 | 用途 | 下游如何使用 |
|---|---|---|---|
| **故事线.md** | 剧情总览（非节奏/模块权威） | 全书故事框架识别、剧情大纲总表（25 条连续编号）、故事线片段、主线/支线/补充分类 | 作为总览检索；只可**摘要/引用**节奏与模块两权威，不得与之并列 |
| **节奏.md** | 🔴 权威（节奏） | 关键信息推进表、爽点循环索引、情绪触动点索引、爆发节奏总结 | `story-long-write` **直接读取**；管「节奏 / 触动点 / 爽点」 |
| **情绪模块.md** | 🔴 权威（模块） | 读者需求/情绪引擎、故事框架与套路运行图、6 张可复现模块卡、重组与复现指南 | `story-long-write` **直接读取**；管「读者需求 / 模块复现」 |
| **散落情节.md** | 兜底归档 | 孤立比例评估与覆盖率结论、跨弧段待回收悬念备忘 | 检查覆盖率是否达标（本书≈98.3%，少量散落无需处理） |
| **README.md** | 本索引 | 目录导航与权限说明 | — |

## 二、两权威文件的边界（重要）

- **`节奏.md`** 管：节奏控制、信息推进链条、爽点、情绪触动点、爆发间隔与长间隔小钩子维持策略。
- **`情绪模块.md`** 管：读者想看什么（情绪引擎）、套路组合运行图、可复现模块卡（含不可照搬项红线）、重组复现指南。
- 二者为**并列权威**，`故事线.md` 仅作剧情总览，不得宣称与二者同权。下游 `story-long-write` 应以 `节奏.md` + `情绪模块.md` 为准进行续写/复用。

## 三、关键校验数据（速览）

- **框架**：蜕变成长 + 多线交织 + 恋爱后宫 + 反派洗白（混合）。
- **剧情总数**：25 条（预期 10–25，实际落在区间内，处上限）。
- **章节覆盖率**：284/289 = **98.3%**（≥85% 通过）。
- **散落比例**：≈ 1.4%（<5%，少量散落无需处理）。
- **故事线**：合并为 9 条主线/感情/权谋/谜团/成长线。
- **主线/支线/补充**：约 60% / 32% / 8%。

## 四、溯源提示

- 剧情编号与「核心目标/核心冲突/主题/概要」对应 `故事线.md` 第一、二节。
- 爽点/触动点/信息链均回指「剧情 N」或具体章节，便于 grep 回溯。
- 模块卡中的「不可照搬项」为红线，复现时必须替换为自有设定。
