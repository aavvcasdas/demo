**概要**：本章以回溯揭开黄泉来历。她曾为被猎魔者囚于铁笼的幽暗地域生物，濒死之际被伟岸的魔王撕顶相救，赐名"黄泉"命其效力，予其新生与归属。在军械库岔道她初遇覆鳞魔族战士岩刺——沉默如岩石的巨斧先锋，多次并肩后成为彼此可托后背的同伴。魔王命二人辅佐其女梅琳娜，公主紫眸甜笑却藏审视，令黄泉生出隐不安。及至魔域禁区，梅琳娜入地下城归来，竟将黄泉唯一的朋友与下属尽数制为提线傀儡，仍挂着美丽笑容嘱黄泉"为我保守这个秘密"。一段黑暗忠诚的源起，为后续黄泉的疯狂与梅琳娜的真凶身份埋下根脉。

**关键事件**：1.魔王破笼救黄泉并赐名效力 2.黄泉与岩刺成可托背战友，受命辅佐梅琳娜 3.梅琳娜制傀儡逼黄泉保密

**逐章写法公式**：

- **情绪流向**：起：囚笼濒死压抑 → 承：获救归属的温馨 → 转：梅琳娜甜笑藏刀的反转 → 合：傀儡保密的压抑钩子
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：濒死被救赐名（立原点） + 遇岩刺成战友（立关系） + 受命辅梅琳娜（埋暗雷） + 傀儡逼保密（钩子）
- **本章核心技巧**：给反派一段"被拯救"的来路，让疯狂有了可悯的根。
- **卡点与伏笔**：结尾卡点：对话型+梅琳娜"保守秘密"轻笑+黄泉被拿捏；埋设/回收伏笔：梅琳娜制傀儡 → 解释黄泉后续疯狂与对格雷格的执念；魔王赐名 → 为黄泉"对魔王忠诚"抗压强埋性格因
