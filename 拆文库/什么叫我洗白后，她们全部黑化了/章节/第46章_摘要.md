**逐章写法公式**：

- **情绪流向**：起：奔逃藏匿加压 → 承：魔物擦肩窒息 → 转：脱险互呛爆动机 → 合：迷失绝境引救援钩
- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：三人深层逃亡藏灌木（加压） + 岩石魔物擦肩死里逃生（窒息） + 互呛合约陷阱倒动机（爆背景） + 迷失绝境+声传黑暗（钩）
- **本章核心技巧**：用"刚脱险就内讧"把群像底层角色的悲凉写得真实不煽情，同时为救援铺路。
- **卡点与伏笔**：结尾卡点：类型悬念+内容"争吵声引出魔物"引第47章格雷格现身救援；埋设/回收伏笔：三人=凯瑟琳首次测试者 → 回扣37/45章；魔导器与地图丢失 → 坐实测试失败。
