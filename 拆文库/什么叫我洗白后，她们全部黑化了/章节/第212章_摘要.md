**逐章写法公式**：

- **情绪流向**：起：澄清误会的释然（轻松） → 承：反客为主被剑反杀（搞笑紧张） → 转：秒怂后释怀（甜） → 合：豪华庄园揭财富悬念（钩子）
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：澄清误会（解） + 剑抵颈喜剧（反） + 释怀问事（转） + 庄园显富（钩）
- **本章核心技巧**：把"道歉"写成攻防战——男方刚占上风就被武力秒破，既保喜剧又立艾莉危险又可靠的女仆形象。
- **卡点与伏笔**：结尾卡点：悬念型——格雷格疑教团为何如此富有，下章进庄园见温蒂揭组织实力；埋设/回收伏笔：艾莉敌视薇薇安 → 持续人物张力；豪华庄园据点 → 暗夜教团势力线；女仆军团 → 温蒂管理线。
