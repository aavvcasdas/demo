**逐章写法公式**：

- **情绪流向**：起：吻后宁静与力量平息（温馨） → 承：看面板惊叹强力（爽） → 转：猫舌倒刺搞笑+地下城无效的小打击（起伏） → 合：定计带艾莉+温蒂遥望（铺垫/钩子）
- **节奏配比**：慢铺垫 20% / 快冲突 10% / 爽点爆发 30% / 悬念留白 40%
- **本章结构公式**：查面板确认强度（给甜） + 猫娘调侃破功（搞笑） + 设限转念（调节） + 带艾莉定计+温蒂线（铺下章）
- **本章核心技巧**：先堆数值爽点，再用"地下城无效"精准设限避免过于无敌，主角快速翻篇保持爽感不塌。
- **卡点与伏笔**：结尾卡点：铺垫型——温蒂望北方帝国、似有心事，下章期待温蒂如何被卷入赴帝国；埋设/回收伏笔：加护地下城无效 → 限制变数；温蒂带艾莉 → 208章起执行；艾莉迷路人设 → 后续交通方案。
