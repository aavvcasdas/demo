**概要**：本章双线。明线：赤足黑裙、紫罗兰眸的少女梅琳娜在街头向水果摊主老约翰讨苹果，咬下时美得令摊主魂销；老约翰向邻铺老皮特描述却因记忆被莫名模糊而被当谎话。暗线：小巷中梅琳娜听灰袍下属回报——旧坟场亡灵已清，黄泉生死不明，唯一异样是"格雷格·萨斯独胜亡灵骑士"。梅琳娜断定计划出了"意外变量"，饶有兴味地追问此人是谁。章末以"到底是谁吗？"收束，把男主推到新反派视野中心。

**关键事件**：1.梅琳娜街头讨苹果，摊主惊为天人却事后记不清其貌 2.老约翰向老皮特描述被当成白日梦遭嗤笑 3.灰袍人回报坟场异样，梅琳娜锁定"格雷格·萨斯"为意外变量

**逐章写法公式**：

- **情绪流向**：起：街头惊艳的轻柔 → 承：记忆模糊遭嘲的反差 → 转：小巷汇报揭坟场异样 → 合：梅琳娜锁定男主为变量的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：梅琳娜讨苹果慑摊主（立反派） + 老约翰记忆模糊被嘲（埋异象） + 灰袍人回报坟场（推进暗线） + 梅琳娜锁定格雷格（钩子）
- **本章核心技巧**：同一章用"市井轻喜剧+幕后暗线"双线，先以柔美立反派、再以情报把男主送上对手雷达。
- **卡点与伏笔**：结尾卡点：对立型——梅琳娜盯上格雷格，期待其后续介入；埋设/回收伏笔：黄泉生死不明 → 为后续该角色去向埋线；亡灵骑士独胜 → 回收163章事实，并转成反派情报。
