**逐章写法公式**：

- **情绪流向**：起：面板确认的爽 → 承：心态膨胀的喜剧 → 转：隐患克制的清醒 → 合：邀约与转场钩子
- **节奏配比**：慢铺垫 30% / 快冲突 0% / 爽点爆发 30% / 悬念留白 40%
- **本章结构公式**：面板快照显实力（爽） + 心态跃迁写膨胀（喜剧） + 隐患克制保清醒（稳压） + 邀约转场引第三幕（钩子）
- **本章核心技巧**：用"系统面板+内心独白"在轻松章里既给进度满足，又用配角邀约与下一幕目标自然收束第二幕、开启第三幕。
- **卡点与伏笔**：结尾卡点：进度型+第二幕最后一个事件节点（导师考核）、为第三幕与"二弟"线索铺垫，下章期待第三幕开启；埋设/回收伏笔：破碎之母馈赠 → 本章点明为定时炸弹隐患；爱丽丝教授/莉莉丝 → 新幕人物线索；恶役贵族的救赎 → 上章第二阶段完成收束。
