**逐章写法公式**：

- **情绪流向**：起：冷静观察(平淡) → 承：原作悲剧回忆(压抑/心疼) → 转：现场推断与戏谑(轻松/紧张) → 合：同类相惜决定+察觉异样(温馨/悬念)
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：格雷格回忆薇薇安原作命运（立反差） + 薇薇安现场推断凶手（推悬念） + 奈特梅尔调侃斗嘴（调气氛） + 格雷格决定相助并潜伏撤离（埋伏笔）
- **本章核心技巧**：用"同为剧本反派"的身份共鸣替代俗套感情线，以长线伏笔制造含蓄羁绊。
- **卡点与伏笔**：结尾卡点：状态型——薇薇安察觉岩壁异样归为错觉，留下"她是否记住了格雷格气息"的期待；埋设/回收伏笔：薇薇安黑化命运 → 后续黑化线预警；金辉蛛丝 → 前文讨伐收获回收。
