**逐章写法公式**：

- **情绪流向**：起：射线来袭的紧张（危机） → 承：配合拆敌的爽（热血） → 转：挟童献祭的再危机（谷底） → 合：剑气救场+薇薇安止步（悬念）
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：避射线立分工（开打） + 技能协同拆三徒（爽） + 挟童设谷底（转） + 剑气救场+识人止步（钩子）
- **本章核心技巧**：战斗胜利即给"虚假安全"，立刻用人质事件砸碎，再用未知剑客的银光救场，爽点叠加不腻。
- **卡点与伏笔**：结尾卡点：悬念型——薇薇安识剑气主人却止步，下章揭晓剑气主即艾莉及她与薇薇安旧怨；埋设/回收伏笔：碎影步伐/地火爆破/水枪 → 技能复用；薇薇安与剑气主人过节 → 211章艾莉敌意溯源。
