**逐章写法公式**：

- **情绪流向**：起：事件设定揭示(荒诞/好奇) → 承：真凶疑云与变数(悬念/紧张) → 转：格雷格决定顶上(决断) → 合：奥德丽交易前奏(压抑/钩子)
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：揭示绑架事件设定（立荒诞） + 排查真凶与维多利亚变数（推紧张） + 格雷格决定事前拦截（显主动） + 奥德丽书房遇乌鸦（埋交易伏笔）
- **本章核心技巧**：用"本该在场的勇者因伤缺席"这一小目标变数，自然把主线高光转移给恶役主角。
- **卡点与伏笔**：结尾卡点：事件型——奥德丽将为一子天赋绑架西尔维娅，期待"格雷格如何拦截"；埋设/回收伏笔：维多利亚肩伤 → 前章探视回收；乌鸦代表的势力 → 第64章交易展开。
