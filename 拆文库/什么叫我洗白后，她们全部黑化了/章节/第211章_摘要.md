**逐章写法公式**：

- **情绪流向**：起：冲巷见艾莉的轻松（重逢） → 承：碰壁求生喜剧（搞笑） → 转：点破醋意与退婚溯源（温情反转） → 合：纠正误读留半月考验（钩子）
- **节奏配比**：慢铺垫 15% / 快冲突 20% / 爽点爆发 10% / 悬念留白 55%
- **本章结构公式**：认人追入（重逢） + 三连求生（喜剧） + 点破醋意溯源（温情） + 纠正误读（钩子）
- **本章核心技巧**：用"她为什么生气"当全章谜题，最后用三年前退婚往事一击解开，把醋意写成忠诚的证明。
- **卡点与伏笔**：结尾卡点：铺垫型——格雷格强调未破镜重圆、距休息半月，下章期待他如何彻底澄清并借艾莉赴帝国；埋设/回收伏笔：艾莉敌视薇薇安 → 后续三人同框冲突；退婚旧事 → 人物前史补全；剑气主人揭晓 → 回收210章钩子。
