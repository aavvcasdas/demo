**概要**：格雷格潜入帝都地下迷宫，借奈特梅尔（黑猫形态）引开守卫视线，避开帝国骑士的警戒，成功潜入迷宫深处。途中他权衡局势：营救温蒂虽急，但必须先与艾莉汇合、速通三层地下城，否则终辩后无时间攻略，第三幕结束便会死亡。本章确立"唯一完美结局窗口"的紧迫基调，并以龙套对话侧写出不在场的"暗影剑客"。

**关键事件**：1.三骑士闲聊魔王教动乱与暗影剑客传闻 2.奈特梅尔引开守卫化解暴露危机 3.格雷格阐明先攻略地下城再救温蒂的战略逻辑

**逐章写法公式**：

- **情绪流向**：起：守卫松懈闲聊(轻松) → 承：暗影剑客传闻(好奇) → 转：异响警戒(紧张) → 合：黑猫化解+战略阐明(余波钩子)
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：守卫闲聊(交代背景) + 奈特梅尔引开(化解危机) + 格雷格致谢(关系) + 战略独白(锚定目标)
- **本章核心技巧**：用龙套对话侧写不在场的强者，用主角内心独白把"为何不立刻救人"讲成唯一合理决策。
- **卡点与伏笔**：结尾卡点：行动钩子+格雷格按图纸向地下城进发，下章期待与艾莉汇合；伏笔：暗影剑客身份(→艾莉？)、迷宫戒备变严(→后续被发现风险)
