**逐章写法公式**：

- **情绪流向**：起：舆论聚焦前婚约的尴尬 → 承：薇薇安漠然破冰问艾琳 → 转：家族妹妹对照共鸣 → 合：堕落暗线埋拯救悬念
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：公开同行引舆论（立压力） + 薇薇安破冰问艾琳（转关系） + 妹妹对照共鸣（深人物） + 堕落暗线（埋伏笔）
- **本章核心技巧**：用主角"已知结局"的视角把后续暗线前置剧透，把"救不救得回"变成持续钩子。
- **卡点与伏笔**：结尾卡点：铺垫+格雷格认定根源在天赋差距，期待下章破解之法；埋设/回收伏笔：薇薇安与莉莉丝矛盾 → 后续黑化主线伏笔；艾琳过继妹妹 → 家族线人物补全。
