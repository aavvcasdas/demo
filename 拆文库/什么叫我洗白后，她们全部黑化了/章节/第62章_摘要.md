**逐章写法公式**：

- **情绪流向**：起：环境异动(好奇) → 承：营地被扰+资金焦虑(压抑) → 转：日常陪伴与冷静决策(轻松/安稳) → 合：盘算明夜行动(期待/悬念)
- **节奏配比**：慢铺垫 50% / 快冲突 0% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：地下城异动迫使遮营（设压力） + 悬赏猜测与放弃露面（显理性） + 营地日常与奈特梅尔陪伴（暖基调） + 盘算明夜绑架事件（埋钩子）
- **本章核心技巧**：用"已知剧本"的内部独白把即将到来的主线事件提前剧透，制造读者上帝视角的期待感。
- **卡点与伏笔**：结尾卡点：事件型——明晚西尔维娅绑架事件将发生，格雷格决定介入，期待"他如何破局"；埋设/回收伏笔：奈特梅尔收集的奇特石板 → 第64/72章石板纹路呼应；三枚金币将尽 → 经济线压力。
