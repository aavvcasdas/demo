- **情绪流向**：起：临别赞许的轻松 → 承：邀宴与蹭饭疑云加压 → 转：阳谋点破更衣的爆发 → 合：识破却认命的钩子
- **节奏配比**：慢铺垫 25% / 快冲突 5% / 爽点爆发 20% / 悬念留白 50%
- **本章结构公式**：车夫赞许（闲笔） + 邀宴更衣疑（设谜） + 凯瑟琳阳谋（揭谜） + 格雷格认命（钩子）
- **本章核心技巧**：让反派/合作者用"正当理由"施阳谋，读者与主角同陷温柔陷阱。
- **卡点与伏笔**：结尾卡点：关系型+格雷格被套牢跟行+凯瑟琳有趣暗喜；埋设/回收伏笔：艾莉"会杀了他" → 回收前文欠三金币设定；凯瑟琳观察欲 → 为155章餐馆再贴近埋线
