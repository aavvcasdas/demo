## Stage 2 结构 + 情节节点

### 故事核

- **设定**：15 岁少年在校门口麻辣烫摊被同学激将，吃下一碗变态辣。
- **主题**：即时刺激（辣=多巴胺、身份、被围观的快感）与缓慢代价（味觉钝化、胃病、与母亲的味道断连）之间的置换。
- **核心行动**：13 年里把辣度一路加码到「辣哭算我输」，直到凌晨急诊后从一碗白粥里重新尝到甜味，最后一次点面说出「微辣」。
- **一句话**：一个为了面子吃下第一碗变态辣的少年，用 13 年把味觉换成身份，最后在急诊病床上的一碗白粥里把它换了回来。

### 故事梗概

15 岁冬天，「你」在县一中东门的麻辣烫摊被胖子一句「有本事你去吃变态辣」架住，当众硬吃完一整碗，被封「辣王」，第一次体会到被辣到极限的飘飘然。当晚妈炖的排骨汤尝不出味，你谎称在外面吃过了；次日腹泻 40 分钟，对镜发誓再不碰变态辣——誓言只维持三天，第四天你独自回到摊前说「再多加一勺」。

大学后辣度随生活费一起涨：外卖备注「辣哭算我输」，37 个小米辣的视频上同城榜 2.4 万赞，叙述者却点破「不是能扛，是嘴唇早就麻了」。辣成为你的身份：嘲笑微辣、品酒师式鉴定死神辣酱、自熬辣椒油灌进玻璃分装瓶随身带，婚宴 16 道菜挖了 16 勺。

25 岁，舌头「先一步退休」，辣从味道变成开关；胃镜查出胃炎伴糜烂，医生三个字「忌辛辣」，你走出医院台阶就给自己找好了说法。妈来省城又炖了排骨汤，看到你往里加红油没说话，一勺勺把红油撇掉，你尝不出味却说「鲜，跟小时候一个味」。

28 岁加班夜点了双倍辣炸串，凌晨 3:17 蜷在床上被室友叫了 120。换病号服时玻璃瓶滚出来，护士看了看放在床头柜。输液三天只能喝白粥，妈赶来晾的粥入口是甜的——你想起上一次尝出食物本味是 15 岁之前妈的排骨汤。出院第三天，面馆老板娘照例问「特辣多加辣油」，你顿了一下说「微辣」。清汤上飘几粒葱花，这次你没有再加辣。

| 维度 | 分析 |
|------|------|
| 铺垫 | 前 790 字完成两件事：让读者亲历一次变态辣的身体过程（烟头、喷嚏、耳朵嗡、校服湿透），并给出第一次社交奖赏；N6 立刻埋下「排骨汤尝不出味」——这是全篇的回收对象 |

**叠加爆点**：表层爆点是身体崩溃（急诊，-8）→ 深层爆点是味觉回归（白粥甜，+5/-5）→ 叠加效果：急诊只证明「辣有害」，白粥才证明「你失去了什么」——前者读者早知道，后者才是新信息。

**多爆点串联**：爆点①母亲撇红油（76%）| 爆点②玻璃瓶滚出（86%）| 爆点③粥是甜的（91%）→ 串联方式 **递进**：三个都围绕同一物件系统（汤/瓶/粥），情绪从愧疚到羞耻到顿悟。

## Stage 4 反转 + 写作手法

### A. 反转分析

#### 前置反转检查

无。故事时间线前不存在谎言或误判，所有信息与读者同步。

#### 主反转分析

**反转类型**：认知反转（读者对「辣王」这一身份的整体理解被颠覆——从「能扛」到「早就麻了」，再到「为了面子把味觉抵押出去」）。

**反转机制**：
- 铺垫线索 1（26%）：「可你的舌头像隔了一层塑料布」——第一次代价出现在第一次奖赏后不到 100 字，读者从此知道每一次辣都在扣分。
- 铺垫线索 2（47%）：「没人知道那不是能扛 / 是你的嘴唇早就麻的没了知觉」——叙述者直接拆穿主角的公开叙事，把「辣王」重新定义为「感觉缺失者」。
- 铺垫线索 3（64%）：「辣对你来说已经不是一种味道 / 是个开关」——在高潮前 27% 处把「味道」这个词从辣身上剥离，为「粥是甜的」预留位置。
- 铺垫线索 4（76%）：母亲撇红油后你说「鲜 / 跟小时候一个味」而「其实从头到尾都没尝出来」——同一句谎言（N6「在外面吃过了」→ N17「鲜」）第二次出现，谎言升级为对母亲而不是对自己。
- 误导方向：表层叙事顺着「辣王」的自我叙事走——同城榜、拆弹专家、11 次试出的配方，每一段都给足主角风光；读者容易顺着「能吃辣=硬核」的社交共识往下读。
- 真相揭示：不靠任何人说破，靠一勺白粥。感官事实替代了所有说教。
- 合理性：经得起回看——第一次吃变态辣时「前两秒什么感觉都没有」已经写了辣的延时性，最后一段「米有一股很淡很淡的甜味 / 要含一会才出来」是同一个延时结构的镜像。

**时机**：全文 91% 位置 | 铺垫:释放 ≈ 10:1（约 2900 字铺垫 / 约 300 字释放）

**效果**：惊喜度 3（读者预见到会出事，但没预见到用「甜」收）| 合理性 5 | 情绪冲击 4

### B. 写作手法

详见 `写作手法.md`。核心手法 Top3：①感官白描做情绪载体；②同一物件三次出现（排骨汤 / 玻璃瓶 / 白粥）替代心理描写；③叙述者对第二人称主角的「拆穿式旁白」。

**投稿层观察**：
- 平台基调：抖音口播 / 番茄短篇一路——顺滑无毒点、不设付费断点、大满贯式收尾改成「克制版」。不是知乎盐选的剥洋葱结构（没有认知颠覆式的信息藏匿）。
- 导语写法：前 185 字是「场景型导语」，四维骨架里只给了「人设底色」（省钱的初三学生）和「起因」（校门口的摊），核心冲突与情绪反转都后置。黄金三角中「具体物件」（三个搪瓷缸）落在第 20 行，「留白钩子」是「加辣不要钱」。
- 最强断点：如果切成付费章，最强断点在 N17 结尾「你其实从头到尾都没尝出来」（81%）——之后读者最想知道「他到底什么时候完蛋」。

### C. 结尾分析

**最后一段**：「面端上来 / 清汤上飘着几粒葱花 / 两片青菜 / 你先喝了一口汤 / 还是熟悉的味道 / 但是这次你没有再加辣」

| 维度 | 分析 |
|------|------|
| 结尾类型 | 开放式偏 HE——「微辣」不是「不辣」，「没有再加辣」只写了这一次 |
| 情绪落点 | 读者离开时在想：他能坚持多久？（与 N8「誓言有效期三天」形成隐性对照，源文没有给答案） |
| 余韵设计 | 有——「还是熟悉的味道」这句在 N6（「汤还是那个汤」）、N17（「跟小时候一个味」）之后第三次出现，前两次是尝不出，这次是真尝到了清汤的味 |
| 传播欲 | 中高——读者会转发给「无辣不欢」的朋友，附一句「说的是不是你」；共鸣型传播而非反转型传播 |
| 收束完整性 | 排骨汤 → 白粥（回收）；玻璃瓶 → 床头柜（回收，未写扔掉）；辣王身份 → 「太阳打西边出来了」（回收）；未回收：妈的反应（最后一段妈不在场，源文没有让母亲看到「微辣」） |
| 价值观传达 | 你用什么换来的身份，最后要用什么换回来；感官的钝化是一切成瘾的共同代价 |
| 结尾情绪强度 | 6/10（通透满足档，不追求虐或爽） |

## Stage 6 综合评估

**一句话评价**：这篇成立的机制是「用感官替代议论」——13 年的成瘾史全部靠舌头、胃、耳朵、后背的身体反应推进，说教句一句没有，最后用「粥是甜的」五个字完成所有价值判断。

### 五维评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 开头吸引力 | 3/5 | 场景型开头，靠公共记忆（校门口摊、省下的 10 块钱）建立代入；冲突在 185 字才出现，节奏偏慢。系列片头「今天你要体验的人生副本是」替代了自建钩子——脱离系列语境后开头会更弱 |
| 情感拉扯力 | 4/5 | 剪刀差曲线（奖赏递减 +7→+5→+4，代价递增 -4→-5→-6→-8）9 次翻转；最强拉扯在 N17（-7/+6 复合），母亲撇红油不说话 |
| 反转设计 | 3/5 | 认知反转，铺垫 4 条、比例 10:1，合理性满分；但读者在 47% 处（「嘴唇早就麻了」）已被叙述者提前告知，惊喜度靠「用甜收」而不靠「出事」 |
| 节奏控制 | 4/5 | 六段占比 24/15/21/21/15/4，前 40% 完成瘾的定义，中段两次 20% 的平台期靠数字加码（37 个 / 16 勺 / 11 次配方）维持事件密度；无节奏塌陷 |
| 结尾余韵 | 4/5 | 「微辣」一词回收开头「变态辣」；「还是熟悉的味道」第三次出现才成真；缺一个母亲在场的收束 |

### 爆点性

核心爆点是 91% 处的「粥是甜的」。铺垫充分：前文三次写「尝不出」（塑料布 / 一团温吞吞 / 同一种东西），一次写「味道」被剥离（「辣不是味道是开关」），所以「甜」这个最弱的味觉信号能产生最大反差。释放到位：只用了「很淡很淡 / 要含一会才出来 / 一闪又没了」三个短句，没有解释。传播性：中——爆点是内向的顿悟而非外向的打脸，适合「转给某个人」而非「全网讨论」。

### 话题性

- 「无辣不欢是不是一种瘾」——评论区会分成「吃辣是自由」和「说的就是我」两派；源文在 N16 已把「四川人不也活得好好的」这条反驳预先写进主角嘴里，等于替评论区提前吵了一架。
- 「你上一次尝出食物本来的味道是什么时候」——可直接做成评论区提问，是代入式自省的入口。
- 代际议题：母亲三次不说话的劝阻（端回厨房 / 撇红油 / 晾温）会引发「我妈也这样」的经历共鸣。

### 共鸣分析

| 共鸣层次 | 强度 | 触发点 |
|----------|------|--------|
| 情感共鸣 | 强 | 母亲撇红油不说话（N17）；病床上妈晾粥（N20） |
| 价值观共鸣 | 中 | 「忌口的人生跟坐牢有什么区别」——很多读者会先认同这句再被后文打脸 |
| 经历共鸣 | 强 | 校门口麻辣烫、被同学激将、外卖备注「往死里辣」、体检自费加胃镜、加班后点炸串 |
| 社会现象共鸣 | 中 | 「能吃辣」被当作社交货币、同城榜的围观文化、辣度商品化（特辣加 6 块） |
| 文化共鸣 | 中 | 中国式母亲的「多喝汤」、「长身体」、坐 4 小时大巴带排骨 |
| 普世价值共鸣 | 中 | 用感官换身份、用长期换短期的成瘾结构，可替换为糖 / 酒 / 熬夜 / 短视频 |
| 哲学思考共鸣 | 弱 | 「辣不是味道是开关」触及刺激与感受的区别，但源文没有展开 |
| 情感深度共鸣 | 中 | 谎言的两次升级（对自己 → 对母亲）写出了成瘾者的羞耻结构 |
| 人物深度共鸣 | 中 | 主角没有恶意、没有大错，只是每一次都「再多加一勺」——读者不会恨他，会怕自己是他 |

### 核心手法

反转类型{认知反转} | 情感曲线形态{剪刀差波浪 + V 形回升} | 关键钩子{排骨汤失味（24%）/ 玻璃瓶（55%）/ 「忌辛辣」（68%）} | 核心手法 Top3{感官白描替代议论 / 物件三现法（汤—瓶—粥）/ 叙述者拆穿式旁白}

### 可复用结构

1. **「三次预警全失效」结构**：设置三个不同身份的外部预警者（同行 → 专业权威 → 至亲），预警强度递增、字数递减（「你可想好了」→「忌辛辣」三个字→ 撇红油零台词），主角每次用一句自我合理化推掉。读者的焦躁在第三次达到峰值，为崩溃蓄力。— 适用场景：成瘾 / 拖延 / 不健康关系等「当事人最后一个知道」的世情短篇。
2. **感官钝化—感官回归闭环**：先在早期（<30%）写一次「尝不出」并绑定一个具体食物，中段把该感官从主角身上剥离（「不是味道是开关」），高潮不用大事件，用最弱的感官信号回归（甜 / 淡 / 温）完成反转。— 适用场景：任何以身体感受为主线的短篇（味觉 / 睡眠 / 听力 / 触觉），尤其适合抖音口播第二人称。
3. **谎言升级法**：同一句谎言在全篇出现两次，第一次是对自己（「在外面吃过了」），第二次是对最在乎的人（「鲜，跟小时候一个味」），中间不加评论。第二次出现时读者自动回想第一次，愧疚感翻倍。— 适用场景：亲情线、隐瞒型人设。
4. **奖赏递减 / 代价递增剪刀差**：正向峰值每次降 1–2 分（+7→+5→+4），负向谷值每次加深 1–2 分（-4→-5→-6→-8），让读者在中段就「看见」结局，把阅读动力从「会怎样」换成「他什么时候承认」。— 适用场景：沉沦型 / 堕落型 / 慢性悲剧短篇。
5. **数字加码做时间压缩**：跨年跳跃后立即用一个可数的量重新校准程度（一勺 → 再多加一勺 → 37 个 → 16 次 → 第三勺 → 双倍），一句话替代一段过渡。— 适用场景：需要在 3000 字内跨十年的短篇。

### 同类型写作动作

写同类「一件小事的一生」短篇时可直接执行：
1. 先定一个**可数**的成瘾单位（辣度 / 杯数 / 小时数）和一个**可尝**的失去物（母亲的某道菜 / 某个人的声音）。
2. 在前 25% 写完第一次奖赏，并在其后 100 字内写第一次「尝不出」。
3. 写三个预警者，台词字数递减，最后一个零台词只做动作。
4. 高潮前找一个物件让它在「最不该出现的场合」出现（玻璃瓶在病房）。
5. 结尾用一个比开头弱一档的词收（变态辣 → 微辣），不写「戒掉」。

### 节奏速报

| 指标 | 数值 | 判断 |
|------|------|------|
| 事件密度 | 22 节点 / 3254 字 ≈ 6.8 个/千字 | 高；跳年后密度不降，因为每次跳跃都跟一个数字事件 |
| 对话密度 | 约 9%（全文直接引语约 290 字） | 低；对白只用于预警（老板 / 医生）、激将（胖子）、母亲三句、点单两句；情绪全部由身体描写承担 |
| 冲突密度 | 约 35%（N2/N4/N7/N15/N18 五处直接冲突，其余为内部压力） | 直接冲突少，压力主要来自身体与母亲的沉默；无一处争吵 |

### 待补（WARN 项，不阻断）

- 对话潜台词率未逐句量化（对白总量过少，样本不足以给出稳定百分比）。
- 母亲在结尾缺席，「微辣」未被她见证——这是源文的留白，不是拆文缺失，写同类时可作为可选补强点。
