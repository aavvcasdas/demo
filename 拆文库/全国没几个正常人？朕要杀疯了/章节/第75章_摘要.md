**概要**：卢龙塞外，耶律烬因强攻卢龙塞不顺、运粮队被奚族屡劫、弟弟的人马消极怠战而头疼，决定写信逼弟弟配合攻城，并扬言宁可不要太子之位也要打下卢龙塞去跟萧衍换萧容音。此时一名幽州士卒送来李乾亲笔信：萧衍已被斩于京城下，二十万幽州军归顺，五万西凉铁骑将抵卢龙塞，信上仅一行字"不退兵，朕即杀萧容音"。耶律烬忆起五年前风雪乞食被白衣小女孩（萧容音）救命，决意先攻奚族、再寻机救她。回京路上，李乾见一汉子吴刚在歪脖子树上上吊，命胡车儿救下。吴刚哭诉：入赘脸盲症妻子徐丽宁，一年辛苦赚钱，却被一穿黑衫的假冒丈夫潘章赶出家门，因未登记、村民不识他而无处申冤，生无可恋。李乾令冯保买十套黑衫，陪他回村。

**关键事件**：1. 耶律烬收李乾信，知萧衍死、幽州归顺，被威胁杀萧容音 2. 耶律烬忆五年前救命之恩，决定攻奚族救萧容音 3. 李乾救下上吊的吴刚 4. 吴刚诉脸盲妻被冒名丈夫赶走，李乾买十套黑衫

**逐章写法公式**：
- **情绪流向**：起：耶律烬困局头疼的压抑 → 承：李乾捷报+威胁信的强势反转 → 转：耶律烬回忆软化为救萧容音 → 合：吴刚荒诞上吊喜剧转入下章整蛊
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 20% / 悬念留白 + 搞笑 30%
- **本章结构公式**：耶律烬困局（加压） + 李乾信降维打击（反转） + 救萧容音执念（柔化） + 吴刚上吊整蛊引子（喜剧钩子）
- **本章核心技巧**：双线交切——用敌方视角放大主角威势，再用一段市井喜剧给高密度权谋"换气"。
- **卡点与伏笔**：结尾卡点：类型=喜剧整蛊钩子——李乾买十套黑衫要陪吴刚回村"十个黑衫丈夫站门口"，读者期待打脸冒名者；埋设/回收伏笔：萧容音（五年前救耶律烬）→ 后续情感/人质线；五万西凉铁骑抵卢龙塞（信中）→ 75-76章边境局势。
