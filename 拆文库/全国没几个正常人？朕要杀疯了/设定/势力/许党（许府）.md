# 许党（许府 / 外戚总敌）

- **类型**：家族＋外戚集团＋朝堂旧权力核心（含清流、影密卫残余）
- **核心人物**：许中正（丞相，外戚总敌、李乾主要政敌，第10、100-101章）；许朗（金吾卫大将军，母后胞兄，未来弑父者，第14章）；许端（三子，户部郎中，第102章）；许谦（四子，宠青楼妾柳云裳，第102-103章）；许嫣然（才人，许端之女，第102章）；田夫人（许母，第105章）；柳云裳（青楼出身妾，第102章）；杨燕燕（许谦妻）；大虎（柳云裳野男人，第104-105章）；许嫣红（三小姐，痴恋大虎，第105章）。
- **立场倾向**：反复→敌（先以"宽和收人心"示好，暗中定"嫁孙女夺权""改天换日"谋反，最终与李乾全面对立）。
- **与其他势力关系**：
  - 掌控/从属——影密卫（先帝听其建，第10章）、四军（燕国军、平卢军、禁军、金吾卫皆有许党人，第101章）。
  - 盟（暗）——韦氏（第100-101章邀谋反）、萧衍／原剧情摄政王。
  - 敌——李乾、帝党、西凉军。
- **关键事件**：
  - 第10章定"嫁孙女生太子"夺权计，推庞德主考科举。
  - 第14章萧容音泄"三年后许丞相被长子许朗弑父、李乾掌权"原剧情。
  - 第100-101章许中正夜会韦阁老抛"大魏的天该换了"，四军底牌一次性亮出。
  - 第102-105章丞相寿宴连续丑闻：柳云裳假摔嫁祸、许谦休妻、大虎野男人曝光、田夫人骂护卫被掌掴，许府体面将碎。
- **实力/资源概述**：当朝丞相，门生故旧遍布朝堂与四军；财力雄厚（寿宴车马盈门、红绸满廊）。具体兵力由其渗透的四军体现，是全书旧权力格局的核心对手。
