# 北虏（含北胡）

- **类型**：外敌（游牧政权 / 国家）
- **核心人物**：耶律烬（北虏太子，重生/被穿者，第54章）；贺兰部（第71-77章裴长风换脸潜回）；奚族（被耶律烬攻伐）；北胡穿越者（未出场，第57章造出火药）。
- **立场倾向**：敌（李乾的外患死敌，短期内不可收编）。
- **与其他势力关系**：
  - 敌——大魏（李乾）、幽州军、西凉军。
  - 勾结——原剧情中徐浮屠（萧衍姐夫）泄密勾连北虏（第55章萧容音口述）；萧衍败逃后曾投奔萧容音引北虏。
- **关键事件**：
  - 第54章卢龙塞告急，耶律烬率二十万铁骑大举攻幽州，扬言破关屠三镇只为夺萧容音。
  - 第55章萧容音吐露"五年后北虏与北胡勾结攻魏、自己带萧衍陆玄亲征成女帝"原剧情；李乾命萧容音写信牵制耶律烬、放张昭回幽州御敌，定五年筹备。
  - 第57章确认北胡有穿越者搞出火药，埋跨书五年危机线。
  - 第71-77章蓝田失守，裴长风换脸潜回贺兰部，耶律烬收信攻奚族，边境暗棋推进。
- **实力/资源概述**：北虏太子亲率二十万铁骑（第54章）；北胡另出穿越者技术（火药），威胁等级高于常规敌军。具体兵力、地盘原文未全面明确。
