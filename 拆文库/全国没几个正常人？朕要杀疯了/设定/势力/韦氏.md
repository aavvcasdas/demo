# 韦氏 / 外戚

- **类型**：家族（京兆韦氏门阀，半外戚）
- **核心人物**：韦阁老（族长，李乾称"崇岳兄"，第100章）；韦应（驸马房家主，娶李乾五姑姑新城公主，第100-101章）；韦香儿（偏房嫡女，封四品美人，第67、100章）；韦雨卿（西眷房嫡女，第101-102章）；韦德厚（族中"韦奸"，取心头血黑幕，第90-96章）；韦初月（县主，被林晚救活，第100章）。
- **立场倾向**：反复（表面附李乾清田、送女入宫；暗中被许中正拉入谋反，韦应实际参与）。
- **与其他势力关系**：
  - 盟（表面）——李乾（韦香儿封妃、韦阁老配合清田、韦初月事件结善）。
  - 盟（暗）——许党（第100章许中正邀韦阁老"改天换日"，被推给韦应；第101章韦应领命途中杀燕国公）。
  - 敌——新城公主（韦应受折辱，埋报复动机）。
- **关键事件**：
  - 第67章李乾封韦香儿为美人；第84章借韦香儿清韦氏田。
  - 第90-96章韦氏取心头血家族黑幕（韦德厚），李乾借韦氏屠堡威逼韦阁老清田、树榜样逼士族。
  - 第100章韦阁老欲以女医官林晚为眼线刺探宫中；夜会许中正被推脱。
  - 第101章韦应领许中正令途中杀燕国公、自曝四军有许党人；韦雨卿献孤臣反间计救燕国公。
- **实力/资源概述**：京兆大族，有坞堡田产（第100章"龙门房少一脉丢三座坞堡"），族中出美人入宫、出官员入朝。财力与兵力原文未明确量化，但为清田改革关键样板家族。
