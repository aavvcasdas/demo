# 西凉军 / 李乾嫡系

- **类型**：军队（主角嫡系精锐）
- **核心人物**：李乾（统帅）；董辅（西凉心腹，第51章）；唐铮（将领，第16章报功抄金银）；胡车儿（贴身护卫/行刑打手，第12-13章）；铁牛（第4章摘敌首）；飞熊营等番号见梗概提及。
- **立场倾向**：盟（李乾本人根基，绝对效忠）。
- **与其他势力关系**：
  - 敌——影密卫（第12、15-16章围剿藏龙巷）、北虏（第54-55章北上御敌）、幽州叛军（第49-50章平叛）、各级作恶权贵（执行抄家赐死）。
  - 盟——帝党文官（贾先生、冯保等为其提供情报与政务支撑）。
- **关键事件**：
  - 登基初期即作为武力背书，西凉兵围场斩儒（第13章）。
  - 第15章李乾调一千西凉铁骑＋五千禁军剿灭影密卫藏龙巷，第16章铁骑碾压指挥使卫阳心腹、零伤亡俘敌。
  - 第49-50章三千西凉铁骑冲锋破萧衍，堆京观；第54章合计二十万（西凉＋京营＋幽州）北上抗北虏。
  - 第65章数十西凉精兵潜伏郡公喜宴无声镇场，亮明身份擒沈兰舟。
  - 第103-105章西凉士兵执行许府杖责、拔刀威压。
- **实力/资源概述**：李乾被贬边关十年经营之漠北铁骑，战力碾压禁军（第16章"刀没举起来便被撞飞"）；可调动规模至少数千至数万级，是全书皇权集权的核心军事支柱。具体总兵力原文未明确。
