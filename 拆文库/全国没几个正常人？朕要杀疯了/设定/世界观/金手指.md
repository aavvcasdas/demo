# 金手指设定：全国没几个正常人？朕要杀疯了

## 类型（type）
{ transmigration（主角） + system（配角） }

本书的金手指分两层：**主角李乾**是单纯的**穿越者（transmigration）**，自身**没有系统、空间、重生或特殊体质**；而**多名穿越女配角**携带**攻略系统（system）**，任务均为「攻略暴君李乾」。书名「全国没几个正常人」真正指的不是某一项能力，而是「这个世界里绝大多数人都是恋爱脑 / 穿越者 / 重生者人设，唯独清醒务实的李乾相对正常」。

## 名称（name）
- 主角侧：无专属叫法，统称「穿越 / 穿成七皇子」。
- 配角侧系统：自称「**系统妈妈**」（第20章江陵楚氏嫡女，原文 L4093），对张澄则称「**系统 / 宿主**」（第59-60章，原文 L12037、L12567）。任务内核为「**攻略暴君**」。

## 描述（description）
主角的「金手指」本质是**穿越者信息差**：他来自现实认知，看穿女频套路与穿书者剧本，不被话术、恋爱脑、万人迷光环拿捏，并据此制定铁血战略。他并无任何超自然能力或系统面板。

配角侧的攻略系统则是典型「女配金手指」：绑定穿越女，下达攻略皇帝的任务，并能向宿主「显示」目标情报。例如张澄的系统显示「李乾在凉州杀生无数、胡人小儿止啼、极度危险」（原文 L12039、L12567）。但该系统的可靠性存疑——它一面称李乾「极度危险」，一面又让宿主误以为「纸片人皇帝轻松拿捏」（原文 L12043、L12103），属反向误导。

**触发与运转**：配角系统在角色一穿越即激活（「一觉醒来穿越到选秀现场……有系统」，原文 L4103-4105）；但第20章系统在开局即因「**检测到高维干扰，系统暂时失联**」（原文 L4095）而离线，此后能否回归**原文未明确**。系统是否可升级、有无多阶段任务，**原文未明确**。

## 核心机制（core mechanism）
「穿越者（清醒皇帝）」与「携带攻略系统的穿越女配」之间的**信息差与认知战**——系统误判李乾为可攻略的纸片人，李乾却反手识破并碾压。

## 当前能力（current abilities）
- **主角李乾（无系统，优势即金手指）**：穿越者认知、识破穿书/重生者身份、二十万西凉大军调度、理性战略布局（挟女主令诸侯、清洗禁军、蚕食六部）。
- **配角攻略系统（已展现）**：发布「攻略暴君」任务；向宿主显示目标杀戮记录与危险评级；开局即因高维干扰失联（江陵楚氏嫡女线）；对张澄持续提示「对方极度危险」。

> 结论：本书**主角无明显金手指/系统设定**；真正具象化的「金手指」是若干穿越女配角携带的「攻略系统」，且多在开局失联或严重误判，沦为被主角反杀的伏笔。
