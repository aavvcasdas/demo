# 背景设定：全国没几个正常人？朕要杀疯了

## 一、现实 / 架空程度

本书为**完全架空**的虚构王朝（国号「大魏」），非真实历史。世界底色是一个**女频小说世界**——书中角色多带「恋爱脑 / 万人迷 / 作精」等女频人设，且混有大量**穿越者、穿书者、重生者**。原文明确点出书名所指：「这个国家很不正常」（原文 L113）、「这狗屁的女频世界，到底塑造出了几个不正常的脑残角色？」（原文 L183）。

同时，书中存在由穿越者带入的**现代工业/技术元素**（玻璃、肥皂、新盐、火药、土豆、工业革命设想等），均作为虚构爽文设定呈现，非考据向。

## 二、核心规则与特殊设定

1. **穿越 / 穿书 / 重生是普遍现象，而非特例。**
   - 主角李乾：**穿越者**，穿成女频世界的七皇子，被贬边关十年（西凉/凉州），后借京城巨变登基（原文 L13、L37）。
   - 萧容音：自称「重生者」，实为**穿书万人迷女主**，来自女频书《绝世娇颜，帝王以国相聘》（原文 L85、L293、L1583）。
   - 薛令儿：**重生者**（魂魄飘荡数年后归来，原文 L5695）。
   - 另有多个「穿越女」（原文 L4123「又是一个穿越女」），如江陵楚氏嫡女、张澄（玩乙游的穿越女）。
   - 北胡一方亦有穿越者（第57章「搞出火药」，原文未明确姓名）。

2. **「系统 / 金手指」主要挂在配角（穿越女）身上，主角自身无系统。**（详见 `金手指.md`）

3. **朝堂 / 后宫 / 边军权力结构（原文核实）：**
   - **皇权**：李乾登基，但初回京城「毫无根基」（原文 L131），依赖西凉军为底牌。
   - **外戚许家**：许丞相（主角外祖父），门生故吏遍布朝廷，控制六部大部分高层职位（原文 L1031）；两子分别掌控**禁军、金吾卫**（原文 L353）。
   - **摄政王**：先帝之弟，五年前起代政，掌握**京营**，与许家联姻（原文 L741、L1033）。
   - **镇国长公主李长月**：曾被送往北虏为质子归来，获开府之权，拉拢朝臣（原文 L743-745）。
   - **太后（许太后）**：神神叨叨，许家势力代表（原文 L17）。
   - **军队系统**：西凉铁骑（李乾，二十万）、幽州军（萧衍，二十万，已叛）、禁军五卫（虎贲卫、金吾卫等）、北府军（陆氏，江南）、平卢军、陷阵营（贾先生，李乾心腹）、京营（摄政王）。
   - 原文未明确给出「全国共有几州几郡、中央官制品级表」等量化设定。

4. **本书无独立修炼力量体系。** 武力差异以**军队规模 / 个人武艺**描写呈现：提及「天生神力」（胡车儿）、「武艺高强 / 武艺高超」（林唐等）、「武功苏氏」（原文 L3853）等，但**无等级、境界、内力、先天、大宗师等修炼设定**。原文 L7627 仅以「等级森严」形容李乾治军，非力量等级。

## 三、主角优势来源（无金手指时的底气）

- **穿越者认知差**：看穿女频套路与穿书者剧本，不被话术/恋爱脑拿捏。
- **二十万西凉大军**：经营边关十年，「威震天下」「镇压漠北胡人不敢犯境」（原文 L911-913、L297）。
- **理性战略布局**：挟女主以令诸侯、清洗禁军、蚕食六部、拉拢长公主与江南士族等。

> 注：原文 L14341 他人议论「那皇帝似乎开了天眼」，是对李乾料事如神的观感，并非主角拥有读心 / 预知类能力；李乾曾言在凉州遇过「梦中预知未来」的奇人（原文 L11523），但此人设是否为主角自身能力**原文未明确**。
