# 张昭

**身份背景**：萧衍最信任的心腹兄弟，幽州军高级将领（注意：非暗恋萧容音的副将"江昭"，二人不同）。叛军核心层人物。

**核心经历**：第47章萧衍令撤军时，众将纷纷看向张昭，盼其劝阻萧衍；第50章率军拦住萧容音突围马车欲救，被李乾一箭钉地逼退；在萧容音瑟缩恐惧的目光下，为保她妥协，亲口认同"萧衍该杀"；第51章随李乾入宫，向百官述说平叛经过，离走前仍忍不住看萧容音。

**性格特质**：对萧衍与萧容音重情重义；压力下以所爱之人为先而妥协；并非死硬，识时务。

**能力特长**：统军、骑兵指挥。

**人际关系**：萧衍（主公/义兄）；萧容音（舍命欲救之人）；赵充（同营老将）；李乾（兵败后归顺之主）。

**成长轨迹**：萧衍死忠心腹 → 兵败被箭逼退 → 为萧容音妥协归顺 → 随新君入宫。

- **archetype**：supporting（原反派阵营核心，后归顺）
- **关键情节（时序）**：① 第47章 被众将寄望劝阻撤军；② 第50章 拦萧容音被李乾一箭逼退；③ 第50章 妥协认同"弑君者该杀"；④ 第51章 随李乾入宫说平叛。
- **成长弧线（character_arc）**：从誓死效忠叛主，到以萧容音安危为砝码转向新君，忠诚对象随实力易主。

**别名列表**：张将军（称呼｜高）；心腹（叙事｜高）。
