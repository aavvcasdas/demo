# 韦阁老

- **身份背景**：韦氏一族家主，大魏顶级门阀掌门。族中女儿入宫为贵妃（韦贵妃），故为外戚核心。许中正当面称其"崇岳兄"，可知其字为崇岳。第92章"韦爵爷，请抄家"所指即韦氏一脉。
- **核心经历**：第100章韦氏寿宴上，婢女林晚救活中毒的朝阳县主韦初月，韦阁老眸光一闪，盘算将这新封女医官收作刺探李乾宫中动向的眼线。当夜许中正单独在后园邀他"改天换日"谋反，他眼底精光一闪却敛去，以配合清田为由滴水不漏推脱，将事推给韦应。其家族最终走向被抄家灭族（"韦爵爷，请抄家"）。
- **性格特质**：老狐狸，深谋远虑，凡事留退路；表面波澜不惊，袖中攥紧却不动声色。
- **能力特长**：门阀势力经营、政治算计、识人用间。
- **人际关系**：韦应（族中驸马房家主，谋反执行者）、韦雨卿（西眷房嫡女，族中智囊）、韦贵妃（族女，后宫依靠）、许中正（谋反盟友试探对象）。
- **成长轨迹**：从云端外戚权贵，到谋反暗线反噬、家族被抄，属于"高处跌落"型反派弧。

- **archetype**：antagonist（外戚权臣，谋反暗线核心）
- **关键情节**（时序）：
  1. 寿宴欲以林晚为宫中耳目（第100章）
  2. 许中正抛谋反邀约，他推脱给韦应（第100章）
  3. 默许韦应接谋反令，家族卷入篡位局（第101章）
  4. 韦氏被抄家灭族，"韦爵爷请抄家"（第92章）
- **成长弧线**：character_arc——由位极人臣的外戚核心，因贪权涉反，终致家族倾覆；全程无明显正向成长，作为权力博弈的祭品。
- **别名列表**：韦崇岳（字，来源许中正称"崇岳兄"，置信度中）、韦相/韦氏家主（称谓，置信度高）、韦贵妃之父（族女入宫为贵妃，置信度高）
