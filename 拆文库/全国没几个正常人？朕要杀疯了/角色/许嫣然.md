# 许嫣然

**身份背景**：李乾的才人（后宫封号），许中正（许相）的孙女/嫡女，书中称"真嫡女"，带怨毒。属许党却入后宫，是李乾制衡外戚的棋子之一。

**核心经历**：第47章提及李乾"不让嫣然侍寝"，可见其虽为才人却未得宠；第103章丞相府寿宴，李乾令其当众复述所见，她清晰作证柳云裳自己松手故意摔下、四婶根本未碰，成为拆穿绿茶的关键证人，自呼"臣妾"；事后李乾借其证词依大魏律绞死柳云裳、杖许谦，许家联姻棋局裂痕。

**性格特质**：表面恭顺、敢当众作证；对家族带怨毒，甘为李乾所用。

**能力特长**：作人证、以后宫身份参与宅斗/权斗。

**人际关系**：李乾（夫/皇）；许中正（祖父，许党核心）；柳云裳、杨燕燕（宅斗相关）；许嫣红（堂/姐妹，同府丑事）。

**成长轨迹**：边缘才人 → 被李乾借力为关键证人 → 后宫与许党间的微妙存在。

- **archetype**：supporting（后宫）
- **关键情节（时序）**：① 第47章 提及未得侍寝；② 第103章 当众作证拆穿柳云裳，成李乾清算许党一环。
- **成长弧线（character_arc）**：从不得宠的才人，转为被皇帝当众倚重、借以敲打本家的工具，立场游移于许党与皇权之间。

**别名列表**：嫣然（称呼｜高）；才人（封号｜高）；臣妾（自称｜高）。
