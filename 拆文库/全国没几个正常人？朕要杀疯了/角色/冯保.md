# 冯保

**身份背景**：李乾贴身内侍（宦官）。真实身份是长平侯府"假世子"——当年接生嬷嬷将他与真世子掉包；三年前真世子烧毁先帝御赐夜明珠，长平侯家令其顶罪，先帝赐宫刑，遂为阉奴。

**核心经历**：第2章登场，小宦官主动为李乾领路；第5章奉李乾命勒死、再以红绫吊死胁迫太后的许嬷嬷；途中自曝假世子身世，李乾怜其遭遇，定计明日带他回长平侯府，既收忠宦又打压摄政王势力；此后常随李乾左右（第81章黄府门外守候等）。

**性格特质**：忠诚、机敏、身世悲苦；对李乾感恩图报；执行处决干脆利落。

**能力特长**：内廷运作、近身侍奉、执行死刑（勒死/吊死）。

**人际关系**：李乾（主君，收其为己用心腹）；长平侯府（养父母/假身份来源）；许嬷嬷（奉命杀之）。

**成长轨迹**：假世子顶罪受刑为阉奴 → 被李乾识才收编 → 成皇帝最可信之内侍。

- **archetype**：supporting（内廷核心）
- **关键情节（时序）**：① 第2章 登场领路；② 第5章 奉命杀许嬷嬷；③ 第5章 自曝身世被收编、随回侯府；④ 后续常随侍。
- **成长弧线（character_arc）**：从隐忍苟活的阉奴，到借新君之恩重获尊严与权力，完成"真假世子"逆用。

**别名列表**：咱家（自称｜高）；奴婢（自称｜高）；老保（第81章称｜中）。
