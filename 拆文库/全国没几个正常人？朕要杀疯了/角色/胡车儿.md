# 胡车儿

**身份背景**：李乾贴身护卫，天生神力，西凉出身，是李乾"最信任之人"之一（第2章与"铁牛"同指）。西凉武力的近身化身。

**核心经历**：第2章登场随侍李乾；第5章一拳一个打碎许家将校脑袋，唐铮惊其"非人"；第17章一刀砍断女子脖颈；第81章随李乾赴黄府、门外懵懂随侍；第103章推开扑打的许嫣红、一脚踢晕大虎、拧断其四肢，并嘲"京城小姐眼瞎喜欢土匪"；第105章作为李乾"贴身护卫"，田夫人骂之，李乾掌掴田夫人立威，西凉士兵齐拔刀。

**性格特质**：悍勇、粗直、忠诚到骨；带市井幽默与粗痞（嘲小姐、自称"俺"）。

**能力特长**：天生神力、近身格杀、执行死刑，是李乾命令最可靠的"手"。

**人际关系**：李乾（主君，绝对忠诚）；冯保（同侍内廷）；许嫣红、大虎（被其制服者）。

**成长轨迹**：西凉猛士 → 皇帝贴身护卫，常随执行脏活与立威。

- **archetype**：supporting（主角护卫）
- **关键情节（时序）**：① 第2章 登场随侍；② 第5章 一拳碎许家将校；③ 第103章 制服许嫣红、大虎；④ 第105章 护卫身份被李乾当众立威。
- **成长弧线（character_arc）**：始终是李乾最不动脑、最可托的武力执行者，角色功能稳定，无大变化，凸显主角底牌的"确定性"。

**别名列表**：铁牛（第2、5章称｜高）；胡车儿（本名｜高）。
