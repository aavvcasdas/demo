# 黎玉

- **身份背景**：自称"九天玄女"转世，叶扶芷之母，以"肉身布施"蛊惑百姓的邪教头目。其夫为右金吾卫中郎将叶玮。
- **核心经历**：第51—53章，黎玉在京城宣扬"九天玄女的女儿要以肉身布施，人人有份"，逼女儿叶扶芷（小玄女）供众人性侵以"平息百姓疾苦、躲避刀兵"。叶玮制止，黎玉反斥"叶玮，你怎敢对九天玄女不敬"。李乾识破邪教，以"既然你是九天玄女，福泽比女儿还深厚，一万人都受得住"的反逻辑将她按"肉身布施"惩处；黎玉至死喊"我是佛子亲封的九天玄女"仍被诛，叶玮被拿下后归顺李乾。
- **性格特质**：疯魔自欺，以爱女为名行残忍之实，沉浸话本式妄想。
- **能力特长**：话术蛊惑、邪教组织动员。
- **人际关系**：叶扶芷（女儿/受害者）、叶玮（夫，阻止者）、李乾（镇压者）、被蛊惑百姓（信众）。
- **成长轨迹**：无，邪教反派被清算。

- **archetype**：antagonist（邪教首领，荒诞恶役）
- **关键情节**（时序）：
  1. 宣扬"肉身布施"，逼女儿供众（第51章）
  2. 叶玮制止，反斥其不敬九天玄女（第52章）
  3. 李乾识破，以反逻辑惩处（第53章）
  4. 至死自称玄女仍被诛，叶玮归顺（第53章）
- **成长弧线**：无正向成长；以"荒诞邪教被铁腕镇压"收尾，强化主角"绝不容邪教"的立意。
- **别名列表**：九天玄女（自称，置信度高）、叶扶芷之母（身份，置信度高）、黎氏（姓氏，置信度中）
