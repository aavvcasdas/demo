# 冯振

- **身份背景**：长平侯真世子，冯保的替罪羊对象（当年冯保被推去替他抵烧珠死罪，受宫刑）。
- **核心经历**：第10章李乾乔装入长平侯府，见冯振搂着冯保未婚妻张芊芊，嘲冯保"人不人鬼不鬼的狗阉奴"，得意自曝当年故意烧夜明珠害冯保被赐宫刑。第11章自认放火、称父母早知仍让冯保抵罪、刨了冯保亲奶奶坟将尸骨暴尸、将养父母发配西北苦力，扬言"世子位、父母、张芊芊全要抢回"。第12章狡辩仍被令掌嘴，张芊芊指认后李乾赐死，胡车儿拧断其颈。
- **性格特质**：阴狠自私、嚣张跋扈的真小人；以"贱民"蔑称触李乾逆鳞。
- **能力特长**：无真实能力，全仗侯府权势。
- **人际关系**：冯保（曾替罪之养兄弟，仇恨对象）、张芊芊（倒戈的未婚妻）、长平侯/王夫人（父母）。
- **成长轨迹**：无，纯粹恶役炮灰。

- **archetype**：minor（恶役型反派，爽点祭品）
- **关键情节**（时序）：
  1. 抱张芊芊、自曝烧珠害冯保（第10章）
  2. 自认放火、刨奶奶坟、发配养父母（第11章）
  3. 装委屈倒打一耙（第11章）
  4. 狡辩掌嘴后被赐死拧颈（第12章）
- **成长弧线**：无成长；以"越可恨越打脸越爽"的恶役逻辑收场。
- **别名列表**：真世子（身份，置信度高）、冯郎（张芊芊称，置信度高）
