# 楚招摇

- **身份背景**：江陵楚氏嫡长女，穿越女大学生（带系统），后被李乾敕封为楚妃。
- **核心经历**：第20、22章系统令其攻略"暴君"李乾；第22章梦呓"男人都是混蛋"泄露穿越者身份，李乾内心点破并布冯保监视。第32章醉酒自曝穿越与现代知识（武大、应用化学、会造玻璃），顺嘴漏出"系统叫我攻略狗皇帝"。李乾将计就计，把她塑造成独宠后宫的宠妃，扶持楚氏与许党打擂台，同时严密拿捏其穿越者底牌。
- **性格特质**：自带现代优越感、嘴硬、怕死；醉酒吐真，清醒时装腔。
- **能力特长**：现代知识（玻璃/工业概念）、系统任务视角，可作为帝王情报棋子。
- **人际关系**：李乾（夫/监视者，棋手）、许嫣然（怨毒的宫斗竞争者）、系统（未知存在）。
- **成长轨迹**：从试图攻略暴君，沦为皇帝掌中棋子，身份被完全拿捏。

- **archetype**：supporting（穿越者配角，被主角利用的棋子）
- **关键情节**（时序）：
  1. 系统令攻略暴君，梦呓泄密（第20、22章）
  2. 封楚妃，成独宠棋子（第22章后）
  3. 醉酒自曝穿越与现代知识（第32章）
  4. 被李乾严密监视、扶楚氏抗许党（第22、32章及后续）
- **成长弧线**：character_arc——由"带系统来攻略"的穿越女，逆转为被皇帝反向操控的情报源；主动性逐步丧失。
- **别名列表**：楚妃（封号，置信度高）、江陵楚氏嫡长女（身份，置信度高）、穿越女（身份，置信度高）
