# 徐浮图

**身份背景**：平卢军将领（平卢将军），拥兵一方的地方军头。

**核心经历**：第50章潼关僵持时冷眼旁观，盘算趁乱拿下年轻皇帝控制京城，见十余万西凉铁骑涌出后冷汗跪伏；第87章黄柏五十大寿，盯上随李乾赴宴的姜玉漱、眼红黄柏封蓝田县子；第88章为博姜玉漱欢心（"臣妾想看"）应黄柏舞剑，不料黄柏实下死手，互刺同归于尽。李乾将之定性"舞剑失手"，追封平卢侯（三岁幼子袭爵），顺势擢马忠为平卢军大将军，平卢军落入李乾手。

**性格特质**：好色、眼红权位、轻浮恃勇；对姜玉漱垂涎，因色送命。

**能力特长**：统平卢军、剑术（不及黄柏）。

**人际关系**：姜玉漱（觊觎对象）；黄柏（同归于尽者）；马忠（副将，后上位）；李乾（君主，借其死完成平卢军收编）。

**成长轨迹**：平卢将领 → 觊觎后宫、卷入寿宴死局 → 舞剑身死，平卢军被收编。

- **archetype**：antagonist / supporting（反派系将领，被借刀除掉）
- **关键情节（时序）**：① 第50章 暗生异心，被西凉铁骑震慑跪伏；② 第87章 觊觎姜玉漱、眼红封爵；③ 第88章 为博欢心舞剑，与黄柏同死。
- **成长弧线（character_arc）**：野心未展、因色忘形，成了李乾不费刀兵收编平卢军的棋子。

**别名列表**：徐将军（称呼｜高）；平卢将军（身份｜高）。
