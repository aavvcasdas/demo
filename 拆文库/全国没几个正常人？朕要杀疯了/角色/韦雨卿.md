# 韦雨卿

- **身份背景**：韦氏西眷房嫡女，小字卿卿，韦氏一族中的智谋担当。
- **核心经历**：第101—102章，燕国公侄子窦常征因伯父被李乾下旨缉拿而焦虑回京，向韦雨卿求救。韦雨卿献"孤臣反间计"：让朝臣对燕国公纷纷落井下石、弹劾罪名越离谱越好（懒政、藏前朝旧物、意图不轨），使皇帝看出满朝文武合谋倾轧燕国公，燕国公反成最不可能结党营私的"孤臣"，皇帝反而最放心。她以"周长恭横扫七国却因谗言呕血死"类比，从容如指点江山。窦常征听得热血，许诺大伯平安便去韦氏提亲娶她。
- **性格特质**：聪慧从容，智计过人，谈吐间志在必得；对权谋有天然的掌控欲。
- **能力特长**：反向逻辑权谋、政治博弈设计、动员权贵之子施压。
- **人际关系**：窦常征（恋人/盟友，燕国公侄子）、燕国公（营救对象）、韦氏（族援）。
- **成长轨迹**：智谋少女→扭转燕国公危局的关键谋士，情感线与智斗线并行。

- **archetype**：supporting（韦氏智囊，反派阵营中的谋士型配角）
- **关键情节**（时序）：
  1. 窦常征求救，定调"交权即生"（第102章）
  2. 献孤臣反间计，以周长恭类比（第101章）
  3. 列"懒政/谋逆"等离谱罪名，动员权贵之子实操（第101—102章）
  4. 被窦常征许诺提亲，智斗收束于柔情（第102章）
- **成长弧线**：character_arc——从族中聪慧嫡女，成长为能设计扭转朝局危局的核心谋士；情感上由独身谋士转为有婚约许诺。
- **别名列表**：韦卿卿（小字，置信度高）、韦氏西眷房嫡女（身份，置信度高）
