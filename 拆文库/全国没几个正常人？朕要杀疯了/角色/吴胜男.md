# 吴胜男

- **身份背景**：白莲宗女弟子，选秀入宫的"作女"型配角。
- **核心经历**：第19章选秀中，吴胜男自报"自幼跟随白莲宗习武"，并宣称"臣女犯有厌男症，不能嫁给陛下"，试图以江湖门派与特立独行博关注。李乾一眼识破其造假与穿越者式话术（言谈中的"平等"等现代观念），冷然限制：七招之内败给西凉军第一猛将铁牛，便要吴家陪葬。吴胜男见铁牛如铁塔身躯、地上碎木屑，小腿打颤，被拖出时仍挣扎嘶喊。
- **性格特质**：中二仗势，以"厌男""习武"标新立异，实则色厉内荏。
- **能力特长**：粗浅武艺（远不足以抗猛将），白莲宗背景。
- **人际关系**：白莲宗（师门）、李乾（碾压者）、铁牛（西凉第一猛将，对手）。
- **成长轨迹**：无，作女炮灰。

- **archetype**：minor（江湖门派作女，爽点祭品）
- **关键情节**（时序）：
  1. 选秀自称白莲宗弟子、患厌男症拒嫁（第19章）
  2. 李乾识破造假与穿越话术（第19章）
  3. 被限七招败铁牛、否则吴家陪葬（第19章）
  4. 见铁牛威势吓垮被拖出（第19章）
- **成长弧线**：无正向成长；以"作女被碾压"的喜剧/爽点收尾，并顺带引出白莲宗这一江湖势力伏笔。
- **别名列表**：白莲宗弟子（身份，置信度高）、吴女侠（自诩，置信度低）
