# 许中正

- **身份背景**：当朝丞相（许丞相/许相），许氏外戚核心，权倾朝野。第2章提及李乾忌惮"外公许丞相门生故吏遍布朝廷，两个儿子还掌控禁军、金吾卫"，足见其外戚根基。
- **核心经历**：第10章府中定"嫁孙女入太子"夺权计；第14、37章萧容音预言三年后许丞相被长子许朗弑父、李乾趁机掌权。第100—101章，他在韦氏后园压低声音抛"这大魏的天该换了"，邀韦阁老"改天换日"谋反，被推给韦应；随即令韦应途中杀燕国公、自曝燕国军、平卢军、禁军、金吾卫皆有自己人，谋逆底牌一次性亮出。
- **性格特质**：深沉毒辣，野心勃勃，自信拉满；善于以"中正兄"姿态结交门阀。
- **能力特长**：朝堂经营、兵权渗透（四军安插人马）、权谋布局。
- **人际关系**：许朗（长子，未来弑父者）、许嫣然（孙女，入宫为才人）、韦阁老/韦应（谋反盟友）、李乾（对抗的君主）。
- **成长轨迹**：权臣→公开谋反，走向覆灭线。

- **archetype**：antagonist（外戚权臣，谋反主谋）
- **关键情节**（时序）：
  1. 定联姻夺权计、朝会收人心（第10章）
  2. 萧容音预言其将被长子弑父（第14章）
  3. 邀韦阁老谋反被推给韦应（第100章）
  4. 令韦应杀燕国公、自曝四军有己人（第101章）
- **成长弧线**：character_arc——由隐性专权到显性篡位，自信膨胀直至底牌尽露；典型"反派亮底牌"型，无正向成长。
