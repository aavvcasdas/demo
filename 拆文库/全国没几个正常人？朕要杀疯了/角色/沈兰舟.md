# 沈兰舟

- **身份背景**：陇西郡公，本朝最年轻的郡公，摄政王一党，掌握一营京营兵马。
- **核心经历**：第57章萧容音梦中预警"三天后陇西郡公大婚，会有一场很大的闹剧"；李乾由此知悉这位年轻郡公站在摄政王那边，且掌京营兵马。其娶京营都指挥之女林婉儿，喜宴排场盛大。李乾借薛令儿渗透其喜宴进行布局（第90余章薛令儿如约赴陇西郡公沈兰舟喜宴），将其纳入清算摄政王党的棋局。
- **性格特质**：年轻权贵，站队清晰，依仗兵权与婚盟。
- **能力特长**：京营兵权（一营）、门第婚盟经营。
- **人际关系**：林婉儿（妻，京营都指挥之女）、摄政王（党主）、薛令儿（渗透布局者）、李乾（敌/布局者）。
- **成长轨迹**：作为摄政王党羽进入皇帝清算视野。

- **archetype**：supporting（摄政王党羽，待清算的势力配角）
- **关键情节**（时序）：
  1. 萧容音梦预警其大婚闹剧（第57章）
  2. 李乾确认其为摄政王党、掌京营兵马（第57章）
  3. 娶林婉儿，喜宴成布局切入点（第90余章）
  4. 薛令儿渗透喜宴，纳入清算棋局
- **成长弧线**：character_arc——由"最年轻郡公"的权贵新贵，转为皇帝削藩夺兵权的目标；书中尚在布局阶段。
- **别名列表**：陇西郡公（封号，置信度高）、郡公爷（称谓，置信度高）、沈郡公（简称，置信度高）
