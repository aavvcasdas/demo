# 董辅生

**身份背景**：西凉铁骑飞熊营主将，李乾在西凉十年经营的核心将领之一。西凉军分四营——飞熊营、山字营、龙骁营、虎贲营（后三营主将书中未具名）。李乾真正的底牌与基本盘。

**核心经历**：第50章率五万西凉骑军抵京勤王，本章先以营号"飞熊营"呼之；第51章具名为董辅生，向李乾报"五万西凉骑军全部抵达，十日内跨越两州十七县，沿途无人阻拦"，领命开往幽州。李乾当众宣示将幽州拆分，"使幽州成为第二个属于朕的凉州"。

**性格特质**：虎背熊腰、自豪、对李乾绝对忠诚；报功时理直气壮，是十年经营的见证者。

**能力特长**：统飞熊营铁骑、长途奔袭、跨州机动（十日两州十七县）。

**人际关系**：李乾（主君，十年栽培之核心）；西凉另三营主将（同僚，未具名）。

**成长轨迹**：西凉边将 → 勤王入京核心 → 经略幽州、成帝国新支柱。

- **archetype**：supporting（主角核心武力）
- **关键情节（时序）**：① 第50章 飞熊营勤王护驾、压服全场；② 第51章 报抵达、受命赴幽州。
- **成长弧线（character_arc）**：长期伏笔（西凉十年）在危机一刻集中释放，从边军主将跃为帝国新军支柱。

**别名列表**：董辅（第50章以营号呼｜中）；飞熊营主将（称号｜高）。
