# 楚慕白

- **身份背景**：影密卫前任指挥使之子，背负灭门血仇。以太平县衙主簿身份掩护，活跃于市井江湖，坊间传其有"凤凰之才"，得之可得半壁江山。
- **核心经历**：第10章周兴荐其对付影密卫。第15章白衣撩袍入御书房，风流蕴藉、名士风范，自报身份后恃才与李乾讨价还价"卫阳归臣，影密卫归你"；李乾赐死威胁下吓垮，慌乱供出影密卫藏身藏龙巷及兵甲粮食。第16章李乾问死活，楚慕白毫不犹豫跪下"求陛下活"，被令入影密卫随周兴效力。
- **性格特质**：风流名士派头，恃才傲物，但极度惜命、临危易垮。
- **能力特长**：谋略、熟悉影密卫内情与江湖门道。
- **人际关系**：卫阳（杀父仇人）、李乾（新主）、周兴（直属上司）。
- **成长轨迹**：从复仇者/讨价还价者，到被收服为皇帝所用的工具。

- **archetype**：supporting（被收编的谋士型配角，原反派阵营子弟）
- **关键情节**（时序）：
  1. 周兴荐其对付影密卫（第10章）
  2. 白衣入见，恃"凤凰之才"讨价还价（第15章）
  3. 被赐死吓垮，供出藏龙巷（第15章）
  4. 求活入影密卫，随周兴效力（第16章）
- **成长弧线**：character_arc——由复仇孤傲的名士，转为惜命投效、被皇权收编；从"与帝对等谈判"降为"臣服效死"。
- **别名列表**：楚主簿（太平县衙掩护职，置信度高）、凤凰之才（坊间称，置信度中）
