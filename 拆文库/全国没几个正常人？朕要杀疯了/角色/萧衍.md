# 萧衍

**身份背景**：大魏骠骑大将军，幽州军主帅，以"清君侧"为名起兵造反、意图谋朝篡位。属范阳萧氏（第89章"清河张氏、范阳萧氏，灭绝"可证萧氏为世家大族，萧衍为其代表）。其父与老将赵充是结义兄弟。萧容音众多"恋爱男主"之一。

**核心经历**：拥兵二十万（幽州铁骑）造反，是登基初期最大外患；第47章令大军"明早撤回幽州"，向李乾提三要求和（交萧容音、下罪己诏、给三百万两）；第50章潼关城下与李乾单挑，仅六回合落败，被长枪钉死泥土；死前扭头牵挂萧容音"我死后谁来照顾你"。

**性格特质**：野心勃勃、借"清君侧"掩饰篡位野心；对萧容音深情；对部将号召力有限——众将不愿撤军、只想荣华，内部已离心。

**能力特长**：统帅幽州二十万军、骑战指挥；个人武艺不及李乾（六回合败）。

**人际关系**：赵充（父结义兄弟/幽州二号）；张昭（最信任的心腹兄弟）；萧容音（爱慕对象）；李乾（弑君者/终极对手）。

**成长轨迹**：三代忠烈之后 → 拥兵自重 → 清君侧造反 → 巅峰即崩、兵败身死。

- **archetype**：antagonist
- **关键情节（时序）**：① 第8章（提及）长公主揭其造反；② 第14章 萧容音"萧衍带我骑马"恋爱流水；③ 第47章 令撤军、提三要求；④ 第50章 潼关单挑被李乾斩杀、首级传示九边、堆京观。
- **成长弧线（character_arc）**：起兵夺权至顶峰时内部松动，一战崩盘；其"奉天靖难"谎言被部将看穿，失败早有伏笔。

**别名列表**：萧贼/逆贼（李乾称｜高）；萧大将军（旧称｜高）；清君侧叛军（叙事｜高）。
