# 林晚

- **身份背景**：现代穿越者（三甲医院护士），原是韦氏别院婢女，因救活县主被李乾当场敕封为女医官。
- **核心经历**：第100章韦氏寿宴，朝阳县主韦初月中毒，林晚施急救救活，内心独白自曝"好歹三甲医院出来的护士，这点急救还是会的"，并惋惜古代女医少。李乾当场封其为随驾女医官。第101章李乾赐金百两，令其与沈青青专门训练女医、在京多开药铺惠民；林晚试探取名"要不叫医院"，李乾正等此词，决意以"医院"之名作饵，钓日后露馅的穿越者。
- **性格特质**：专业务实，略带现代自豪感，对救人有真诚热忱。
- **能力特长**：现代急救与护理、医学常识，穿越者身份标识。
- **人际关系**：李乾（主君，利用其穿越者身份布饵）、沈青青（训练女医的合作伙伴）、韦初月（所救县主）。
- **成长轨迹**：从婢女→御封女医官，并成为李乾穿越者情报网的一环。

- **archetype**：supporting（穿越者配角，被收编的技术型角色）
- **关键情节**（时序）：
  1. 救活中毒的韦初月，自曝护士底牌（第100章）
  2. 被封女医官，大喜（第100章）
  3. 受命与沈青青训练女医、开药铺惠民（第101章）
  4. 提"医院"之名，被李乾用作钓穿越者之饵（第101章）
- **成长弧线**：character_arc——由隐藏身份的穿越婢女，转为公开效力的女医官；其现代词成为帝王情报陷阱，被动卷入权谋。
- **别名列表**：女医官（官职，置信度高）、林医官（称谓，置信度高）、穿越护士（身份，置信度高）
