# 长平侯

- **身份背景**：开国元勋，世袭罔替侯爵，冯振、冯保之父（冯保为其养子，曾替真世子冯振抵罪受宫刑）。
- **核心经历**：第10—12章，真世子冯振搂着冯保青梅竹马的未婚妻张芊芊、自曝当年故意烧毁先帝御赐夜明珠害冯保被赐宫刑。长平侯闻声出场，偏袒冯振、一脚踹倒冯保逼其跪向冯振道歉；王夫人亦抽冯保巴掌骂其"阉奴"。李乾现身质问烧珠李代桃僵之罪，长平侯亮出"开国元勋、世袭罔替"身份试图压人，李乾一句"开国元勋就可以欺君？"将其赐死，胡车儿一脚踹飞撞墙毙命。
- **性格特质**：护短昏聩，倚仗功勋特权，对养子刻薄无情。
- **能力特长**：门第权势（在绝对皇权面前无效）。
- **人际关系**：冯振（真世子/子）、王夫人（妻）、冯保（养子/阉奴，被弃）、李乾（死刑执行者）。
- **成长轨迹**：无，作为"功勋免死"幻觉破灭的爽点祭品。

- **archetype**：minor（倚仗功勋的作恶外戚，炮灰反派）
- **关键情节**（时序）：
  1. 冯振抱张芊芊、自曝烧珠害冯保（第10章）
  2. 偏袒冯振，踹倒冯保逼道歉（第11章）
  3. 亮元勋身份被李乾反问"欺君？"（第12章）
  4. 被胡车儿踹死，满门连诛（第12章）
- **成长弧线**：无正向成长；典型"亮身份求饶仍被诛"的反派收尾。
- **别名列表**：侯爷（称谓，置信度高）、开国元勋（身份，置信度高）
