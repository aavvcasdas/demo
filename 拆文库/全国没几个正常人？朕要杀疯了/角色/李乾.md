# 李乾

**身份背景**：大魏七皇子，原主是个对萧容音死缠烂打的"舔狗皇子"；现代穿越者取代原主。因父皇抛江山随白月光出走、太子及诸皇子恋爱脑出走，借京城权力真空登基称帝，自称"朕"。本书绝对主角（男频视角下的"理性暴君"）。

**核心经历**：登基首日赐死作精萧容音/温行舟立威；收禁军、密调西凉铁骑入宫；清洗许家将校、立三道"杀无赦"铁律；平叛萧衍（潼关单挑六回合斩之）；当众册封赵充、逼张昭归顺，收编幽州军；借黄柏徐浮图同死收编平卢军；清田抄家、灭清河张氏与范阳萧氏；压制京营、斩陈都指挥使夺权。

**性格特质**：冷酷务实、杀伐果断、不吃女频套路；暴力始终服务于战略，常以"程序正义"包装（如依大魏律绞妾、诬告反坐）；冷静算计，惯用"假放真杀""收编分化"。

**能力特长**：① 穿越者信息差——识破女频男主名（宋怀瑾、墨凛川之类）、知小说剧情走向；② 十年西凉经营——炼成西凉铁骑四营（飞熊、山字、龙骁、虎贲），沿途关卡驿站粮道皆其党羽；③ 武艺——练枪十年，单挑斩萧衍；④ 权术——舆论战（贾先生操盘）、离间、投名状绑忠。

**人际关系**：母后许太后（控制利用）；萧容音（双穿越者，控制为牵制皇叔/北府少帅的棋子）；冯保、胡车儿（贴身内侍与护卫）；赵充、张昭（收编降将）；姜玉漱、许嫣然、楚招摇等（后宫/技术流）；徐浮图（平卢，已除）。

**成长轨迹**：被贬边关的弃皇子 → 登基称帝 → 收权清洗 → 平叛收编两镇军 → 清田灭世家、集权中央。

- **archetype**：protagonist
- **关键情节（时序）**：① 第1章 登基赐死立威；② 第2章 识破萧容音穿越、召西凉铁骑入宫；③ 第8章 逼萧容音交会试泄题内幕、布局许党；④ 第50章 潼关单挑斩萧衍、十余万西凉铁骑现身跪伏；⑤ 第88–89章 收编平卢军、灭世家清田。
- **成长弧线（character_arc）**：从无权边将到铁血独夫，信息差与西凉底牌贯穿始终，权柄由虚转实、由守转攻。
- **金手指说明**：李乾本人无 literal 系统（系统属楚招摇、张澄等穿越女）；其"金手指"= 穿越者先知 + 西凉十年布局 + 对女频世界规则的认知碾压。

**别名列表**：朕（自称｜高）；陛下（臣下称｜高）；七皇子（早年身份｜高）；理性暴君（叙事评｜高）；疯批暴君（萧容音视角｜中）。
