# 韦应

- **身份背景**：韦氏驸马房家主，娶李乾的五姑姑新城公主为妻，是韦阁老指派接手许中正谋反事宜的关键执行者。
- **核心经历**：半生受善妒的新城公主折辱——公主曾因他与婢女多说几句话，便割下婢女下身皮盖在他头上。第100章补叙其身世，为后续报复动机埋下锚点。第101章许中正在后园单独见他，命其于影密卫缉拿燕国公途中派人杀之、逼反燕国军；韦应领令沉默点头，并暗忖"或许是时候该报复回来了"，将私人恩怨注入谋反令。
- **性格特质**：外表儒雅，眉宇间压着说不清的阴郁；隐忍半生，记仇且一旦决断便狠。
- **能力特长**：门阀资源调度、执行力强，能压下情绪扮恭敬。
- **人际关系**：新城公主（妻，折辱来源）、韦阁老（族长，指派者）、许中正（谋反合作者）、韦雨卿（同族）。
- **成长轨迹**：从受辱驸马，到借谋反令寻求报复公主府，完成黑化转身。

- **archetype**：antagonist（谋反执行者，私怨驱动型反派）
- **关键情节**（时序）：
  1. 受新城公主折辱，埋半生恨意（第100章补叙）
  2. 韦阁老将许中正之事推给他（第100章）
  3. 领许中正杀燕国公、逼反燕国军之令，沉默点头（第101章）
  4. 借谋反局谋划报复公主府（第101章）
- **成长弧线**：character_arc——隐忍→黑化，私人屈辱转化为政治叛乱行动力；作为"受辱者反噬"的支线反派。
- **别名列表**：韦氏驸马房家主（身份称谓，置信度高）、新城公主驸马（身份，置信度高）
