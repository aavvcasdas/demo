# 萧容音

**身份背景**：女频小说《绝世娇颜，帝王以国相聘》的穿书女主/天命之女、万人迷。实为现代穿越者（能说出"小说"二字，故被李乾判定为穿越者而非重生者）。前世剧情中曾被李乾救回并册封为皇后。本书中是被李乾控制、利用的"工具人"。

**核心经历**：第1章带温行舟闯宫逼李乾让龙袍，反被赐死（未遂）；第2章被识破穿书万人迷，改"挟女主以令诸侯"；第8章被绑爬逃、剑抵颈时喊出"重生者"，交出谢太傅买通贡员泄题扳倒庞德的内幕保命；第14章奉命写幽州军情报却写成"骑马摘花哄睡"恋爱流水被嘲；第47章自荐劝萧衍退兵被李乾扼颈逼写信；第49章李乾"接容音回家"；第50–51章平叛中被吓得蜷缩臣服，被李乾留作牵制皇叔与北府少帅的棋子。

**性格特质**：初期作精、茶、恋爱脑，自认天命之女；撞上绝对权力后转为恐惧、臣服、实用主义；带反差萌（暗赞李乾颜值、怕惩罚乖乖交稿）。

**能力特长**：预知/知晓女频剧情线（萧衍、陆玄、镇南王、耶律烬等男主结局）；写情报（但常写成恋爱流水）；对男主们有"舔狗"级吸引力。

**人际关系**：李乾（控制者/前世救命恩人/册后者）；萧衍（恋爱男主之一，为其退兵）；陆玄（北府少帅，男主）；江昭（幽州副将，暗恋她、赠并蒂莲玉簪）；张昭（欲救她被箭逼退）。

**成长轨迹**：自信天命之女 → 被识破穿越 → 囚徒工具 → 恐惧臣服。

- **archetype**：supporting（双穿越者，亦敌亦工具）
- **关键情节（时序）**：① 第1章 闯宫逼让龙袍；② 第8章 喊"重生者"交泄题内幕；③ 第14章 恋爱流水被李乾嘲笑；④ 第49章 被李乾接"回家"；⑤ 第51章 扑地哭求"别杀我，我还有用"。
- **成长弧线（character_arc）**：从被众男主捧上天的新天命之女，到认清李乾才是至高无上皇帝，从"被爱者"沦为"被驯服者"。
- **注意**：与萧衍有情感线，但非范阳萧氏血亲（书中未明其族属）。

**别名列表**：容音（李乾称｜高）；天命之女（设定名｜高）；萧女主（叙事｜中）；重生者/穿越者（实际身份｜高）。
