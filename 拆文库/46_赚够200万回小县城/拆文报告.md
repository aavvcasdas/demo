## Stage 2 结构 + 情节节点

### 故事核

**设定**：十年 996 的程序员攒够 200 万，一次凌晨心悸后裸辞回县城。
**主题**：大城市高压职场 vs 县城低物价慢生活；「躺平」是不是「废了」。
**核心行动**：辞职、全款买房买车、把生活拆成一件件小事重新过一遍，对旧世界三次不接招。
**一句话**：被 996 榨了十年的程序员揣着 200 万回县城，用一年时间把「不用」造成的自由过成清单，最后对「躺平＝废了」回一句「我这叫通关了」。

### 故事梗概

主角十年 996，抠搜攒钱加炒股套现凑够 200 万。一次凌晨心悸让他决定「这破班一天都不能再上了」，次日辞职信拍桌，扔掉西装和工牌，只带几件 T 恤坐高铁回老家。县城 40 万全款买带院一楼，自己刷墙改电竞房，十几万全款提国产越野。此后是生活切片的铺排：超市不看打折区、10 块牛肉面、不定闹钟、水库钓鱼、领养土狗、逛菜市场做饭。中段三次与旧世界相遇——钱主管问私活被拉黑、发小烧烤敬「不用装孙子」、老同学问发财他笑说「失业啃老」。半年后身体修复：不掉头发、胃痛消失、撸铁。继续清单：河堤散步混进老年人、木工打狗窝、进山露营、前同事晒加班他默默点赞、雨天不用赶公交、看病几十块、名表收抽屉。79% 处半夜惊醒以为方案没写完，看清旧家具才释然。月息五六千跑赢通胀；江边对过去的自己说「辛苦了兄弟」；回县城一周年和狗在院子里庆祝；加满油向西开到雪山。结尾：有人说 30 多岁回县城躺平是废了，他笑着清点 200 万、健康、车房、不看脸色——「我这叫通关了」。

## Stage 4 反转 + 写作手法

### A. 反转分析

#### 前置反转检查

无。故事时间线之前不存在谎言或误判；十年 996 是明写的前史。

#### 报应设计（无反转/报应型适用）

本篇无传统反转，属**治愈清单型**，报应链弱化为「对照」而非「惩罚」：

| 阶段 | 旧世界的压迫 | 对照结果 | 爽感来源 |
|------|-----------|----------|----------|
| 钱主管 PUA | 问要不要接私活 | 拉黑删除，「吸血鬼的PUA在小县城彻底失效」 | 主动切断 |
| 前同事 | 凌晨晒加班「拼搏的青春」 | 默默点赞，翻身睡死 | 位置对调（我在睡，你在加班） |
| 老同学攀比 | 问在哪发财 | 笑说失业啃老 | 信息差（读者知道 200 万） |
| 「有人说」 | 躺平＝废了 | 四项清点 + 通关 | 判词驳回 |

报应链效果：递进——处理旧世界的成本逐次降低（拉黑要动手 → 点赞一下 → 一句玩笑 → 心里一笑），最后才揭牌。无人受罚，所有「反派」都停留在原地继续原来的生活——这是治愈型与打脸型的分界：文本不让旧世界变坏，只让主角离开。

#### 主/副反转分析

**反转类型**：无反转（`_meta.json.structure_counts.reversal_type = 无反转`，`setup_clues` 按契约跳过阈值）

**接近反转的两处**：
- N17「笑着说失业了 / 回来啃老」——对剧中人是信息差，对读者不是反转（读者从第一句就知道 200 万）。属于**爽点内敛化**处理，不是反转。
- N24「半夜惊醒 / 以为方案没写完」——情绪上的短暂回摆，让读者意识到创伤未愈；是曲线的浅坑，不改变任何认知。

**铺垫线索**（虽无反转，结尾判词有三条可回溯的铺垫）：
1. N19「提前过上了梦寐以求的退休生活」@56%——「退休」一词先把「躺平」正名
2. N23「你的底气……全在那7位数的余额里」@79%——「底气」为结尾「不用看任何人脸色」备案
3. N26「我们以后只为自己活」@88%——自我和解在先，外界判词在后：结尾的「笑了」因此不是逞强

**效果**：惊喜度 2 | 合理性 5 | 情绪冲击 3

### B. 写作手法

完整 9 项手法见 [写作手法.md](写作手法.md)。要点：

| 维度 | 分析 |
|------|------|
| POV 类型 | 第二人称贯穿；N26 嵌入一个「他」（过去的自己）作自我对话对象 |
| 选择效果 | 代入：读者直接领取 200 万和一年自由；第二人称让「不用」句全部变成对读者的许诺 |
| 信息操控 | 读者全知（200 万），剧中人无知；主角对每个来访者都不揭牌 |
| POV 切换 | 无 |
| POV 代价 | 无法写他人视角，因此三次对照的「对方反应」全部缺席（钱主管被拉黑后如何、老同学听到「啃老」的表情都不写）——爽点只能在读者脑内完成 |

| 指标 | 数值 | 评价 |
|------|------|------|
| 对话占比 | ≈3% | 本文本倾向极低。合集内 01–38 平均约 10–15%，本篇是最低档之一。功能：仅老同学一问一答（信息差场景）与心中对过去自己的一句（和解场景），其余全部叙述——口播治愈体的典型形态，台词只留判词 |
| 潜台词率 | ≈100%（2 处对话都有潜台词） | 「失业了回来啃老」实为「我不需要向你证明」；「辛苦了兄弟」实为「我原谅了那个忍了十年的自己」 |
| 对话模式 | 信息差式 + 自我对话式 | 见上 |

| 时间操控 | 位置 | 效果 |
|------|------|------|
| 前史压缩 | N1 | 十年 996 只用两行，把「代价」当作已知项直接进入「兑换」 |
| 切片并列 | N9–N13、N19–N23 | 无时序的生活清单，每段可互换——阅读节奏均匀，适合口播的一句一镜 |
| 三刻度锚定 | N10 / N18 / N27 | 一个月→半年→一周年：在无时序切片里插三根进度桩 |

| 时刻 | 读者知道的 | 主角知道的 | 对手知道的 | 信息差 |
|------|-----------|-----------|-----------|--------|
| 开头 | 200 万 + 心悸 | 同 | 老板只知道他辞职 | 读者=主角>老板 |
| 中段 | 200 万 + 房车已全款 | 同 | 钱主管/老同学以为他失业啃老 | 读者=主角>>剧中人 |
| 结尾 | 全部 | 全部 | 「有人说」不知道 | 揭牌给读者，不揭给剧中人 |

| 意象/物件 | 出现位置 | 每次承载的含义 | 演变轨迹 |
|-----------|---------|---------------|---------|
| 工牌/西装 → T 恤/大裤衩/人字拖 | N4 / N17 / N23 | 职场身份 → 县城身份 | 扔 → 穿 → 「衣柜里全是几十块的」 |
| 名表 → 旧手环 | N23 | 装饰的底气 → 余额的底气 | 收进抽屉 |
| 土狗 | N12 / N19 / N20 / N27 | 陪伴 / 「不用担心加班没人喂」 | 领养 → 散步 → 狗窝 → 周年在场 |
| 身体症状 | N2 / N5 / N9 / N18 / N24 / N29 | 报警 → 松绑 → 复苏 → 修复 → 余震 → 健康 | 见写作手法 3「身体账本」 |

**主题意象群**：工牌/名表/西装（旧身份器物）与 T 恤/手环/拖鞋（新身份器物）构成一组「价签下降、自由上升」的对照；狗与身体症状构成「陪伴/修复」组。

### 爆点性

核心爆点是结尾的判词对撞「废了 / 通关了」，铺垫充分（退休、底气、和解三处），释放到位（四项清点一次揭牌）。但爆点强度受限于类型：读者从第一句就持有 200 万，结尾揭牌只对「有人说」成立，对读者不构成惊喜。传播性中高——「我这叫通关了」可作评论区金句；「男人 30 多岁回县城躺平算不算废了」可作话题。

### 话题性

- **主争议**：200 万在县城够不够躺一辈子——文本用「月息五六千 / 物价极低 / 跑赢通胀」正面回应，但 2026 年的利率环境下 200 万月息五六千对应年化 3–3.6%，评论区会算账。这是可预见的高互动点。
- **副争议**：「靠炒股套现凑够」——运气成分未被文本处理，「不是人人都能复制」的质疑有据可依。
- **代入式自省**：「如果我有 200 万我会不会辞职」；「我的工牌勒了几年了」。
- **价值分歧**：「提前退休混在老头老太里」对 30 多岁男性是自由还是放弃——文本用「通关」正面盖章，反对方会用「废了」原话反击。

### 可复用结构

1. **否定句清单法**：新生活拆 15–25 个切片，每个切片挂一句「不用/再也不」，旧生活靠否定句反向显影 — 适用场景：逃离/辞职/退休/治愈向人生副本
2. **数字兑换链**：总额开局 → 三笔大项各标价 → 其中一笔必须是被动收入 → 小额消费精确到个位 — 适用场景：暴富/攒钱回乡/财务自由类（回应「坐吃山空」质疑）
3. **身体账本**：开场身体报警作决定理由 → 中段症状消退作里程碑 → 结尾回收同一症状 — 适用场景：治愈弧/康复弧/戒断弧
4. **零对话对照**：旧世界三次来访，主角只给一个动作（拉黑/点赞/笑），优越感留在读者脑内 — 适用场景：内敛型爽文/抖音口播反装逼
5. **判词对撞收束**：最后 50–80 字「有人说 X」→ 3–4 项名词清点 → 用开场隐喻系统的词收口 — 适用场景：所有人生副本口播稿

### 同类型写作动作

- 写 46 的同型稿（如「带着 50 万回二线」）时：先列 20 个「不用」句再写切片，切片顺序按空间半径排（屋→街→城→郊→远方）；必须给一个 N24 式的 50 字浅坑，否则曲线全平。
