## Stage 2 结构 + 情节节点

### 故事核

**设定**：大一军训认识一个人前冰山、私下藏不住的女生。
**主题**：口是心非——嘴上否认、行动出卖；喜欢在没有身份之前只能捂着。
**核心行动**：你从被冷淡到解码她的露馅规律，逐次试探，表白，恋后见到她「仅对你可见」的一面。
**一句话**：军训加了个两字回复的冰山女生，你靠六次「嘴硬但行动出卖」的物证把她的喜欢一层层剥出来，表白后她把最粘人的一面设成对你一个人的仅可见。

### 故事梗概

大一军训同方阵，你帮教官搬水顺手加了她微信。夜里闲聊她只回「还行」「不去了」，你觉得她防备心重，正要睡她却补发「你要去买吗」。此后你发现她字少但秒回，问正事解释清楚——不是高冷，是脑内弹幕太多。你一天没找她，她拿防诈骗截图当借口找你，说漏「你今天挺安静啊」又硬邦邦撤回「随便问问」。你开始故意不主动，她总找烂借口接上。约二食堂她淡淡说「行」，你提前到，她已坐好，桌上是你最爱的黄焖鸡、常喝的冰柠茶、吸管插好，嘴上说「顺手买的」。绕操场你直球问她是不是喜欢你，她语速飞快否认，接着顺拐、耳根红透。深夜 12 点她问「是认真的吗」，你装傻，她撤回；第二天又恢复清冷。周末看电影你提前 10 分钟，她已在喷泉旁，奶茶捏变形、吸管咬满牙印。楼下没路灯处你表白，她低头委屈「你怎么现在才说啊」，仍不承认，只在暗处揪住你卫衣带子。恋后她班里仍保持距离，拐角却反手塞手；班会散场牵手，嘴上「我现在也很正经」手却握得更紧；以前「随便」，现在直接发电影票截图「别迟到」。你才懂她以前克制是名不正言不顺，如今拿到「男朋友」这张通行证——那座万年冰山早把最软萌的一面设成对你一个人的仅可见。

## Stage 4 反转 + 写作手法

### A. 反转分析

#### 前置反转检查

无。故事时间线之前不存在谎言；她的「冰山」是人设不是骗局，且开场第 8 行已告知读者「只有你知道她多容易露馅」。

#### 报应设计

不适用（无反派、无惩罚）。

#### 主/副反转分析

**反转类型**：无反转（`structure_counts.reversal_type = 无反转`，`setup_clues` 按契约跳过阈值）

甜宠推拉型的「反转」全部是**对剧中人的反转、不是对读者的反转**：读者从 N1 就持有答案，N3 的「防备心重」是主角误判而非文本误导。全篇的认知变化发生在「你」身上（从「难沟通」到「心里有数」到「藏不住了」），读者只是看着他追上自己已知的答案。

**接近反转的一处**：N17「纯粹是因为名不正言不顺」——把闷骚归因于身份而非性格。这改变的不是「她喜不喜欢你」（读者早知道），而是「她从什么时候开始喜欢你」（比六次露馅更早）。属于归因升级，不是认知反转。

**铺垫线索**（结尾归因「名不正言不顺」的可回溯证据）：
1. N6「你今天挺安静啊」@25%——主角一天没找她，她先受不了：主动方其实一直是她
2. N9「他猛地抬头看了你一眼 / 想说什么又给咽下去了」@57%——想说的话被咽下：不是不想说，是不能说
3. N13「你怎么现在才说啊 / 我还以为你昨晚耍我呢」@73%——「现在才」三字明示她等了很久
4. N14「生怕别人看出来」@81%——恋后仍怕人看出：她的克制是关于「别人」的，不是关于「你」的

**效果**：惊喜度 2 | 合理性 5 | 情绪冲击 4（甜度冲击，非震惊）

### B. 写作手法

完整 8 项手法见 [写作手法.md](写作手法.md)。要点：

| 维度 | 分析 |
|------|------|
| POV 类型 | 第二人称贯穿 |
| 选择效果 | 代入 + 信息控制：读者只能看到她的外部行为（消息/物件/步态/耳朵），看不到内心——这正是「闷骚」题材需要的限制 |
| 信息操控 | 读者=主角（除 N3 主角短暂误判）；她的内心全程黑箱，只在 N13「你怎么现在才说啊」漏出一次 |
| POV 切换 | 无 |
| POV 代价 | 无法写她的心理，因此所有「她其实很喜欢你」都必须靠物证——文本把这个代价变成了手法（露馅升级链） |

| 指标 | 数值 | 评价 |
|------|------|------|
| 对话占比 | ≈17% | 本文本倾向中高（合集 01–38 平均 10–15%，46 仅 3%）。功能：推拉全靠短对话——她的台词 ≤5 字为常态，主角的台词是试探句；同型 48c 对话占比更高（≈27%）但物证减少，说明 48a 用对话和物证各分担一半 |
| 潜台词率 | ≈80% | 她的每句台词都是反话（还行=想聊 / 不去了=你要去吗 / 随便问问=想你了 / 顺手买的=特意买的 / 没有啊=有 / 我也刚到=等很久了）；主角的台词潜台词率低，多为直球 |
| 对话模式 | 推拉式 + 撤回式 | 她说→撤回→深夜再发；主角问→她否认→身体出卖 |

| 时间操控 | 位置 | 效果 |
|------|------|------|
| 三拍延迟 | N6 | 「哦」→半分钟→「你今天挺安静啊」：沉默时长写进节奏 |
| 深夜时间戳 | N10 | 快 12 点：白天咽下的话夜里发——时间即勇气 |
| 恋前慢/恋后快 | N1–N13 vs N14–N17 | 78% 篇幅铺垫，21% 释放：铺垫:释放≈4:1 |
| 昼夜切换 | N10→N11 | 24 小时内完成一次人设复原，证明二态并存 |

| 时刻 | 读者知道的 | 主角知道的 | 她知道的 | 信息差 |
|------|-----------|-----------|-----------|--------|
| 开头 | 她私下藏不住（N1 已告知） | 她难沟通、防备心重 | 自己喜欢他 | 读者>主角；她>主角 |
| 中段 | 她喜欢他 | 心里有数（N8 起） | 自己已经露馅 | 三方趋同，她仍不认 |
| 结尾 | 她从很早就喜欢 | 同 | 同 | 归因揭牌（名不正言不顺），三方对齐 |

| 意象/物件 | 出现位置 | 每次承载的含义 | 演变轨迹 |
|-----------|---------|---------------|---------|
| 吸管 | N8 / N12 | 为你插好（准备）→ 咬满牙印（焦虑） | 同一物件从「对你的心意」变成「等你的证据」 |
| 手机消息 | N3 / N4 / N6 / N10 / N16 | 两字回复 → 补发 → 借口+撤回 → 深夜追问 → 电影票截图命令句 | 从被动应答到主动安排：消息是她的勇气量表 |
| 手 | N8 抠包装袋 / N13 揪卫衣带 / N14 塞手 / N15 握更紧 | 紧张 → 答复 → 主动 → 加码 | 她的手比嘴早承认 |
| 耳朵/脸 | N9 耳根红透 | 身体出卖 | 单次 |
| 步态 | N9 顺拐 | 军训语境专属露馅 | 单次（48c 改拧瓶盖后丢失） |

**主题意象群**：吸管 / 手 / 消息三组都在做同一件事——「嘴不认、别的地方认」。

**手法总计**：8 项 | 核心手法 Top3：露馅升级链 / 细节记忆三层递进 / 「正在输入」可视化 | 创新手法：军训语境专属动作（顺拐）
