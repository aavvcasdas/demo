## Stage 2 结构 + 情节节点

### 故事核

- **设定**：一个入行 30 天、被系统罚到咽血的外卖骑手，发现「权力是抢来的」。
- **主题**：平台算法系统里没有合伙人，只有耗材——爬得越高，被回收时摔得越重。
- **核心行动**：用外挂、暴力、克扣和行贿从骑手爬到城市运营总监，在算法升级 + 副手背叛 + 舆论事件三重夹击下被系统当祭品抛出，背债坐回立交桥下，看着下一个新人注册上线。
- **一句话**：一个被平台罚哭的骑手，用七集把自己变成平台的绞肉机，第八集发现自己只是系统养肥的猪。

### 故事梗概

第一集：雨夜倒计时 12 秒，6 楼门开，顾客一点「订单已取消」，罚 50 元。你入行 30 天，膝盖针扎，认清自己是「最廉价的蓝色耗材」，咽下血腥味重新上线。第二集：你买了刷机手机装抢单外挂，占住 CBD 地下车库的高价单盲区，让同伴踹翻闯入的新手，说「滚出这条街」——「权力是抢来的」。存款破 5 万。第三集：升站长，三块屏幕 80 个蓝点，垃圾单派给不听话的新人，肥单给核心圈抽 20% 加密货币；一个月前骂你「底层垃圾」的餐厅老板来求单，你回一句「系统故障」——「这就是权力的味道」。第四集：500 骑手、32 站点、月净赚 40 万，空壳公司卖车、租电池、扣一半保险；13 个老骑手拉横幅，你在平板上勾选全网封禁；高管夸你是「最有效率的清道夫」。第五集：48 楼办公室，5000 骑手；总部 V4.0 算法砍掉你 3% 分成，副总裁「在国外开会」；副手老狗凌晨 3 点越权访问你的财务库——「棋盘在震动」。第六集：你把时效再压 15%、台风天不熔断，一天 6 起重伤，让老狗去医院塞钱私了；次日你的权限被降级，老狗说「系统升级可能有点 bug」。第七集：骑手被水泥搅拌车碾碎的视频引爆全网，股价跌 9%，「系统需要一个替罪羊」；你的指纹失效，老狗穿着你送的阿玛尼站在法务官和警察中间，交出你全部账本：「时代变了大哥，平台需要合规，你太脏了」；手铐落下——「你只是系统养肥的一头猪」。第八集：你被保释只为在破产清算书上签字，背 1500 万债坐在立交桥下，看电动车洪流像工蚁；不远处一个年轻人掏出 2000 块买下二手车、绑上保温箱、点击注册——「请开始您的接单之旅」。你闭上眼睛。

### B. 爆点分析

| 维度 | 分析 |
|------|------|
| 铺垫 | 前 386 字给出两件事：系统的绝对冷漠（12 秒 / 取消 / 罚 50）+ 「耗材」定义。之后每一集都埋一个回旋镖：「滚出这条街」（对新手）、「系统故障」（对餐厅老板）、「清道夫」（高管对你）、阿玛尼（你送老狗） |
| 积累 | 386–1543 字三集连升，每升一级越界一次（外挂 → 暴力 → 派单腐败 → 克扣保险 → 封禁抗议者 → 行贿高管）；读者的道德账本越积越厚，等待清算 |
| 延迟 | 第五集裂缝出现后没有立刻崩，第六集反而让主角加速作恶（6 起重伤），把清算再推后一集——延迟机制是「困兽反扑」 |
| 爆发点 | 78%：「老狗穿着你送他的那套阿玛尼西装 / 面无表情的看着你 / … / 时代变了大哥 / … / 平台需要合规 / 你太脏了」。爆发的不是被抓，是「你自己养的人用你自己的话（合规 / 脏）处决你」 |

**叠加爆点**：表层爆点是被捕（法律清算）→ 深层爆点是老狗的台词（道德清算由你教出来的人执行）→ 叠加效果：法律清算读者早预见，老狗的「你太脏了」把清算从「系统 vs 你」改写成「你 vs 你自己造出来的系统」。

**多爆点串联**：爆点①老狗越权（57%）| 爆点②权限降级 + 「系统升级有点 bug」（66%）| 爆点③阿玛尼 + 账本（78%）→ 递进，三次都是老狗，每次台词更长、姿态更高。

## Stage 4 反转 + 写作手法

### A. 反转分析

#### 前置反转检查

无。

#### 反转链（多反转结构）

| 序号 | 反转类型 | 触发事件 | 读者认知变化 | 与前层因果关系 |
|------|----------|----------|-------------|---------------|
| 1 | 身份反转（受害者 → 加害者） | N4 踹翻新手（17%） | 「他是耗材」→「他成了耗材的消耗者」 | — |
| 2 | 认知反转（合伙人 → 猎物） | N11–N12 V4.0 + 老狗越权（50–57%） | 「他掌控系统」→「系统在收网」 | 反转 1 的每一次越界都是反转 2 的证据链 |
| 3 | 信息反转（副手 → 内鬼） | N16 阿玛尼 + 账本（78%） | 「老狗在观望」→「老狗一直在记账」 | 反转 2 给了动机（合规），反转 3 给了执行者 |
| 4 | 结构反转（终点 → 起点） | N20 新人注册（95%） | 「这是一个人的故事」→「这是一个循环的故事」 | 前三层反转合起来证明「个人无法打破系统」，反转 4 用新人证明系统继续运转 |

反转链效果：递进 + 回环。因果链强度：**强**——删除反转 1，反转 2 没有清算对象；删除反转 3，反转 2 只是「运气差」；删除反转 4，故事变成个人悲剧而非系统寓言。

**伏笔式反转（回看含义改变的语句）**：
- N7「系统故障 / 我也没办法 / 你再等等吧」（32%）——初读是主角借系统之名施虐；N14 老狗「系统升级 / 可能有点 bug」（66%）用同一句式还给主角。
- N10「最有效率的清道夫」（45%）——初读是夸奖；知道结局后，清道夫是「用完即弃的清洁工具」，高管在夸他的同时已经给他定了性。
- N2「你是最廉价的蓝色耗材」（10%）——初读是控诉；N13「重症监护室里躺着你的耗材」（61%）主角自己用了这个词；N19「你甚至连耗材都不如」（93%）收束。

**主反转铺垫（供 structure_counts 计数）**：
1. 「清道夫」称谓（45%）
2. 老狗凌晨 3 点越权（57%）
3. 权限降级 + 「系统升级有点 bug」（66%）
4. 阿玛尼西装是「你送他的」（78%，反转发生时才揭示为铺垫，属于同句自证）
5. 副总裁「在国外开会」（50%）——平台先于老狗切割

误导方向：第四集用「不可或缺 / 无坚不摧」和高管拍肩把主角（和顺着第二人称走的读者）推向「他已经进入圈子」；第六集让主角握电击棍盯老狗，把读者的注意力引向「老狗要动手」，而实际老狗不动手、只交材料——暴力的想象被文件的现实替换。

**时机**：主反转 78% | 铺垫:释放 ≈ 8:1

**效果**：惊喜度 3（背叛可预见，「你太脏了」的执行方式有惊喜）| 合理性 4 | 情绪冲击 4

### B. 写作手法

详见 `写作手法.md`。核心手法 Top3：①定义句三段递进（耗材 → 猪 → 尘埃）；②台词回旋镖（滚出这条街 / 系统故障 / 清道夫 / 阿玛尼）；③每集一个身份名词做标题，用「命名」替代过渡。

| 前 100 字 | 读者知道核心矛盾：倒计时 vs 顾客一点取消——系统对个体的绝对不对称 |
| 信息密度 | 高——前 200 字有 7 个数字（23:58 / 6 楼 / 3 公斤 / 12 秒 / 50 元 / 30 天 / 120 公里） |
| 代入感 | 强——第二人称 + 身体细节（提手勒进冻僵的肉里） |
| 声音辨识度 | 强——冷硬短句 + 系统机械女声穿插 |
| 开头情绪强度 | 8/10（屈辱直接开场，是四篇里最强的开头） |

**投稿层观察**：
- 平台基调：小程序短剧 / 番茄短篇一路——开局即地狱、每集末卡断点（「重新上线」/「掌控这场游戏」/「比金钱更上瘾」/「无坚不摧」/「棋盘在震动」/「屠刀悬在头顶」/「养肥的一头猪」）。
- 导语写法：前 200 字是标准四维骨架——起因（超时）、核心冲突（系统 vs 人）、人设底色（30 天新人）、情绪反转（咽血重新上线）全部到位；黄金三角里「具体物件」是 3 公斤麻辣香锅，「信息差」是「你不敢敲门」，「留白钩子」是「重新上线」。
- 最强断点：第五集末「棋盘在震动」（57%）——付费点放这里，之后每集剧情密度递增（第六集 2 个事件、第七集 4 个事件）。

### C. 结尾分析

**最后一段**：「他拿出手机 / 点击了那个蓝色的APP图标 / 注册成功 / 请开始您的接单之旅 / 机械女声在冷风中响起 / 她不知道前方等待她的是什么 / 但她以为自己能掌控命运 / 你静静地看着她 / 闭上了眼睛」

| 维度 | 分析 |
|------|------|
| 结尾类型 | BE + 循环式留白 |
| 情绪落点 | 读者离开时在想：这个新人会走同一条路吗？我是不是也在某个系统里刚「注册成功」 |

## Stage 6 综合评估

**一句话评价**：这篇成立的机制是「把系统写成唯一的角色」——全篇没有一个具体的反派，罚款、派单、算法版本、权限、机械女声轮流出场，主角每一次以为自己在对抗系统时，其实都在替系统执行下一层剥削，直到系统用他教出来的人把他清掉。

### 五维评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 开头吸引力 | 5/5 | 200 字 7 个数字 + 一点取消 + 「不敢敲门」，屈辱强度 8/10 直接开场；系列四篇中最强 |
| 情感拉扯力 | 3/5 | 倒 V 单峰，翻转仅 2 次；读者的道德位从 17% 起与主角分离，中段的「+」是等待清算的蓄力而非共情。拉扯来自「看他掉下来」，不来自「为他揪心」 |
| 反转设计 | 4/5 | 四层反转链因果强；伏笔式回旋镖三处（系统故障 / 清道夫 / 耗材）回看全部成立；扣分在老狗背叛可预见性高（第五集就明示越权） |
| 节奏控制 | 4/5 | 8 集等长（300–450 字），每集固定「身份名词标题 → 一次质变 → 一句格言收束」，工业化稳定；第六集是唯一的纯蓄力集，功能明确 |
| 结尾余韵 | 4/5 | 循环结尾 + 机械女声首尾同源；扣分在第八集前半 240 字的独白（「系统没有情绪没有道德只有吞噬…」）把已经用画面证明的结论又说了一遍 |

### 爆点性

核心爆点是 78% 老狗的「时代变了大哥 / 平台需要合规 / 你太脏了」。铺垫充分（越权 → bug → 阿玛尼三级）。释放方式有辨识度：不是暴力清算而是文件清算，主角握着电击棍等来的是法务官。传播性高：三个定义句（耗材 / 猪 / 尘埃）+ 「权力是抢来的」+ 「棋盘在震动」都是可独立传播的短句。

### 话题性

- 「外卖平台算法」是现成的社会议题，源文把「超时罚款 / 恶劣天气不熔断 / 保险克扣 / 站点加盟制」全部写进去，评论区会有真骑手来对照。
- 「你会不会也这样」——第二人称把读者放进黑化路径，每一步的选择（装外挂 / 踹新手 / 派垃圾单）都有「换我也会」的辩护空间；争议点在「他到底是加害者还是受害者」。
- 「老狗对不对」——「平台需要合规，你太脏了」在道德上站得住，在情义上站不住，是评论区分裂点。

### 共鸣分析

| 共鸣层次 | 强度 | 触发点 |
|----------|------|--------|
| 情感共鸣 | 中 | 第一集楼道里不敢敲门；第八集回想那个哭泣的自己 |
| 价值观共鸣 | 强 | 「权力是抢来的」vs「系统没有合伙人」——两句话代表两种世界观，读者会站队 |
| 经历共鸣 | 强 | 超时罚款、倒计时、顾客一点取消、恶劣天气派单——外卖 / 网约车 / 快递从业者的日常 |
| 社会现象共鸣 | 强 | 平台经济、算法管理、加盟制层层转包、舆情驱动的「替罪羊式合规」 |
| 文化共鸣 | 弱 | 无明显文化专属元素 |
| 普世价值共鸣 | 中 | 「爬上去的人变成压迫者」是普世叙事；「系统会把你用完扔掉」适用于任何科层组织 |
| 哲学思考共鸣 | 中 | 「你变成了系统本身」——个体被结构同化的命题，源文用「齿轮 / 绞肉机」意象点到 |
| 情感深度共鸣 | 弱 | 主角没有亲密关系线，老狗的「挡过刀」只有一句回忆 |
| 人物深度共鸣 | 中 | 主角的每一步都有明确动机（房租 / 被骂 / 分成被砍），黑化不突兀；但内心从第二集起就不再有挣扎 |

### 核心手法

反转类型{认知反转（合伙人→猎物），含四层反转链} | 情感曲线形态{倒 V} | 关键钩子{耗材定义（10%）/ 系统故障（32%）/ 清道夫（45%）/ 老狗越权（57%）} | 核心手法 Top3{定义句三段递进 / 台词回旋镖 / 身份名词做集标题}

### 可复用结构

1. **「八集升级—崩塌」模板**：1 集最低点 + 定义句 → 3 集三级跳（每集一次权力质变 + 一次道德越界 + 一句格言）→ 2 集裂缝（外部规则变化 + 内部背叛铺垫，主角加速作恶）→ 1 集清算（外部事件引爆 + 背叛揭晓 + 定义句二）→ 1 集尘埃（空间反转 + 独白 + 循环镜像）。— 适用场景：任何「系统内爬升」题材（平台 / 职场 / 灰产 / 官场），本系列 03 雇佣兵、04 彩票同模板。
2. **台词回旋镖**：让主角在掌权期对下位者说一句话（「系统故障我也没办法」），崩塌期由下位者 / 继任者用同一句式还回来（「系统升级可能有点 bug」）。中间不加任何提示。— 适用场景：黑化 / 报应型短篇；每篇 1–2 处即可。
3. **定义句三段递进**：用同一个贬义名词在 10% / 60% / 90% 三处定义主角——第一次是系统给的（耗材），第二次是主角给别人的（你的耗材），第三次是主角给自己的（连耗材都不如）。— 适用场景：身份异化题材。
4. **系统即角色**：不设具体反派，用「机械女声 / 算法版本号 / 权限变更 / 数据大屏」四类非人元素代替反派出场，反派的每一次「行动」都是一条系统提示。— 适用场景：反乌托邦、平台经济、赛博题材。
5. **数字校准替代过渡**：每集开头 50 字内给出一个新的量级（5 万 / 80 个 / 500 个 32 站 40 万 / 5000 个 48 楼 / 1500 万），用数字的指数增长直接表达时间流逝与权力膨胀。— 适用场景：需要在 3000 字内跨越数年的升级流。

### 同类型写作动作

写同模板短篇时可直接执行：
1. 先写第八集的最后一个画面（新人注册），再倒推第一集的最低点，让两者共用同一个物件（保温箱）、同一个数字（2000）、同一个声音（机械女声）。
2. 给每一集起一个身份名词标题（恶犬 / 调度者 / 主宰…），写完检查名词是否单调递增到顶再单调递减。
3. 在第三集让主角对某人说一句「借系统之名」的台词，在第六集让另一个人用同一句式对主角说。
4. 第四集必须埋一个「夸奖即判决」的称谓（清道夫 / 齿轮 / 白手套）。
5. 第八集独白控制在 100 字内，把结论交给画面。

### 节奏速报

| 指标 | 数值 | 判断 |
|------|------|------|
| 事件密度 | 20 节点 / 3313 字 ≈ 6.0 个/千字 | 高且均匀；每集 2–3 个节点，无空集 |
| 对话密度 | 约 7%（直接引语约 230 字） | 极低；台词只有 8 句，每句都是回旋镖或定义句（滚出这条街 / 系统故障 / 哥单子派不出去 / 清道夫 / 系统升级 bug / 时代变了 / 罪名 / 注册成功）。其余全部为第二人称陈述 |
