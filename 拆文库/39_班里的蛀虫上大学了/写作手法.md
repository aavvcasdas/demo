# 《班里的蛀虫上大学了》写作手法清单

> 12 项可复用手法，按可偷度排序。每项含：手法名 / 源文依据 / 拆解 / 复用配方。本篇为迷因荒诞志（校园编年×迷因因果），手法清单兼两种身份：作为荒诞喜剧的技术 + 作为系列增量（元叙事层与 UGC 尾）的可迁移部分。

## 1. 漏洞开局法——自由的规则缝隙

**源文**：「宿舍规定只禁止养猫狗 / 没说不让养猪」@4%。

**拆解**：欲望的第一道门从来都是规则自己留的——**列举式禁令的天然漏洞：没列的都合法**。全篇由此启动，且在 N21 完成终章对位（用艺术展的名义申请场地）：蛀虫的一生都在读规则的言外之空。

**复用配方**：开场 5% 内给出一个「规则没说」的空白（只禁猫狗/只查考勤/只统计获奖），让主角顺着空白完成第一次越界——**越界的理由必须合规，喜剧才成立**。

## 2. 藏匿道具二段式——同一道具的成功与失效

**源文**：第一次「塞进宽大的外套里」@9%…「这种体型再来几次也藏得住」@13%；第二次「拉链只拉到一半 / 猪的后背还露在外面」@16%。

**拆解**：道具复用即道具贬值——**藏匿方案没有跟上增长曲线**。胜利宣言（再来几次也藏得住）与失效（后背还露在外面）之间只隔一个季节：**所有基于现状的乐观都是没算增长率的乐观**。

**复用配方**：给危机一个物理解法（外套/柜子/书包），让它成功一次并配胜利宣言；中段让同一道具再次出场并精确失效（差一点是最绝望的刻度）——失效的度量越精确，笑声越干。

## 3. 尺寸判词链——增长的度量衡

**源文**：「只有两只手那么大」→「猪还只有书包那么大」→「拉链只拉到一半」→「原来的围栏已经关不住它」。

**拆解**：体积不可直接写，全部换算成日常参照物（两只手/书包/外套拉链/围栏）——**增长的进度条是道具的耐受力**。「书包那么大」与「两只手那么大」之间只隔一次查寝：编年的最省力刻度。

**复用配方**：任何「变大/变多/变糟」的过程，禁用形容词，只用三到四个参照物递进；参照物必须来自主角自己的生活半径（宿舍器物优先）。

## 4. 父亲判词学——离别用黑色幽默过账

**源文**：「先养着不能吃 / 你爸摆了摆手 / 过年你有口福了」@24%。

**拆解**：同一头猪的两种命名：宠物与年货——**代际的情感全部走物流通道**。一个摆手完成一次告别：没有拥抱没有不舍，台词两句半，惜别的重量全部压在「有口福」三个字的错位上。

**复用配方**：离别拍的台词预算≤2 句；让长辈用最务实的语言处理最感伤的场景（吃/用/卖/修）；晚辈的嘱咐与长辈的回应必须错位到毫不相干——**错位即情感，相通即煽情**。

## 5. 反思的自我开脱式收束——想来想去还是没钱

**源文**：「为什么连自己养的猪都守不住」…「给他搭个最大的猪圈 / 想来想去 / 还是没钱」@25-27%。

**拆解**：把情感问题翻译成预算问题，是蛀虫的思维母语——**反思的全部内容是一次价目查询**。「想来想去」的思考量与「还是没钱」的结论量悬殊，输入与输出的落差即笑点；同时它又是引擎：下半场搞钱由此启动。**一个判词同时完成收束与转场**。

**复用配方**：在每个段落转折处安放一次「自我开脱式反思」：三行铺垫（如果不这样/如果有钱/如果有时间）+ 三个字的结论（没钱/算了/再睡）——结论必须比铺垫短一个数量级。

## 6. 身份代行套娃——代理职责的现场扩编

**源文**：「替老师点完了一节课的名」→「你又找对方要了5块钱 / 从那以后 / 班长团支书学委一律加钱」→「你夹着嗓子答了一声」→「你给下周的张甜甜留了3个」。

**拆解**：代课→意外代班长点名→代女生答到→代女生欠下表演债：**代理的职责范围被一次次现场扩编**。三重喜剧机关：①主角永远是最后一个知道自己是班长的人（周围的人开始回头看你）；②危机的物证化（笔尖停了下来——老师的笔比目光先起疑）；③债务式承诺（躲 1 个欠 3 个：拖延的利息率 200%，且债务被正式入账——老师低头记了一笔）。

**复用配方**：让主角接一单小代理，然后被环境连续加码（职务/性别/日程）；每次加码配一个「制度的宽容」（没有继续追问）——**宽容是套娃的润滑剂**；以「欠下 N 倍债务」收束该段。

## 7. 命名公式元笑话——文本自嘲自己的赛道

**源文**：「不少比赛名字非常正式 / 实际却非常水 / 国际青年当代艺术大奖赛 / 几个词换着顺序排列 / 就能组成一场全新的比赛」@52-56%。

**拆解**：把「水赛产业」的生成语法写成一行代码——**元叙事层是本篇对系列的最大增量**：文本公开承认 国际+青年+当代+艺术+大奖赛 这类命名可以排列组合地批量生产，然后下一节整段由该公式生成（构石国际当代艺术大奖赛）。**自嘲先于抄袭：把套路说破，再用套路，套路就成了引用**。

**复用配方**：在需要生成「假机构」前，先用三行写出该机构的命名公式（几个词+排列组合），让观众看见生成器——**观众看见生成器之后，生成器的每一次输出都是笑点**。

## 8. 假机构道具学——官僚制的全套仿真

**源文**：「首届构石国际当代艺术大奖赛 / 海报报名表组委会奖项设置全给补齐 / 参赛对象上写着面向全球 / 年龄地区专业及物种不限 / 你们又用AI生成了一排国际评委」@58-61%。

**拆解**：权威的样子比权威本身更容易生产——道具四件套（海报/报名表/组委会/奖项）+ 章程狂欢条款（物种不限：**埋得最深的钩子，28% 之后由一条狗字面兑现**）+ AI 评委（静态造假）与摄像头全关（动态造假）的两级结构。

**复用配方**：造一个假机构需要：名字（套公式）、四件道具、一条过度宽容的章程条款（该条款即最终反转的伏笔）、一组不存在的评委；**章程里那句最离谱的话，就是结尾要兑现的那句话**。

## 9. 现实入侵法——足够认真的假会召唤真的

**源文**：「多出了一份陌生投稿」…「作品名叫价值重估 / 创作说明从消费主义 / 一路写到公共空间」→「实物作品寄到哪里 / 你们赶紧回复 / 本赛事仅接受影像资料 / 请勿邮寄作品原件」@68-73%。

**拆解**：假赛事吸引真投稿，且**陌生投稿者比创办者更懂这个笑话的哲学**（把构石贴上金箔，正是「价值重估」的字面执行）。现实入侵的标志是产生物流需求（实物寄到哪里）；假机构第一次行使真权力是拒绝现实（请勿邮寄原件）。

**复用配方**：假机构成立后，立刻安排一个比主角更认真的外人（真投稿/真咨询/真赞助）；外人必须无意间把笑话执行得更彻底——**让配角比主角更懂主角的玩笑**。

## 10. 动物作者反转——去中心化的作者论

**源文**：「作者还在外面」…「他牵着一条狗重新走了进来」…「作品是他完成的 / 我只负责投稿」@86-88%。

**拆解**：全篇喜剧峰——投稿者是代理人，创作者是狗。与《离校前夜》（作者是猪）构成镜像：**你的猪没进前三，别人的狗拿了一等奖——动物艺术也有水平高低**。揭晓用三拍（作者还在外面→转身出去→牵狗进来），悬念的物理移动，荒诞用最平的步速走完。

**复用配方**：把某个成果的真正源头交还给一个非人角色（宠物/软件/意外），揭晓前用「作者还在外面」式的空场拖延一拍；**代理人说出的解释必须一句说完、不加辩解**。

## 11. 葬礼符号与朝圣——低俗的纪念碑化

**源文**：「另一个舍友从门外抬进来一个花圈 / 上面写着永远的够石」@92%；「还有人牵着狗过来朝圣」@99%。

**拆解**：庆祝的场合借用哀悼的道具，「永远」与谐音低俗词并置——低俗词获得纪念碑的语法。谐音在挽联里完成最后一次变奏（构→够）。后续的「纪念遗址/朝圣」把一场闹戏送进宗教语汇：**命名即历史，围观即封圣**。

**复用配方**：给荒诞事件一个实体纪念碑（花圈/铜牌/横幅），再让不知情的路人用严肃语汇解读它（遗址/朝圣/历史）——**仪式道具与俚俗内容的错位层级越多，余韵越长**。

## 12. 遗产永生尾——笑话脱离作者自治

**源文**：「纪念牌没有立刻拆掉」…「纪念牌附近陆续出现 / 了没有报名的新作品」@96-100%。

**拆解**：临时性设施的不拆除即转正——**故事结束后，生产仍在继续**。39 篇合集里，叙事在结尾处仍然生长的只有本篇（与 12 的世界设定同级的开放收束）：机构的生命力不依赖创办者意图而延续，「陆续出现」是全篇最后一个动词短语，也是唯一没有完成时的动作。

**复用配方**：结尾不收干净——留一件该拆没拆的实物（牌/摊/群），再让陌生人继续使用它；最后一行必须是进行时态的新增（没有报名的/没有署名的/没有人知道的），**让文本的结束成为文本内生态的开始**。

## 指纹速查

- **数字判词**：300多块 / 第5口人 / 25块 / 5块钱 / 3个 / 快两个小时
- **器物判词**：旧衣服+食盆+围栏（家）/ 外套（藏匿）/ 名单（权力）/ 金箔+黑丝绒（艺术）/ 红布（仪式）/ 花圈（哀悼）/ 纪念牌（遗产）
- **谐音避审**：构石（正文）/ 够石（挽联）——同一谐音的两代变体
- **零道德审判**：全篇无一句教训、无一次真悲伤；连「正宗大肥猪」的判决都来自评论区
- **台词密度约 12%**：台词只留给判词句（不舒服穿这么多/过年你有口福了/你叫张甜甜吗/我只负责投稿）
