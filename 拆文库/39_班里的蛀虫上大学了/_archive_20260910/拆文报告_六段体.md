# 《班里的蛀虫上大学了》拆文报告

## Stage 1：类型识别与基础设施

- **源头**：用户提供（对话粘贴，文件名 9月4日.txt），2137 字，ASR 字幕稿——非合集《8月16日》内容，作者 9 月新篇
- **类型判定**：迷因荒诞志（校园编年×迷因因果）
- **主类型论证**：全篇因果链由三个「最短路径决策」驱动：漏洞养猪（规定没说不让）→灰色代课（老师认不全人）→自办水赛（命名公式）。每一环都是懒人解决问题时顺手推开的最省事的门，而每扇门后都是更大的房间。**荒诞的推进器是懒惰而零巧合——这是它与 29/30/31 迷因家族的分界：前者的引擎是情绪（愤怒/品味/资产），本篇的引擎是路径依赖。** 迷因因果在 N17 之后接管叙事：假机构（构石大奖赛）一旦成立，就按真机构的逻辑运行——吸引真投稿（价值重估）、真赞助（活动公司）、真场地（学校批的）、真遗址（纪念牌+朝圣）——**假的只有发起者，其余全真**。
- **视角**：第二人称口播（副本框架句开场：今天体验的人生副本是）——「你」在此是蛀虫的代行位：观众被安放在一个从不生产、只做套利的位置上，且全程不被审判。
- **核心设定**：蛀虫——不生产只收租的制度寄生者。标题的判词功能：全篇没有一处解释「蛀虫」，行为已经完成定义。
- **时间跨度**：一个学期（刚开学没多久→入秋→学期后半段→活动结束以后），编年推进的颗粒度=章节。
- **有名人物：1**——张甜甜，且属于一个从未出场的人（被代行的名字）：**全篇唯一的人名是个空位**。其余角色全部功能性命名（舍友/宿管/学生会/辅导员/你爸/外校学生）。

## Stage 2：结构与节奏

**段界与占比**：0–168（8%）/ 168–413（19%）/ 413–598（28%）/ 598–1052（49%）/ 1052–1737（81%）/ 1737–2137（100%）——种猪入舍 → 查寝攻防 → 猪去圈空 → 代课经济学 → 构石大奖赛 → 狗与遗产

- **密度**：2137 字 25 节点≈11.7/千字，系列第二高（仅次于 34 的 16/千字）——**一笑点一节点，气口即节拍**。黄金区间（2400–3600）之下 263 字，荒诞系允许的短体量：笑点密度补偿了字数。

## Stage 3：叙事视角与人物

**视角**：第二人称。三个功能——①蛀虫的代入位（观众全程坐在违规者的座位上且不被审判）；②白描的取景框（只拍动作与器物，不进内心——全篇唯一一次内省是 N11 的三行价目查询式反思）；③口播的节奏载体（行=气口）。

**人物（有名 1，功能性五组）**：

1. **你（蛀虫）**——**系统的套利者**：与 02 外卖员构成一枚硬币的两面——02 是系统把人变成耗材（顺从的极致），本篇是人把系统变成饲料（钻营的极致）。他的三项技能：读规则的空白（只禁猫狗）、借别人的身份（班长/张甜甜）、给废物起名（离校前夜/优秀构石奖）。**他从头到尾没有生产过任何东西——除了那个机构，而机构最终也不属于他**。
2. **共谋宿舍（群像）**——藏猪的、扮评委的、抬花圈的：**集体创作的一人分工制**。舍友没有名字但有职责表——荒诞喜剧的群像纪律：不需要人物弧，需要功能位。
3. **父亲（判词机器）**——台词一句（过年你有口福了），动作一个（摆了摆手）：**全篇最经济的角色**。
4. **张甜甜（空位人名）**——被代行的名字：性别错位喜剧的全部道具。她越不存在，「下周的张甜甜」越成立。
5. **狗（去中心化作者）**——全篇真正的高光角色：绕着奖杯闻一圈、在红布旁即兴创作——**它做的每件事都是狗的正常行为，也同时是先锋艺术的全部姿态**。

## Stage 4：语言与指纹

- **ASR 格律**：无标点、行=气口；「了」跨行（出现/了没有报名）为转写原貌，保留。
- **谐音避审双变体**：构石（正文）/够石（挽联）——同一避审词的两代写法并存，是 ASR 稿的时间戳证据。
- **数字判词链**：300多块（欲望定价）→第5口人（家庭成员）→25块（时间定价）→5块钱（职务溢价）→3个（债务利息）→快两个小时（现编的时长即敬业度）。
- **器物判词谱系**：家（旧衣服+食盆+围栏）→藏匿（外套）→权力（名单）→艺术（金箔+黑丝绒）→仪式（红布）→哀悼（花圈）→遗产（纪念牌）——**七个器物即七个机构阶段**。
- **台词纪律**：密度约 12%，台词只留给判词句；「作品是他完成的 / 我只负责投稿」是全篇唯一被完整引用两遍结构（对白+舞台说明）的时刻。
- **零道德审判**：无一句教训、无一次真悲伤——连暴露谷（学生会抬头看向你们）都不配后果描写，处置直接跳到「当天晚上辅导员把电话打到了家里」的行政时态。

## Stage 5：可复用方法论（校园荒诞七步流水线）

1. **漏洞开局**（5%：规则没说的空白）
2. **据点建立**（器物清单四件套）

6. **假机构全套**（命名公式→四件道具→章程狂欢条款→AI 评委→现实入侵→意外落榜）
7. **动物作者+永生尾**（成果归非人角色+该拆不拆的遗产+进行时态新增）

**文体税**：①审核风险（谐音词/假赛事/动物领奖——需避审变体与免责模糊语）；②笑点密度要求（≥10 节点/千字，气口即节拍）；③情感拉扯先天弱（无真正的失去，五维拉扯封顶 3）；④真感锚点必备（小香猪骗局/水赛产业/AI 评委/综测——荒诞的每个环节都要有现实原型，否则滑向胡闹）。

**现实锚清单**：迷你猪骗局（买家猪当迷你猪卖，长成大肥猪）／代课灰色市场（百人大课的信任漏洞）／综测加分产业（水赛产业链）／AI 生成评委（技术造假的最低门槛）／线下展赞助（流量收编）。
